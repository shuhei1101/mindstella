components / voice-input

音声の入力

コメントの入力と返信の入力に置く、マイクのボタンと録音中・文字起こし中の並び（PR #476）。

コメントの入力

通常（マイクのボタンを置く）

「レビューに追加」の左に、マイクのアイコンだけのボタンを置く。読み上げの名前とツールチップは「音声で入力」。押すと録音を始める。

マイクのボタンのホバーとフォーカス

ホバーで面だけを変え、キーボードのフォーカスは印の色の輪。ツールチップはホバーとフォーカスで出す。

録音中（案 A: 結果の行に経過の時間を出す）

マイクと「レビューに追加」の位置を、文字の「キャンセル」と主な操作の「文字起こし」に切り替える。入力欄の下の結果の行に「録音中 0:12」を出し、支援技術には録音を始めたこと・終えたことだけを知らせる（経過の時間は読み上げない）。入力欄は打てるまま残す。

録音中 0:12

録音中（案 B: ボタンの左に経過の時間を出す）

経過の時間を 2 つのボタンの左に並べ、結果の行を使わない。入力欄の幅は案 A より狭くなる。

録音中 0:12

録音中（入力欄に打ちかけがある）

打ちかけの「確認: 」とカーソルの位置を残したまま録音する。文字起こしの結果はカーソルの位置へ挿入する。

録音中 0:12

文字起こし中

「文字起こし」を押した後、結果が返るまで 2 つのボタンを押せなくし、「文字起こし中」の回る印を出す。1 秒未満で返ったときは出さない。入力欄は読み取りだけにする。

文字起こししています。

送信した（文字起こし後の挙動が「送信する」）

結果を挿入した全文を、溜めずにその 1 件だけ送信する。入力欄を空にして元のボタンに戻し、結果の行に送信したことと Claude Code へ入力したかを出す。

送信し、Claude Code へ入力しました。

送信した（Claude Code へ入力しなかった）

tmux の外で開いたときなど、スレッドにはしたが Claude Code へ入力しなかった場合。

送信しました。Claude Code へは入力していません。

挿入した（文字起こし後の挙動が「入力欄へ挿入する」）

結果をカーソルの位置へ挿入し、送信しない。カーソルは挿入した文字の後ろ。

文字起こしの結果を挿入しました。

押せない（voice-paste が起動していない）

マイクのボタンを押せない見た目にし、フォーカスは受けたまま、ホバーとフォーカスで理由のツールチップを出す。押したときも結果の行に同じ理由を出す。「レビューに追加」は押せるまま。

voice-paste が起動していないため、音声で入力できません。

押せない（voice-paste がブラウザの機能を組み込んでいない）

voice-paste に届くが `/web/` の下が 404 のとき。

voice-paste がブラウザの機能を組み込まずに起動しているため、音声で入力できません。

押せない（このページでマイクを使用できない）

HTTPS でない経路から外の端末で開いたときなど、ブラウザがマイクを使えないとき。

このページではマイクを使用できません。HTTPS か localhost の URL で開いてください。

押せないマイクのボタンを押した

ツールチップを見ずに押したときも、結果の行に理由を出す。

voice-paste が起動していないため、音声で入力できません。

マイクの許可を拒否した

録音を始めず、元のボタンのまま、結果の行に許可が要ることを出す。

マイクを使用できませんでした。ブラウザの設定でこのページのマイクを許可してください。

文字起こしに失敗した

元のボタンに戻し、入力欄の打ちかけは残す。

文字起こしできませんでした。もう一度お試しください。

文字起こしの結果を送信できなかった

文字起こしはできたが送信でサーバーにつながらなかったとき。結果を挿入した全文を入力欄に残し、「レビューに追加」かマイクのボタンで続けられるようにする。

送信できませんでした。文字起こしの結果は入力欄に残しています。

狭い幅の録音中（390px）

2 つの文字のボタンを入力欄の右に並べる。

録音中 0:12

入力の幅が 360px 以下では、2 つのボタンを入力欄の下の行へ移して右端に置き、入力欄の幅を保つ。

録音中 0:12

コメントの入力と同じ理由のツールチップ。
