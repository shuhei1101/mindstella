資料のエクスポートのメニュー

詳細パネルと詳細の全画面の見出しに置くエクスポートの入口と、形式を選ぶメニュー、Markdown を選んだときの警告。警告の置き方は案 A（メニューの中）と案 B（確認のモーダル）を並べる。

入口（本文が Markdown の資料）

見出しの「編集する」と ← の間に置く、枠の無いアイコンボタン。読み上げは「エクスポート、ボタン、折りたたみ」。

入口を置かない（本文が HTML の資料）

入口のホバー・フォーカス

ホバーは面の色だけを変え、フォーカスは印の色の輪を付ける。

形式を選ぶ（メニューを開いている）

入口を押した面にし、入口の下に右端を揃えて開く。行の全体が押せ、名前と説明を 2 行で出す。Esc と外を押すと閉じ、入口へフォーカスを戻す。

形式の行のホバー・フォーカス

ホバーは行の面の色、フォーカスは印の色の輪を内側に付ける。

エクスポート

案 A: メニューの中で警告

「Markdown でエクスポート」を押すと、メニューの中身を警告と「戻る」「エクスポート」に替える。開いた時点のフォーカスは「エクスポート」。「戻る」で形式を選ぶ中身に戻し、「Markdown でエクスポート」にフォーカスを戻す。

Markdown でエクスポートしますか?

埋め込んだ HTML・チャート・操作できる部品は含まれず、共通のスタイルも外れます。

案 B: 確認のモーダル

「Markdown でエクスポート」を押すとメニューを閉じ、画面の中央に確認のモーダルを開く。開いた時点のフォーカスは「キャンセル」。閉じると入口へフォーカスを戻す。詳細の全画面から開くと、モーダルの上にモーダルを重ねる。

Markdown でエクスポートしますか?

埋め込んだ HTML・チャート・操作できる部品は含まれず、共通のスタイルも外れます。
