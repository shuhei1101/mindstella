回答・意見の送信

詳細パネルと詳細の全画面の下端に置く、項目の ID ごとに回答・意見を送る入力と、サーバーにつながらないときのトップバーの表示。

通常（入力が空）

詳細パネルの下端に、本文と線で区切って置く。ラベルは常に見せ、どの項目へ送るかを ID で示す。入力欄は 2 行から始まる。

入力中（フォーカス）

入力欄に印の色の輪。中身に合わせて 8 行まで伸びる。Ctrl+Enter でも送れる。

送るボタンのホバー・フォーカス

ホバーは面の色、フォーカスは印の色の輪。

送っている（読み込み中）

二重に送らないよう送るボタンを押せなくし、入力欄を書き換えられなくする。1 秒を超えたら回る印と「送っています」を出す。

送っています

送った

入力欄を空にし、送った時刻と、次の話し合いで取り込むことを出す。次に入力を始めたら消す。

送りました（10/04 11:23）。次の話し合いの最初に取り込みます。

本文が空（入力エラー）

送らずに、入力欄の枠と文言で本文が要ることを示し、入力欄へフォーカスを戻す。入力を始めたら消す。送るボタンは押せないようにしない。

回答・意見を入れてから送ってください。

送れなかった（エラー）

サーバーが止まっているとき。立ち上げ直すと URL が変わり、開き直した画面には入力途中の本文が引き継がれないので、本文を写すボタンを添える。入力した本文を残し、次に送るまで文言を消さない。

送れませんでした。サーバーが止まっています。起動スクリプトで立ち上げ直し、示された新しい URL で開いてから送ってください。

長文

8 行を超えたら入力欄の中を送る。

狭い幅（390px）

詳細パネルが画面幅いっぱいになる幅。左右の余白を 16px にする。

送れませんでした。サーバーが止まっています。起動スクリプトで立ち上げ直し、示された新しい URL で開いてから送ってください。

最も狭い幅（320px）

結果の文言は折り返し、送るボタンの幅は保つ。

送りました（10/04 11:23）。次の話し合いの最初に取り込みます。

配る書き出し

サーバーなしで開く 1 枚の HTML では、記録を書き換える操作を持たないので送信の入力を出さない（詳細パネルは本文で終わる）。

（送信の入力は出さない）

接続の状態（サーバーにつながらない）

トップバーの検索の入口の左に出す。押せない表示。最後に読めた記録で描き続けていることと、その時刻を添える。
