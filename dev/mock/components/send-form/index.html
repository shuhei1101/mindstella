コメントの入力

詳細パネル・詳細の全画面の下端と、コメントの一覧の新しいスレッドの入力に置く、コメントをレビュー中に溜める入力。「レビューに追加」は入力欄の右のアイコンだけのボタンにし、結果は入力欄の下に出す（PR #473）。

通常（入力が空）

入力欄の右に、吹き出しのアイコンだけの「レビューに追加」を置く。読み上げの名前は「レビューに追加」、ツールチップは「レビューに追加（Ctrl+Enter）」。結果が無い間は入力欄の下に行を取らない。

入力中（フォーカス）

入力欄に印の色の輪。Ctrl+Enter（macOS は Cmd+Enter）でも溜められる。

溜めるボタンのホバー

塗りのまま少し薄くし、ツールチップを出す。

溜めるボタンのフォーカス

Tab で入力欄の次に届き、印の色の輪を出す。ツールチップはフォーカスでも出す。

箇所を添えた（本文）

入力欄の上に箇所の名前と選んだ文を出し、× で外す。ボタンの並びは変わらない。

本文 3 行目
受け取る人へ渡す形

箇所を添えた（値・長い選んだ文）

選んだ文は 3 行までにして末尾を省く。

案 C のデメリット
表の密度が下がる。表の列を詰めて並べるため、1 行に出せる項目の数が減り、ID と状態の列が画面の外へ押し出される。狭い幅では横に送らないと読めない列が増え、比べるのに手間がかかる

溜めている

入力欄を書き換えられなくし、ボタンを押せなくする（面を沈める）。1 秒を超えたら回る印と「レビューに追加しています」を入力欄の下に出す。

レビューに追加しています

溜めた

入力欄を空にし、入力欄の下に溜めたことと件数を出す。入力を始めたら消す。

レビューに追加しました（レビュー中 3 件）。

本文が空

入力欄の枠を要見直しの赤にし、入力欄の下に本文が要ることを出す。ボタンは押せるまま。

コメントを入れてから追加してください。

溜められなかった（サーバーにつながらない）

本文を残し、入力欄の下に理由とコピーのアイコンだけのボタン（読み上げの名前とツールチップは「本文をコピー」）を出す。

レビューに追加できませんでした。サーバーが止まっています。起動スクリプトで立ち上げ直し、示された新しい URL で開いてから追加してください。

溜められなかった（サーバーが理由を返した）

本文を残し、入力欄の下に理由を出す（コピーのボタンは出さない）。

本文 3 行目
受け取る人へ渡す形

レビューに追加できませんでした。選んだ文が本文の 3 行目にありません

長文（ボタンの縦の位置: 案 A・推奨）

入力欄は 8 行まで伸び、それより長いと中を送る。ボタンは入力欄の下端に合わせ、書き終えた位置の近くで押せる。

長文（ボタンの縦の位置: 案 B）

ボタンを入力欄の上端に合わせた案。行数が増えてもボタンの位置は動かない。

アイコンの案 B（送信のアイコン）

まとめて送るボタンと同じ紙飛行機のアイコンにした案。押すと溜まる操作だと読み取りやすいが、まとめて送る操作と取り違えやすい。

閉じた

右上の ^ で開く。閉じている間は「{ID} へのコメント」の 1 行だけを出し、入力欄・添えた箇所・結果・「レビューに追加」を出さない。

D-022 へのコメント

閉じた（書きかけあり）

書きかけは閉じても残る。書きかけがあるときだけ、「{ID} へのコメント」の右に鉛筆の印と「書きかけ」を出す。

D-022 へのコメント書きかけ

開閉のボタンのホバー・フォーカス

開いている間は v（コメントの入力を閉じる）、閉じている間は ^（コメントの入力を開く）。ツールチップはホバーとフォーカスで出す。

D-022 へのコメント

項目を指さないコメント（コメントの一覧の新しいスレッドの入力）

見出しを出さず、入力欄と右のボタンだけにした同じ部品。名前「項目を指さないコメント」は読み上げにだけ持つ。

項目を指さないコメント（畳んだ形）

読み上げのラベルと 1 行の入力欄だけを出す。ボタンと結果は出さない（今のまま）。

狭い幅（390px）

部品の幅によらず入力欄とボタンを 1 行に並べ、結果は入力欄の下に幅いっぱいで出す。

入力欄はボタンの幅を除いた残りに広がり、結果の文言は折り返す。

閉じても開閉のボタンの幅は保つ。書きかけの印があるときも 1 行に収める。

音声: 通常（マイクのボタンを置く）

「レビューに追加」の左に、マイクのアイコンだけのボタンを置く。読み上げの名前とツールチップは「音声で入力」。押すと録音を始める。

音声: マイクのボタンのホバーとフォーカス

ホバーで面だけを変え、キーボードのフォーカスは印の色の輪。ツールチップはホバーとフォーカスで出す。

音声: 録音中

マイクと「レビューに追加」の位置を、アイコンだけの × の「キャンセル」と、塗りの ✓ の「文字起こし」に切り替える（文字は出さず、名前は読み上げとツールチップに持つ）。入力欄の下の結果の行に、失敗の色の丸と経過の時間だけを出す。支援技術には録音を始めたこと・終えたことだけを知らせる（経過の時間は読み上げない）。入力欄は打てるまま残す。

録音中0:12

音声: 録音中（入力欄に打ちかけがある）

打ちかけの「確認: 」とカーソルの位置を残したまま録音する。文字起こしの結果はカーソルの位置へ挿入する。

録音中0:12

音声: 文字起こし中

✓ を押した後、結果が返るまで 2 つのボタンを押せなくし、✓ の位置と結果の行に回る印だけを出す（文字は出さない）。1 秒未満で返ったときは出さない。入力欄は読み取りだけにする。

文字起こししています。

音声: 送信した（文字起こし後の挙動が「送信する」）

結果を挿入した全文を、溜めずにその 1 件だけ送信する。入力欄を空にして元のボタンに戻し、結果の行に送信したことと Claude Code へ入力したかを出す。

送信し、Claude Code へ入力しました。

結果をカーソルの位置へ挿入し、送信しない。カーソルは挿入した文字の後ろ。

文字起こしの結果を挿入しました。
