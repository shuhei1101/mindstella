コメントの入力

詳細パネルと詳細の全画面の下端に置く、開いている項目へのコメントをレビュー中に溜める入力。選んだ箇所を添えられる。配る書き出しでは出さない。

通常（入力が空）

詳細パネルと詳細の全画面の下端に、本文と線で区切って置く。ラベルは常に見せ、どの項目へのコメントかを ID で示す。書いたコメントは送らずにレビュー中に溜める。

入力中（フォーカス）

入力欄に印の色の輪。書きかけはサーバーに保ち、パネルを閉じても・立ち上げ直しても戻る。Ctrl+Enter でも溜められる。

溜めるボタンのフォーカス

印の色の輪。

箇所を添えた（入口を押した後の入力の置き場所の案 A・推奨）

選んだ箇所の入口を押すと、入力欄の上に箇所の名前と選んだ文を添える。× で外すと、項目へのコメントに戻る。

本文 3 行目受け取る人へ渡す形

箇所を添えた（値・長い選んだ文）

選んだ文は 3 行までにして末尾を省く。値のときは箇所の名前にキーの名前を出す。

案 C のデメリット表の密度が下がる。表の列を詰めて並べるため、1 行に出せる項目の数が減り、ID と状態の列が画面の外へ押し出される。狭い幅では横に送らないと読めない列が増え、比べるのに手間がかかる

溜めている

入力欄を書き換えられなくし、ボタンを押せなくする。回る印で処理中を示す。

溜めた

入力欄を空にし、溜めたことと件数を入力の近くに出す。入力を始めたら消す。

本文が空

溜めずに、本文が要ることを出す。入力欄の枠の全体を状態の色にする。

コメントを入れてから追加してください。

溜められなかった（サーバーにつながらない）

入力した本文を消さずに残し、次に溜めるまで理由を出す。開き直すと書きかけが戻らないため、本文を写すボタンを添える。
