表の列を選ぶボタン

表に出す列を選ぶポップオーバーを開くボタン。今の「表示する列」を、列のアイコンと短い名詞の文言にし、表の上端に付けずに置く。置き場所は案 A（表の上の帯の右端・推奨）と案 B（トップバーの絞り込みのボタンの隣）、文言は案 A「列の表示」（推奨）と案 B「列」。

案A: 表の上の帯の右端（絞っていない・推奨）

条件のチップの行の右端に置き、行と表の間に 12px の余白を取る。文言は案 A「列の表示」（推奨）。読み上げ名も同じ文言。
