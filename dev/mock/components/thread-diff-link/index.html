書き込みのまとまりのリンク

AI の書き込み

1 つの書き込みに、まとまりのリンク（文言に項目の ID を含む）・項目の ID のボタン・まとまりのリンクにならない書き方（記録に無い V-99）が並ぶ。リンクには文言だけを出し、文言の中の A-14 はボタンにしない。

利用者の書き込み

diff が since のもの・diff を持たない # のリンクは、書いた文字のまま出す。

スレッドの中のレビュー中の書き込み

破線の枠と「レビュー中」の印の書き込みも、同じ描き方で出す。

レビュー中を確かめる画面の行

行の本文は今と同じく項目の ID を文字のまま出し、まとまりのリンクだけを描く。

ホバー

案 A は下線を印の色に濃くし、案 B は項目の ID のボタンと同じく枠と文字を印の色にする。

キーボードのフォーカス

Tab で項目の ID のボタンと同じ並びの順に止まり、Enter で差分の表示に切り替わる。

長い文言・ほかの引数を持つリンク

#tab=docs&id=A-11&diff=V-5 は diff だけを読んでリンクにする。長い文言は書き込みの幅で折り返す。
