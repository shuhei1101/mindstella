本文の差分（段落・表の行）

Markdown を描いたまま、足した塊に +、消した塊に − と取り消し線を付ける。表は行ごとに付ける。

−消した:

システム開発のフェーズの並び。

 +足した:

システム開発のフェーズの並び。モジュール構成をフェーズに含めるかを見直している。
フェーズ決めること
要件できること（ユースケース）・品質の目標・運用
−消した: 構成サブシステム・外部システム・ライブラリ・データの置き場所
+足した: 構成サブシステム・外部システム・ライブラリ・データの置き場所・主な処理の流れ

変えていない段落には印を付けない。

図の凡例と消したものの一覧（色を付ける 5 種類）

足したノード・辺は太い実線、変わったノード・辺は太い破線。消したノード・辺は図の外に一覧で出す。

色を付けない種類の変わった図（gantt など）

図の枠を太い破線にし、Raw へ案内する。
