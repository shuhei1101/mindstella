返信の入力

空

入力が空の間は「返信する」を押せない（入力欄が空であることが押せない理由）。

入力中

Ctrl+Enter でも送る（変換の確定の Enter では送らない）。Esc は入力から外れるだけで、一覧へは戻らない。

送っている

入力欄を読み取りだけにし、「返信する」を押せなくする。

送った（Claude Code に入力した）

入力欄を空にし、送った時刻とともに Claude Code へ入力したことを出す。

送った（Claude Code に入力できなかった）

返信は保存されていて、次に話し合いを始めたときに取り込まれることを出す。

送れなかった

入力を残し、理由と直し方を出す（自動で消さない）。

長文

入力欄は 8 行まで広がり、それより長いと中でスクロールする。
