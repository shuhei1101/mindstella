Markdown の中の html のコードブロック

Markdown の本文の中の言語指定 html のコードブロックを、同じ枠に描く。前後の見出し・段落は Markdown のまま。コードブロックの <style>（p を赤くする）は前後の段落に効かず、<script> は動かない。行の印は付けず、枠の中で文を選んでもコメントの入口は出さない。
