components / comment-tabs

コメントの一覧のタブ

レビュー中のタブを選んでいる

レビュー中のコメントが 1 件以上あるときに開くタブ。タブの件数は、レビュー中はレビュー中のコメントの件数、会話はオープンのスレッドの件数。

会話のタブを選んでいる

レビュー中のコメントが 0 件のときに開くタブ。選んだタブは文字を濃くし、下線を差し色にする（太さは変えない）。

件数が 0

中身が無くてもタブを消さず、押せなくもしない。0 件の理由はタブの中に出す。

件数が多い

件数は桁を省かずに出す。2 桁・3 桁でも閉じるボタンを押し出さない。

ホバー・フォーカス

ホバーは文字を濃くする。キーボードのフォーカスはタブの枠の全体に出し、左右の矢印キーで隣のタブへ移る。

狭い幅（390px）

幅 900px 以下はパネルが画面いっぱいになり、タブと閉じるボタンは 1 行に収まる。
