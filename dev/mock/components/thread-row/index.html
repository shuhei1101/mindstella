スレッドの行

オープン・AI が返信した

1 行目に状態の札と要約（2 行まで）、2 行目に向けた項目の ID・最後の書き手・最後の書き込みの日時を出す。タグは行の下に並べ、押すとそのタグで絞る。

AI が立てたスレッド（利用者の返事待ち）

最初の書き込みが AI の問い。最後の書き手は AI。

AI の返信待ち・要約がまだ無い

最後の書き手が利用者のオープンのスレッドに「AI の返信待ち」の札を出す。要約がまだ無い行は、最初の書き込みの先頭を太さを落として出す。

クローズ

状態の札を「クローズ」にし、色は薄い文字にする（印と文字でも分ける）。

長い要約・タグが 2 つ・項目を指さない

要約は 2 行で末尾を省く。項目を指さないスレッドは ID を出さない。

向けた項目が消えた

返信待ちでないスレッドは記録として残り、消した項目の ID を文字のまま出す。

タグで絞っている行

絞っているタグは枠の全体と面で示す（押し直すと外れる）。

ホバー・フォーカス

ホバーは行の面を変える。フォーカスは行（開くボタン）とタグのそれぞれの枠の全体に出す。

一覧の上の絞り込みの帯

状態のセグメント（オープン・クローズ・すべてと件数）を帯の幅いっぱいに置き、タグで絞っているときだけ、その下に解除のチップと「残った件数 / 全体の件数」を出す。

0 件

絞り込みの状態とタグを文言に含める。

狭い幅（390px）

パネルが画面いっぱいのときも、行の 2 行目は折り返して収める。
