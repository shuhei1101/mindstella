# コンポーネント索引

新しく足す部品の、状態ごとの案を並べたモック。

| コンポーネント | 中身 |
| --- | --- |
| [doc-board](./doc-board/index.html) | 資料のボード（状態の 3 列・成果物を先頭・0 件の列・長い題・ホバー・フォーカス・詳細を開いている・狭い幅） |
| [filter-drawer](./filter-drawer/index.html) | 絞り込みのボタンとドロワー（絞っていない・絞り込み中・開いている・ホバー・フォーカス・バッジの数の案・何も選んでいない・値を選んでいる・0 件の値・長いタグ・キーワードに一致した件数・該当なし・狭い幅・列の見出し） |
| [fullscreen-button](./fullscreen-button/index.html) | 全画面表示のボタン（押していない・押されている・ホバー・フォーカス・狭い幅） |
| [selection-comment](./selection-comment/index.html) | 選んだ箇所のコメントの入口（ピル・丸・吹き出し・ホバー・フォーカス・上に出す・入口の中で書く・狭い幅） |
| [send-form](./send-form/index.html) | コメントの入力（空・入力中・箇所を添えた・溜めている・溜めた・本文が空・溜められなかった・項目を指さない・文言の案・長文・狭い幅・配る書き出し）と、サーバーにつながらないときのトップバーの表示 |
| [table](./table/index.html) | 表（並べ替え・列の絞り込み・条件のチップ・ピン留め・表示する列・該当なし） |
| [topbar](./topbar/index.html) | トップバーとタブの帯（開いている画面・つながり・ホバー・フォーカス・長い題名・狭い幅・コメントのボタンの置き場所と件数） |
| [view-switch](./view-switch/index.html) | 表示形式の切り替え（どのタブでも同じ位置・同じ幅） |
