# コンポーネント索引

新しく足す部品の、状態ごとの案を並べたモック。

| コンポーネント | 中身 |
| --- | --- |
| [body-links](./body-links/index.html) | 本文のリンク（見出しのリンク・用語の印とツールチップ・項目の ID のリンク・付けない所・狭い幅） |
| [body-format-badge](./body-format-badge/index.html) | 本文の形式のバッジ（HTML の資料だけ・ほかの札と並べたとき・資料のカードの種類の右・ボードのカード・表の形式の列・詳細のヘッダー・ホバーとフォーカス・狭い幅） |
| [comment-mark](./comment-mark/index.html) | コメントの印（件数ごと・差分の印と並んだとき・ホバーとフォーカス・つながりの玉・角のバッジの案・狭い幅） |
| [diff-marks](./diff-marks/index.html) | 差分の表示の部品（変更履歴のボタンと選んだ時点の札・変更履歴のモーダル・タブの印・新規と変更の印・詳細パネルの冒頭・キーの差分・本文の差分・図の凡例と消したもの・Raw の差分・前の版を組み立てられない・前後を組み立てられない古いまとまり） |
| [doc-board](./doc-board/index.html) | 資料のボード（状態の 3 列・成果物を先頭・0 件の列・長い題・ホバー・フォーカス・詳細を開いている・狭い幅） |
| [filter-drawer](./filter-drawer/index.html) | 絞り込みのボタンとドロワー（絞っていない・絞り込み中・開いている・ホバー・フォーカス・バッジの数の案・何も選んでいない・値を選んでいる・0 件の値・長いタグ・キーワードに一致した件数・該当なし・狭い幅・列の見出し・列の文字の条件（B 案）・文字の条件のチップ） |
| [fullscreen-button](./fullscreen-button/index.html) | 全画面表示のボタン（全画面でない・全画面の間の縮小のアイコン・ホバー・フォーカス・狭い幅） |
| [html-body-frame](./html-body-frame/index.html) | HTML の本文の枠（描いた本文・本文の <style> が外へ漏れない・描く前・スクリプトを含む本文・Markdown の中の html のコードブロック・差分の描いた結果の印と原文の差分への切り替え・差分を出せない・狭い幅） |
| [look-pick](./look-pick/index.html) | ネットワークの見た目の選び（深宇宙のダーク・ライト・グロウ・星屑・ホバー・フォーカス・開いている・既定が別の見た目・狭い幅） |
| [map-lock](./map-lock/index.html) | 検討事項のマップの節の鍵（ロックしていない・開いた鍵・閉じた鍵・ロック中にほかの節を開いた・鍵の震え・長い題・コメントの印と鍵） |
| [network-label](./network-label/index.html) | ネットワークの名前・状態の印・鍵・コメントの印（注目していない・状態の印・資料の成果物の箱・開いた鍵・閉じた鍵・ほかの項目を開いた・鍵の震え・遠い距離の札・コメントの印・鍵とコメントの印の順の A と B。ライトとダーク） |
| [removed-mark](./removed-mark/index.html) | 消した項目（消した印・一覧の上の帯の案 B・一覧の末尾の行とカードとボードの列の案 A・タブの点・時点の件数・長いタイトル・狭い幅） |
| [selection-comment](./selection-comment/index.html) | 選んだ箇所のコメントの入口（ピル・丸・吹き出し・ホバー・フォーカス・上に出す・入口の中で書く・狭い幅） |
| [settings-panel](./settings-panel/index.html) | 表示の設定のパネル（既定のまま・端末で変えている・種類を一部外した・保存した直後・既定が届いた・端末に保存できない・配る書き出し・ライト / ダークも置く案・既定を別の区画で選ぶ案・ホバー・フォーカス・狭い幅）と、ワークスペースの既定の確かめ（変える項目・変えない項目・保存している途中・保存できなかった・狭い幅） |
| [send-form](./send-form/index.html) | コメントの入力（空・入力中・箇所を添えた・溜めている・溜めた・本文が空・溜められなかった・項目を指さない・文言の案・長文・狭い幅・配る書き出し）と、サーバーにつながらないときのトップバーの表示 |
| [table](./table/index.html) | 表（並べ替え・列の絞り込み・条件のチップ・ピン留め・表示する列・該当なし・A 案の列の見出しの文字の絞り込み） |
| [topbar](./topbar/index.html) | トップバーとタブの帯（開いている画面・ネットワークの入口と星座の形のアイコン・ホバー・フォーカス・長い題名・狭い幅・コメントのボタンの置き場所と件・表示の設定のボタン・表示しない種類を外したタブの帯・検索の入口のキーの案内 Ctrl+K） |
| [view-switch](./view-switch/index.html) | 表示形式の切り替え（どのタブでも同じ位置・同じ幅） |
| [withdrawn-mark](./withdrawn-mark/index.html) | 取り下げの印（札と薄い文字の案 A・取り消し線の案 B・状態の札と並べたとき・表の行・ホバーとフォーカス・資料のカード・詳細パネルの題と理由・キーの差分・消した項目と並んだとき・狭い幅） |
