components / filter-drawer

絞り込みのボタンとドロワー

絞り込みのボタン

どの画面もキーワードの隣に 1 つだけ置く。絞っていないときはバッジを出さず、絞り込み中だけ印の色のバッジを付ける。ドロワーを開いている間は押された見た目にし、もう一度押すと閉じる。

件数のバッジに出す数（未確定）

同じ条件（状態で 4 つ・タグで 1 つを選び、36 件中 3 件）を、案ごとのバッジで出す。推奨は C。

ドロワー

条件ごとに値を件数つきのチェックボックスで並べる。値を選んだ条件にだけ「解除」を出し、今の条件では 0 件になる値は文字を薄くする。広い幅では本文の横に並べ、下端のボタンは「閉じる」にする。

狭い幅（390px）

ボタンは文字を隠してアイコンとバッジだけにし、名前は読み上げで渡す。ドロワーは本文に重ねるモーダルにし、画面の幅から 48px を引いた幅で右に後ろの画面を残す。下端のボタンは絞った件数を添えて閉じる。

表の列の見出し

列の見出しの絞り込みのボタンを外し、並べ替えとピン留めだけを残す。
