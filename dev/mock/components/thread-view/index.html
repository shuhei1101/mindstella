スレッド 1 件

AI の問い（オープン）

見出しは、上の行に「一覧へ戻る」と「クローズにする」、その下に状態の札と題、向けた項目とタグ。AI の書き込みは左に寄せて面の色を変え、利用者の書き込みは右に寄せる。書き手は名前でも示す。

レビュー中の返信を持つ

溜めた返信は、書き込みの末尾に破線の枠と「レビュー中」の印つきで出し、その場で修正・削除する。

レビュー中の返信を修正している・消した

左が修正の入力（キャンセル・修正）、右が消した後（元の場所に「元に戻す」）。

AI の返信待ち

最後の書き込みが利用者のオープンのスレッドは、書き込みの後ろに「AI の返信を待っています」を出す。

クローズ・オープンへの戻しの記録

状態を変えた日時と理由を、書き込みの並びの中に枠の無い 1 行で出す。理由が無い記録は 1 行だけ。

理由の入れ方の案 A（変える前に、その場で理由を書く）

「クローズにする」「オープンに戻す」を押すと、見出しの下に理由（任意）の入力と「キャンセル」・確定を出す。左がクローズ、右がオープンへの戻し。

理由の入れ方の案 B（すぐ変え、後から理由を書き足す）

押すとすぐ状態を変える。最後の記録に「理由を書く」を出し（左）、押すと記録の下に入力を出す（右）。

理由の入れ方の案 C（理由を選択肢から選び、文も書く）

クローズのときだけ、選択肢（選ばない・解決した・取り下げ・重複）と補足の入力を出す。

クローズ

見出しのボタンを「オープンに戻す」にし、下端は返信の入力の代わりに「クローズにしたスレッドです。」を出す。

まだ送っていない新しいスレッド

状態の札は「レビュー中」。最初の書き込みをレビュー中の印つきで出し、クローズと返信の入力を出さない。

クローズにできなかった

見出しの下に理由と直し方を出す（自動で消さない）。理由の入力は開いたまま残す。

向けた項目が消えた・記録に無い ID

向けた項目が消えたときは押せない ID だけを出す。本文の中の記録に無い ID は文字のまま。
