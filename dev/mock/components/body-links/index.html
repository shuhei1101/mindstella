本文のリンク

詳細パネルと詳細の全画面の本文（Markdown）に付ける、見出しのリンク・用語の印・項目の ID のリンク。コードブロックと図には付けない。

見出しのリンク

見出しの右に # のリンクを置き、見出しに乗せる・リンクにフォーカスすると出す。乗せる操作が無い端末では常に出す。押すとその見出しまでスクロールし、URL のハッシュをその見出しを指す形（h={見出し}）に書き換える（履歴には積まない）。本文の中の [文言](#見出し) のリンクも、その見出しまでスクロールする。

用語の印

本文に用語集の用語（用語の項目のタイトル）が出てきたら、文字の色は変えず点線の下線を引く。乗せる・フォーカスすると、用語と ID・意味のツールチップを出し、押すとその用語の詳細を開く。長い用語から順に当て、用語の項目自身の本文ではその用語に付けない。

項目の ID のリンク

記録にある項目の ID（D-15 など）は、等幅の印の色の文字と下線のリンクにし、押すとその項目の詳細を開く。インラインコードの中の ID にも付ける。記録に無い ID と、開いている項目自身の ID はそのままにする。

やりたいこと

プラグインの版を上げても、作ったワークスペースを壊さずに今の形へ整えられるようにする（D-1）。今の migrate は版を持たず、データの形から前の形式を推し量っている。
