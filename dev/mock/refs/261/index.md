# 261

本文の差分の表示を、インラインと左右に並べる表示で切り替えられるようにする（[PR #261](https://github.com/shuhei1101/mindstella/pull/261)・起点 [Issue #220](https://github.com/shuhei1101/mindstella/issues/220)）。
画面は、develop のプレビューのスクリプトをつないだものにこの PR の変更を当てたもの（`assets/app.js`、当てた箇所に「261:」のコメント）と、#237 の見本の記録（`../237/assets/data.js`）を読む。
サーバーの代わり（`../214/assets/mock-server.js`）が記録とレビュー中のコメントの読み書きに応え、プレビューをサーバーにつながった状態で開く。
スタイルは今のプレビューの `style.css` の上に、この PR の分とモック専用の操作列（`assets/style.css`）を重ねる。
見本の記録で左右に並べるのは、A-14「プレビューの差分の読み方（手引き）」（V-6 で段落・箇条書きの項目・表の行・図を足し、消し、変えた）、A-16（60 個の段落のうち 30 か所を変えた）、A-15（本文が短い）、A-11（本文が HTML。V-5 で段落を書き換えた）。
A-2 は V-6 で本文が変わっておらず、A-17 は前の版を組み立てられないため、どちらも切り替えを出さない。
モック専用の操作列で、切り替えを置く画面の案・見本の資料・時点（差分を出さない）・選んだ並べ方を保つ範囲の案（この端末に保つ / 開いている項目の間だけ）を切り替える。
クエリの `layout=side` で、左右に並べた状態で開く。
