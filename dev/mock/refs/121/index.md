# 121

コメントを書いた項目に、ボード・表・マップ・つながりで吹き出しの印と件数を出す（[PR #121](https://github.com/shuhei1101/mindstella/pull/121)）。
画面は 52 の見本のデータと、78 のスクリプトに差分の印とコメントの印を足したもの（`assets/app.js`）を読み、スタイルは 65・71・78 の上に印の分（`assets/style.css`）を重ねる。
レビュー中のコメントは、サーバーの代わりに端末の保存領域にモックの状態ごとに置く。
コメントの一覧（トップバーのコメントのボタンで開く左のパネル）で消す・元に戻す・まとめて送ると、開いている画面の印の件数がその場で変わる。
差分の印は、変更履歴で「前回開いてから」を選んだ状態の見本（D-005・D-022・A-005・R-002 変更、D-024・T-002 新規）を出す。
モック専用の操作列で、状態（0 件・2 桁・途中で切断・サーバー無し・配る書き出し）と、印の見た目（A ピル・B 角）・表での置き場所（A 横・B 列）・つながりでの出し方（A ラベル・B 輪）の案、差分の印を並べるかを切り替える。
