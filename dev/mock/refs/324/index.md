# 324

タスクに予定（開始・期限）と実績（着手・完了）を持たせ、プレビューの詳細パネルとタスクの表に出す（[PR #324](https://github.com/shuhei1101/mindstella/pull/324)・起点 [Issue #26](https://github.com/shuhei1101/mindstella/issues/26)）。
画面は、develop のプレビューのスクリプトをつないだものにこの PR の変更を当てたもの（`assets/app.js`、当てた箇所に「324:」のコメント）と、#237 の見本の記録（`../237/assets/data.js`）のタスクに予定と実績を足したもの（`assets/data-extra.js`）を読む。
サーバーの代わり（`../214/assets/mock-server.js`）が記録とレビュー中のコメントの読み書きに応え、プレビューをサーバーにつながった状態で開く。
スタイルは今のプレビューの `style.css` の上に、この PR の分とモック専用の操作列（`assets/style.css`）を重ねる。
見本のタスクは、4 つとも持つ T-1・T-4、予定と着手日の T-2・T-5・T-14、期限だけの T-3、開始予定だけの T-13、予定だけの T-9、予定の無い T-8・T-12、どれも持たない T-6・T-7・T-10 ほか。
モック専用の操作列で、案・見本のタスク・日付の出し方（記録の値のまま / 曜日を添える）を切り替える。
クエリの `date=locale` で、曜日を添えた日付で開く。
