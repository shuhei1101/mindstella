# 190

詳細パネルのレビュー中のコメントから、コメントを直す・消すことができるようにする（[PR #190](https://github.com/shuhei1101/mindstella/pull/190)・起点 [Issue #134](https://github.com/shuhei1101/mindstella/issues/134)）。
画面は、develop のプレビューのスクリプトをつないだものにこの PR の変更を当てたもの（`assets/app.js`、当てた箇所に「190:」のコメント）と、#127 の見本の記録（`../127/assets/data.js`）を読む。
サーバーの代わり（`assets/mock-server.js`）が記録とレビュー中のコメントの読み書きに応え、プレビューをサーバーにつながった状態で開く。コメントは開いている間だけ持ち、開き直すと見本の 5 件に戻る。
スタイルは今のプレビューの `style.css` の上に、この PR の分とモック専用の操作列（`assets/style.css`）を重ねる。
モック専用の操作列の「見本」で、通常・行を直している・空白だけで直そうとした・届かずに直せなかった（クエリの `fail=edit`）・行を消した状態を開ける。「画面」で詳細パネルと詳細の全画面を行き来する。

| 画面 | 中身 |
| --- | --- |
| [detail-panel](../../pages/detail-panel/190/index.md) | 詳細パネルのレビュー中のコメントの行の直す・削除・元に戻す。「直す」「削除」の見え方を 3 案 |
| [detail-full](../../pages/detail-full/190/index.md) | 詳細の全画面での同じ行の操作 |
