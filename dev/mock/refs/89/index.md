# 89

話題のタグを付け、今ある画面を 1 つのドロワーで種類・状態・タグで絞り込めるようにする（[PR #89](https://github.com/shuhei1101/mindstella/pull/89)）。
画面は 52 の見本のデータのタグを話題のタグに置き換えたもの（`assets/data.js`）と、71 のスクリプトの絞り込みを 1 つの絞り込みのボタンとドロワーにしたもの（`assets/app.js`）を読み、スタイルは 71 の上に絞り込みの分（`assets/style.css`）を重ねる。
モック専用の操作列で、件数のバッジに出す数・マップとつながりの帯の扱い・ボードで状態の条件から外した列の案と、配る書き出し・描画のライブラリが読めない状態に切り替える。
URL のハッシュに `drawer=1` を足すと、ドロワーを開いた状態で開く。
絞り込みのドロワーは #78 のコメントの一覧と同じく、幕を付けずにタブの帯の下から左に重ねる非モーダルのパネルにし、コメントの一覧とは同時に開かない。絞り込みのボタンはコメントのボタンと並べてトップバーに置く。コメントのボタンと一覧は、切り替えを見せるための見本として置く。
