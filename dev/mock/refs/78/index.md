# 78

プレビューのコメントをレビュー中に溜めて選んで送り、選んだ箇所へコメントできるようにする（[PR #78](https://github.com/shuhei1101/mindstella/pull/78)）。
画面は 52 の見本のデータと、71 のスクリプトをコメントを溜めて選んで送る形に変えたもの（`assets/app.js`）を読み、スタイルは 65・71 の上にコメントの分（`assets/style.css`）を重ねる。
画面は 1 枚の HTML の中で URL のハッシュの `tab` で切り替え、どの案のページからもタブ・コメントの一覧へ移れる。
レビュー中のコメントと書きかけは、サーバーの代わりに端末の保存領域に置き、開き直しても戻る。
撮影のときは URL のハッシュに `shot=1` を足し、詳細の全画面をモーダルにせず同じ位置へ重ねて出す（撮影の赤枠を全画面の上に描くため）。
モック専用の操作列で、コメント 0 件・長文と大量・箇所が合わない・サーバーにつながらない・配る書き出しの状態と、文言・コメントのボタンの置き場所・削除の取り消し方・入口の形の案を切り替える。
