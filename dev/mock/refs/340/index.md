# 340

詳細のサイドバーを既定の幅で開き、ドラッグで幅を変えられるようにする（[PR #340](https://github.com/shuhei1101/mindstella/pull/340)・起点 [Issue #150](https://github.com/shuhei1101/mindstella/issues/150)）。
画面は、develop のプレビューのスクリプトをつないだものに、この PR の既定の幅と左端の区切りを当てたもの（`assets/app.js`、当てた箇所に「340:」のコメント）と、#237 の見本の記録（`../237/assets/data.js`）を読む。
サーバーの代わり（`../214/assets/mock-server.js`）が記録とレビュー中のコメントの読み書きに応える。
スタイルは今のプレビューの `style.css` の上に、この PR の区切りの分とモック専用の操作列（`assets/style.css`）を重ねる。
モック専用の操作列で、開く項目（資料・検討事項の表・検討事項のマップ）・残した幅の見本（消す・下限・上限）・区切りの状態の見本（ふだん・乗せた・フォーカス・ドラッグ中）を切り替える。
