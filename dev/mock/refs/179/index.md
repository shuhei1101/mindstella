# 179

プレビューの変更履歴・差分の表示に、消した項目と取り下げの印を出す（[PR #179](https://github.com/shuhei1101/mindstella/pull/179)・起点 [Issue #174](https://github.com/shuhei1101/mindstella/issues/174)）。
画面は、develop のプレビューのスクリプトをつないだものにこの PR の変更を当てたもの（`assets/app.js`、当てた箇所に「179:」のコメント）と、#127 の見本の記録に消した項目と取り下げた項目を足したもの（`assets/data.js`）を読む。
スタイルは develop の `style.css` の写し（`assets/base.css`）の上に、この PR の分（`assets/style.css`）を重ねる。
見本の記録のまとまりは、V-1「検討事項・タスク・資料を整理する」（A-9 を取り下げ、D-53・T-19・A-10 を消した）、V-2「重複と不要な調査を片付ける」（R-1 を取り下げ、N-6 を消した）、V-3「メモを足す」（N-7）、V-4「足したメモを消す」（N-7）。用語 G-6 は前から取り下げてある。
前回開いた日時は V-2 と V-3 の間に置き、「前回開いてから」は足して消した N-7 の 1 件だけになる。
モック専用の操作列で、時点（V-1・V-2・前回開いてから・差分を出さない）、変更履歴のモーダルを開いた状態、取り下げの印の案（A 札と薄い文字・B 取り消し線）を切り替える。
消した項目を出す場所の案（A 一覧の末尾・B 一覧の上の帯）は、案のディレクトリで分ける。
