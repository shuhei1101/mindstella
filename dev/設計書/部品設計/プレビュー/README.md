# プレビュー

プレビューの画面が共通で使う部品

## 目次

| ページ | 概要 |
| --- | --- |
| [トップバー.ts](./トップバー.ts.yaml) | 題名・検索の入口・ライト / ダークと、画面を移るタブの帯 |
| [表示形式の切り替え.ts](./表示形式の切り替え.ts.yaml) | マップ・ボード・カード・表を切り替えるセグメント |
| [表.ts](./表.ts.yaml) | 並べ替え・絞り込み・ピン留め・列の表示を持つ項目の一覧 |
| [差分の印.ts](./差分の印.ts.yaml) | 差分の表示の間、足した項目に新規（+）、変えた項目に変更（●）、消した項目に消した（−）の印 |
| [変更履歴.ts](./変更履歴.ts.yaml) | 差分の表示で比べる時点を選ぶモーダル |
| [コメントの入力.ts](./コメントの入力.ts.yaml) | 詳細パネル・詳細の全画面の下端と、コメントの一覧の新しいスレッドの入力に置く、コメントをレビュー中に溜める入力欄とボタン |
| [選んだ箇所のコメントの入口.ts](./選んだ箇所のコメントの入口.ts.yaml) | 本文の文章か項目の値を選んだときに、選んだ範囲の近くに出すピルの形の入口 |
| [表示の設定.ts](./表示の設定.ts.yaml) | 表示する種類を選び、既定に戻す・ワークスペースの既定にするを持つ左のパネルの中身 |
| [既定の保存の確かめ.ts](./既定の保存の確かめ.ts.yaml) | ワークスペースの既定として保存する前に、今の既定と保存する値を並べるモーダル |
| [絞り込み.ts](./絞り込み.ts.yaml) | 条件ごとに値を件数つきのチェックボックスで選ぶ、左に重ねる絞り込みのドロワー |
| [コメントの印.ts](./コメントの印.ts.yaml) | レビュー中のコメントを書いた項目に出す、吹き出しと件数の小さなピル |
| [消した項目の帯.ts](./消した項目の帯.ts.yaml) | 差分の表示の間、選んだ時点で消した項目を一覧の上に消した印・ID・タイトルで並べる帯 |
| [取り下げの札.ts](./取り下げの札.ts.yaml) | 取り下げた調査・資料・用語集・メモ・会話ログのタイトルの右に置く、枠付きの × と「取り下げ」の札 |
| [本文の形式の札.ts](./本文の形式の札.ts.yaml) | 資料の種類の右に置く、本文の形式を `MD` / `HTML` で示す札 |
| [HTMLの本文の枠.ts](./HTMLの本文の枠.ts.yaml) | HTML の本文と `html` のコードブロックを、スクリプトを動かさない枠に描く |
| [HTMLの本文の差分.ts](./HTMLの本文の差分.ts.yaml) | HTML の本文の差分を、描いた結果の印と原文の差分で切り替えて見せる |
| [本文の印のツールチップ.ts](./本文の印のツールチップ.ts.yaml) | 本文の印に一致した用語・資料・調査を、種類ごとの見出しと区切り線で印の上に並べるツールチップ |
| [スレッドの行.ts](./スレッドの行.ts.yaml) | スレッドの一覧の 1 行。状態の札・題・向けた項目・最後の書き手と日時・レビュー中の印・タグ |
| [スレッドの書き込み.ts](./スレッドの書き込み.ts.yaml) | スレッドの中の書き込み・クローズとオープンへの戻しの記録・レビュー中の返信の 1 件 |
| [返信の入力.ts](./返信の入力.ts.yaml) | スレッドの下端に留める、返信をレビュー中に溜める入力欄とボタン |
| [差分のミニマップ.ts](./差分のミニマップ.ts.yaml) | 差分の表示の間、詳細の本文のスクロールバーの外側に変わった箇所の印を並べ、押す・ドラッグで本文を送る縦の帯 |
| [本文の差分の並べ方の切り替え.ts](./本文の差分の並べ方の切り替え.ts.yaml) | 差分の表示の間、本文の差分の頭に置く「インライン」「左右に並べる」のボタンの組 |
| [左右に並べた本文の差分.ts](./左右に並べた本文の差分.ts.yaml) | Markdown の本文を左に選んだ時点、右に今で描き、変えていない塊を同じ高さで向かい合わせる |
| [保存待ちの印.ts](./保存待ちの印.ts.yaml) | 保存待ちの編集がある項目・キー・案に、破線の枠に重ねた紙の印と「保存待ち」「保存で削除」「書き込めない」を出す札 |
| [Markdownの本文.ts](./Markdownの本文.ts.yaml) | 描いた Markdown の本文に、表の列の幅・固定・見出しの固定・しま模様、セクションの折りたたみ、コードブロックの札とコピー、Alert の囲みを当てる |
| [本文の折りたたみ.ts](./本文の折りたたみ.ts.yaml) | レビュー中の書き込みの本文を見た目の 5 行までに畳み、超えるときだけ「続きを読む」「折りたたむ」を出す |
