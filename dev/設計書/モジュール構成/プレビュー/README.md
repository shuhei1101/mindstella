# プレビュー

## 目次

| ページ | 概要 |

| [画面と部品.ts](./画面と部品.ts.yaml) | 表・トップバー・表示形式の切り替え・回答・意見の送信と、概要からつながりまでの画面 |
| [差分.ts](./差分.ts.yaml) | 選んだ時点の印・前の版の組み立て・行の差分・図の要素の突き合わせ |
