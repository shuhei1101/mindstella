# サーバー

起動と、MCP のツール・プレビューの配信でワークスペースを読み書きするサーバーのモジュール

## 目次

| ページ | 概要 |
| --- | --- |
| [入口.py](./入口.py.yaml) | MCP サーバーのツールの登録・結果とエラーの組み立て・ツールごとの処理 |
| [読み書きと検証.py](./読み書きと検証.py.yaml) | 種類の定義・例外・ワークスペースの読み書きと検証 |
| [検索.py](./検索.py.yaml) | 検索・1 件の表示と参照元・属性名の一覧 |

| [点検.py](./点検.py.yaml) | スキーマ違反・ID の重複・参照切れ・本文のずれ・設定に無いフェーズ |
| [ビルド.py](./ビルド.py.yaml) | プレビューの記録の収集・雛形の組み立て・配る書き出し |
| [ゴール判定.py](./ゴール判定.py.yaml) | ゴールに届いたかの判定と goal の処理 |
| [移行.py](./移行.py.yaml) | 版の比較と、版ごとの移し替えの手順を並べる・写しを取って当てる・値を入れる・版を書く |

| [設定の更新.py](./設定の更新.py.yaml) | 設定の更新の引数の確かめ・設定の置き換え・フェーズの付け替え・設定と種類の YAML のまとめた書き込み |
| [変更履歴.py](./変更履歴.py.yaml) | 変更履歴の 1 回分・本文の差分・書き換えのまとまり・前回開いた日時 |
| [コメント.py](./コメント.py.yaml) | レビュー中のコメントと書きかけの読み書き・まとめて送る |
| [箇所.py](./箇所.py.yaml) | コメントが指す箇所の形と、今の項目に合うかの確かめ |
| [ワークスペースのREADME.py](./ワークスペースのREADME.py.yaml) | 直下の README.md の中身の組み立て・書くかの判定・書き込み |
| [登録.py](./登録.py.yaml) | 起動スクリプトを呼ぶ alias と環境変数の登録・読み返し・外す |
| [ClaudeCodeへの入力.py](./ClaudeCodeへの入力.py.yaml) | まとめて送った後に Claude Code のペインへ貼り、会話の記録で届いたかを確かめる |
