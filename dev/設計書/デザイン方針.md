# デザイン方針

mindstella の画面全体に通すデザインの方向性。

## 採用スタイル

| 項目 | 内容 | 補足 |
| --- | --- | --- |
| スタイル | 開発者ツール × スイス | 規約『デザインスタイル』の組み合わせ |
| 分類 | 業務系 × 表現系 | - |
| 明暗 | 両方 | 既定は端末の設定に従い、トップバーのボタンで切り替える |
| 見本（画面全体） | [dev/mock/styles/dev-swiss-cards/](../mock/styles/dev-swiss-cards/index.html) | - |
| 見本（部品） | なし | Storybook は部品設計で置く |
| 値の置き場所 | `plugins/mindstella/skills/mindmap/preview/tokens.css` | 雛形への取り込み方はモジュール構成設計で決める |
| 選んだ理由 | ジャンルは開発者ツール（業務・SaaS）。利用者は Claude Code で話し合いを記録した本人で、表と数値を長く読み返す。無彩色の骨格に印の 1 色だけを置き、見出しと本文の大きさの差で先に読むところを示す | ユーザーと見本で決めた（[確認ログ](../pr/21/確認ログ.md)） |

## 雰囲気のことば

理知的・静か・手元の道具

## モチーフ・装飾

| モチーフ・装飾 | 使う場所 | 補足 |
| --- | --- | --- |
| 枝分かれの図形 | トップバーのサイト名の前 | 印の色で描く |
| 紙のような地とざらつき | つながり（3D）のライトの地 | - |
| 墨色に淡い光のにじみ | つながり（3D）のダークの地 | - |

## 色の役割

| 役割 | 使う場所 | トークン | 補足 |
| --- | --- | --- | --- |
| 地 | 画面の地 | `--bg` | ライトは灰色、ダークは墨色 |
| 面 | タイル・表・詳細パネル | `--surface` / `--thead-bg` | 地との明るさの差で区切る |
| 文字 | 本文・補足・控えめな補足 | `--text` / `--text-2` / `--text-3` | どれも置く面の上で 4.5:1 以上 |
| 線 | 部品の枠・表の行の境 | `--border` / `--border-soft` | - |
| 印 | マップの枝の線・選択中・進み具合・フォーカスの輪・リンク | `--accent` / `--accent-weak` / `--accent-line` | 強い色はこの 1 色だけ。主なボタンは文字色で塗り、印の色を使わない |
| ホバー | 押せるものに乗せたとき・キーボードのフォーカスがある表のセル | `--hover` / `--row-hover` | 面だけを変える。`--hover` は面に文字色を 9% 混ぜた色で、全ての画面で同じ値を使う |
| 選択中 | 選んだ行・項目 | `--row-selected` | 印の色の薄い面と細い枠 |
| 状態 | 状態の印（決定済み・未決定・要見直し・保留・未整理・取り下げ） | `--st-done` / `--st-open` / `--st-review` / `--st-hold` / `--st-loose` / `--st-off` | 状態の表示だけに使い、色に加えて形でも分ける |
| 失敗 | 回答・意見の本文が空・送れなかった・サーバーにつながらないときの印と入力欄の枠 | `--st-review` | 状態の表示の外で要見直しの赤を使う例外。色に加えて印のアイコンと文言でも伝える |
| 種類 | つながりの玉と種類の切り替え | `--k-dec` / `--k-task` / `--k-res` / `--k-doc` / `--k-term` / `--k-note` / `--k-log` | 検討事項・タスク・調査・資料は色、用語集は濃い灰・メモは茶・会話ログは薄い灰 |
| つながりの地 | つながり（3D）の描画面 | `--g-bg` / `--g-bg-center` / `--g-grain` / `--g-glow` / `--g-line` / `--g-label` / `--g-dot` | `--g-dot` は選んだ玉からの線を流れる小さな玉 |
| トップバー | トップバー | `--topbar-bg` / `--topbar-fg` / `--topbar-fg-2` / `--topbar-line` / `--topbar-hover` | 明暗どちらでも暗い帯 |
| 当たった語 | 検索・マップのキーワードの強調 | `--hit` | 黄色 |
| 重ねる面の影 | 詳細パネル・検索・全画面・図の拡大・ポップオーバー | `--shadow-panel` / `--shadow-pop` | 本文に重ねる面だけに付ける |
| 幕 | 検索・図の拡大・詳細の全画面の後ろ | `--scrim` / `--scrim-soft` | 全画面は元の画面が透けて見える薄い幕（`--scrim-soft`）にする |

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 見出し | サンセリフの太字（Inter・Noto Sans JP） | 題名は本文の 2.4 倍（`--fs-h1`）、大きな数字は 3.1 倍（`--fs-big`） |
| 本文 | サンセリフ（Inter・Noto Sans JP） | 14px（`--fs-body`）。補足は 13px・12px の 2 段まで |
| ID・数値 | 等幅（JetBrains Mono） | 桁を揃える。表の数値の列は右揃え |
| 読み込み | Google Fonts から読む | 端末によらず字形を揃える（[確認ログ](../pr/21/確認ログ.md)） |

## 形と奥行き

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| タイル | 地より明るい面だけ。線と影は使わない | 角丸 4px（`--radius`） |
| 表 | 行の境を薄い線で区切る | 見出し行と押した列までを留め、留めた列の境だけに影 |
| 部品（ボタン・入力・切り替え） | 1px の線 | 高さは `--control-h` に揃える |
| ID のボタン | 1px の線 | 見えている枠を縦横 `--target-min` 以上にする |
| 詳細パネル・検索 | 面と線、重ねる面には影（`--shadow-panel` / `--shadow-pop`） | 詳細パネルの幅は `--panel-w`。検索は地を暗くして重ねる |
| 図（本文の mermaid） | 面と線 | ノードの面・線・辺のラベルの地と文字をトークンから決める |
| フォーカス | 印の色の 2px の輪 | ホバー（面の色）・選択中（印の色の薄い面）と見分ける |

## 動き

| 場所 | 動き | 補足 |
| --- | --- | --- |
| マップの依存の線 | 選んだときに線の上を小さな玉がゆっくり流れる | - |
| つながり（3D） | 回転・引き寄せ・寄り。止まって少しすると、ごくゆっくり自動で回る | - |
| 詳細パネル | ゆっくりすべり込む | 本文の寄せは開閉と同時に切り替え、パネルだけを動かす |

動きを減らす設定では全て止める。

## 使わないもの

| 使わないもの | 理由 | 補足 |
| --- | --- | --- |
| 印の色以外の強い色 | 印が目立たなくなる | 状態と種類の色は表示にだけ使う |
| タイルの影 | 奥行きの表し方を面の色の差 1 つに揃える | 本文に重ねる面の影（`## 形と奥行き`）とは別 |
| 光る影・文字のグラデーション・左端だけの太い色線 | 飾りが情報より先に目に入る | - |
| 入ったときに自動で動くアニメーション | 読み返す画面で目を散らす | - |
| 絵文字のアイコン | 線のアイコン 1 セットで揃える | - |
