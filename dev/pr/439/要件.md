# 要件

## 要望

画面で語の面（`span.df-word`）が付くことを確認する次のテストに、開く前（単体テストは詳細パネルを組み立てる前）に `performance.now()` を読み込んだ時刻で止める初期化スクリプト `FREEZE_PERFORMANCE_NOW_JS` を当て、語の差分の打ち切り時刻が描画の時間で過ぎないようにする。

語の面が付かないことを確認するテスト（`test_diff_body_when_inline_words_unpaired`・`test_diff_body_when_inline_words_little_same`・単体の `test_detail_panel_when_diff_lines_unpaired`・`test_detail_panel_when_diff_key_words_skipped` 等）は、確認の前提が打ち切りに依らない（行の数・同じ部分の割合・比べられない値で付かない）ものだけに当てる。
`INSTALL_LINE_DIFF_TIMEOUT_SCRIPT` で時計を進めて打ち切りを起こすテスト（`test_detail_panel_when_diff_key_words_body_too_large`）には当てない（時刻を止めると打ち切りが起きなくなる）。

打ち切りは非機能要件「差分の表示の切り替えの時間」から割り出した設計どおりの挙動なので、製品コードは変えない（打ち切りの挙動は単体テスト `test_diff_inline_when_deadline_passed` が確認する）。
完了の基準は、負荷を掛けた状態（CPU を使い切る busy loop を並べる）で、対象の単体テスト・結合テストを含むファイルをまとめて実行して全 pass すること。E2E はスプリントの release ブランチで実行する。
