# 語の面（span.df-word）を確認するテストで、語の差分の打ち切り時刻が描画の遅れで過ぎないようにする

## 概要

画面で語の面（`span.df-word`）が付くことを確認する単体テスト・結合テスト・Storybook のテスト・E2E が、負荷が高いときにも毎回 pass するようにする。

## 背景

[Issue #437](https://github.com/shuhei1101/mindstella/issues/437) の要望。
語の差分（`diffInline`）の打ち切り時刻は、詳細パネルが本文の行の差分を呼ぶ直前の時刻に `LINE_DIFF_TIMEOUT_MS`（40ms）を加えた時刻で、その後の描画の時間も同じ枠を使う。負荷で描画が遅れると語の面が付かず、テストが fail しうる。
[#436](https://github.com/shuhei1101/mindstella/pull/436)（起点 [Issue #434](https://github.com/shuhei1101/mindstella/issues/434)）は `test_diff_body_side_by_side_when_linked` だけを、`performance.now()` を止める初期化スクリプト `FREEZE_PERFORMANCE_NOW_JS` で修正した。
