## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 時刻を止めるスクリプトの置き場所 | `FREEZE_PERFORMANCE_NOW_JS` を、どのテストの層からも import できる `tests/` 直下のモジュールへ移し、`preview_word_diff_helpers.py` はそこから import して公開を続ける | 既存の `test_diff_body_side_by_side_when_linked` の import は変えない |
| ブラウザで開くテスト（結合・Storybook・E2E） | 開く前に `page.add_init_script(FREEZE_PERFORMANCE_NOW_JS)` を当てる | 初期化スクリプトは `page.reload()` の後も効く（`_color` のテスト） |
| 単体テスト | スクリプトを読み込んだ後、詳細パネルを組み立てる `evaluate` の前に `preview_page.evaluate(FREEZE_PERFORMANCE_NOW_JS)` で当てる | 単体テストのページは開き直さないため、初期化スクリプトでは効かない |
| 語の面が付かないことを確認するテスト | 付かない理由が打ち切りに依らないテストだけに当て、`INSTALL_LINE_DIFF_TIMEOUT_SCRIPT` で打ち切りを起こすテストには当てない | 当てるかの判断はテストごとに `## テスト結果` の補足列に書く |
| 毎回 pass することの確認 | 負荷を掛けた状態で、対象の単体テスト・結合テスト・Storybook のテストを含むファイルをまとめて実行し、全 pass したログを配置する | E2E はスプリントの release ブランチで実行する |
