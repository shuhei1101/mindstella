# セットアップで起動スクリプトの alias と環境変数を設定し、サーバーで使うときの絞り込みを保存する

## 概要

利用者が `/mindstella:setup` で起動スクリプトの alias と環境変数を登録し、alias から立ち上げられるようになる。
サーバーの配信で開いたプレビューで、選んだ絞り込みの条件が読み込み直しても残るようになる。

## 背景

[#10](https://github.com/shuhei1101/mindstella/issues/10) の要望のうち、[#4](https://github.com/shuhei1101/mindstella/issues/4)・[#5](https://github.com/shuhei1101/mindstella/issues/5)・[#6](https://github.com/shuhei1101/mindstella/issues/6)・[#13](https://github.com/shuhei1101/mindstella/issues/13)・[#117](https://github.com/shuhei1101/mindstella/issues/117) へ移した後に残った範囲。
起動スクリプトは [#71](https://github.com/shuhei1101/mindstella/pull/71) で入ったが、利用者は叩くたびに `claude plugin list --json` から `installPath` を引いて `{プラグインのフォルダ}/bin/mindstella` を叩いており、alias への登録は #10 のスコープに残っていた。
ユーザーとの話し合いで、alias の登録と環境変数の設定はセットアップのスキル `mindstella:setup` が受け持ち、MCP の無い状態でも動くようスキルの配下のスクリプトで行うと決まった（[コメント](https://github.com/shuhei1101/mindstella/issues/10#issuecomment-6042682415)）。
絞り込みの条件は [#21](https://github.com/shuhei1101/mindstella/pull/21) で「保存しない」とし、サーバーで使うときの保存を #10 に残していた。
