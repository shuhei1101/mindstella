## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 登録のスクリプト | `plugins/mindstella/skills/setup/scripts/` に置く。起動スクリプトを呼ぶ alias と、起動スクリプトが読む `MINDSTELLA_*` の環境変数を書き込み、登録済みのものを読み返す・消す口も持つ。ワークスペースには書かない。MCP のツールにも mindstella の仮想環境にも頼らず、システムの `bash`（と `python3` の標準ライブラリ）だけで動く | 書く先は `~/.config/mindstella/` の専用のファイル（インターフェース定義『起動スクリプトの登録』）。alias は叩くたびに今の `installPath` を引く |
| セットアップのスキルの分岐 | MCP のツールが無いとき、案内して止まる代わりに、登録の有無を登録のスクリプトで読み、無ければ登録を持ちかける。登録した後と、登録済みのときは、新しいシェルで alias にワークスペースのフォルダを渡して立ち上げ直すよう案内して止まる。登録済みで変えたい・外したいと言われたら登録のステップへ進む | ワークスペースに何も書かないことは今と同じ |
| 環境変数を尋ねる範囲 | 既定のままでよい値は尋ねず、利用者が設定したいと言った環境変数だけを書き込む。既に登録した値は読み返して示し、変えるものだけを書き換える | 秘密の値は持たない |
| アカウントごとの alias | `/mindstella:setup` でアカウントを足したいと言われたら、アカウントの名前と Claude Code の設定のフォルダを尋ね、`installPath` を引く `claude plugin list --json` と起動スクリプトの両方に `CLAUDE_CONFIG_DIR` をそのフォルダにして渡す alias `mindstella-{名前}` を登録する。外す・変えるも同じ登録のスクリプトで行う | [確認ログ](./確認ログ.md) |
| `allowed-tools` | 登録のスクリプトだけを `Bash({スクリプト}:*)` で足す。ワークスペースの読み書きは MCP のツールのまま | インターフェース定義『セットアップ』の「Bash は許していない」を書き換える |
| MCP のツールがあるとき | 今の流れ（新しいワークスペース・既存のワークスペース）のまま。登録を変えたいと言われたときだけ登録のステップへ進む | - |
| エラー表示 | 書き込めない・ログインシェルを判定できないときは、何も書かずに理由と手で書く行を示す | - |
