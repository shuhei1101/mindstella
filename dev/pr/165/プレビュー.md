## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 保存する範囲 | サーバーの配信で開いたときだけ、画面（検討事項・タスク・資料・記録の表・ネットワーク）ごとに絞り込みのドロワーの条件（値の選び・列の文字）を保存する。配る書き出しでは今のまま保存しない | 端末の保存領域に画面ごとに持つ（要件.md） |
| 保存する時機 | 条件を変えるたびに書く。チップの解除・全部解除で外した条件も、外した状態で書く | - |
| 開いたとき | 保存した条件で描く。URL のハッシュに `f.{列}` があれば、その画面はハッシュの条件で開き、保存した条件を書き換えない | 概要の「すべて表示」・セルから開いた条件で、保存した条件を上書きしない |
| 画面の既定の条件 | 保存した条件が無い画面は、今の画面の既定の条件（検討事項の状態など）で開く | - |
| 既定に戻す | 表示の設定の「既定に戻す」で、保存した絞り込みの条件も外し、画面の既定の条件へ戻す。「この端末で変えている項目」に、条件を保存している画面を並べる | - |
| 記録から消えた値 | 保存した値が今の記録に無くなったら、その値を条件から外して描く | - |
| 保存できない環境 | 今と同じく、開いている間だけ保つ | - |
