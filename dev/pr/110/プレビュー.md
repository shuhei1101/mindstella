| 対象 | 方針 | 補足 |

| 図の描き直し | 差分の表示の切り替えで、今の版の図は描いた SVG を使い回し、`mermaid.render` を呼ぶのは前の版の図だけにする | 使い回す方法は要件.md の `## 要望` |

| 性能 | 見本の D-7（本文 1000 行と、ノード 50 の `flowchart TD`）で、非機能要件『差分の表示の切り替えの時間』の measurement のとおり 200 ms 以下 | 実装の後、負荷の低いときに直す前と同じ見本で測り、直す前の値と並べて原因が図の描き直しだったことを確かめる |
