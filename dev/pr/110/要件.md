# 要件

## 要望

詳細パネルを開いたまま変更履歴でまとまりを選んだとき（差分の表示の切り替え）、図の差分を、今の版の図を描き直さずに使い回し、前の版の図だけを描いて突き合わせる形にする。
PoC（[#83](https://github.com/shuhei1101/mindstella/pull/83)）で採った形に揃える。

- 満たす基準は、非機能要件『差分の表示の切り替えの時間』の決定値 200 ms（図のノード 50・本文 1000 行まで。measurement のとおり 5 回の中央値）
- 図・本文・Raw の差分の出し方（印・凡例・消したもの・打ち切ったときの扱い）は変えない
- 決定値と規模の条件は変えない。直しても届かず決定値か規模の条件を緩めることになる場合は、要件を変えるため設計の中でユーザーへ確かめる

今の版の図は、図を描く口（`renderDiagrams`）が直前の呼び出しで描いた SVG を記法ごとに覚え、同じ記法の図は描き直さずに新しい ID で写す。
覚えるのは直前の呼び出しの図だけにし、テーマが変わったら捨てる。
前の版の図（`renderDiagramSvg`）は覚えずに毎回描く。
