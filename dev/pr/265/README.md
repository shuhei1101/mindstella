# 詳細パネルの本文の見出しを、本文の最も上の段から h4 に詰めて段を飛ばさないようにする

## 概要

読み上げで詳細パネルを読む利用者が、節の見出し「本文」（h3）の次の本文の見出しを、段を飛ばさずに h4 から辿れるようになる。

## 背景

[#240](https://github.com/shuhei1101/mindstella/issues/240) の要望。
詳細パネルの本文の見出しは `lowerHeadings()` が一律に 3 段下げるため、本文が `##` から始まると「本文」の h3 の次が h5 になり、h4 を飛ばす。
外部規約『操作とアクセシビリティ』の「見出しの段を飛ばさない」から外れている。
[#237](https://github.com/shuhei1101/mindstella/pull/237)（起点 [#209](https://github.com/shuhei1101/mindstella/issues/209)）のモック作成で designer が見つけ、対象外として切り出した。
