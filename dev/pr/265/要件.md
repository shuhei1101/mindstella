# 要件

## 要望

詳細パネルと詳細の全画面で、本文の Markdown の見出しのうち最も上の段を h4（節の見出し「本文」の h3 の次）にし、ほかの見出しはその段からの差を保って並べる。
例として、本文が `##` と `###` だけを持つときは `##` を h4、`###` を h5 にする。
h6 を超える段は今までどおり h6 の要素にして、`aria-level` で段を伝える。
差分の表示の間は、今の本文と、差し込む消した行のかたまりの見出しを合わせた最も上の段を h4 にする（今の本文と消した部分で同じ段の差を使う）。
見出しの見た目（`data-md-level` による大きさ）と、見出しのリンク・行の印は変えない。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 詳細パネルの文字列の値（`renderValue` で描く背景・案の内容など）の中の見出し | 同じ型の箇所。`renderValue` は見出しを下げず、値に `#` を書くと節の見出しより上の段（h1）になる。`renderValue` はコメントの一覧など詳細パネルの外でも使い、置く場所ごとに下げる段が違うため、今回の `lowerHeadings()` の直しとは分けて扱う | [#266](https://github.com/shuhei1101/mindstella/issues/266) |
| `dev/mock/refs/` のモックに写した `lowerHeadings()` | 過去の PR の参考に残したモックで、配る画面ではない | 予定なし |
