## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 選んだ時点の印 | `resolveDiffPoint` が選んだ時点の `removed` を集め、`DiffPoint` に消した項目（ID・種類・タイトル）を持たせる。合わせた範囲で足して消した ID は `added` から除く | - |
| 消した項目の描画 | 差分の表示の間、種類ごとの画面の一覧の上に「消した項目」の帯を置き、消した印・ID・消したときのタイトルで並べる。押しても詳細パネルを開かない | 確認ログ |
| タブの点 | 足した・変えた・消した項目のどれかを持つ種類のタブに点を付ける | - |
| 時点の件数 | `points[].count` を足した・変えた・消した項目の数にする | - |
| 取り下げの印 | `withdrawn` が真の調査・資料・用語集・メモ・会話ログに、差分の表示によらず、表・カード・ボード・詳細パネルで取り下げの印を出し、詳細パネルに `reason` を出す。印はタイトルの右の枠付きの「取り下げ」の札と薄い文字 | 確認ログ |
| アクセシビリティ | 消した印・取り下げの印は色だけに頼らず、文言を読み上げに残す | 部品設計『差分の印』の `accessibility` と同じ扱い |
| 既存機能への影響 | `removed` を持たないまとまり・`withdrawn` を持たない項目の表示は変えない | - |
