# プレビューの変更履歴・差分の表示に、消した項目と取り下げの印を出す

## 概要

利用者が、プレビューの変更履歴・前回からの差分の表示で、AI が消した項目と、取り下げた調査・資料・用語集・メモ・会話ログを見分けて読めるようになる。

## 背景

[#174](https://github.com/shuhei1101/mindstella/issues/174) の要望。
[#167](https://github.com/shuhei1101/mindstella/pull/167)（起点 Issue [#96](https://github.com/shuhei1101/mindstella/issues/96)）の要件.md の `## スコープ外` から切り出した。
#167 で、消した項目は `changes.yaml` の `removed` に ID・種類・タイトルで残り、取り下げは `withdrawn`・`reason` のキーで記録されるようになったが、画面の見た目は変えていない。
今の変更履歴の時点の件数は足した・変えた項目だけを数え、差分の印は新規（+）と変更（●）だけで、消した項目と取り下げは画面に出ない。
