# プレビューの検索・絞り込み・画面の固定・本文のリンクを使いやすくする

## 概要

利用者が、プレビューで項目を探す・読む・行き来する手間を減らせるようになる。
表を列の値と ID で絞り込め、全体の検索は `Ctrl+K` で開いて完全に一致する項目が上に出る。
上の帯はどの画面でも見えたままで、本文の見出し・用語・項目の ID から移れる。

## 背景

[#85](https://github.com/shuhei1101/mindstella/issues/85) の要望。
手元の aituber の設計のワークスペースを使っていて気づいた。
本文の項目の ID のリンクは、[#85 のコメント](https://github.com/shuhei1101/mindstella/issues/85#issuecomment-6015368657) で書き足された。
表の絞り込みは [#89](https://github.com/shuhei1101/mindstella/pull/89) で入ったドロワーの種類・状態・タグだけで、列の値・ID では探せない。
全体の検索は `/` で開き、結果は種類の順に並ぶため、用語集の項目が一番下に出る。
トップバーとタブの帯は `position: sticky` だが、ページ全体がスクロールし、ボードでは帯が見えなくなる。
