## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 検索機能（ショートカット） | 文書の `keydown` で `Ctrl+K`（macOS は `Cmd+K`）を受けたら既定の動作を止めて全体の検索を開く。入力欄にフォーカスがあっても開く。`/` の処理は消す。検索が開いているときにもう一度押したら、入力欄を選び直す | トップバーの検索の入口のキーの案内を `Ctrl+K` にする |
| 検索機能（並び） | `searchItems` の結果のうち、ID かタイトルが言葉と完全に一致する項目（大文字・小文字と前後の空白を区別しない）を先頭のまとまりにし、残りは今の種類の順・ID の順で並べる。完全一致のまとまりは種類の見出しより上に出し、下の種類のまとまりには重ねて出さない | Enter で開く先頭の結果は完全一致の項目になる |
| 閲覧機能（表の絞り込み） | 絞り込みのドロワーに、列（ID・用語など）ごとに文字を入れる条件を足す。文字を入れたら、その列の値に文字を含む行に絞る（大文字・小文字を区別しない）。既存のドロワーの条件と同時にかけ、表の上のチップにも出す。列の見出しに絞り込みのボタンは置かない | `未確定`（決める段: モック作成。要件.md の案 A / B、推奨 B） |
| 画面の作り（スクロール） | `body` をウィンドウの高さに固定し、トップバー・タブの帯の下に、画面ごとにスクロールする領域を 1 つ置く。表・マップ・つながり・ボードはその領域の高さいっぱいに広げ、中で縦・横にスクロールさせる。ページ全体の縦スクロールは出さない | `100dvh` から帯と余白を引く今の高さの計算をやめる |
| 画面の作り（上の帯） | トップバーとタブの帯をスクロールする領域の外に置き、どの画面でも見えたままにする | sticky に頼らずに見えたままになる |
| 閲覧機能（本文の見出し） | 本文の見出しに、見出しの文言から作る ID と、その見出しを指すリンクを付ける。本文の中の `#見出し` のリンクと、見出しを指す URL のハッシュで、その見出しまでスクロールする | ハッシュの形はインターフェース定義『プレビューを開く』で決める |
| 閲覧機能（本文の用語） | 本文を描いた後、コードブロックと図の外の文字から、用語集の用語のタイトルを長いものから順に探して印を付ける。印にカーソルを合わせる・フォーカスするとその用語の意味をツールチップで出し、押すとその用語の詳細を開く | 用語の項目自身の本文では、その用語自身に印を付けない |
| 閲覧機能（本文の項目の ID） | 本文を描いた後、コードブロックと図の外の文字から、記録にある項目の ID をリンクにし、押すとその項目の詳細を開く | 記録に無い ID はそのまま |
| 閲覧機能（全画面表示のボタン） | 全画面表示の間はアイコンを縮小に替え、ボタンの色は変えない | `aria-pressed` は残す |
| 閲覧機能（マップの中間の層） | カテゴリー・フェーズのラベルに枠か背景を付け、線と重ならない面を持たせる | 見た目はモック作成で決める |
| 閲覧機能（詳細の全画面） | モーダルを今より大きくし、本文の幅の上限（`920px`）を外してモーダルの幅いっぱいにする。開いている間は後ろの画面のスクロールを止める | 大きさはモック作成で決める |
| アクセシビリティ | 用語の印はキーボードでフォーカスでき、フォーカスでもツールチップを出す。見出しのリンク・項目の ID のリンクはリンクとして読み上げる。全画面表示のボタンは状態に合わせて読み上げ名を替える | 動作環境の「全ての操作にキーボードで届く」 |
| 既存機能への影響 | 選んだ箇所へのコメントは、用語・ID のリンクと見出しのリンクを含む範囲を選んでも、今と同じ行・引用で添える。差分の表示の足した・消した印は、リンクを付けた後も残す | - |
