# E2E『資料を読む』のドロワーのタグの並びの期待値を日本語の順にする

## 概要

E2E『資料を読む』の `test_normal_when_main_tag_marked` のドロワーのタグの並びの期待値を日本語の順へ修正し、元のシナリオの記述を合わせて、release/v0.12.0 の該当の 1 件が通るようにする。

## 背景

[#447](https://github.com/shuhei1101/mindstella/issues/447) の E2E の fail。
[release/v0.12.0 の E2E](https://github.com/shuhei1101/mindstella/pull/438) で毎回 fail した。
ドロワーの値は `order` を持たない列で日本語の順に並ぶため、画面の並びは `画面`・`保存` で、テストは文字コードの順を期待している。
製品のコードは変えない。
