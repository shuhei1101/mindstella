## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| レスポンシブ対応 | `style.css` のトップバーの狭い幅の作り（`.comments-btn` / `.filter-btn` / `.settings-btn` の `.label` を隠す指定と、変更履歴の札の節の `.hist-btn`・`.df-chip`・`.search-trigger`・`.topbar:has(.df-chip)` の指定）を、`@media (max-width: 900px)` から `@media (max-width: 1100px)` へ移す | 1100px は詳細パネル・接続の状態の文言で使っている既存の区切り。トップバー以外の 900px の指定は変えない |
| レスポンシブ対応 | サーバーにつながらないとき（`.topbar:has(.conn)`）は、上の狭い幅の作りと、`.conn .conn-long` を隠して `.conn .conn-short` を出す指定を、`@media (max-width: 1440px)` で当てる | 今の CSS で、つながらないときは幅 1101〜1337px（差分の間は 1365px）がはみ出す。札の最小幅（`5.5em`）を入れると、つながらない＋差分のときのはみ出しは 1424px まで延びる。つながっているときの区切りは 1100px のまま |
| レスポンシブ対応 | 差分を出している間の札は、どの幅でも `5.5em` 以上を取る（`.df-chip` の `min-width: 5.5em` をメディアクエリの外へ出す）。足りない幅は題名（`.brand-sub`）の側を縮める | 札が潰れる事象への対応。幅 1101px 以上でも長い題名で札が 28px まで潰れていた |
| 既存機能への影響 | 幅 900px 以下の見た目と、つながっているときの幅 1101px 以上の札以外の見た目、ボタンの読み上げの名前は変えない | 読み上げの名前は文字を隠しても残る（部品設計『トップバー』） |
| 結合テスト | トップバーのストーリーを、部品設計『トップバー』の `FilterDiffMedium`・`FilterDiffOffline` の状態で幅 901px・963px・1100px・1101px・1440px・1441px に開き、トップバーとページが横にはみ出さないことと、札の幅が `5.5em` 以上あることを確かめる。`FilterDiffMedium` の題名を `LongTitle` の題名にして幅 1101px で開き、札の幅が `5.5em` 以上あることも確かめる | - |
