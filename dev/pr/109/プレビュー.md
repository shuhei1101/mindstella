## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| レスポンシブ対応 | 表示幅 901〜1100px で、絞り込み・表示の設定・コメントのボタンを出す画面のトップバーが幅に収まり、`document.documentElement.scrollWidth` が表示幅以下になるよう、ボタンの文字を隠す幅を広げる | `未確定`: 隠す幅の決め方（`要件.md` の `## 要望`。決める段: 部品設計） |
| レスポンシブ対応 | 差分を出している間の札は、文字を隠す幅で幅 900px 以下と同じ `5.5em` 以上を取る | 札が 12px に潰れる事象への対応 |
| 既存機能への影響 | 幅 900px 以下と幅 1101px 以上の見た目と、ボタンの読み上げの名前は変えない | 読み上げの名前は文字を隠しても残る（部品設計『トップバー』） |
| 結合テスト | トップバーのストーリーを、絞り込み・表示の設定・コメントのボタンと差分の札を出した状態で幅 901px・963px・1100px に開き、トップバーとページが横にはみ出さないことを確かめる | - |
