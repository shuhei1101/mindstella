# 幅 901〜963px でもトップバーのボタンが幅に収まり、ページが横にスクロールしないようにする

## 概要

プレビューの利用者が、表示幅 901〜963px でも横にスクロールせずにトップバーの全てのボタンを使えるようにする。

## 背景

[Issue #107](https://github.com/shuhei1101/mindstella/issues/107) の報告。
release/v0.6.0 の実機での確認で、非機能要件『画面サイズ』が不合格になった（[結果の報告](https://github.com/shuhei1101/mindstella/pull/106#discussion_r4192377535)）。
幅 903〜963px で、絞り込みのボタンを出す画面のトップバーがはみ出してページ全体が横にスクロールし、差分の時点の札が 12px に潰れる。
[#89](https://github.com/shuhei1101/mindstella/pull/89) の絞り込みのボタンと [#95](https://github.com/shuhei1101/mindstella/pull/95) の表示の設定のボタンが増えた一方、ボタンの文字を隠すのは幅 900px 以下だけのままになっている。
v0.6.0 を master へマージする前に直す。
