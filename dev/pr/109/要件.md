# 要件

## 要望

表示幅 390px 以上のどの幅でも、プレビューの全ての画面でトップバーが幅に収まり、ページ全体が横にスクロールしないようにする。

- 表示幅 901〜1100px を 1px ずつ変えて、絞り込み・表示の設定・コメントのボタンを出す画面（検討事項・タスク・資料・記録の表・つながり）と概要を開いたとき、`document.documentElement.scrollWidth` が表示幅以下になる
- 同じ幅で、トップバーの全てのボタン（右端のコメントのボタンを含む）が横にスクロールせずに見える
- 同じ幅で差分を出している間、差分の時点の札は幅 900px 以下と同じく `5.5em` 以上の幅を取り、名前が数文字読める
- 幅 900px 以下と幅 1101px 以上の見た目は今のまま変えない
- トップバーを狭い幅の作り（絞り込み・表示の設定・コメントのボタンと「変更履歴」の文字を隠し、差分の札に幅を回す）にする幅を、900px 以下から既存の区切りの 1100px 以下へ広げる
