# 要件

## 要望

E2E の補助関数から、前回開いた日時の秒を越えるまでの待ち（`wait_past_boundary`）を外す。

| 項目 | 要件 |
| --- | --- |
| 外す待ち | `tests/e2e/preview_helpers.py` の `visit_and_close` が閉じた後に呼ぶ `wait_past_boundary(opened)` と、`tests/e2e/単一ユースケース/test_diff_view.py` が直接呼ぶ 2 か所（`test_normal_when_rewritten_while_open` の `wait_past_boundary(page.evaluate(SINCE_SCRIPT, SINCE_KEY))`・`test_normal_when_first_open` の `wait_past_boundary(committed["at"])`） |
| 外せる理由 | 「前回開いてから」の範囲は、開いた時点の先頭のまとまりの `until_seq` より大きい `until_seq` のまとまりで決まる（`preview/core/diff.ts` の `resolveDiffPoint`）。開いた後の書き換えは日時の秒に関わらず範囲に入り、開く前にまとめた書き換えは範囲に入らない |
| 消すもの | 呼ぶ所が無くなる `wait_past_boundary`・`BOUNDARY_MARGIN_SEC`・`BOUNDARY_POLL_SEC`・`BOUNDARY_TIMEOUT_SEC`、`visit_and_close` の `.mindstella-opened` の読み取り、使われなくなる import と `__all__` の行 |
| 結果 | `visit_and_close` を使う E2E 1 件ごとの約 2 秒の待ちと、直接呼ぶ 2 件の待ちが無くなる |
| 確かめる中身 | `test_diff_view.py`・`test_preview_reread.py` の確かめる操作と期待値は変えない |
