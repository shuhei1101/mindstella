# E2E から、前回開いた日時の秒を越えるまでの待ちを外す

## 概要

`visit_and_close` を使う E2E が、前回開いた日時の秒を越えるまでの約 2 秒を待たずに進む。

## 背景

[#293](https://github.com/shuhei1101/mindstella/issues/293) の要望。
`tests/e2e/preview_helpers.py` の `wait_past_boundary` は、「前回開いてから」の範囲を日時で決めていたときに、後の書き換えを境目より後の秒に入れるための待ち（[PR #271](https://github.com/shuhei1101/mindstella/pull/271)）。
[PR #292](https://github.com/shuhei1101/mindstella/pull/292)（[#272](https://github.com/shuhei1101/mindstella/issues/272)）で範囲を開いた時点の通し番号で決めるようになり、この待ちは要らなくなった。
