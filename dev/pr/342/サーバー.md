## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配る書き出し | `export` が、mdmark の配布物を jsDelivr のタグを固定した GitHub の URL から取り、1 枚の HTML の中に持つ。ネットにつながらない端末で開いても本文と図が描かれる | mdmark の `index.js` は `<script type="text/plain">` に持ち、Blob の URL から `import()` で読む（PoC 結果） |
| ライセンス | 中に持つ mdmark とその同梱物のライセンス（`dist/THIRD_PARTY_LICENSES.txt`）を、今のライブラリと同じく HTML の中に入れる | - |
| 取れないとき | 今と同じく、1 回の要求で接続と 1 回の読み取りをそれぞれ 30 秒まで待ち、取れなければ何も書かずにエラーで終える | - |
| 外したライブラリ | プレビューから外したライブラリは、中に持つライブラリの一覧からも外す | - |
