# プレビューの資料とスレッドの描画を mdmark に置き換える

## 概要

利用者が、プレビューの資料の本文とスレッドの書き込みを、mdmark の記法と共通スタイルで描いたものとして読めるようになる。

## 背景

[Issue #339](https://github.com/shuhei1101/mindstella/issues/339) の要望。
プレビューの本文は marked と mermaid で描いており、スレッドの書き込みは Markdown として描かず文字のまま出している。
描画の基盤 mdmark（[shuhei1101/mdmark](https://github.com/shuhei1101/mdmark)）の見た目と部品を各リポジトリにそろえるため、mindstella の描画を mdmark に置き換える（knowledge のワークスペース `tmp/mcpベストプラクティス検討` の TH-85・TH-101）。
[#212](https://github.com/shuhei1101/mindstella/issues/212)（HTML の埋め込み・書き出し）と [#267](https://github.com/shuhei1101/mindstella/issues/267)（スレッドの AI の返信を本文と同じ描画で出す）は、この置き換えの上で進める。
