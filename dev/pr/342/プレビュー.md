mdmark の行の属性の読み替え（核心部）:

```js
const lines = source.split("\n");
for (const el of root.querySelectorAll("[data-source-line]")) {
  const start = Number(el.getAttribute("data-source-line"));
  // フェンスのコードだけ、中身がフェンスの次の行から始まる（字下げのコードは足さない）。引用・リストの中のフェンスは行頭の > とマーカーを除いて見る
  const fence = el.tagName === "PRE" && /^(?:[ \t]*(?:>|[-*+]|\d+[.)])[ \t]?)*[ \t]*(```|~~~)/.test(lines[start] ?? "") ? 1 : 0;
  el.setAttribute("data-line-start", String(start + 1 + fence));
}
```

- 配る書き出しは、今の `<script>{配布物}</script>` の形では ES モジュールを持てないため、`text/plain` で持って Blob の URL から読む形にする
- `print` は既定の描画でも `beforeprint` で DOM を変えず、止めたことの差を観測できなかった。設定で `false` にすることだけを決める
- 図は mdmark v0.7.0 が描かないため、今の mermaid で描き続ける
- フェンスの判定は、1 行目が ```` ``` ```` か `~~~` で始まる字下げのコードもフェンスと見なし、1 行後ろにずれる。単体テストにこの境界を入れ、ずれを許すかを実装照合で確かめる
