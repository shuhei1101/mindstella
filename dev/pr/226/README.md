# 差分の表示で、変わった行の中の変わった語だけを濃い背景で示す

## 概要

利用者が、プレビューの差分の表示で、変わった行の中のどの語が変わったのかを、濃い緑・濃い赤の面で見分けて読めるようになる。

## 背景

[#198](https://github.com/shuhei1101/mindstella/issues/198) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-173）。
今の差分の表示は、本文と図の Raw を行の単位（`Diff.diffLines`）で比べ、足した行・消した行の面を緑・赤にするだけで、行の中の変わった文字は示さない。
