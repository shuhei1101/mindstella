## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 行の対 | 行の差分で、消した行のかたまりのすぐ後に足した行のかたまりが続き、両方の行の数が同じとき、前から順に 1 行ずつ対にする。行の数が違うかたまりは対にしない | 関係の無い行どうしを対にしないため。数が同じでも同じ部分がほとんど無い対の扱いはモジュール構成設計で決める |
| 語の差分 | 対の 2 行を語の単位で比べ、変わった語の範囲を返す。jsdiff の語の差分に打ち切り（`timeout`）を渡し、打ち切ったら語の範囲を返さない | 語の区切り方は `未確定`（要件.md の `## 要望`） |
| 本文の差分 | 対になった消したブロックと足したブロックの描いた文字の中で、変わった語の範囲を濃い面の要素で囲む。Markdown の記法（`**` など）は描いた文字に出ないため、記法の行ではなく描いた文字どうしで比べる | 表の行・箇条書きの項目・段落・見出しを対象にする |
| 図の Raw の差分 | 対になった消した行と足した行の中の変わった語を濃い面の要素で囲む。詳細パネルと図の拡大で同じにする | - |
| 色 | 行の面より濃い足した色・消した色の面を足す。ライト・ダークの両方で文字との対比を保つ | 濃さは画面設計で決める |
| 性能 | 語の差分は対の行だけにかけ、差分の表示の切り替えの 200 ms の内訳に入れる | 非機能要件の値は変えない |
| アクセシビリティ | 語の面は色だけで示す行の面の補いで、行の +・−・下線・取り消し線は今のまま残す | - |
