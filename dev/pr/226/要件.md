# 要件

## 要望

差分の表示で、変えた行（消した行と、それに続けて足した行の対）の中の変わった語だけに、行の面より濃い色の面を付ける。
足した側は濃い緑、消した側は濃い赤の面にし、行の面（足した色・消した色）と +・−・下線・取り消し線は今のまま残す。
対象は詳細パネルの本文の差分と、図の Raw の差分（詳細パネルと図の拡大）にする。
対にならない行（足しただけの行・消しただけの行）には語の面を付けない。
語の面を付けても、差分の表示の切り替えは非機能要件『差分の表示の切り替えの時間』の決定値（200 ms）に収める。
語の差分を計算しきれないときは、語の面を付けず行の面だけで示す。

語は、jsdiff の `Diff.diffWords` に `Intl.Segmenter` の語の単位を渡して区切る（モジュール構成『差分』の `diffInline`）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| キーの差分（前の値と今の値を並べる文字列の値）の語の面 | 要望は「変わった行」で、キーの差分は行ではなく値の前後を並べる表示。今回入れる語の差分を値の前後へ当てる後続になる | [#232](https://github.com/shuhei1101/mindstella/issues/232) |
| 本文の差分を左右に並べる表示 | 別の要望で、今回は今のインラインの表示に語の面を足すだけ | [#220](https://github.com/shuhei1101/mindstella/issues/220) |
| `tests/unit/preview/test_detail.py` の `test_detail_panel_when_alias_tip`・`test_detail_panel_when_alias_tip_escape_in_full` で、型注釈の `LoadPreviewStyles` を import していない | コーディング規約（ruff の F821）から外れているが、#219 で入ったもので今回の要望に含まれない | [#231](https://github.com/shuhei1101/mindstella/issues/231) |
