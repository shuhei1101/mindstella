# HTML の本文の差分を左右に並べたとき、左の列の Markdown の本文の見出しを節の見出しの次の段から下げる

## 概要

詳細パネルで HTML の本文の差分を左右に並べ、選んだ時点の本文が Markdown のとき、左の列の本文の見出しが節の見出し「本文」の次の段から並ぶ。

## 背景

[#288](https://github.com/shuhei1101/mindstella/issues/288) の不具合。
左の列の Markdown の本文は見出しを下げずに描くため、`#` を書いた本文は節の見出し「本文」（h3）より上の段の h1 になり、外部規約『操作とアクセシビリティ』の「見出しの段を飛ばさない」から外れる。
[#266](https://github.com/shuhei1101/mindstella/issues/266)（[PR #286](https://github.com/shuhei1101/mindstella/pull/286)）の現状調査で同じ型の箇所として見つかり、切り出された。
