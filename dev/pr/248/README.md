# 差分の表示のキーの差分で、前の値と今の値の変わった語だけを濃い面で示す

## 概要

利用者が、プレビューの差分の表示で、詳細パネルのキーの前の値と今の値のどの語が変わったのかを、濃い緑・濃い赤の面で見分けて読めるようになる。

## 背景

[#232](https://github.com/shuhei1101/mindstella/issues/232) の要望。
[#226](https://github.com/shuhei1101/mindstella/pull/226)（起点 [#198](https://github.com/shuhei1101/mindstella/issues/198)）で、本文と図の Raw の変えた行の中の変わった語に濃い面が付くようになった。
一方、詳細パネルのキーの差分（`screens/detail.ts` の `keyDiff`）は前の値と今の値をそのまま並べるだけで、値の中のどの語が変わったのかは示さない。
#226 の要件.md の `## スコープ外` から切り出した。
