# インターフェース定義『記録の形式の移行』の手順を当てる流れの期待値を、.mindstella/ へ移した後のパスに揃える

## 概要

インターフェース定義『記録の形式の移行』の期待値が、記録を `.mindstella/` へ移した後のパスで書かれ、結合テスト `test_migrate.py` が確かめる内容と一致する。

## 背景

[#182](https://github.com/shuhei1101/mindstella/issues/182) の要望。
[#180](https://github.com/shuhei1101/mindstella/pull/180)（起点 Issue [#177](https://github.com/shuhei1101/mindstella/issues/177)）のレビューの対象外の逸脱の報告（[discussion_r4228984479](https://github.com/shuhei1101/mindstella/pull/180#discussion_r4228984479)）で見つかった。
v0.6.0 の手順で直下の記録を `.mindstella/` へ移すようになった後も、`正常系（手順を当てる）` の期待値は直下の `config.yaml`・`mindstella-version.ini` のパスで書かれたまま残っている。
結合テスト `test_normal_when_apply` は `.mindstella/` の下のパスを確かめており、設計書と食い違っている。
