## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `正常系（手順を当てる）` の `expected` | 資料を `.mindstella/docs.yaml`、設定ファイルを「直下に `mindmap.yaml`・`config.yaml` が無く、`.mindstella/config.yaml` が `mindmap.yaml` の中身（`field` を `playbooks` に移した後）を持つ」、`needs_values` を `.mindstella/config.yaml` の `summary`、版のファイルを `.mindstella/mindstella-version.ini` で書く | 写し（`backup.ref`）の行は変えない |
| `異常系（手順が失敗する・StepFailedError）` の `expected` | 版のファイルを `.mindstella/mindstella-version.ini` で書く | - |
| `異常系（点検に合わない・SchemaMismatchError）` の `setup`・`expected` | セットアップを `summary` を持たない `.mindstella/config.yaml` のワークスペース、版のファイルを `.mindstella/mindstella-version.ini` で書く | エラーの本文の行（`config.yaml: ` で始まる）は変えない |
