# 設計書の flow・diagram を mermaid のコードブロックで囲む（プレビューを開く・保存待ちの編集）

## 概要

設計書の `flow`・`diagram` のうち ```` ```mermaid ```` のコードブロックで囲まれていない図を、全て囲む。

## 背景

[#400](https://github.com/shuhei1101/mindstella/issues/400) の要望。
[#396 のレビュー](https://github.com/shuhei1101/mindstella/pull/396#discussion_r4450564449)で、対象外の逸脱として報告された。
テンプレート『共通』の `$defs/mermaid` は ```` ```mermaid ```` のコードブロックで記載すると定めているが、[#325](https://github.com/shuhei1101/mindstella/pull/325)・[#327](https://github.com/shuhei1101/mindstella/pull/327) で追加した図が囲まれておらず、生成した Markdown で図として描かれない。
図の中身と製品のコードは変えない。
