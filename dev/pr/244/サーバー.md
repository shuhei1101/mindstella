## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 環境変数を消す fixture | `tests/conftest.py` に、テスト全体（`session`）の `autouse` の fixture を置き、`pytest.MonkeyPatch.context()` で 3 つの環境変数を `os.environ` から消し、テストが終わった後に戻す | テスト全体で共有する `mcp_server` も `session` で、テストごとの `monkeypatch` では立ち上げの前に消せないため `session` にする |
| 消す環境変数の名前 | 3 つの名前を `tests/conftest.py` の定数の組に置く | - |
| 値を確かめるテスト | 今のまま `start_server` の `extra_env`・関数の引数で値を自分で渡す | 書き換えない |
| 消えていることの確かめ | 単体テストで、テストのプロセスの `os.environ` に 3 つの環境変数が無いことを確かめる | 3 つを設定したシェルから流して確かめる |
| 回帰 | 単体テスト作成で、単体テストの全件と、上の現状の表の結合テストを流す | - |
