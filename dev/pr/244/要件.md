# 要件

## 要望

テストは、`MINDSTELLA_PREVIEW_START_HOOK`・`MINDSTELLA_PREVIEW_STOP_HOOK`・`MINDSTELLA_ALLOWED_HOSTS` の 3 つを消した状態で走る。

- 全テスト共通の `tests/conftest.py` が、テストの始まる前に 3 つの環境変数をテストのプロセスから消す
- 消した後の環境は、テストのプロセスの中で呼ぶ関数・MCP のツールと、テストが立てる子プロセス（MCP サーバー・起動スクリプト・`claude`・tmux のペイン）の全てに効く。テスト全体で共有する MCP サーバー（`mcp_server`）にも効く
- フックと許可するホスト名を確かめるテストだけが、自分で値を渡す（`start_server` の `extra_env` などで渡す今の書き方のまま）
- 3 つの環境変数を設定したシェルからテストを全て走らせても、テストが手元のフックのコマンドを 1 度も呼ばず、結果が設定していないシェルから走らせたときと同じになる

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `MINDSTELLA_VENV` をテストから消す | 外のコマンドを呼ぶ環境変数ではなく、要望は外のコマンドを呼ぶ 3 つとそれに並ぶ許可するホスト名に限る。起動スクリプトを動かすテストは fixture `sandbox` が環境変数を組み直して渡している | 予定なし |
