# テストを手元のフックと許可するホスト名の環境変数から切り離す

## 概要

開発者が、配信の起動・終了のフックと許可するホスト名を設定したシェルからテストを走らせても、テストが外のコマンドを呼ばず、結果が手元の環境変数に左右されないようにする。

## 背景

[Issue #193](https://github.com/shuhei1101/mindstella/issues/193) の不具合。
`MINDSTELLA_PREVIEW_START_HOOK`・`MINDSTELLA_PREVIEW_STOP_HOOK`・`MINDSTELLA_ALLOWED_HOSTS` は [Issue #138](https://github.com/shuhei1101/mindstella/issues/138)（[PR #155](https://github.com/shuhei1101/mindstella/pull/155)）で足した環境変数で、MCP サーバーが起動時に読む。
テストの共有の fixture（`start_server`・`mcp_server`・`run_claude` など）は `os.environ` をそのまま子プロセスへ渡しており、手元でフックに shuhdev-gateway の `gw add` / `gw rm` を設定していたところ、テストが立てたワークスペース `workspace` のサーバー 15 件ほどがゲートウェイへ公開・取り下げされた。
