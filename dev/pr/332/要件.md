# 要件

## 要望

詳細パネルと詳細の全画面で、本文の文章か項目の値を選び終えたときに出す選んだ箇所のコメントの入口を、今のピル（幅 104px・高さ 32px）より幅の小さい見た目にし、選んだ範囲の近くの行を隠しにくい位置に出す。
選んだ範囲の文字の矩形に重ならないことは今のまま保つ。
押したときの動き（下端の入力に箇所と引用を添える）・Esc で閉じる・出す条件・押せる的の高さ 32px 以上・読み上げの名前「選んだ箇所にコメント」は変えない。

モック作成で決めた論点。

<!-- table: data -->

| 論点 | 決定 | 設計書 |
| --- | --- | --- |
| 入口を出す位置 | 選んだ範囲の始まりの上に出し、上に収まらなければ終わりの下に出す。収まるかは画面の端と本文のスクロール領域（見出しの帯の下から下端のコメントの入力の上まで）で判定する。左端は選んだ範囲の始まりの左端に揃え、左右は画面の端から 8px の内側に収める | モック『detail-panel / a-above』・『detail-full / a-above』 |
| 「コメント」の文字を入れるか | 入れない。アイコンだけの 32px の丸にし、名前「選んだ箇所にコメント」は読み上げと、乗せたとき・フォーカスしたときのツールチップで伝える | モック『selection-comment』 |
| 背景を透過にするか | 透過にしない（不透明） | モック『selection-comment』 |
| 名前のツールチップの出し方 | 入口の子の要素にし、乗せたとき・フォーカスしたときだけ CSS で選んだ範囲と反対の側に出す。入口との間を透明な領域でつなぎ、ツールチップに乗せている間も消さない | モック『selection-comment』 |
