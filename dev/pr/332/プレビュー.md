## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 入口の位置 | 選んだ範囲の始まりの上に出し、上に収まらなければ終わりの下に出す。収まるかは画面の端と本文のスクロール領域で判定し、左右は画面の端から 8px の内側に収める | 要件のモック作成で決めた論点 |
| 入口の見た目 | アイコンだけの 32px の丸で、背景は不透明。名前は乗せたとき・フォーカスしたときのツールチップで出し、ツールチップに乗せている間も消さない | 要件のモック作成で決めた論点 |
| アクセシビリティ | 読み上げの名前「選んだ箇所にコメント」・Tab で届く・Esc で閉じる・ホバーとフォーカスの見分けを保つ。文字を消すときは、乗せたときとフォーカスしたときに名前のツールチップを出す | - |
| 既存機能への影響 | 押したときの動き・出す条件・HTML の本文の枠での出し方は変えない | - |
