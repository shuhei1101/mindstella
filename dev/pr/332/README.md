# 本文を選択したときのコメントの入口を、選んだ箇所の邪魔にならない位置と見た目にする

## 概要

利用者が、詳細パネルと詳細の全画面で本文や値を選んだとき、選んだ箇所を隠さないコメントの入口から、選んだ箇所へコメントできるようになる。

## 背景

[Issue #139](https://github.com/shuhei1101/mindstella/issues/139) の要望（aituber のワークスペースの話し合いで画面から送られた送信 S-24）。
選んだ箇所のコメントの入口は [#78](https://github.com/shuhei1101/mindstella/pull/78) で入り、選んだ範囲の終わりの下に、印と「コメント」の文字を持つ幅 104px のピルを出している。
このピルが大きく、選んだ箇所の近くの本文を隠す。
