## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文のスタイル | `.md` の本文の表・見出し・コード・引用のスタイルを 1 か所にまとめ、詳細・本文の差分・配る書き出しで同じものを当てる | Pages から拾う見せ方は要件の `未確定` |
| 列の幅と折り返し | 本文を描いた後に表の列ごとのセルの最大の文字数を数え、短い・中くらい・長文の 3 つに分けて列の幅と折り返しを決める。表の幅は中身に合わせ、本文より広いときは表の入れ物の中だけで横に送る | 境目の文字数は要件の `未確定` |
| 表の列の固定 | オンのとき、列の見出しに固定のボタンを出し、押した列より左を sticky で固定する。固定した列の右端に影の線を出す | 一覧の表（`table.grid`）の固定と同じ見た目に揃える |
| 表の見出しの固定 | オンのとき、本文の区画を縦に送っても見出しの行を区画の上端に残す | 表の入れ物が横に送るため CSS の sticky では区画の上端に残せない。AI Monitor の Pages と同じく、本文の区画の送り量をスクリプトで見出しの行へ縦のずらしとして入れる |
| 表のしま模様 | オンのとき、本文の表の本体の行を 1 行おきに塗る | ライト・ダークの両方で、行のホバー・差分の印と見分けられる色にする |
| セクションの折りたたみ | オンのとき、見出しの頭に開閉の矢印のボタンを置き、その見出しの下を畳み・開ける（上位 2 つの階層だけ）。畳んだ状態は残さない | 見出しのリンク（`linkHeadings`）と、URL のハッシュで見出しへ移る動きを壊さない |
| 表示の設定 | 4 つの切り替えを区画「詳細に表示するもの」に足し、個人の上書きとして残す。「この端末で変えている項目」「既定に戻す」の対象にする | ワークスペースの既定には含めない。既定は列の固定・見出しの固定・折りたたみがオン、しま模様がオフ |
| 本文の差分 | 本文の差分の表にも同じスタイルと、表の列の固定・見出しの固定・しま模様を当てる。セクションの折りたたみは当てない。差分の印・ミニマップと重ならないようにする | 左右に並べた差分で片側だけ畳むと、変えていない塊を同じ高さで向かい合わせる並びが崩れるため |
| 配る書き出し | 配る書き出しでも同じスタイルと切り替えが当たる | 端末の保存領域に書けないときは開いている間だけ当たる（今の表示の設定と同じ） |
| アクセシビリティ | 列の固定のボタンとセクションの開閉のボタンに読み上げの名前と `aria-pressed`・`aria-expanded` を持たせ、キーボードで操作できる | - |
| レスポンシブ対応 | 幅 320px でも本文の区画を横に送らせない。狭い幅での列の固定と見出しの固定の扱いはモックで決める | 一覧の表は幅 720px 以下で固定を外している |
