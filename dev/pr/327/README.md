# Markdown の本文に共通のスタイルを持たせ、表の列の固定・見出しの固定・しま模様・セクションの折りたたみを表示の設定で切り替えられるようにする

## 概要

利用者が、プレビューで資料などの Markdown の本文を、表の列の固定・見出しの固定・しま模様・セクションの折りたたみを表示の設定で切り替えながら読めるようになる。
列が多い表も、セルが数文字ごとに折り返されて縦に伸びずに読めるようになる。

## 背景

[Issue #135](https://github.com/shuhei1101/mindstella/issues/135) の要望。
資料の Markdown の表が見にくく、AI Monitor の Pages（開発ドキュメントのサーバー）の表の見せ方を取り込みたい。
本文に独自のタグを書いて見せ方を変える方式にはせず、資料は普通の Markdown のまま保つ。
表のセルの折り返しを列の文字数で決める要望は、[Issue #135 の追記](https://github.com/shuhei1101/mindstella/issues/135#issuecomment-6090843628)（送信 S-171）。
今の本文の表は本文の幅いっぱいに広げるため、列が多いとセルが 2〜3 文字ごとに折り返される。
