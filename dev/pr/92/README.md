# プレビューの詳細パネルの本文をキーボードで送れるようにする

## 概要

利用者が、プレビューの詳細パネルと詳細の全画面で、本文の中にフォーカスできる要素が無い項目でも、キーボードだけで本文を送れるようにする。

## 背景

[Issue #88](https://github.com/shuhei1101/mindstella/issues/88) の不具合。
[#78](https://github.com/shuhei1101/mindstella/pull/78) の実装照合で、変わった画面を axe にかけて見つけた #78 の対象外の不具合。
詳細パネルと詳細の全画面の本文のスクロール領域 `.panel-body` は縦に送れるが `tabindex` を持たず、関係する項目のボタンなどフォーカスできる要素を持たない項目を開くと、キーボードだけでは本文を送れない（axe の `scrollable-region-focusable`、WCAG 2.1.1）。
非機能要件の `入力方式` は、全ての操作にキーボードで届くことを決めている。
