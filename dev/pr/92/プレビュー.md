## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文のスクロール領域 | `detailPanel` が作る `.panel-body` に `tabindex="0"`・`role="region"`・`aria-label` を付ける | パネルと全画面の両方に効く |
| 領域の名前 | 読み上げの名前は「詳細の本文」 | 画面設計の要素名と合わせる |
| フォーカスの輪郭 | `.panel-body:focus-visible` だけ、全体の `:focus-visible` の輪郭の色と太さのまま `outline-offset: -2px` で内側に描く | 外側に描くと、パネルの右辺は画面の外に出て、上辺は見出しの下線と、下辺は下端の入力と重なる。表の行（`.cat-table tbody tr[data-act]:focus-visible`）に同じ前例がある |
| フォーカスの置き場所 | パネルを開いたとき・項目を移ったとき・全画面を開閉したときのフォーカスの置き場所は変えない | Tab の順は見出しのボタンの後、本文の中の要素の前 |
| 描き直し | 本文のスクロール領域にフォーカスがあるときに詳細パネルを描き直したら（`preserving`）、描き直した後の本文のスクロール領域へフォーカスを戻す | スクロールの位置は今のとおり保つ |
| Esc | 本文のスクロール領域にフォーカスがあるときも、Esc は今のとおりパネルを閉じる・全画面から戻る | - |
| 確かめ方 | 関係する項目を持たない項目を開き、Tab で本文のスクロール領域にフォーカスして、PageDown で `scrollTop` が増えることと、axe の `scrollable-region-focusable` に当たらないことを確かめる | パネルと全画面の両方 |
