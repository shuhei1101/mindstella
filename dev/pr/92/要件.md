# 要件

## 要望

プレビューの詳細パネルと詳細の全画面で、本文のスクロール領域（見出しと下端の間のスクロールする範囲）にキーボードで届くようにする。

- 本文のスクロール領域を Tab の順に入れ、フォーカスしたら矢印・PageUp / PageDown・Home / End・Space で本文を送れる
- 読み上げで何の領域かが分かる名前を付ける
- 中にフォーカスできる要素を持たない項目（関係する項目もコメントの入力も無い項目）を開いたときも、本文のスクロール領域が axe の `scrollable-region-focusable` に当たらない
- フォーカスしたときの輪郭は、全画面で共通の `:focus-visible` の輪郭の色と太さで、領域の内側に描く
- 詳細パネルを開いたとき・項目を移ったときのフォーカスの置き場所と、Esc で閉じる・全画面から戻る今の動きは変えない

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 本文のコードブロック（`.md pre`）と図の Raw（`.dg-raw`）の横スクロール | 同じ `scrollable-region-focusable` に当たりうる箇所。中にフォーカスできる要素を持たず、長い行で横に送れるときに当たる。本文のスクロール領域にフォーカスしても横には送れない。本文のブロックごとに Tab の止まりを足すと、ブロックの多い本文で Tab の往復が増え、横に送れるときだけ止めるかの設計が要る。#88 の再現の範囲外のため含めず、横展開の残りとして起票した | [#93](https://github.com/shuhei1101/mindstella/issues/93) |
| 表・マップ・ボード・検索の結果・コメントの一覧などのそのほかのスクロール領域 | 中に行・節・カード・結果・コメントのボタンを持ち、中身があるときはフォーカスできる要素から送れる。空のときはスクロールする量が無い | 予定なし |
| 詳細の拡大表示（モーダル）の大きさ・背景のスクロール・本文の幅 | 同じ詳細の表示を触るが、本文のスクロール領域へのフォーカスとは互いを消さない | [#85](https://github.com/shuhei1101/mindstella/issues/85) |
