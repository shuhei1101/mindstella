# 要件

## 要望

移し替えの手順の並びとプラグインの版を期待する設計書とテストを、特定の版の並びで固定せず、プラグインの版（`plugins/mindstella/version.ini` の 1 行目）と移し替えの手順のフォルダ（`plugins/mindstella/skills/mindmap/migrations/` の版のフォルダ）から割り出す書き方に揃える。
次の版で移し替えの手順のフォルダを足し、`version.ini` を上げても、この PR で直す設計書の期待値とテストを書き直さずに通る状態を基準にする。

| 項目 | 要件 |
