# 移し替えの手順の並びの期待値を、プラグインの版と移し替えの手順のフォルダから割り出す

## 概要

移し替えの手順の並びとプラグインの版を期待する設計書とテストが、次の版で移し替えの手順が足されても書き直さずに通るようになる。

## 背景

[#177](https://github.com/shuhei1101/mindstella/issues/177) の要望。
[#176](https://github.com/shuhei1101/mindstella/pull/176)（起点 Issue [#169](https://github.com/shuhei1101/mindstella/issues/169)）のレビューで、特定の版の並びで手順を期待している箇所が他にもあると分かった（[discussion_r4226894530](https://github.com/shuhei1101/mindstella/pull/176#discussion_r4226894530)）。
#176 は release/v0.7.0 を止めている『話し合いのセットアップ』の 1 箇所だけを直し、手順の版を割り出す `_step_versions_after` を `test_discussion_setup.py` の中に置いた。
プラグインの版を読む `_plugin_version` は E2E の 3 ファイルに同じものがあり、[#176 のレビューの任意の指摘](https://github.com/shuhei1101/mindstella/pull/176#discussion_r4226977687)を受けて、この PR でテストの共通の置き場所へまとめる（[書き添え](https://github.com/shuhei1101/mindstella/issues/177#issuecomment-6075046850)）。
