## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文の形式の持ち方 | 資料の本文を Markdown か HTML のどちらか 1 つで持つ | `未確定`（要件の『本文の形式の持ち方』。決める段: インターフェース定義設計） |
| 項目の追加・更新 | 資料だけ HTML の本文を受ける。資料以外の種類に HTML の本文を渡したときはエラーで返す | 形式を変えた更新は、前の形式の本文のファイルを消し、本文の差分は変更履歴に残す |
| 項目の表示・記録の取得 | HTML の本文も Markdown の本文と同じく返し、形式も読めるようにする | - |
| 項目の削除 | HTML の本文のファイルも消す | - |
| 点検 | `missing_body`・`orphan_body` の対象に HTML の本文を足す | - |
| 書き換えの知らせ | 見ているファイルの印に HTML の本文を足す | - |
| 選んだ箇所の照らし合わせ | HTML の本文も本文の行の範囲で照らす | `未確定`（要件の『HTML の本文で選んだ箇所を本文の行にする方法』。決める段: PoC 検証） |
| 配る書き出し | HTML の本文も埋め込む | 描き方はプレビューの計画書 |
| セキュリティ | HTML の本文はファイルに書くだけで、サーバーは中身を解釈・実行しない | 描くときの無害化はプレビューの計画書 |
| 既存のワークスペース | 今の Markdown の資料はそのまま読め、移し替えの手順を足さない | - |
