## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| HTML の本文の描画 | 詳細パネル・詳細の全画面で、HTML の本文を `sandbox="allow-same-origin"`（`allow-scripts` なし）の iframe の `srcdoc` に描き、`ResizeObserver` で高さを中身に合わせる | PoC で成立 |
| 選んだ箇所のコメント | 親の画面が iframe の文書に `pointerup`・`selectionchange` の受け手を足し、サーバーが足した行の印から選んだ範囲を本文の行の範囲の箇所にしてコメントの入口へ渡す。入口の位置は iframe の中の矩形に iframe の位置を足す | PoC で成立 |
| 形式のバッジ | 資料のカード・ボード・表と詳細のヘッダーに、本文が Markdown か HTML かのバッジを出す | 文言・位置はモック作成で決める |
| 変更履歴・差分 | HTML の本文の差分を見せる | `未確定`（要件の『HTML の本文の差分をどう見せるか』。決める段: モック作成） |
| 全体の検索 | HTML の本文はタグを除いた文で当てる | - |
| 配る書き出し | ネットにつながらない端末でも、HTML の本文を詳細で描ける | 本文が外の画像・CSS を読むときは、その端末で読めないままでよい |
| セキュリティ | HTML の本文は記録の持ち主が書いたものとして扱い、画面の記録・操作・保存領域へ触れさせない | 非機能要件のセキュリティの決定値を見直す |

結論: 成立。
HTML の本文は `sandbox="allow-same-origin"` の iframe に描き、本文のスクリプトは動かさずに、親の画面から選択・位置・高さを読める。
`allow-scripts` を付けずに親の realm から足した受け手は呼ばれるため、選んだ箇所のコメントの入口は iframe の文書にも受け手を足せば出せる。
テストで気をつけること: sandbox の iframe の上では Playwright の `page.mouse` と `scroll_into_view_if_needed` が返らなかった。マウスで選ぶ操作は CDP の `Input.dispatchMouseEvent` で送り、位置は親の画面のスクリプトで求めた（[計測の結果](https://github.com/shuhei1101/mindstella/blob/e6de8392a2c9f50275c964ed5899e410f2549b9b/poc/html-body/out/result.json)）。

最小再現コードの要点（`poc/html-body/harness.js`）:

```js
const frame = document.createElement("iframe");
frame.setAttribute("sandbox", "allow-same-origin");
frame.addEventListener("load", () => {
  const doc = frame.contentDocument;
  doc.addEventListener("pointerup", onSelect);
  doc.addEventListener("selectionchange", onSelect);
  new ResizeObserver(() => { frame.style.height = `${doc.documentElement.scrollHeight}px`; }).observe(doc.documentElement);
});
frame.srcdoc = annotatedHtml;

function selectionRect(frame) {
  const inner = frame.contentWindow.getSelection().getRangeAt(0).getClientRects()[0];
  const outer = frame.getBoundingClientRect();
  return { left: outer.left + frame.clientLeft + inner.left, top: outer.top + frame.clientTop + inner.top };
}
```

diff の見どころ: `harness.js` の `locate`（行の印を持つ最も近い要素からの改行に、コメントの中の改行も足す）と、`run.py` の `check_events`（CDP で送るマウスの入力）。
