# 資料の本文を HTML でも書けるようにする

## 概要

AI が資料の本文を HTML でも書け、利用者がモックや図のような見た目のある資料を、Markdown の資料と同じく詳細・拡大表示で開いて選んだ箇所へコメントできるようになる。

## 背景

[Issue #151](https://github.com/shuhei1101/mindstella/issues/151) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-53）。
資料の本文は `docs/{ID}.md` の Markdown だけで、画面は marked で描いて DOMPurify で無害化して出すため、見た目のある資料を作れない。
起点 Issue への追記（送信 S-200・S-211）は [書き直しの判断](https://github.com/shuhei1101/mindstella/issues/151#issuecomment-6096028058) で [#212](https://github.com/shuhei1101/mindstella/issues/212) へ分け、HTML の資料の共通の基盤と作り方の手順書は [#213](https://github.com/shuhei1101/mindstella/issues/213) が持つ。
