# 検討事項に選択肢を必須にし、推奨・採用と状態の連動・詳細の並びと本文の描画を直す

## 概要

利用者が、検討事項の案と AI の推奨を詳細パネルで見比べてすぐ答えられ、案を採用した検討事項は決定済みとして記録される。

## 背景

[#86](https://github.com/shuhei1101/mindstella/issues/86) の要望。手元の aituber の設計のワークスペースを使っていて出た。
今の検討事項は案（`options`）を持たなくても書き込め、問いだけを出されると答えづらい。
AI が推す案を記録する項目が無く、`adopt` は採用する案だけを切り替えて状態を変えないため、採用の印があるのに未決定のままの検討事項ができる。
詳細パネルは決定内容と理由を案の上に出し、リード・決定内容・理由などの文字列を Markdown として描かない。
取り込みの手順で検討事項に案を書くことは [#50](https://github.com/shuhei1101/mindstella/issues/50) で入っている。
