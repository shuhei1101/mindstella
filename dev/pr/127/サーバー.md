## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 検討事項の形 | `options` を必須の対象の状態で 1 つ以上にする。案ごとに推奨の印（真の案は 0 か 1 つ）を足す | 必須の対象の状態は `未整理`・`対象外`・`取り下げ` を除く状態（[要件](./要件.md)） |
| 書き込みの検査 | `add`・`update`・`batch`・`edit_option` で、案を持たない検討事項・採用した案を持たない `決定済み` の検討事項・採用した案を持つ `未決定` の検討事項を、書き込む前にエラーで返す。`edit_option` は最後の案を消すとエラー | エラーの本文に検討事項の ID と直し方を書く |
| 採用と状態 | `adopt` は採用する案を切り替え、状態を `決定済み` にする。答え（`answer`）は今と同じく変えない | 方針転換の手順は `answer` を `update` で直す |
| 推奨の書き換え | `edit_option` の渡せるキーに推奨の印を足す。印を立てた案のほかの案の印は外す | `adopt` と同じく 1 つに切り替える |
| 点検 | `check` で、案を持たない検討事項・採用した案を持たない `決定済み` の検討事項・採用した案を持つ `未決定` の検討事項を問題として返す | |
| 移し替えの手順 | このスプリントの版の手順を足し、既存の検討事項を要件の形へ直す | `決定済み` は答えから採用した案を作り、残りは移し替えのスキルが直す（[要件](./要件.md)） |
