## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 取り込み | 検討事項は必ず案を書いて足し、未決定なら推奨の印を付ける。決めたこととして足すときは選ばれた案を採用にし、状態を `決定済み` にする | 未整理の扱いは必須の対象の状態に合わせる |
| ヒアリング | 聞く前に推奨を記録し、案の表の推奨と揃える。答えを受けたら `adopt` で採用し、`answer`・`reason` を書く | 案の無い検討事項を `update` で書き足す手順は、案が必須になり不要になる |
| 方針転換 | `adopt` で状態が `決定済み` になることに合わせて文を改める | |
| 移し替え | 移し替えの直し方に合わせて、案を持たない検討事項を直すステップを足す | 直し方は `未確定`（[要件](./要件.md)） |
| ツールの表 | `edit_option` の `option` のキーに推奨の印を足す | |
| 質問の書式 | 表の下の `推奨:` の記号を、写す先の案の推奨の印に対応づける | 取り込みとヒアリングはこの決まりで推奨を記録する |
