## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 検討事項の並び | タイトル → 背景（`lead`）→ 案（内容・メリット・デメリット・推奨の印）→ 採用した案と理由（`answer`・`reason`）→ 本文 → 関係する項目 | 並びと推奨の印の見た目はモック作成で決める |
| 推奨の印 | 推奨の印を持つ案のカードに印を出す。採用した案があるときは採用の表示を優先する | 一覧の画面に出すかはスコープ外（[要件](./要件.md)） |
| 文字列の描画 | 詳細パネルが出す文字列の値を、本文と同じ Markdown の描画（無害化を含む）で描く | 値のコメント・選んだ箇所のコメント・差分の表示が値のキーで指す仕組みを保つ |
