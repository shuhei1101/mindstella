# E2E『項目の詳細を読む』の html のコードブロックのテストで、詳細パネルで下げた後の段に依らず本文の見出しを確かめる

## 概要

E2E『項目の詳細を読む』の html のコードブロックのテストが、詳細パネルで下げた後の見出しの段に依らず、コードブロックの前後の見出しが描かれることを確かめて通るようにする。

## 背景

[#276](https://github.com/shuhei1101/mindstella/issues/276) の不具合。
release/v0.8.0 の E2E で `test_normal_when_html_code_block` が fail した（[#194 の実行の結果](https://github.com/shuhei1101/mindstella/pull/194#discussion_r4285228807)）。
詳細パネルは本文の見出しを `lowerHeadings()` で下げて描くため、本文の `# 見出し` は h1・h2 にならず、テストの `aside.panel .md h1, aside.panel .md h2` が 0 件になる。
テストは [#214](https://github.com/shuhei1101/mindstella/pull/214) で足され、そのマージの時点から fail している。
