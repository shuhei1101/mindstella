# 画面から送ったコメントを、起動スクリプトが立てた tmux のセッションの Claude Code へすぐに入力する

## 概要

利用者がプレビューでコメントをまとめて送ると、その内容が起動スクリプトの立てた tmux のセッションの Claude Code へ文字列としてすぐに入力される。

## 背景

[#117](https://github.com/shuhei1101/mindstella/issues/117) の不具合。
起動スクリプトで立てた tmux のセッションで `/mindstella:session` を始めた後に画面からコメントを 4 件送ると、画面には「4 件を送りました」と出るが、Claude Code の会話には何も入らなかった。
まとめて送る処理は `submissions.yaml` に書き足すだけで、`session` は話し合いの最初に 1 回だけ送信を拾うため、話し合いの途中で送ったコメントは AI が改めて `submissions` を呼ぶまで取り込まれない。
送信を tmux のセッションの Claude Code へ送る項目は [#10](https://github.com/shuhei1101/mindstella/issues/10) のスコープに残っていたが、作業 PR [#165](https://github.com/shuhei1101/mindstella/pull/165) でユーザーが不具合として #117 で扱うと決め、スコープ外へ回した。
