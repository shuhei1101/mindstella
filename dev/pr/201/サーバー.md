## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 入力の時点 | まとめて送る処理が `submissions.yaml` と `comments.yaml` を書き終えた後に、足した送信を tmux のペインへ入力する。書き込みの鍵を持ったまま tmux を待たない | 送り先は要件の `未確定`（インターフェース定義設計） |
| 複数行の本文 | 改行で入力が確定されないよう、ペーストとして貼ってから確定のキーを送る | 使う tmux のコマンドは PoC 検証で確かめる |
| 入力の失敗 | 送り先のペインが無い・tmux が失敗した・時間内に終わらないときは、送信を残したまま 201 を返し、入力しなかったことを応答に載せる。ログに理由を残す | 待つ上限はインターフェース定義設計で決める |
| 応答 | `POST /api/comments/send` の 201 の本文に、Claude Code へ入力したかを足す | プレビューの「送った結果」の出し分けに使う |
| 二重の取り込み | 入力した送信も `taken` は空のまま残し、AI が取り込んだときに `take_submission` で取り込み済みにする。話し合いの最初の取り込みは `taken` が空のものだけを拾う | 既存の取り込み済みの仕組みを使う |
