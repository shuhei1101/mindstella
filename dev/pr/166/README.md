# メンバーと役割（任意のオーナー・管理者・メンバー）と、パスワードのログインを足す

## 概要

ワークスペースにメンバーと役割（オーナー・管理者・メンバー）を持たせ、社内のサーバーで共有するときにパスワードでログインして使えるようにする。
メンバーを登録しないひとりの利用は、今と同じくログインなしで使える。

## 背景

[#25](https://github.com/shuhei1101/mindstella/issues/25) の要望。
今の配信は `127.0.0.1` だけで待ち受け、開けた人を見分けない（[#67](https://github.com/shuhei1101/mindstella/issues/67) の要件）。
外の入口の内側から開く使い方は [#138](https://github.com/shuhei1101/mindstella/issues/138) で入り、外から開く画面の認証は外の入口に任せている。
`config.yaml` の既定を画面から書き換える口は [#24](https://github.com/shuhei1101/mindstella/issues/24) で入り、開けた人は誰でも書ける。
共有サーバーを複数の人で使う要望（[#14](https://github.com/shuhei1101/mindstella/issues/14)）と、タスクの担当・レビュアー（[#26](https://github.com/shuhei1101/mindstella/issues/26)）は、この PR のメンバーを前提にする。
