# 部品設計の外の設計書で、実装済みの項目の状態を implemented に揃える

## 概要

部品設計の外の設計書で、実装済みの項目の `status` を `planned` から `implemented` に揃える。

## 背景

[Issue #287](https://github.com/shuhei1101/mindstella/issues/287) の要望で、[PR #285](https://github.com/shuhei1101/mindstella/pull/285)（[Issue #264](https://github.com/shuhei1101/mindstella/issues/264)）の Issue 受付でスコープ外として切り出した。
テンプレート『共通』の `status` は `planned` が予定、`implemented` が実装済みで、部品設計の分は PR #285 で揃えたが、画面設計・モジュール構成・インターフェース定義・設定・アーキテクチャ図・外部ライブラリ・非機能要件には、実装した PR で `implemented` にしないまま `planned` が残った項目がある。

## 計画書

| ファイル | 中身 |
| --- | --- |
| [要件](./要件.md) | 要望の整理と影響する UC 一覧 |
| [プレビュー](./プレビュー.md) | プレビューの画面設計・モジュール構成の `status` を揃える計画書 |
| [サーバー](./サーバー.md) | サーバーのインターフェース定義・設定・アーキテクチャ図・外部ライブラリ・非機能要件の `status` を揃える計画書 |
