# 要件

## 要望

本文の印のツールチップの結合テスト `test_body_alias_tooltip_scroll`（`tests/integration/preview/test_detail_panel_screen.py`）を、同じコードなら毎回同じ結果にする。

| 項目 | 要件 |
| --- | --- |
| 原因 | 本文を送った直後に本文の上のどの要素の高さが変わって `scrollTop` がずれるかを突き止め、完了報告に書く |
| 結果の揃い方 | 直した後、このテストだけを 20 回続けて流して 20 回とも pass する |
| 確かめる中身 | 印の上に収まらない項目の多いツールチップを印の下に 6px 空けて出し、最大の高さ 360px で止め、中をスクロールして末尾の調査まで読め、後ろの本文を送らないことを確かめ続ける。確かめる操作と期待値を減らさない |

直す場所はテストの送り方・待ち方だけにし、ツールチップと詳細パネルの実装は変えない。
本文を送る位置は、送った後の上の要素の高さの変わり方によらず、印が本文の領域の中に見えたまま、印の上の余白がツールチップの高さより狭くなる位置にする。
