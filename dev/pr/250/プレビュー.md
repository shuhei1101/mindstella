## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の切り分け | このテストを続けて流して fail を再現し、送った直後と hover の直前の `scrollTop`・本文の領域の上端・印の位置を記録して、高さが変わる要素を突き止める | - |
| テストの送り方 | `scrollTop` の固定値に代えて、本文の上の要素の高さが落ち着くのを待ってから、印の位置から送る量を求めて、印が本文の領域の中に見えたまま上の余白がツールチップの高さより狭くなる位置に送る。hover の直前に印が本文の領域の中にあることを確かめる | - |
| 確かめる中身 | `before`（下に 6px・高さ 360・中でスクロール・`overflow-y: auto`・`overscroll-behavior-y: contain`）と `after`（末尾の `R-1` まで読め、本文を送らない）の期待値は残す。`body_scrolled == 300` は送った位置を求める形に合わせて書き換える | - |
| ツールチップと詳細パネルの実装 | 変えない。印が見えない位置で乗せたときに Playwright が印を見える位置まで送るのはテストの操作の側の挙動で、実装は本文を送らない | - |
| 既存機能への影響 | `test_detail_panel_screen.py` のほかの結合テストは変えずに pass させる | - |
