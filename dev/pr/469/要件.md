# 要件

## 要望

親 [#365](https://github.com/shuhei1101/mindstella/issues/365) の決定（D-8・D-13・D-14・D-16・D-20〜D-23）と、[#429](https://github.com/shuhei1101/mindstella/pull/429)・[#444](https://github.com/shuhei1101/mindstella/pull/444) で配置した React の土台と画面の決まり（モジュール構成『プレビュー / React』）に従い、親の分割の子 4 の画面と部品を React へ移行する。
子 6（[#371](https://github.com/shuhei1101/mindstella/issues/371)）で切り替えるまで、今の画面（`/mindstella.html`）とその部品・ストーリー・テストはそのまま配信し、動かし続ける。

| Issue | 終わりの条件 |
| --- | --- |
| [#369](https://github.com/shuhei1101/mindstella/issues/369) | コメントの一覧・スレッド・レビュー中の書き込みの画面と、選んだ箇所のコメントの入口・コメントの入力・返信の入力が React へ移り、表示の設定のパネルと既定の保存の確かめのモーダルが React へ移り、既存の機能が失われずに再現されている（D-23） |

<!-- table: data -->

| 対象 | 要件 |
| --- | --- |
| コメントの一覧 | 画面設計『コメントの一覧』の要素と操作（状態とタグでの絞り込み・スレッドの行・新しいスレッドの入力・ピン止め・未読の印）を全て再現する。見た目は shadcn/ui・Tailwind とデザイン方針のトークンに合わせて一新してよい |
| スレッド | 画面設計『スレッド』の要素と操作（書き込みと状態の変更の記録の並び・返信をレビュー中に溜める・クローズとオープンへの戻し・開いたときの利用者の既読）を全て再現する |
| レビュー中の書き込み | 画面設計『レビュー中の書き込み』の要素と操作（新しいスレッドと返信の並び・書き換え・削除と元に戻す・チェックしたものをまとめて送る・箇所が合わない書き込みの表示）を全て再現する。レビュー中のコメントの並びの昇順・降順（[#140](https://github.com/shuhei1101/mindstella/issues/140)）と長い本文の折りたたみ（[#331](https://github.com/shuhei1101/mindstella/issues/331)）も再現する |
| 詳細のコメント | 詳細パネル・詳細の全画面の下端のコメントの入力と、本文の文章か項目の値を選んだときの選んだ箇所のコメントの入口・レビュー中のコメントの一覧を、今の画面を開くリンクから React の部品へ置き換える（画面設計『詳細パネル.tsx』『詳細の全画面.tsx』） |
| 部品 | 部品設計『コメントの入力』『選んだ箇所のコメントの入口』『スレッドの行』『スレッドの書き込み』『返信の入力』『本文の折りたたみ』『表示の設定』『既定の保存の確かめ』の引数・イベント・状態を全て再現する |
| 書きかけ | コメントと返信の入力欄の書きかけを、今の画面と同じく向けた先ごとに `PUT /api/drafts` で保ち、開き直したときに戻す |
| 表示の設定 | 画面設計『表示の設定』『既定の保存の確かめ』の要素と操作（表示する種類のこの端末だけの上書き・既定に戻す・ワークスペースの既定として保存する前の確かめ・設定の画面への入口）を全て再現する。上書きは今の画面と同じ `localStorage` のキーと値の形で読み書きする |
| 画面の状態 | コメントの一覧・スレッド・表示の設定のパネルを開いているかと、開いているスレッドを、TanStack Router の `validateSearch` + Zod で URL の search に持つ（値の形はインターフェース定義設計で決める） |
| トップバー | コメントのボタンと表示の設定の入口から、今の画面を開かずに React の画面のパネルを開く |
| API | 移す画面が呼ぶ配信の API のうち OpenAPI の定義に無いもの（`POST /api/comments`・`PATCH`/`DELETE /api/comments/{id}`・`PUT /api/drafts`・`POST /api/comments/send`・`PATCH /api/threads/{id}`・`POST /api/threads/{id}/seen`・`PUT /api/config/display`）を定義に追加し、orval で生成する。サーバーの API の振る舞いは変えない |
| Storybook | 移す部品の状態ごとのストーリーを `@storybook/react-vite` の設定に追加する。データは MSW と props で差し込む |
