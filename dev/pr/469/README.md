# コメントの一覧・スレッド・レビュー中の書き込みと、表示の設定・既定の保存を React へ移行する

## 概要

コメントの一覧・スレッド・レビュー中の書き込みの画面と、詳細のコメントの入力・選んだ箇所のコメントの入口・返信の入力、表示の設定のパネルと既定の保存の確かめのモーダルを React へ移行する。

## 背景

[#369](https://github.com/shuhei1101/mindstella/issues/369) の要望で、親 [#365](https://github.com/shuhei1101/mindstella/issues/365) を分割した子 4。
子 1（[#366](https://github.com/shuhei1101/mindstella/issues/366)・[#429](https://github.com/shuhei1101/mindstella/pull/429)）の React の土台と、子 2・子 3（[#367](https://github.com/shuhei1101/mindstella/issues/367)・[#368](https://github.com/shuhei1101/mindstella/issues/368)・[#444](https://github.com/shuhei1101/mindstella/pull/444)）で移した一覧と詳細の画面の上に、今は今の画面（`/mindstella.html`）を開いているコメントと表示の設定を移行する。
移行を終えるまでは今の画面を配信し続け、子 6（[#371](https://github.com/shuhei1101/mindstella/issues/371)）で切り替える。
