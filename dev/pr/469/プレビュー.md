## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 画面の状態 | コメントの一覧・スレッド・表示の設定のパネルを開いているかと、開いているスレッドを `validateSearch` + Zod の search に持つ | インターフェース定義『SPAを開く』 |
| フォルダ構成 | 画面を `features/{domain}/{screen}/` に、複数の画面が使用する部品（コメントの入力・本文の折りたたみほか）を `shared/components/` に配置する | モジュール構成『プレビュー / React』と knowledge の規約『フォルダ構成』 |
| コメントの一覧・スレッド・レビュー中の書き込み | 今の画面の要素と操作を、`GET /api/threads`・`GET /api/comments` の query と、追加・書き換え・削除・送信・状態の書き換え・既読の mutation で組む。書き換えの知らせを受けたら再取得する | 書き換えの知らせへの接続は今の `app.tsx` のとおり |
| 詳細のコメント | 詳細パネル・詳細の全画面の今の画面を開くリンクを、コメントの入力と選んだ箇所のコメントの入口・レビュー中のコメントの一覧に置き換える。選んだ箇所は mdmark が描いた本文から、今の画面と同じ箇所のスキーマで取得する | 箇所のスキーマを mdmark に合わせるのは `要件.md` の `## スコープ外` |
| 書きかけ | 入力欄の書きかけを向けた先ごとに `PUT /api/drafts` で保ち、`GET /api/comments` の書きかけから戻す | - |
| 表示の設定 | 表示する種類の上書きを今の `localStorage` のキーで読み書きし、既定の保存は確かめのモーダルで確認した後に `PUT /api/config/display` を呼ぶ。設定の画面への入口を配置する | `use-visible-kinds` と `prefs-store` を使用する |
| トップバー | コメントのボタンと表示の設定の入口で、今の画面を開かずに search のパネルを開く | - |
| API | 移す画面が呼ぶ API を OpenAPI の定義に追加し、orval で hook・Zod・MSW を生成し直す | サーバーの振る舞いは変えない |
| Storybook | 移す部品の状態ごとのストーリーを追加し、画面の本体のストーリーは MSW の handler でデータを差し込む | knowledge の規約『Storybook』 |
| アクセシビリティ | Storybook の addon-a11y と、結合テストの Playwright の axe で WCAG の違反を検査する | - |
| 既存機能への影響 | 今の画面・部品・ストーリー・テストは触らない | 子 6 で削除する |

## 実装

実装で設計書と変わった点（モジュール構成へ反映した）:

- `shared/components/post-body.tsx`・`shared/core/post-links.ts`（書き込みの本文の描画と、項目の ID のボタン・まとまりのリンク）、`features/comments/shared/thread-state.tsx`（状態の札・レビュー中の印・未読の札）・`review-edit-form.tsx`（レビュー中の書き込みの修正）・`use-comment-data.ts`（コメントの画面が読む値）を追加した
- `shared/stores/theme-store.ts` に、既定に戻すでライト / ダークの上書きを外す `clearTheme` を追加した
- `useSaveDraft` が返す関数に、入力欄を離れたときに待たずに送る `now` の引数を足した
- 画面設計『表示の設定.tsx』の「既定が変わった知らせ」は、パネルを開いていなくても出すため、状態を `shared/stores/display-notice-store.ts` に置き、外枠が記録の `settings.display` の変化を比べて呼ぶ。自分が既定にした値は `useSaveDisplayDefault` の `onMutate` で控えて知らせない
- `useMarkThreadSeen` の失敗時の読み直しは、スレッドの query を画面が読んでいない間も戻すため `refetchQueries` にした
- 単体テスト作成の工程でモジュール構成に足した `test_files` は、スキーマが `tests/` の下しか許さず検査を通らないため戻した（[e0151fbb](https://github.com/shuhei1101/mindstella/commit/e0151fbb)）。既存の React の設計書と同じく、置き場所は `notes` の `単体テスト` に書いてある
