# ワークスペースの直下に README を置き、コマンドの一覧とプレビューの URL を案内する

## 概要

利用者が、ワークスペースのフォルダを開いたときに、直下の README から、そのフォルダの起動・接続のコマンドとスキルの呼び方、記録を見るプレビューの URL を引けるようになる。

## 背景

[#103](https://github.com/shuhei1101/mindstella/issues/103) の要望。
[#102](https://github.com/shuhei1101/mindstella/pull/102)（[#46](https://github.com/shuhei1101/mindstella/issues/46)）で記録を全て `.mindstella/` にまとめ、直下には `.mindstella/` だけが残る形になった。
直下に画面の HTML を置く案は、画面はサーバーの配信で見るため採らず、代わりに直下へ README を置いてサーバーへのアクセス方法を書く方向が[ユーザーの返信](https://github.com/shuhei1101/mindstella/pull/102#discussion_r4190862782)で示された。
プレビューは `preview_url` が `127.0.0.1` の空きポートで立てるため、URL は起動のたびに変わり、フォルダの中からは開き方が分からない。
