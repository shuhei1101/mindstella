## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| README の書き出し | `create_workspace` が `.mindstella/config.yaml` を書いた後に、直下へ `README.md` を書く。`files` に `README.md` を足す | 既に `README.md` があれば書き換えず、`files` にも載せない |
| 書けないとき | `README.md` を書けなければ `WriteFailedError` にし、作った `.mindstella/` と `README.md` を消す（前からあったファイルは消さない） | 今の `init` の失敗時の扱いに合わせる |
| README の文面 | プラグインに雛形のファイルを持ち、`init` と移し替えが同じ雛形から書く | 置き場所はモジュール構成設計で決める。文面は要件の `未確定` |
| 記録の扱い | `README.md` はどのツールも読まず、`check` の対象にしない。ワークスペースの見分けは `.mindstella/config.yaml` のまま | ER図『ワークスペース』に直下のファイルとして載せる |
| 既にあるワークスペース | `migrations/v0.7.0/steps.yaml` の `call`（`workspace_readme`）で、直下に `README.md` が無ければ雛形から書く | - |
| プラグインの版 | `plugins/mindstella/version.ini` を `v0.6.0` から `v0.7.0` に上げる | 上げないと v0.7.0 の手順が並ばず、v0.6.0 のワークスペースが移し替えに進まない |
