## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| README の中身 | 新しいモジュール `scripts/readme.py` が、自動で書いた印・プレビューの URL・コマンド（起動・接続・セッション・セットアップ・アップグレード。太字の見出し・短い説明・`bash` のコードブロック）・公開ドキュメントへのリンクを組み立てる | 形はインターフェース定義『README の書き出し』の制約。プラグインのフォルダは動いている `server.py` の場所から、セッションの名前は `launch.py` の `session_name` から引く |
| 書くかの判定 | 直下に `README.md` が無いか、1 行目が自動で書いた印のときだけ書く | 利用者が書いた README は書き換えない |
| 作るとき | `create_workspace` が `config.yaml` を書く前に README を書き、書いたら `files` に `README.md` を足す | 書けなければ `WriteFailedError` にし、作ったものとこの呼び出しで書いた README を消す |
| 話し合いの始め | MCP のツール `readme` を足し、`/mindstella:session` の準備で版の比較が `same` のときに呼ぶ | `allowed-tools` に `mcp__mindstella__readme` を足す。前から使っているワークスペースもここで置かれる |
| プレビューの URL | `preview_url` が配信を立てた呼び出しで、README を URL つきで書き直す | 書けなくても配信は止めず URL を返す。`readme` は `PreviewRegistry.url_of` で配っている URL を引く |
| 記録の扱い | `README.md` は印の確かめのほかにどのツールも読まず、`check` の対象にしない。ワークスペースの見分けは `.mindstella/config.yaml` のまま | ER図『ワークスペース』に直下のファイルとして載せる |
