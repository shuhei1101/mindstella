# 『前回からの差分を見る』の保持する回数 0 のシナリオとテストで、足した検討事項の ID を準備に揃える

## 概要

シナリオ『前回からの差分を見る』の `正常シナリオ（保持する回数が 0）` とその E2E テストで、準備に置く検討事項と、後から足す検討事項の ID を揃える。

## 背景

[Issue #99](https://github.com/shuhei1101/mindstella/issues/99) のテスト不備。
release/v0.5.0（`03a3589`）の E2E（[#97 の実行の結果](https://github.com/shuhei1101/mindstella/pull/97#discussion_r4182801758)）で、`tests/e2e/単一ユースケース/test_diff_view.py::test_normal_when_history_limit_zero` が fail した（表の印が `{"D-3": None, "D-6": MARK_NEW}` の期待に対して `{"D-3": None, "D-4": "df-mark df-new"}`）。
準備は検討事項 D-3 だけで、`add` が足す検討事項は D-4 になるが、シナリオとテストは D-1〜D-5 を持つ `正常シナリオ` の前提を写して D-6 を待っている。
シナリオとテストは [#79](https://github.com/shuhei1101/mindstella/pull/79) で入った。
直さないと v0.5.0 を master へ入れられないため、release/v0.5.0 を base にする。
