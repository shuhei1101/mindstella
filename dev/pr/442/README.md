# リポジトリの文書とコードを dev-docs に掲載し、タグ・概要文・関連で検索できるようにする

## 概要

エージェントが、mindstella のリポジトリの Markdown とソースコードを、dev-docs の `search_docs` でタグ・概要文・関連から検索できるようになる。

## 背景

[Issue #373](https://github.com/shuhei1101/mindstella/issues/373) の要望。
設計書の YAML と目次は [#395](https://github.com/shuhei1101/mindstella/pull/395)・[#397](https://github.com/shuhei1101/mindstella/pull/397) で dev-docs の配信元 `mindstella` に掲載済みだが、Markdown（`docs/` の利用者向けのページ・スキルの手順・`デザイン方針.md`）とソースコードは掲載されておらず、どの文書にもタグが無い。
管理用の YAML（`files.yaml`）の列と関連の入れ方は、依存の [shuhei1101/dev-docs#34](https://github.com/shuhei1101/dev-docs/issues/34) で dev-docs に入った。

## 計画書

| --- | --- |
