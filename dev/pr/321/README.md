# 差分のミニマップの印の無い所を押す結合テストを、送った位置のずれで fail しないようにする

## 概要

差分のミニマップの帯の印の無い所を押す結合テスト `test_diff_minimap_when_empty_area_pressed` が、押した位置に見合う送りを確かめて pass する。

## 背景

[Issue #319](https://github.com/shuhei1101/mindstella/issues/319) の不具合。
帯の中ほどを押した後の本文の送りが `assert 711 == 714.0 ± 2` となり、develop で fail している。
[#318](https://github.com/shuhei1101/mindstella/pull/318) の結合テスト作成で見つかった。
