develop（481718f4）で押した位置と受け取った位置を測ると、帯の上端 145px・高さ 523.875px の中ほど 406.9375px を押し、`click` の `clientY` は 406 だった。
`clientY` が整数に切り捨てられた 0.94px が、帯の高さに対する本文の全体の高さ（1952px）の比 3.7 倍で送りへ広がり、`scrollTop` が 711（期待値 714）になる。

## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 押す位置 | `press_empty_area` は、帯の上端から `offset_y` の位置を整数の画面の座標に丸めて押し、押した座標を返す | `test_open_preview.py` の呼び出しは戻り値を使わない |
| 期待値 | 中ほどを押した後、見えている範囲の面の中央（`viewTop + viewHeight / 2`）が押した座標から `MINIMAP_TOLERANCE_PX` 以内にあることを確かめる | 上端に近い所を押した後の大小の確かめ・履歴とハッシュの確かめは変えない |
| 既存機能への影響 | 製品のコードと `MINIMAP_TOLERANCE_PX` の値は変えない | - |
