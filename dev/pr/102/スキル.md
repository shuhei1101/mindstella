## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定と YAML の置き場所 | 手順とインターフェース定義が Read で読む `config.yaml`・`decisions.yaml` のパスを、サブフォルダの下に改める | 手順の流れは変えない |
| setup の振り分け | サブフォルダの `config.yaml` を読めれば既存のワークスペース、直下の `config.yaml` か `mindmap.yaml` だけを読めれば版が古いワークスペースとして移し替えを案内する | |
| upgrade の入口 | 入口の条件を、サブフォルダの `config.yaml` か、直下の `config.yaml`・`mindmap.yaml` を読める、にする | 移す手順そのものはサーバーの `migrations/` が持つ |
| `release/` の置き場所 | ゴール判定の手順が Write で書く `release/`、プレビューの手順の「ワークスペースの `release/` の中は選べない」、進め方ガイド（`playbooks/*.md`）の「`release/` に次を書き出す」を、`.mindstella/release/` に改める | `clear_release` が消す場所と揃える |
| 取り込みの本文 | タスク・用語集・メモにも、経緯や補足があれば `body_markdown` で本文を書く | どの種類に何を本文に書くかは取り込みの手順の表で決める |
