# 記録の形を直す（すべての種類に本文・記録はサブフォルダへ・編集した人）

## 概要

利用者がワークスペースのフォルダを開くと記録のフォルダ `.mindstella/` だけが見え、どの種類の項目にも本文を残せ、AI は項目を最後に編集したのが AI か利用者かを見分けられるようになる。

## 背景

[#46](https://github.com/shuhei1101/mindstella/issues/46) の要望。手元の mindstella の話し合いで決めた D-22・D-25・D-39・D-46 を記録の形に入れる。
今のワークスペースは、設定・種類ごとの YAML・`docs/`・`release/`・ロックなどのファイルを直下に並べ、画面はサーバーの配信（`/mindstella.html`）だけで開く。
本文（`body`）を持てるのは検討事項・調査・資料・会話ログだけで、タスク・用語集・メモは持てない。
項目は作成日時（`created`）と更新日時（`updated`）を持つが、誰が書き換えたかは持たない。
項目ごとの変更履歴と AI が最後に読んだ時点（D-46 の残り）は [#79](https://github.com/shuhei1101/mindstella/pull/79)・[#94](https://github.com/shuhei1101/mindstella/pull/94) で develop に入っている。
`config.yaml` と画面のファイル名 `mindstella.html` は [#95](https://github.com/shuhei1101/mindstella/pull/95) が決め、`config.yaml` のサブフォルダへの移動と直下への `mindstella.html` の書き出しをこの PR へ回した。直下に画面を書き出すことは、画面はサーバーの配信で見るため採らない（[確認ログ](./確認ログ.md)）。
