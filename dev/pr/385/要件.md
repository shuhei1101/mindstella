# 要件

## 要望

`find` の返す量を AI が選べるようにし、項目とタグの組ごとに主題を持たせる。
Issue 本文の「決まったこと（詳細）」のうち D-12・D-31・D-39・D-51・D-52 は話し合いで取り下げ済みで、Issue の「インターフェース定義（A-14）」を正とする。
タグのマスターを持たない方針（D-169）により、`tags` の query は取り消し。

| 要望 | 終わりの条件 |
| --- | --- |
| `find` の返す量 | `find` が `response_format` の代わりに `view`（`brief` / `standard` / `full`。既定 `brief`）と `include` / `exclude`（項目名の enum の配列）を受け、省いた項目を `omitted` で返す。`response_format` は受け付けない |
| 文字数と総件数 | `find` の結果の各行に文字数（`chars`）を、結果の先頭に総件数と、当たった全件の合計文字数を返す |
| `count_only` | `find` が任意の `count_only` を受け、`true` のときは一覧を返さず、総件数・合計文字数・タグごとの件数だけを返す。session の手順で先に呼ぶことは強制しない |
| `format` | `find` が `format`（`markdown` / `json`。既定 `markdown`）を受ける。`markdown` は一覧を Markdown の表（各行に ID とタイトル）で返し structuredContent を返さない。`json` は structuredContent と text に同じ JSON を入れる |
| 項目のタグの主題 | 全種類の項目の `tags` の 1 件が、タグの名前と、主題なら `main: true` を持つ。`add`・`update`・`batch` で主題を付け外しでき、`show`・`batch` の取得・プレビューの記録の取得が主題を返す |
| 主題の一致を上に並べる | `find` で `tags`・`any_tags` を渡したとき、渡したタグを主題として持つ項目を上に並べる。`find` の結果の行のタグで主題が分かる |
| 取り込みで主題を付ける | session の取り込みの手順に、主題のタグを付ける条件が書かれている |
| プレビューの主題のマーカー | プレビューが項目のタグを表示する箇所で、主題のタグをマーカーで見分けられる。タグの絞り込み・表の列・ネットワークのタグは、主題の有無によらずタグの名前で扱う |
| 既存のワークスペースの移し替え | upgrade が既存のワークスペースの項目の `tags` を、文字列の並びから主題を持てる形へ移し替える（移し替えた直後はどのタグも主題を持たない） |

`未確定`: 画面の項目の編集で主題を付け外しできるようにするか（決める段: 画面設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 項目の編集のタグの入力で、タグごとに主題を付け外しできる | 利用者が画面で主題を直せる | タグの入力の操作が増える |
| B | 画面は主題のマーカーを表示するだけにし、付け外しは AI の MCP だけで行う。編集で触らないタグの主題はそのまま保つ | タグの入力が今のまま | 利用者が直すには AI に頼む |

推奨: A

画面でタグを編集できる以上、主題だけ直せないと利用者が直す手段が会話に限られ、保存待ちの編集の流れからも外れる。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `tags` の query（正規化した名前・aliases・説明に一致するタグを返す） | タグのマスターを持たない方針（D-169）で取り消し | 予定なし |
| スレッドのタグの主題 | 主題（D-45）は文書とタグの組の決まりで、スレッドは対象に含まれない | 予定なし |
| 会話キー（`session_id`・`agent_id`）と、同じ内容を 1 セッションで 1 回だけ返すこと | 別の Issue の範囲 | [#341](https://github.com/shuhei1101/mindstella/issues/341) |
| 区間の変更一覧（`list_changes`）と取得の差分モード | A-14 の追加分のうちこの Issue の範囲に当たらない | 予定なし |
| `show` の `view`・`include` と、`ids` の配列での複数取得 | 要望は `find` の返す量に限る。`show` の読み取りは dev-docs へ任せる Issue が扱う | [#345](https://github.com/shuhei1101/mindstella/issues/345) |
| `find` の `limit` の上限を A-14 の 100 に合わせること | 要望に含まれない。A-14 のツール名・引数名・値は仮 | 予定なし |
| 記録の読み取りを dev-docs の `search_docs` に任せること | 別の Issue で扱う。この PR の `view`・`count_only` を受け継ぐかは、その着手時に決める | [#345](https://github.com/shuhei1101/mindstella/issues/345) |
