## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 記録の型 | 項目の `tags` を `{name, main?}` の配列にする | スレッドの `tags` は文字列の並びのまま |
| 主題のマーカー | 詳細パネル・詳細の全画面・資料のカードのタグで、主題のタグをマーカーで見分けられるようにする。見た目はモック作成で決める | - |
| 表・絞り込み・ネットワーク | タグの列・絞り込みの値・件数は、主題の有無によらずタグの名前で扱う | - |
| 項目の編集 | タグの編集で主題を保つ | `未確定`: 主題の付け外しを画面でできるようにするか（要件.md。決める段: 画面設計） |
