# find の返す量を view・include・count_only・format にして文字数を返し、項目のタグに主題のマーカーを持たせる

## 概要

AI が `find` の結果の件数と文字数を見て、取る量と返す項目を選べるようにする。
項目とタグの組ごとに主題かを持たせ、タグで探したときに主題として持つ項目を上に並べる。

## 背景

[Issue #335](https://github.com/shuhei1101/mindstella/issues/335) の要望。
`find` の返す量は `response_format`（`concise` / `detailed`）だけで、各行の文字数・総件数・合計文字数を返さないため、全件を読む前に量を見積もれない。
項目のタグは文字列の並びで、その項目の主題のタグと、触れているだけのタグを区別できない。
`response_format` は [#303](https://github.com/shuhei1101/mindstella/issues/303)（[#308](https://github.com/shuhei1101/mindstella/pull/308)）で入り、タグの語彙は [#333](https://github.com/shuhei1101/mindstella/issues/333)（[#358](https://github.com/shuhei1101/mindstella/pull/358)）でやめた。
合わせるのは knowledge の『MCP サーバー作成ルール』の「読み取りのツール」・『ドキュメント管理』の「メタデータ」と、Issue の「インターフェース定義（A-14）」。
