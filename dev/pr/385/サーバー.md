## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `find` の返す量 | `response_format` を外し、`view`（`brief` / `standard` / `full`。既定 `brief`）と `include` / `exclude` を受ける。各段で返すキーと `include` に渡せる名前はインターフェース定義の段で決める | `brief` は `title`・`status`・`tags`・`chars`、`standard` はそれに `target`・`category`・`phase`・`attrs`・`updated`、`full` はさらに `extra`・`body`・`body_format`。`id`・`kind` は常に返す |
| 文字数 | 各行に `chars`（項目の YAML と本文の文字数の合計）を返し、結果の先頭に総件数と当たった全件の合計文字数を返す | 項目を YAML に書き出した文字数と本文のファイルの文字数の和（コードポイント） |
| `count_only` | `true` のときは一覧を返さず、総件数・合計文字数・タグごとの件数だけを返す | 既定 `false` |
| `format` | `markdown`（既定）は総件数の行・タグごとの件数の表・結果の表を text で返し、structuredContent を返さない。`json` は今の JSON の形に `total_chars`・`tag_counts`・`omitted` を足して structuredContent と text に入れる | 書き込みのツールの返し方は変えない |
| 主題の並び | `tags`・`any_tags` を渡したとき、渡したタグを主題として持つ項目を上に並べ、その中は種類の順・連番の順を保つ | 続きの値（`cursor`）は並べた後の位置を指す |
| 項目のタグのスキーマ | `common.schema.json` の `tags` の要素を `{name, main?}` にする。`main` は `true` だけを書き、主題でないタグは `main` を持たない | 文字列の要素は受け付けない（前の版の形式として移し替えへ案内する） |
| 書き込み | `add`・`update`・`batch` がタグを `{name, main?}` で受ける。タグの比べ方は名前を正規化して比べる | 正規化して同じ名前のタグを 2 件持つと SchemaMismatchError |
| 読み取り | `show`・`batch` の取得・`GET /api/records` は `{name, main?}` のまま返す。`tags` のツールは名前で数える | - |
| 移し替え | 次の版の `migrations/` に、項目の文字列のタグを `{name}` にする手順を置き、前の版の形式の見分けに文字列のタグを加える | 版の番号は計画の Sprint で決まる次の版 |
