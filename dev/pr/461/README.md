# session の手順の修正: 差分のリンクの文言・話題のタグの命名・AI がスレッドをクローズできる条件

## 概要

利用者が、AI の返信の項目の ID から項目のページを開け、読んでいない AI の返信や答えていない質問のスレッドを AI に閉じられなくなる。

## 背景

[#460](https://github.com/shuhei1101/mindstella/issues/460) は、session の手順と記録の仕組みを変える次の 3 件をまとめた束の親 Issue。

- [#405](https://github.com/shuhei1101/mindstella/issues/405): 記録の本文・返信で、AI が項目の ID を差分のリンクの文言にする（`[A-6](#diff=V-15)`）。プレビューの項目の ID の自動のリンクが効かず、項目のページを開けない
- [#376](https://github.com/shuhei1101/mindstella/issues/376): 話題のタグを足すときの分け方と命名を、knowledge の規約『タグと用語の登録』に合わせる
- [#424](https://github.com/shuhei1101/mindstella/issues/424): AI が `set_thread_status` で、利用者の回答待ちや、利用者がまだ読んでいない返信のあるスレッドをクローズする。11-03 の話し合いでは未読の書き込みのあるスレッドを 29 件クローズした
