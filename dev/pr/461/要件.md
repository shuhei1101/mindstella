### #405 差分のリンクの文言

- 記録の本文とスレッドの返信では、項目の ID をリンクで囲まず生の文字で書かせる
- 差分のリンクは項目の ID と分け、まとまりの ID を文言にして書かせる（例: `差分: [V-18](#diff=V-18)`）
- 直す指示は、session の SKILL.md の「記録の書き方」・`docs/リファレンス/スキル.md`・インターフェース定義『話し合いの進行』の制約の 3 か所

### #376 話題のタグの分け方と命名

develop の `steps/取り込み.md` の「話題のタグを付ける」には、[#333](https://github.com/shuhei1101/mindstella/issues/333) で次の決まりが手順書の中に入っている。

| 終わりの条件の項目 | develop の記述 |
| --- | --- |
| 単語まで分ける・名詞句のタグを作らない | 「語を書き出して単語まで分け」、用語集の複合語と一語として定着した複合語だけを分けずに残す |
| 既存に寄せる | 「同じ概念の言い方・活用の違いのタグがあれば、その表記を使う」 |
| facet:value の形 | 「タグの名前は `facet:value` にする」と `action:`・`tool:`・`topic:` の表 |
| action: を当てるか | `action:` は行為の語を名詞形にして付ける |

終わりの条件は develop で満たしているため、この PR では手順書を変えず、満たしていることを確かめて #376 を閉じる。

### #424 AI がスレッドをクローズできる条件

- `set_thread_status` に AI が `status: closed` を渡したとき、次のどちらかに当たればクローズせず、理由をエラーに書く
  - 取り込み待ちの利用者の書き込み（`author: user` で `taken` が無い）がある
  - 利用者が未読の AI の書き込み（`author: ai` で `seen` が偽）がある
- 最後の書き込みが AI のものかは拒否の条件にしない（質問にほかの場所で回答済みのスレッドを閉じられるようにする。#424 の追記）
- 利用者が画面でクローズにする経路（PATCH `/api/threads/{id}`、書き手 `user`）とオープンに戻す操作は変えない
- session の「スレッドの返し方」を #424 の追記の判定（記録に反映 → 返信の要否 → 回答を待つ質問が残るか → ほかの場所で回答済みか → 利用者が全て既読か）に書き換え、`update_thread`（`take: true`）で取り込み済みにしてからクローズにする順番にする。クローズの理由には回答の場所を書かせる
- [#299](https://github.com/shuhei1101/mindstella/issues/299) の「迷ったら早く閉じる」は AI が返信した後には当てない（#299 は #424 の後に入る）
