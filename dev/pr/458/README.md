# インターフェース定義『プレビューを開く』の検討事項の既定の表示形式をボードに合わせる

## 概要

インターフェース定義『プレビューを開く』の検討事項の既定の表示形式を、実装・画面設計・結合テストと同じボードに修正する。

## 背景

[#445](https://github.com/shuhei1101/mindstella/issues/445) の要望。
[#444 のレビュー](https://github.com/shuhei1101/mindstella/pull/444#discussion_r4482804515)で、対象外の逸脱として報告された。
[#122](https://github.com/shuhei1101/mindstella/pull/122) で実装と結合テストの既定をボードにしたが、このインターフェース定義は request `view` の default とケースの記述がマップのまま残っている。
製品のコードとテストは変えない。
