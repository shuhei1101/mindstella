# 幅 390〜900px でもトップバーが幅に収まり、ページが横にスクロールしないようにする

## 概要

プレビューの利用者が、表示幅 390〜900px でも横にスクロールせずにトップバーの全てのボタンを使えるようにする。

## 背景

[Issue #111](https://github.com/shuhei1101/mindstella/issues/111) の報告。
[PR #109](https://github.com/shuhei1101/mindstella/pull/109)（[Issue #107](https://github.com/shuhei1101/mindstella/issues/107) の直し）の実装照合とレビューで、絞り込み・表示の設定・コメント・変更履歴のボタンを出す画面のトップバーを測り、幅 900px 以下でページが横にはみ出すことが分かった（[測った記録](https://github.com/shuhei1101/mindstella/pull/109#discussion_r4193137875)）。
はみ出すのは、つながらない＋差分で 380〜519px、つながらないときで 380〜616px、つながっているときで 481〜492px。
幅 900px 以下に効くトップバーの指定は、ボタンと「変更履歴」の文字を隠すことと、480px 以下で余白を詰めることだけで、接続の状態・差分の札・変更履歴のボタンを含めてさらに詰める指定が無い。
非機能要件『画面サイズ』の「幅 390px 以上」に合わず、v0.6.0 の E2E 実行（[Issue #82](https://github.com/shuhei1101/mindstella/issues/82)）の前に直す。
