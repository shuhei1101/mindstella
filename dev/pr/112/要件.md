# 要件

## 要望

表示幅 390〜900px のどの幅でも、絞り込み・表示の設定・コメント・変更履歴のボタンを出す画面でトップバーが幅に収まり、ページ全体が横にスクロールしないようにする。

- 表示幅 390〜900px を 1px ずつ変えて、絞り込み・表示の設定・コメント（件数 3）・変更履歴のボタンを出すトップバー（`app.ts` の配信と同じ組み合わせ）を、つながっている・つながらないのそれぞれで、差分なし・差分ありで開いたとき、`document.documentElement.scrollWidth` が表示幅以下になる
- 同じ幅で、トップバーの全てのボタン（右端のコメントのボタンと、差分の札の × を含む）が横にスクロールせずに見える
- 差分を出している間、差分の時点の札はどの幅でも `5.5em` 以上の幅を取る
- 幅 901px 以上の見た目と、ボタンの読み上げの名前は変えない
