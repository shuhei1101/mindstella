## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| レスポンシブ対応 | `style.css` の `@media (max-width: 900px)` で、接続の状態を印だけにする（`.conn .conn-short` を、幅 360px 以下の指定と同じく読み上げにだけ残す）。印を 18px にする幅 360px 以下の指定は変えない | 部品設計『トップバー』の `read_at` |
| レスポンシブ対応 | 幅 481〜900px で、トップバーの要素の間隔（`.topbar` の `gap`）を 16px から 8px にする。幅 480px 以下の 3px は変えない | つながっているときの 481〜492px のはみ出しは、480px を境に間隔が 3px から 16px へ戻ることで起きている |
| レスポンシブ対応 | 幅 480px 以下で、つながらないうえに差分を出している間（`.topbar:has(.conn):has(.df-chip)`）は、ツール名の印（`.brand`）も隠す | 印は押せない飾りで、隠しても操作は減らない |
| 既存機能への影響 | 幅 901px 以上の見た目と、ボタンの読み上げの名前は変えない。札はどの幅でも `5.5em` 以上を保つ | 読み上げの名前は文字を隠しても残る（部品設計『トップバー』） |
| 部品設計 | 部品設計『トップバー』に `FilterDiffOfflineNarrow` の状態を足し、`read_at` と `OfflineNarrow` の説明を、接続の状態を印だけにする幅 900px に直す | 済 |
| 結合テスト | `FilterDiffOfflineNarrow` のストーリーを、つながっている・つながらない × 差分なし・差分ありの 4 通り（`connection` と `diffPoint` を URL の `args` で替える）で、幅 390px・405px・480px・481px・492px・519px・616px・900px に開き、トップバーとページが横にはみ出さないことと、札の幅が `5.5em` 以上あることを確かめる。`OfflineNarrow` のテストは、文言が読み上げにだけ残り印だけが見えることに直す | はみ出していた範囲の両端と、900px |

### 設計の段で測った結果

`storybook build` の書き出しで `FilterDiffOffline` のストーリーを開き、body の余白を 0 にして、幅 390〜900px を 1px ずつ `document.documentElement.scrollWidth - innerWidth` と札の幅を測った。

| 状態 | 今の `style.css` ではみ出す幅 | 上の 3 つの指定を当てたとき |
| --- | --- | --- |
| つながらない＋差分 | 390〜519px | なし（幅 390px で札は 5.8em） |
| つながらない（差分なし） | 390〜616px | なし |
| つながっている（差分なし） | 481〜492px | なし |
| つながっている＋差分 | なし | なし |

ツール名の印を隠さず、接続の状態と間隔だけを詰めると、つながらない＋差分の 390〜405px が残った。
