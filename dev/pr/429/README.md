# React 移行の土台を配置し、トップバーと概要の画面を React へ移行する

## 概要

プレビューの画面を React（Vite + shadcn/ui）へ移行する土台を配置し、トップバーと概要の画面を React へ移行する。

## 背景

[#366](https://github.com/shuhei1101/mindstella/issues/366) の要望で、親 [#365](https://github.com/shuhei1101/mindstella/issues/365) を分割した子 1 に当たる。
後続の子 2〜6（[#367](https://github.com/shuhei1101/mindstella/issues/367)〜[#371](https://github.com/shuhei1101/mindstella/issues/371)）は、この土台の上で残りの画面を移行する。
今のプレビュー（`plugins/mindstella/skills/mindmap/preview/`）はバニラ TS で記載されており、knowledge の規約を React 前提に改めたことに合わせて React へ移す。
移行を終えるまでは今の画面を配信し続け、子 6（[#371](https://github.com/shuhei1101/mindstella/issues/371)）で切り替える。
