## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ビルド | Vite（React + TS）と React Compiler でビルドし、出力をプラグインの中へ配置して commit する | 置き場所は `未確定`（要件.md） |
| フォルダ構成 | knowledge の規約『フォルダ構成』の `app/`・`routes/`・`features/{domain}/{screen}/`・`shared/` で分け、barrel を使わない | - |
| スタイル | Tailwind v4 のトークンを `shared/styles/` の `:root` に 3 ティアで持ち、`@theme inline` で割り当てる | トークンの値はデザインスタイル選定で決める |
| UI 部品 | shadcn/ui（Base UI 版）を `shared/components/ui/` に追加する | - |
| ルーター | TanStack Router の型付きのルートと `validateSearch` + Zod で、画面と選んだ状態を URL に持つ | - |
| サーバーのデータ | TanStack Query の QueryClient を `app/` で 1 つ作り、記録の取得と書き換えの知らせを query に反映する | 生成の方式は `未確定`（要件.md） |
| トップバー | 部品設計『トップバー』の題名・検索の入口・ライト / ダークの切り替え・タブの帯を全て再現する | 共通の部品として `shared/components/` に置き、ストーリーを作成する |
| 概要 | 画面設計『概要』のタイルと操作を全て再現する | - |
| Storybook | `@storybook/react-vite` の設定を今の `.storybook/` と別のフォルダに置き、MSW と props でデータを差し込む。addon-a11y を入れる | - |
| lint・検査 | ESLint（Flat Config・typescript-eslint・better-tailwindcss・boundaries・react-hooks・jsx-a11y・sonarjs の cognitive complexity）を error で入れ、React の側だけに当てる | TypeScript のバージョンは `未確定`（要件.md） |
| Git フック | lefthook で commit の前に lint・型検査を実行し、`package.json` の npm scripts から呼ぶ | - |
| アクセシビリティ | Storybook の addon-a11y と、結合テストの Playwright の axe で WCAG の違反を検査する | - |
| 既存機能への影響 | 今の画面・部品・ストーリー・テストは触らない | 子 6 で削除する |
