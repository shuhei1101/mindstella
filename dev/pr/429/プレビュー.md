計測の前の空きメモリは WSL が約 13.7 GB（available）、Windows の空き物理メモリが約 5.2 GB、`get_capacity` の空きは 2 だった。

設計へ持ち越す所見:

| 所見 | 扱い |
| --- | --- |
| ESLint 10 は eslint-plugin-jsx-a11y 6.10.2 の peer（`^9` まで）に合わず、9.39.5 を入れた（サポート終了の警告が出る） | 外部ライブラリの設計書に固定のバージョンと理由を記載する |
| typescript-eslint の `projectService` は対象のファイルに最も近い `tsconfig.json` を引くため、直下の今の画面の設定が当たる。React の側の設定は `frontend/tsconfig.json` に置いた | knowledge の規約『ビルド構成』（設定は直下）との違いを、モジュール構成設計で記載する |
| eslint-plugin-better-tailwindcss 4.10.0 に任意値の専用の規則が無い | `no-restricted-classes` の正規表現（`\[.*\]`）で止める |
| lefthook の npm パッケージは `npm install` の postinstall で、リポジトリの全ての worktree が共有する `.git/hooks/` に `pre-commit`・`prepare-commit-msg` を書く。PoC の間に書かれ、設定の無い worktree の commit でも警告を出したため、検証の後に削除した | 共有のフックに入る時期（`npm ci` を流したとき）と、設定を持たない develop の worktree での振る舞いを、モジュール構成設計で決める |
| `/mnt/c` の上の worktree では、ESLint と pre-commit が約 60 秒かかる | テスト実行方法に前提として記載する |

最小再現コードの要点（[#430 の diff](https://github.com/shuhei1101/mindstella/pull/430/files)）:

```ts
// vite.config.ts: root の外（プラグインの中）へ出力し、React Compiler を Rolldown の babel で当てる
export default defineConfig({
  root: FRONTEND_DIR,
  base: "/spa/",
  plugins: [react(), babel({ presets: [reactCompilerPreset()] }), tailwindcss()],
  resolve: { alias: { "@": `${FRONTEND_DIR}/src` } },
  build: { outDir: OUT_DIR, emptyOutDir: true },
});

// shared/adapters/events.ts: 生成の外の Server-Sent Events を query の読み直しにつなぐ
const source = new EventSource("/api/events");
source.addEventListener("changed", () => {
  void queryClient.invalidateQueries({ queryKey: getGetRecordsQueryKey() });
});
```

diff の見どころは `serve.py` の `spa_response`（出力の外を指すパスと無いファイルを `index.html` へ寄せる）と、`eslint.config.js` の better-tailwindcss の `entryPoint`・`projectService`・boundaries の policies が 1 つの設定に並ぶ箇所。
