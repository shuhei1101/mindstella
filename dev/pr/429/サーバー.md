## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| SPA の配信 | ビルドした SPA の `index.html` と出力の静的なファイルを `/spa/` の下で返す。出力に無いパスと出力の外を指すパスには `index.html` を返し、`/spa` は `/spa/` へ送り直す | インターフェース定義『SPAの配信』 |
| API の定義 | トップバーと概要が読む `GET /api/records`・`GET /api/comments`・`GET /api/edits`・`GET /api/threads` の OpenAPI の定義を、インターフェース定義から記載する。`serve.py` の応答が OpenAPI と一致することを結合テストで確かめる | 置き場所はモジュール構成設計で決める |
| セキュリティ | 追加するパスにも、今のパスと同じ接続先（`Host`）と送り元（`Origin`）の確認を当てる | - |
| 既存機能への影響 | `/mindstella.html` と今の API の挙動を変えない | - |
