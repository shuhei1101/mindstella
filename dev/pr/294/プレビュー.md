## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 画面設計 | 要素「本文の差分」の足した印の文言から 2 か所の「下線」を外す | - |
| 見た目 | 下線は付けない。`.md li.df-li-add` のコメントを「足した色の面と +」に直す | 消した印・変わった語の濃い面は変えない |
| 箇条書きの足した項目の記号 | `markAddedBlocks` の `LI` の分岐で、表の足した行と同じく `signMarks("add")` を項目の先頭に置く。`style.css` に `.md li.df-li-add .df-sign` の色（`--df-add`）と、表の行の記号に揃えた位置の規則を足す | 画面設計の「箇条書きに足した色の面と +」に実装を揃える |
| 左右に並べた本文の差分 | 変えない | - |
| アクセシビリティ | 足した印は色の面に + の記号を併せ、色だけで示さない状態を保つ | - |
| 確かめ方 | 結合テストで、本文の差分の足した塊・箇条書きの足した項目・表の足した行の文字の計算済みの `text-decoration-line` が `none` で、3 つともに `+` の記号（`.df-sign`）があることを確かめる | - |
