# 要件

## 要望

詳細パネルの幅の区切りのドラッグを軽くする。

- ドラッグ中は `sessionStorage` へ幅を保存しない。
  保存するのは、ドラッグを終えたとき（離した・中断した）と、キー（← / → / Home / End）で幅を変えたときだけにする
- ドラッグ中の幅の当て直し（`--panel-w` と `aria-valuenow` の書き換え）は、1 フレームに 1 回にまとめる。
  ドラッグを終えたときは、最後の位置の幅を当ててから保存する
- ドラッグを終えた後の幅・本文の寄せ・下限と上限で止まる動き・開き直したときの幅は今のとおりにする
