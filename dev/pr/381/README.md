# 詳細パネルの幅の区切りのドラッグ中は幅の当て直しを 1 フレームに 1 回にし、保存は離したときにする

## 概要

利用者が、詳細パネルの左端の幅の区切りを、引っかからずにドラッグして幅を変えられるようになる。

## 背景

[Issue #354](https://github.com/shuhei1101/mindstella/issues/354) の報告（利用者の書き込みは話し合いのフォルダ `261004_設計` の TH-753）。
[#340](https://github.com/shuhei1101/mindstella/pull/340) で入れた幅の区切りは、`pointermove` のたびにルートの `--panel-w` を書き換えてページ全体を描き直し、`sessionStorage` へ幅を保存する。
`pointermove` は 1 フレームに複数回来るため、ドラッグが重い。
#340 は v0.11.0 でまだリリースしていない。
