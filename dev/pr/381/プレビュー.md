## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ドラッグ中の当て直し | `pointermove` では持っている幅だけを更新し、`requestAnimationFrame` で予約した 1 回で `apply` する。予約済みのフレームがあれば新たに予約しない | 1 フレームに 1 回 |
| ドラッグの終わり | 押したときに `document` へ付けた `lostpointercapture` のリスナー（押したときの `pointerId` で絞る）で受け、予約中のフレームを取り消し、区切りが文書に残っていれば最後の位置の幅を `apply` してから `onChange` を 1 回呼ぶ。幅が押したときから変わっていないときは呼ばない | 離した・中断したときは区切りから泡立ち、区切りが外れたときは `document` に直接届く |
| ドラッグ中の描き直し | ドラッグ中の幅をモジュールの変数に持ち、ドラッグ中に作られた区切りは `stored` の代わりにその幅から始める | 記録の書き換えで詳細パネルを描き直しても、ドラッグした幅が戻らない |
| キーでの変更 | 今のとおり、1 回押すごとに `apply` と `onChange` を呼ぶ | - |
| 窓の幅の変化 | 今のとおり `apply` だけ（`onChange` は呼ばない） | - |
| 既存機能への影響 | 下限・上限で止まる動き、`data-edge` のカーソル、`aria-valuenow`、本文の寄せは、当て直しのたびに今と同じ値になる | - |
