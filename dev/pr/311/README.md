# 詳細に出す説明文などの文字列の値の改行を、そのまま改行として表示する

## 概要

利用者が、詳細パネルで検討事項の背景（`lead`）などの文字列の値を、書かれた改行のとおりに改行された形で読めるようになる。

## 背景

[Issue #153](https://github.com/shuhei1101/mindstella/issues/153) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-56）で、検討事項の詳細の説明文が 1 段落に繋がって出て、長いと読みにくい。
詳細に出す文字列の値は、画面設計『詳細パネル』の要素「文字列の値の描画」で本文と同じく marked で描いており、marked の既定では段落の中の 1 つの改行が空白になる。
`lead` は文字列で、改行は既に持てる。
