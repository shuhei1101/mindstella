# 要件

## 要望

レビュー中の書き込みの画面で、項目を指さない新しいスレッドの行の頭に「項目を指さない」を出さず、長い本文を折りたたむ。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| 項目を指さない行の頭 | 項目を指さない新しいスレッドの行は、向けた項目の場所に何も出さない（「新しいスレッド」の札は残す）。読み上げの名前「項目を指さないコメントを送る / 修正 / 削除」は変えない |
| 長い本文の折りたたみ | 本文が 5 行を超える行は、開いたときは 5 行までを出して折りたたみ、「続きを読む」で全文を開く。5 行以下の行には何も足さない |

<!-- /table -->

モック作成で決めた論点。

| 論点 | 決定 | 設計書 |
| --- | --- | --- |
| 5 行の数え方 | 行の幅で折り返した後の見た目の行で数える（改行の無い長文も畳む） | モック『comment-review / b-with-open』 |
| 「続きを読む」の置き場所 | 「スレッドを開く」と同じ行の先に置く。返信の行は「続きを読む」だけの行 | モック『comment-review / b-with-open』 |
| 開いた後に畳み直せるか | 全文の下に「折りたたむ」を出し、押すと 5 行までに畳み直す | モック『comment-review / b-with-open』 |
| 畳み直すボタンの文言 | 「折りたたむ」。読み上げの名前は「{行の読み上げの名前}の本文を折りたたむ」 | モック『review-body-fold』 |
| 本文の書き換えから戻ったときの開閉 | 書き換える前の開閉を保つ。書き換えの入力欄を出している間は開閉のボタンを出さない | モック『comment-review / b-with-open』 |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| スレッドの画面と詳細パネルのレビュー中のコメントの長い本文の折りたたみ | 要望の「レビュー中のコメントの欄」はレビュー中の書き込みの画面と読んだ。同じレビュー中の書き込みを出す欄で、含めるかは判断が分かれるためレビューで確定する。今の判断は、要望の対象を広げないため含めない | 起票予定 |
| スレッドの一覧の行の見せ方 | 項目を指さないスレッドは既に 2 行目に ID を出しておらず、要望に当たらない | 予定なし |
