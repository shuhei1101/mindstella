# レビュー中の書き込みで、項目を指さない行の「項目を指さない」を消し、長い本文を折りたたむ

## 概要

利用者が、レビュー中の書き込みの画面で、項目を指さない行に余計な見出しが出ず、長い書き込みを折りたたんだまま一覧できるようになる。

## 背景

[Issue #136](https://github.com/shuhei1101/mindstella/issues/136) の要望（aituber のワークスペースの話し合いで画面から送られた送信 S-13）。
起票の後に [#235](https://github.com/shuhei1101/mindstella/pull/235) でコメントがスレッドになり、要望の「レビュー中のコメントの欄」は今のレビュー中の書き込みの画面に当たる。
この画面の新しいスレッドの行は、項目を指さないとき行の頭に押せない「項目を指さない」を出し、本文は長さによらず全文を出している。
