# 要件

## 要望

プレビューの本文のコードブロックと図の Raw が長い行で横にあふれるとき、キーボードだけで全ての文字を読めるようにする。

- 対象: 詳細パネル・詳細の全画面の本文のコードブロック（`.md pre`）と図の Raw（`.dg-raw`）、図の拡大の Raw（`.v-raw`）
- 基準: 長い行を持つコードブロック・図の Raw に axe の `scrollable-region-focusable` を当てて違反が 0 件。差分の表示の間の図の Raw（`.df-raw`）も同じ
- 非機能要件の `入力方式`（全ての操作にキーボードで届く）の決定値は変えない

`未確定`: 届かせ方（決める段: 画面設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | コードブロック・図の Raw を折り返し（`white-space: pre-wrap`）にして横スクロール自体を無くす | Tab の往復が増えず、横に送れるときだけ止める判定も要らない | 長い行のコードや図の記法が折り返され、行の区切りが読み取りにくくなる |
| B | 横に送れるブロックに `tabindex="0"` を付けて Tab で止め、矢印キーで横に送る | 行の見た目を変えない | ブロックの多い本文で Tab の往復が増え、横に送れるときだけ止める判定（幅が変わったときの付け直しを含む）が要る |

推奨: A

折り返しは CSS だけで済み、幅の変化や差分の表示の描き直しに追従する判定を持たずに済む。
差分の表示の Raw は行ごとの `+` / `−` の印で行の区切りが読める。
