# プレビューの本文のコードブロックと図の Raw の横スクロールへキーボードで届くようにする

## 概要

利用者が、プレビューの本文のコードブロックと図の Raw の長い行を、キーボードだけで最後まで読めるようになる。

## 背景

[#93](https://github.com/shuhei1101/mindstella/issues/93) の要望。
[#92](https://github.com/shuhei1101/mindstella/pull/92)（[#88](https://github.com/shuhei1101/mindstella/issues/88)）の要件のレビューで、#88 の対象外として切り出された。
詳細パネル・詳細の全画面の本文のコードブロック（`.md pre`）と図の Raw（`.dg-raw`）は、長い行で横に送れるとき中にフォーカスできる要素を持たず、axe の `scrollable-region-focusable`（WCAG 2.1.1 キーボード）に当たる。
#92 で本文の縦のスクロール領域（`.panel-body`）にはフォーカスできるが、そこから横には送れず、非機能要件の `入力方式`（全ての操作にキーボードで届く）を満たさない。
