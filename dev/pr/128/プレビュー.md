## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| アクセシビリティ | 長い行を持つ本文のコードブロック・図の Raw・図の拡大の Raw（差分の表示の間の Raw を含む）を、axe の `scrollable-region-focusable` で違反 0 件にする | - |
| 長い行の表示 | `.md pre`・`.dg-raw` を折り返し（`white-space: pre-wrap`・`overflow-wrap: anywhere`）にし、横にスクロールさせない | 本文のコードブロックと図の Raw は縦にあふれないため、フォーカスは足さない |
| 図の拡大の Raw | 記法の枠（`.v-raw`）に `tabindex="0"`・`role="region"`・`aria-label="図の記法"` を付け、縦に矢印キーと PageUp / PageDown で送れるようにする | 折り返しても窓の高さで縦にあふれ、違反が残るため |
| 画面設計 | 詳細パネルの本文と図の拡大の Raw に、長い行の扱いと記法の枠のフォーカスを書く | 詳細の全画面は詳細パネルと同じ要素のため書き換えない |
| 既存機能への影響 | 本文の用語・項目の ID のリンクを付けない範囲（コードブロック・図）、選んだ箇所のコメント、差分の表示の行の印は変えない | - |
| 動作環境 | 非機能要件の `入力方式` の決定値は変えない | - |
