# 結合テスト test_body_alias_tooltip_pinned で、ツールチップに覆われない位置を操作し、決まった時間の待ちを条件の待ちにする

## 概要

本文の印を押して残したツールチップを確認する結合テスト `test_body_alias_tooltip_pinned` が、単独の実行でも負荷を掛けた実行でも毎回 pass するようにする。

## 背景

[Issue #440](https://github.com/shuhei1101/mindstella/issues/440) の要望。
[#439](https://github.com/shuhei1101/mindstella/pull/439) の作業ツリーで、このテストが単独の実行で 3 回中 1 回しか pass せず、負荷を掛けた実行では、出したままのツールチップが押す先を覆って `TimeoutError` になった（#439 の要件.md の `## スコープ外`）。
