## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 版を指す URL | `preview_url` に省略できる引数 `diff`（まとまりの ID）を足す。`changes.yaml` の `sets` にあれば `url` の末尾に `#diff={ID}` を付け、無ければ引数の誤りで配信を立てない | `since`・`pending` は受けない |
| README | 直下の `README.md` にはハッシュを付けない URL を書く | - |
| 既存機能への影響 | `diff` を省いた今の `preview_url workspace` の呼び方と結果を変えない | 破壊的変更なし |
