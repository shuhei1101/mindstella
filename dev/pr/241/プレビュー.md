## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ハッシュの引数 | 選んだ時点（まとまりの ID・`pending`・`since`）をハッシュの引数に持つ。差分を出さないときは書かない | 引数は `diff` |
| ハッシュで開く | 起動時にハッシュの時点を `resolveDiffPoint` で引き、引けたらその時点の差分の表示で開いて端末の保存領域にも残す。引けなければ差分を出さずに開き、ハッシュから外す | ハッシュに時点が無ければ、端末に残した時点で開いてハッシュにも書く |
| 時点を選ぶ・やめる | `selectPoint` で端末の保存領域とハッシュの両方を書き換える。履歴には積まずにハッシュを置き換える | 今の「表示形式の切り替え・重ねる画面の開閉は積まずに置き換える」と揃える |
| 画面の移動 | 画面・項目を移っても、選んだ時点をハッシュに保つ | 今は `navigate` が `filters` だけを外して書く |
| 記録の読み直し | 読み直しで選んだ時点のまとまりが消えたら（保持する回数を超えた）、差分の表示をやめてハッシュから外す | `reload` が `resolveDiffPoint` を引き直す箇所 |
| 配る書き出し | 通信なしで開いた書き出しも同じハッシュを読む | `プレビューを配る` を実行のみで回す |
| 既存機能への影響 | 時点を持たない今のハッシュは、今と同じように開く | 破壊的変更なし |
