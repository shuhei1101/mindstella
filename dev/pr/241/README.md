# 変更履歴で見ている版を URL に持たせ、版を指すリンクを貼れるようにする

## 概要

利用者が、変更履歴で選んだ版の差分を URL で開き直せるようになり、AI が「ここで直しました」と書くときにその版を指すリンクを貼れるようになる。

## 背景

[Issue #210](https://github.com/shuhei1101/mindstella/issues/210) の要望（aituber のワークスペースの話し合いで、画面から送られた送信 S-199）。
変更履歴で過去の版や差分を見ていても URL が変わらないため、「この版で直した」というリンクを貼れない。
プレビューは画面・表示形式・項目・全画面・見出しを URL のハッシュに持つが、変更履歴で選んだ時点は端末の保存領域（`localStorage`）にだけ持っている。
