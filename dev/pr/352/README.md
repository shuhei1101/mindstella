# コメントの修正の入力欄でも Ctrl+Enter で保存できるようにする

## 概要

利用者が、プレビューのレビュー中のコメントを修正するときにも、Ctrl+Enter（macOS は Cmd+Enter）で修正を確定できるようになる。

## 背景

[Issue #330](https://github.com/shuhei1101/mindstella/issues/330) の要望（knowledge のワークスペース `tmp/mcpベストプラクティス検討` の TH-65）。
コメント・返信を追加する入力欄と、スレッドの状態を変える理由の入力欄は Ctrl+Enter で確定できるが、レビュー中のコメントを修正する入力欄では Ctrl+Enter が効かない。
Issue が合わせる先に挙げた送信キーの設定（[#162](https://github.com/shuhei1101/mindstella/issues/162)）は取り下げられており、プレビューに送信キーの設定は無い。
