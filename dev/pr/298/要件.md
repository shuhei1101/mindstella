# 要件

## 要望

表示幅 320〜389px で、トップバーの全てのボタンの押せる的を縦横 `--target-min`（24px）以上に保つ。

- 表示幅 320〜389px で、トップバーの表示の設定・絞り込み・コメントのボタンを、件数の札を持つとき・持たないとき（絞り込みの件数なし・コメント 0 件）のどちらで開いても、各ボタンの枠が縦横 24px 以上になり、axe の `target-size` に違反が出ない
- 印だけのボタン（検索・変更履歴・ライト / ダーク）と差分の札の × も、同じ幅で縦横 24px 以上を保つ
- 幅 320px で、[PR #263](https://github.com/shuhei1101/mindstella/pull/263) の収め方の約束を保つ: 接続（つながる・つながらない）× 差分（なし・あり）の 4 通りを、絞り込みのバッジ 2 桁・コメントの件数 `99+` まで開いても `document.documentElement.scrollWidth` が表示幅以下になり、ボタンを 1 つも隠さず、差分の札は `5.5em` 以上を取る
- 幅 390px 以上の見た目と、ボタンの読み上げの名前は変えない

幅 389px 以下で、表示の設定・絞り込み・コメントのボタンに幅の下限 `--target-min` を足す。
つながらない・差分ありの間だけ、印だけのボタン（検索・変更履歴・ライト / ダーク）を幅 26px にし、トップバーの左右の余白 8px を保つ（[確認ログ](./確認ログ.md)）。
