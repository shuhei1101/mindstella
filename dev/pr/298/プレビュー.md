## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| アクセシビリティ | 幅 389px 以下で、表示の設定・絞り込み・コメントのボタンに幅の下限 `--target-min`（24px）を持たせ、件数の札を持たない間も 24px を割らない | 高さは今の 32px のまま |
| レスポンシブ対応 | 幅 320px・最大の中身（つながらない・差分あり・絞り込み 2 桁・コメント `99+`）でも、#263 の収め方（ボタンを隠さない・差分の札 `5.5em` 以上・`scrollWidth` が表示幅以下）を保つ | 溢れる場合に幅を回す先は要件.md の `未確定` |
| 既存機能への影響 | 幅 390px 以上の規則と、ボタンの読み上げの名前・押したときの動きは変えない | - |
| 部品設計 | `FitNarrowest`・`FitNarrowestDiff`・`FitNarrowestOffline`・`FitNarrowestOfflineDiff` の説明にボタンの幅の下限を書き足し、件数の札を持たないボタンが 320px で並ぶ状態を確かめられるようにする | 件数なしの状態をストーリーに足すかは部品設計で決める |
| 結合テスト | 表示幅 320・361・389px で、320〜389px の状態のトップバーに axe の `target-size` を当てて違反が無いこと、各ボタンの枠が縦横 24px 以上であることを確かめる | 既存の `scrollWidth` の確かめはそのまま流す |
