# 本文の差分の表示を、インラインと左右に並べる表示で切り替えられるようにする

## 概要

利用者がプレビューの差分の表示で、本文の差分をインラインと、変える前と後を左右に並べる表示とで切り替えて読めるようになる。

## 背景

[Issue #220](https://github.com/shuhei1101/mindstella/issues/220) の要望。
差分の表示の本文の差分は、Markdown の本文は 1 列のインライン（足した・消した段落に印）、HTML の本文は描いた結果の上の印と「原文の差分」でしか見られず、詳細の全画面のような広い画面でも前後を並べて見比べられない。
[PR #214](https://github.com/shuhei1101/mindstella/pull/214) のモックの確認で、ユーザーから別の Issue として出すよう依頼された（[コメント](https://github.com/shuhei1101/mindstella/pull/214#discussion_r4237854882)）。
