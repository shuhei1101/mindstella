## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 切り替え | 本文の差分の頭に「インライン」「左右に並べる」の 2 つのボタンの組（`aria-pressed`）を置く。既定はインライン。HTML の本文の差分の「描いた結果」「原文の差分」とは別の組にし、その前に置く | 詳細パネルと詳細の全画面に置く。本文の幅（`.panel-body` へのコンテナクエリ）が 560px に満たないときは切り替えを出さずインラインで出す |
| Markdown の本文 | 左に選んだ時点の本文、右に今の本文を Markdown として描く。行の差分（`diffLineParts`）の変えていない部分・消した部分・足した部分を行の塊として左右に対応づけ、片側にしか無い塊の向かいには同じ高さの空きを置いて高さを揃える | 消した印は左、足した印は右だけに付ける |
| 変えた行の語の差分 | 対になった消した行と足した行は、今のインラインと同じく変わった語だけに濃い面を付ける | 語の差分を計算しきれない対には付けない（今と同じ） |
| 図 | 左は選んだ時点の記法、右は今の記法で描く。図の差分の色付けは右の図にだけ付ける | 図の Raw の差分は今のインラインのまま |
| HTML の本文 | 左に選んだ時点、右に今の本文を描いた結果を並べ、右に今の「描いた結果」と同じ印を付ける。「原文の差分」を選んでいるときは、原文の行を左右に並べる | 選んだ時点が Markdown（形式を替えた）のときは、左を Markdown として描く |
| 選んだ箇所のコメント | 右の列（今の本文）だけで選んだ箇所の入口を出し、左の列の選択では出さない | 今のインラインの消した部分と同じ扱い |
| 差分のミニマップ | 左右の列の印の高さを合わせて集め、今の帯の形のまま並べる | - |
| 出せない旨 | 前後を組み立てられない・本文の差分を出せない・計算しきれない・差分のライブラリを読めないときは、切り替えを出さず、今と同じ旨と今の本文を出す | - |
| 選んだ表示を保つ範囲 | 差分のミニマップと同じく個人の上書きとして端末に保ち、表示の設定の「この端末で変えている項目」に「本文の差分の並べ方」を並べ、「既定に戻す」でインラインに戻す | - |
| アクセシビリティ | 左右の列は読み上げの名前（「選んだ時点の本文」「今の本文」）を持ち、列の頭に「選んだ時点」「今」を出す。足した・消したは色に加えて記号と下線・取り消し線で分ける | 今の印と同じ |
