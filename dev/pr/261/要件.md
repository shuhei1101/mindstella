# 要件

## 要望

差分の表示の間、詳細パネル・詳細の全画面の本文の差分を、今のインラインの表示と、選んだ時点の本文（左）と今の本文（右）を左右に並べる表示とで切り替えられるようにする。
左右に並べる表示は Markdown の本文と HTML の本文の両方で使え、左に消した印、右に足した印を付け、変えていない部分の高さを左右で揃える。
既定の表示は今のインラインのままにし、本文が選んだ時点で変わっていない項目には切り替えを出さない。

切り替えは詳細パネルと詳細の全画面の両方に置き、本文の幅が 560px に満たないとき（資料以外の詳細パネル・狭い画面幅）は切り替えを出さず、左右に並べる表示を選んでいてもインラインで出す。
HTML の本文では、並べ方の組を「描いた結果」「原文の差分」の組の前に別の組で置く。
選んだ表示は、差分のミニマップと同じくこの端末の個人の上書きとして保ち、表示の設定の「既定に戻す」でインラインに戻す。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| キーの差分（状態・答え・案 など）を左右の列に分ける | キーの差分は今も前の値と今の値を並べて出しており、要望は本文の差分に限る | 予定なし |
| 差分の表示の本文の用語・項目の ID のリンク（#154） | 要望に含まれない | [#154](https://github.com/shuhei1101/mindstella/issues/154) |
| インラインの本文の差分の足した印の下線 | 画面設計『詳細パネル』の「本文の差分」は足した印に下線を付けると書くが、実装（`style.css` の `.md ins.df-blk`・`.md li.df-li-add`）は付けない。前からある食い違いで、要望に含まれない | [#283](https://github.com/shuhei1101/mindstella/issues/283) |
