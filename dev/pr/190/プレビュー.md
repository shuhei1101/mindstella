## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 行の操作 | 詳細パネルの「レビュー中のコメント」の各行の右上に「修正」（鉛筆の印）と「削除」（ごみ箱の印）のアイコンのボタンを常に出し、コメントの一覧の行と同じ振る舞いにする | 確認ログの 1 行目 |
| 本文の書き換え | 「修正」で行の本文を入力欄と「キャンセル」「修正」に切り替え、`PATCH /api/comments/{id}` へ `body` だけを送る。空白だけは送らず「コメントを入れてから直してください。」、届かない・エラーのときは入力を残して理由を出す。「キャンセル」と Esc で捨てる。コメントの一覧の書き換えのボタンも同じ文言に改める | 長さの上限はコメントの一覧と同じ 10000 |
| 削除と元に戻す | 確認を挟まず `DELETE /api/comments/{id}` で消し、行を「コメントを削除しました。」と「元に戻す」に置き換える。「元に戻す」は消した中身を `POST /api/comments` へ同じ `id` と `created` で送る | 「元に戻す」は別の項目へ移るか、パネルを閉じるまで出す（確認ログの 2 行目） |
| 処理の共有 | 直す・消す・戻すの処理は、入口がコメントの一覧のために持つ処理を詳細パネルからも呼ぶ。直している ID・消した行は一覧と詳細パネルで同じ状態を見る | 一覧を開いたまま右に詳細パネルを開いたとき、同じコメントを両方で別々に直している状態を作らない |
| 描き直し | 直す・消す・戻した後は、トップバーの件数・コメントの印・詳細パネルのレビュー中のコメント・一覧（開いていれば）を、入力中の欄とスクロールの位置を保って描き直す | 今のレビュー中のコメントの描き直しの経路を使う |
| 全画面 | 詳細の全画面も同じ要素と操作を持つ | 画面設計『詳細の全画面』の詳細の中身の並びに足す |
| 選んだ箇所のコメントの入口 | 行の書き換えの入力欄を選んでも入口を出さない | 今の「レビュー中のコメント・入力を含む選択では出さない」に含める |
| アクセシビリティ | 読み上げの名前はコメントの一覧と同じ形にし、キーボードだけで直す・消す・戻すまで届く。描き直した後は操作していた部品へフォーカスを戻す | - |
| 配る書き出し | 配る書き出しとサーバーにつながらないで開いたときは、節ごと出さない今の扱いを変えない | - |
