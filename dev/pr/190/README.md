# 詳細パネルのレビュー中のコメントから、コメントを直す・消すことができるようにする

## 概要

プレビューの利用者が、詳細パネルの「レビュー中のコメント」から、溜めたコメントを直す・消すことができるようになる。

## 背景

[Issue #134](https://github.com/shuhei1101/mindstella/issues/134) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-8）。
詳細パネルで書いたコメントは「レビュー中のコメント」に並ぶが、そこは読むだけで、直すにはコメントの一覧を開く必要があり不便。
読むだけにしたのは [PR #78](https://github.com/shuhei1101/mindstella/pull/78) の確認事項での決定で、書き換え・削除のエンドポイントはコメントの一覧のために既にある。
