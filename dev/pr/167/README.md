# AI が MCP のツールで項目を消す・取り下げられるようにする

## 概要

AI が、話し合いの途中で検討事項・タスク・調査・資料・用語集・メモ・会話ログの項目を MCP のツールで消す・取り下げられるようになる。

## 背景

[#96](https://github.com/shuhei1101/mindstella/issues/96) の要望。
[#94](https://github.com/shuhei1101/mindstella/pull/94)（起点 Issue [#45](https://github.com/shuhei1101/mindstella/issues/45)）の要件.md の `## スコープ外` から切り出した。
今の MCP サーバーには項目を消すツールが無く、`update` は項目の中のキーを消せるだけで項目そのものは消せない。
取り下げは、検討事項の状態 `取り下げ`・`対象外` とタスクの状態 `中止` だけで、状態を持たない調査・資料・用語集・メモ・会話ログには無い。
話し合いの進行のスキルの取り込みのステップは「項目は消さない」と決めている。
利用者が画面から項目を削除・取り下げる [#48](https://github.com/shuhei1101/mindstella/issues/48) も、消した項目の差分での出し方と参照切れの扱いが要るため、この PR の後ろへ回した（[扱いの判断](https://github.com/shuhei1101/mindstella/issues/96#issuecomment-5991870821)）。
