# 要件

## 要望

プレビューの詳細パネル・詳細の全画面で、本文の語が用語集の用語の別名（`aliases`）に一致したときも、タイトルに一致したときと同じ点線の印とツールチップを出す。

- 当てる範囲（コードブロック・図・リンク・見出しの外。インラインコードは中身がちょうど語のときだけ）と、長い語から当てる・英数字の語は語の切れ目でだけ当てる規則は、タイトルと同じにする
- 別名に一致した印のツールチップと、押したときの動きは、タイトルに一致した印と同じにする（用語 1 件だけに一致した印は用語・ID・意味を出し、押すとその用語の詳細へ移る。資料・調査にも一致した印は種類ごとに並べ、押してもツールチップを残す）
- 同じ用語のタイトルと別名が同じ語のときは、その用語を 1 回だけ並べる
- 開いている用語自身の別名には、その用語の本文の中で印を付けない（タイトルの扱いと同じ）
- 取り下げた用語の別名も、タイトルと同じく当てる
- 空の別名・前後の空白は当てない
- 1 つの語に用語が 2 件以上一致したとき（ある用語のタイトルが別の用語の別名と同じ・2 つの用語が同じ別名を持つ）は、資料・調査にも一致した印と同じく、種類の見出しと詳細へのリンクを持つツールチップを出し、押してもツールチップを残す

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 用語集の使わない表記（`avoid`）を本文で一致させること | 要望は同じものを指す別の言い方（`aliases`）で、使わない表記は書き換えを促す別の目的のキー | 予定なし |
| AI が用語を足すときに別名を付けるよう、スキルの手順を変えること | 要望は本文の印とツールチップで、記録の付け方は変えない | 予定なし |
| 変更履歴の差分の表示で本文の印とツールチップを出すこと | 別の Issue の範囲 | [#154](https://github.com/shuhei1101/mindstella/issues/154) |
| HTML の本文・Markdown に埋め込んだ HTML の中の印とツールチップ | 別の Issue の範囲 | [#212](https://github.com/shuhei1101/mindstella/issues/212) |
