# 本文の語を用語集の用語の別名（aliases）にも一致させ、用語と同じ印とツールチップを出す

## 概要

利用者が、本文に出てきた用語の別の言い方（用語集の別名）にもカーソルを合わせて用語の意味を読み、その用語へ移れるようになる。

## 背景

[Issue #229](https://github.com/shuhei1101/mindstella/issues/229) の要望。
本文の語は、用語集の用語ではタイトルに一致したときだけ点線の印とツールチップが付き、別名（`aliases`）に一致しても付かない。
[#219](https://github.com/shuhei1101/mindstella/pull/219) で資料・調査のエイリアスを本文の語に一致させたが、用語集の別名は要望の範囲外として [#219 の要件](https://github.com/shuhei1101/mindstella/blob/develop/dev/pr/219/%E8%A6%81%E4%BB%B6.md) の `## スコープ外` に回していた。
