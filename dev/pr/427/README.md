# スレッドの画面と詳細パネルで、レビュー中のコメントの長い本文を折りたたむ

## 概要

利用者が、スレッドの画面のレビュー中の返信と、詳細パネルのレビュー中のコメントでも、長い本文を折りたたんだまま読み進められるようになる。

## 背景

[Issue #331](https://github.com/shuhei1101/mindstella/issues/331) の要望。
[#329](https://github.com/shuhei1101/mindstella/pull/329)（起点 Issue [#136](https://github.com/shuhei1101/mindstella/issues/136)）で、レビュー中の書き込みの画面の長い本文を 5 行までに折りたたみ、「続きを読む」で開けるようにした（部品『本文の折りたたみ』）。
同じレビュー中の書き込みを出すスレッドの画面と詳細パネル（詳細の全画面を含む）の欄は #329 のスコープ外とし、本文を全文で出している。

[#401](https://github.com/shuhei1101/mindstella/issues/401)（レビュー中の書き込みの画面の廃止）は、溜めた書き込みの確認をコメントの一覧の先頭の行とスレッドの画面で行うとしており、スレッドの画面と詳細パネルの欄は廃止の後も残る。
