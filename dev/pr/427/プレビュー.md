## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スレッドの画面 | 部品『スレッドの書き込み』の `pending` の本文を部品『本文の折りたたみ』で描き、開閉と開閉のボタンを返す | 置き場所は要件の `未確定` |
| 詳細パネル・詳細の全画面 | レビュー中のコメントの行の本文を部品『本文の折りたたみ』で描く | 描き方は要件の `未確定` |
| 開閉の保持 | 行の ID ごとの開閉を画面が覚え、描き直しと本文の書き換えをまたいで保つ。書き換えている行には開閉のボタンを出さない | レビュー中の書き込みの画面と同じ |
| スタイル | 詳細パネルの行の並びのセレクタ（`.d-list li`・`.review-list li`）を子の `li`（`> li`）だけに絞り、本文の中の Markdown のリストに行の並びの見た目を当てない | モックで見つけた崩れ（`dev/mock/refs/427/assets/style.css` で打ち消した分） |
| アクセシビリティ | 開閉のボタンの読み上げの名前・`aria-expanded`・`aria-controls` は部品のとおり。詳細パネルとコメントの一覧を同時に開いたときは `data-focus` を欄ごとに分ける | 部品に `data-focus` の接頭辞の引数を追加し、詳細パネルは `REVIEW_FOCUS` を渡す |
