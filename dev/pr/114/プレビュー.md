## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の切り分け | 今の版（`74d159a`）を見本の D-7 で measurement のとおり測り、本文の印と図の印が出るまでを分けて記録する。あわせて図の印までの内訳（今の版の図・前の版の本文の `renderMarkdown`・前の版の図の `mermaid.render`・`diffDiagram`）を測る。負荷の低いときの値は参考値として記録する | PoC 検証で行う。端末の空きメモリと MCP `get_capacity` の空き枠を確かめてから測る |
| 図の差分の描き方 | flowchart（`graph` を含む）の図は、前の版の図を SVG に描かず、前後の記法を `mermaid.mermaidAPI.getDiagramFromText` で解析してノードと辺の鍵と文字を取り出し、文字は前後とも解析した結果で比べる。色を付ける要素は今の版の SVG から鍵で引く。前の版の図の記法は今のまま前の版の本文の `renderMarkdown` から取る（前後で取り出し方をそろえ、変えていない図を変えたと取らない）。`state` 以外の図では `boxOf` を呼ばない（案 E） | 案 D の文字の比べ方は PoC の D'。sequence・class・er・state の図は今のまま前の版の図を描いて突き合わせる。解析できない図は今のまま描いて突き合わせる |
| 消したものの名前 | 解析した結果のラベルは記法のまま（`<br>`・Markdown の記号を含む）のため、消したものの一覧に出す名前は、今の版の SVG の文字と同じ表示の文字にそろえる | PoC の `br_removed` で `**消す** 方`（今は `消す 方`）とずれた |
| 図の差分の出し方 | 印・凡例・消したもの・Raw の差分・打ち切ったときの扱いは変えない | - |
| 性能 | 見本の D-7 で、非機能要件『差分の表示の切り替えの時間』の measurement のとおり 200 ms 以下 | 実装の後、切り分けと同じ端末で、各回の load average を記録して測り、直す前の値と並べる |

結論: 成立。案 D' + E を採る。
案 A は縮む分が前の版の本文の `renderMarkdown` の 1〜2 ms だけで、手で取り出すと marked と字下げ・囲みの扱いがずれて変えていない図を変えたと取る余地があるため採らない。
前の版の図の `mermaid.render` が図の印までの時間のほとんどを占め、A + E では届かなかった。前の版を描かずに前後の記法を解析する形で、tester より高い負荷でも 90 ms に収まった。
負荷の低いときの参考値は、計測の間 load average が 7 を下回らず取れなかった。
測る前の端末の空き: WSL の available 38.6 GB・Windows の空き物理メモリ 9.1 GB・MCP `get_capacity` の `free` 1。
`mermaidAPI` は mermaid 12.1.0 の型定義で `@internal` のため、解析できない（例外を投げる）ときは今の方式（前の版を描いて突き合わせる）へ戻す。

最小再現コードの要点（`plugins/mindstella/skills/mindmap/preview/core/diff.ts` の `diffDiagramParsed`）:

```ts
const parts = async (source: string) => {
  const parsed = await mermaid.mermaidAPI.getDiagramFromText(source);
  const nodes = new Map<string, DiagramPart>();
  // SVG のノードの鍵は `flowchart-{id}`
  for (const [id, vertex] of parsed.db.getVertices()) nodes.set(`flowchart-${id}`, { key: `flowchart-${id}`, text: normalized(vertex.text ?? id), element: afterSvg });
  const counts = new Map<string, number>();
  const edges = parsed.db.getEdges().map((edge) => {
    const base = `${edge.start}>${edge.end}`;
    const number = counts.get(base) ?? 0;
    counts.set(base, number + 1);
    return { key: `${base}#${number}`, text: normalized(edge.text ?? ""), element: afterSvg };
  });
  return { nodes, edges };
};
const previous = await parts(beforeSource);
const drawn = extractDiagram(afterSvg, flavor);           // 色を付ける要素は今の版の SVG から
const parsedNow = await parts(afterSource);               // 文字は前後とも解析した結果で比べる
// drawn のノード・辺の text を parsedNow の text に置き換えてから compareDiagrams(flavor, previous, …)
```
