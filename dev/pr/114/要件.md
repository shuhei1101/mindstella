# 要件

## 要望

詳細パネルを開いたまま変更履歴でまとまりを選んだとき（差分の表示の切り替え）、本文と図の両方に差分の印が出るまでを、非機能要件『差分の表示の切り替えの時間』の決定値 200 ms 以下にする。

- 満たす基準は、見本の D-7（本文 1000 行と、ノード 50 の `flowchart TD` の図）で measurement のとおり 5 回測った中央値が 200 ms 以下。端末の負荷は絞らず、tester と同じ条件で測る
- 図・本文・Raw の差分の出し方（印・凡例・消したもの・打ち切ったときの扱い）は変えない
- 着手の最初に、今の版（`74d159a`）の図の印までの内訳を測り、負荷の低いときの値も原因を切り分ける参考値として記録する

flowchart の図は、前の版の図を SVG に描かず、前後の記法を解析して突き合わせる（PoC の案 D' + E）。
sequence・class・er・state の図と、解析できない図は、今のまま前の版の図を描いて突き合わせる。
