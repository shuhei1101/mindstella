# 差分の表示の切り替えで、図のノード 50・本文 1000 行でも 200 ms 以内に図の差分の印を出す

## 概要

詳細パネルを開いたまま変更履歴でまとまりを選んだとき、図のノード 50・本文 1000 行の項目でも 200 ms 以内に本文と図へ差分の印が出るようにする。

## 背景

[Issue #113](https://github.com/shuhei1101/mindstella/issues/113) の不具合。
release/v0.6.0（`74d159a`）の実機での確認（[#106 の結果の報告](https://github.com/shuhei1101/mindstella/pull/106#discussion_r4193616996)）で、非機能要件『差分の表示の切り替えの時間』（200 ms）が中央値 240〜266 ms で不合格になった。
遅れているのは図の側で、本文の印は 48〜67 ms、図の印は 217〜297 ms で出ている。
計測した時の端末の負荷は load average 5.2〜7.3（8 コア）。
[#108](https://github.com/shuhei1101/mindstella/issues/108) の直し [#110](https://github.com/shuhei1101/mindstella/pull/110) で今の版の図を使い回すようにし、中央値は 337 ms から縮んだが、決定値に届いていない。
PoC（[#83](https://github.com/shuhei1101/mindstella/pull/83)）は同じ形で 117〜160 ms だった。
直さないと v0.6.0 を master へ入れられないため、release/v0.6.0 を base にする。
