# 本文の図の通常の表示で虫眼鏡のカーソルを出さず、図の文字を選べるようにする

## 概要

利用者が、プレビューの詳細パネルと詳細の全画面の本文の図の上で、虫眼鏡のカーソルに惑わされず、図の文字を選んでコピーできるようになる。

## 背景

[#204](https://github.com/shuhei1101/mindstella/issues/204) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-185）。
今のプレビューは、本文の図（`.diagram .mermaid`）の上でカーソルを虫眼鏡（`cursor: zoom-in`）にしているが、図そのものに押下の処理は無く、拡大は図の「拡大表示」のボタンだけが行う。
図の拡大表示を外側の押下で閉じる話は [#152](https://github.com/shuhei1101/mindstella/issues/152) で、この PR では扱わない。
