# 要件

## 要望

詳細パネルと詳細の全画面の本文の図（通常の表示。図の拡大は含まない）の上で、カーソルを虫眼鏡（`zoom-in`）にしない。
図の文字（ノード・辺のラベル）の上ではカーソルを文字の選択（`text`）にし、ドラッグで図の文字を選んでコピーできるようにする。
文字の無い図の面の上は既定のカーソルにする。
通常の表示の図は押しても拡大・縮小しない（今の動きのまま）。
図の拡大は今の「拡大表示」のボタンだけが行う。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 図の拡大表示を外側の押下で閉じ、一回り大きくする | 別の要望で、図の拡大表示の閉じ方と大きさの話 | [#152](https://github.com/shuhei1101/mindstella/issues/152) |
| GitHub Pages のドキュメントサイトの図（`docs/assets/style.css` の `.mermaid-holder`）の虫眼鏡のカーソル | プレビューとは別の画面で、要望の対象（話し合いの記録の本文）に含まれない | 予定なし |
| `dev/mock/refs/` の過去の見本のスタイルの `cursor: zoom-in` | 過去の見本の写しで、配る画面に入らない | 予定なし |
| 図の文字を選んだときの選んだ箇所のコメントの入口の出し方 | 要望はカーソルと文字を選べることで、入口の出し方は今の動きのまま変えない。スコープに含めるかはレビューで確定する | 予定なし |
