## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 図の面のカーソル | `.diagram .mermaid` の `cursor: zoom-in` を外し、文字の無い図の面は既定のカーソルにする | 詳細パネルと詳細の全画面の本文の両方に効く |
| 図の文字 | 図の文字（`svg text`・`foreignObject`・`.nodeLabel`・`.edgeLabel`）に `cursor: text` と `user-select: text` を当て、ドラッグで選べるようにする | 図の拡大（`.v-stage svg ...`）と同じ要素の組にする |
| 押下 | 通常の表示の図に押下の処理を足さない。拡大は「拡大表示」のボタンだけ | 今の動きのまま |
| 既存機能への影響 | 図の拡大のカーソル（`grab`・文字の上の `text`）と、Raw・コピーのボタンは変えない | - |
