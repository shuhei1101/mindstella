# 編集を溜めた後の描き直しで書きかけの入力が失われる不具合を修正し、結合テストを安定させる

## 概要

利用者がプレビューで編集を溜めた後の描き直しで、入れた値と「案を追加」で置いた書きかけの案を失わないようにする。
あわせて、実行ごとに不安定に落ちる設定の画面と詳細パネルの結合テストを安定させる。

## 背景

[Issue #328](https://github.com/shuhei1101/mindstella/issues/328) の要望。
[#327](https://github.com/shuhei1101/mindstella/pull/327) の結合テスト作成で、`test_workspace_settings_screen.py` と `test_options_edit` が develop でも不安定に落ちると分かった。
[#327 の reviewer の確認](https://github.com/shuhei1101/mindstella/pull/327#discussion_r4360317510)で、`test_options_edit` はテストの待ち方ではなく、編集を溜めたことによる書き換えの知らせで詳細パネルを描き直したときに書きかけの案が消える画面側の不具合で落ちると分かった（[Issue のコメント](https://github.com/shuhei1101/mindstella/issues/328#issuecomment-6366660174)）。
編集の表示と設定の画面は [#325](https://github.com/shuhei1101/mindstella/pull/325) で入った。
