# 話し合いの途中で、題名・ゴール・プレイブックを変えられるようにする

## 概要

利用者が、話し合いの範囲が広がっても同じワークスペースのまま、題名・ゴール・プレイブック（進め方ガイド）を途中で変えて話し合いを続けられるようになる。

## 背景

[#44](https://github.com/shuhei1101/mindstella/issues/44) の要望で、手元の mindstella の話し合いで決めた分（D-17・D-18・D-23・D-32・D-33・D-43・D-47・D-48）。
今の設定（`mindmap.yaml`）は、題名・分野・ゴールをセットアップで作るときにしか決められず、分野は 1 つ・ゴールは必須になっている。
話し合いの途中で設定を書き換える MCP のツールは無く、方針転換で納品物を外すときだけ Edit ツールで `mindmap.yaml` を直している。
本文の依存の #13（設定を変える MCP のツール）は、MCP への移行を分けた [#67](https://github.com/shuhei1101/mindstella/issues/67)（完了済み）と読み替えて受け付けた（[扱いの判断](https://github.com/shuhei1101/mindstella/issues/44#issuecomment-5979937501)）。
すべてのデータを変える MCP のツールは [#45](https://github.com/shuhei1101/mindstella/issues/45) が扱う。
