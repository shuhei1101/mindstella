## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定の形 | `field`（文字列）を `playbooks`（プレイブックの名前の配列。1 件以上・重複なし）に置き換え、`goal` を任意のキーにする。`goal` の中身（`phase`・`summary`・`deliverables`）は今のまま | `summary`・`target_label`・`phases` は必須のまま |
| 設定を書き換えるツール | 新しい MCP のツールで、`summary`・`playbooks`・`phases`・`target_label`・`goal` のうち渡したキーを置き換える（`goal` は `null` で外す）。置き換えた後の設定をスキーマで検証し、通らなければ書かない | ツールの名前と引数はインターフェース定義設計で決める |
| フェーズの付け替え | 要件の `未確定`（推奨: 設定を書き換えるツールが古いフェーズから新しいフェーズへの対応を受け取り、設定と項目のフェーズを今の書き込みの鍵の中で 1 回で書く）。新しい `phases` に無いフェーズを持つ項目が残る書き換えはエラーにする | 決める段: インターフェース定義設計 |
| ゴールのフェーズ | `goal.phase` は `phases` のどれかであることを、書き換えのときに確かめる | フェーズを付け替えたときはゴールのフェーズも対応で付け替える |
| ゴール判定 | ゴールが無いときは、届いたかを判定せず、ゴールが無いことと、全フェーズの決着していない検討事項を返す | 出力の形はインターフェース定義設計で決める |
| 記録の取得と概要の集計 | ゴールが無いときも `GET /api/records` と `export` が設定と集計を返す。フェーズごとの決着の数は全フェーズで数える | - |
| 移し替え | `migrations/v0.5.0/` に `field` を `playbooks` の 1 件の配列へ移す手順を置く。今の操作で書けなければ、版のフォルダの `scripts/` から呼ぶ操作（`call`）で書く | 呼び名（`target_label`）は書き換えない |
| 前の版の形の見分け | `field` を持ち `playbooks` を持たない設定を前の版の形として見分け、移し替えのスキルを案内する | 今の `summary` の見分けと同じ扱い |
| 書き込みの排他 | 設定を書き換えるツールも、今の `.mindstella.lock` の排他の中で書き、開いている画面へ書き換えを知らせる | - |
