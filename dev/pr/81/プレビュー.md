## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 見出しの上の 1 行 | 設定の話し合いの概要を出す。プレイブックの名前は出さない。概要が無いときは行を出さない | - |
| ゴールまでの進捗のタイル | ゴールが無いときは見出しを「フェーズ別の進捗」にし、「ゴールは決まっていません」と全フェーズの決着の数だけを出す | 見出しのアイコンは画面設計で決める |
| 記録の型 | 設定の型を `playbooks`（配列）と任意の `goal` に直し、ゴールが無い記録でも描画が止まらない | `.ts` を直し、tsc で生成した `.js` を commit する |
| 配る書き出し | 同じ画面のコードを使うため、書き出した 1 枚の HTML も同じ出し方になる | - |
