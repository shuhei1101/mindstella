# E2E のまだまとめていない変更の期待値に removed を足す

## 概要

まだまとめていない変更（`pending`）の返り値を辞書ごと比べる E2E の期待値に、消した項目 `removed` を足して、release/v0.7.0 の E2E を通す。

## 背景

[Issue #183](https://github.com/shuhei1101/mindstella/issues/183) の `E2E失敗`。
[#167](https://github.com/shuhei1101/mindstella/pull/167) で `pending` の返り値に `removed` が足され、消した項目が無いときも `removed: []` を返すようになった。
E2E の 3 箇所は返り値を `{"added": [], "changed": []}` と辞書ごと比べており、release/v0.7.0 の再実行で『記録の追加と更新』『発言の取り込み』が fail した（『設定の更新』は再実行の対象外だったが、同じ原因で落ちる）。
