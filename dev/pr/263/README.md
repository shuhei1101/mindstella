# 幅 320px でもトップバーを画面幅に収め、ページ全体が横にスクロールしないようにする

## 概要

プレビューの利用者が、幅 320px の端末でも横にスクロールせずにトップバーの全てのボタンを使えるようにする。

## 背景

[Issue #239](https://github.com/shuhei1101/mindstella/issues/239) の報告。
[PR #237](https://github.com/shuhei1101/mindstella/pull/237)（起点 [#209](https://github.com/shuhei1101/mindstella/issues/209)）のモック作成で、幅 320px（iPhone SE の 320 x 568）でトップバーが収まらず、ページ全体が 340px（差分の表示の間は 360px）まで広がることが分かった。
幅 480px 以下でトップバーの間隔と余白を詰める指定と、差分の札を出している間の詰め方はあるが、それが効いたうえでなお収まらない。
トップバーのはみ出しは [PR #109](https://github.com/shuhei1101/mindstella/pull/109)（901〜963px）・[PR #112](https://github.com/shuhei1101/mindstella/pull/112)（390〜900px）でも幅の範囲ごとに直してきた。
外部規約『業務画面のUI要素』は狭い端末での見切れを 320 x 568 で見るとし、非機能要件『画面サイズ』の決定値は「幅 390px 以上」になっている。
