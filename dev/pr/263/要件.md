# 要件

## 要望

表示幅 320〜1440px のどの幅でも、トップバーが幅に収まり、ページ全体が横にスクロールしないようにする。

- 表示幅 320〜1440px を 1px ずつ変えて、絞り込み・表示の設定・コメント（件数 3）・変更履歴のボタンを出すトップバー（`app.ts` の配信と同じ組み合わせ）を、つながっている・つながらないのそれぞれで、差分なし・差分ありで開いたとき、`document.documentElement.scrollWidth` が表示幅以下になる
- 同じ幅で、トップバーの全てのボタン（右端のライト / ダークの切り替えと、差分の札の × を含む）が横にスクロールせずに見えて押せる
- 差分を出している間、差分の時点の札はどの幅でも `5.5em` 以上の幅を取る
- 幅 390px 以上の見た目と、ボタンの読み上げの名前は変えない

トップバーのはみ出しを幅の範囲ごとに足してきた詰め方（`## 変更箇所の由来`）を、最も狭い 320px で全ての組み合わせが収まる作りに見直し、320px から広い幅までを 1 つの確かめ方で通す。

幅 389px 以下では、ボタンを 1 つも隠さず、ツール名の文字を隠し、間隔と余白を詰めて収める。
差分の札を出している間はツール名の印も隠し、差分なしの間は印を残す。

非機能要件『画面サイズ』の決定値を「幅 320px 以上」へ下げる。
