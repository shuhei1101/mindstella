## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| レスポンシブ対応 | 幅 320px で、接続（つながる・つながらない）× 差分（なし・あり）の 4 通りの組み合わせが全て収まる畳み方を部品設計『トップバー』の状態として持つ | 幅 389px 以下で、ボタンを隠さず、ツール名の文字（差分の間は印も）を隠して間隔と余白を詰める |
| レスポンシブ対応 | 幅の範囲ごとに足してきた規則を、最も狭い幅で収まる作りを土台にして整理し、幅 390px 以上の見た目は変えない | - |
| 既存機能への影響 | ボタンの読み上げの名前・押したときの動き・差分の札の `5.5em` 以上は変えない | - |
| 結合テスト | 表示幅 320〜1440px を 1px ずつ変えて、4 通りの組み合わせを既定の中身で（320〜389px は最大の中身でも）開き、`scrollWidth` が表示幅以下になり、右端のボタンと札の × が幅の中にあることを確かめる | 幅 390px 以上の最大の中身のはみ出しは #270 |
| 動作環境 | 非機能要件『画面サイズ』の決定値を「幅 320px 以上」へ下げる | - |
