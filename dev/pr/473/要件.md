# 要件

## 要望

コメントの入力と返信の入力の「レビューに追加」を、文字を出さないアイコンだけのボタンにし、入力欄の右（同じ行）に配置する。
あわせて、詳細パネル・詳細の全画面の下端のコメントの入力を、右上の開閉のボタンで閉じたり開いたりできるようにする（[PR の会話欄の追加の要望](https://github.com/shuhei1101/mindstella/pull/473#issuecomment-6724163287)）。
今の画面（`/mindstella.html`）の部品と React の画面（`/spa/`）の部品の両方を変更し、2 つの画面の振る舞いを統一したままにする。

<!-- table: data -->

| 対象 | 要件 |
| --- | --- |
| ボタンの文言 | ボタンに文字を出さず、アイコンだけにする。読み上げの名前（`aria-label`）は「レビューに追加」、ツールチップ（`title`）は今の「レビューに追加（Ctrl+Enter）」のままにする |
| ボタンの配置 | 入力欄の右の同じ行に配置し、入力欄の下のボタンの行を無くす。入力欄はボタンの幅を除いた残りの幅いっぱいに広げる |
| 結果の行 | 溜めている・溜めた・空・失敗の結果は、入力欄の下に幅いっぱいで出す。結果が無い間は行の高さを取らない |
| 押せない状態 | 今のまま変えない（コメントの入力は `saving` の間、返信の入力は入力欄が空白だけの間と `saving` の間） |
| キーの操作 | Ctrl+Enter（macOS は Cmd+Enter）で溜める操作と、Tab でボタンに届くことは変えない |
| 畳んだ形 | コメントの入力の畳んだ形（`collapsed`）は今のまま、ボタンと結果を出さない |
| ボタンの縦の位置 | 入力欄が複数行に伸びたときは、ボタンを入力欄の下端に合わせる |
| ボタンのアイコン | 今と同じ吹き出し（`comment`）のアイコンにする |
| アイコンのボタンの見た目 | 1 行の入力欄と同じ高さの正方形の、主な操作の色で塗ったボタンにする。タッチが主な端末（`pointer: coarse`）では 44 x 44 CSS px にし、1 行の入力欄も同じ高さにする。[#245](https://github.com/shuhei1101/mindstella/issues/245) の選んだ箇所の入口のボタンは、塗りではなく、アイコンだけにすることと読み上げの名前・ツールチップの持ち方をこのボタンに統一する |
| 本文のコピー | コメントの入力の、サーバーにつながらず溜められなかったときに出す「本文を写す」を、コピーのアイコンだけのボタンにする。読み上げの名前とツールチップは「本文をコピー」にする |

| 入力の開閉 | 詳細パネル・詳細の全画面の下端のコメントの入力の右上（「{ID} へのコメント」の行の右端）に、アイコンだけの開閉のボタンを配置する。開いている間は v（読み上げの名前とツールチップは「コメントの入力を閉じる」）、閉じている間は ^（「コメントの入力を開く」）にし、`aria-expanded` で開閉を伝える。閉じている間は「{ID} へのコメント」の 1 行だけを出し、入力欄・添えた箇所・結果・「レビューに追加」を出さない。書きかけは閉じても残す。選んだ箇所の入口を押したときは開いてから入力欄へフォーカスを移す |
| 開閉を置く入力 | 詳細パネル・詳細の全画面の下端のコメントの入力だけに置く。項目を指さないコメント（コメントの一覧の新しいスレッドの入力）とスレッドの返信の入力には置かない |
| 開閉を覚える範囲 | この端末に覚え、項目を移っても・開き直しても同じ開閉で出す |
| 閉じた入力の書きかけ | 閉じている間に書きかけがあるときだけ、「{ID} へのコメント」の右に鉛筆の印と「書きかけ」を出す |
