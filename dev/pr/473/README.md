# コメント・返信の入力の「レビューに追加」をアイコンだけのボタンにし、入力欄の右に配置する

## 概要

利用者が、コメントと返信の入力欄の下にボタンの行を持たずに、入力欄の右のアイコンのボタンでコメントをレビューに追加できるようになる。

## 背景

[#399](https://github.com/shuhei1101/mindstella/issues/399) の要望。プレビューのコメントの入力（詳細パネル・詳細の全画面の下端と、コメントの一覧の新しいスレッドの入力）と返信の入力（スレッドの下端）で、「レビューに追加」が入力欄の右下に文字のボタンとして配置され、その分だけ縦の場所を取っている。
コメントの入力と返信の入力は [#469](https://github.com/shuhei1101/mindstella/pull/469)（[#369](https://github.com/shuhei1101/mindstella/issues/369)）で React へ移行済みで、React の画面へ切り替える [#371](https://github.com/shuhei1101/mindstella/issues/371) までは今の画面の部品も配信している。
本文の文字列を選んだときのボタンをアイコンだけにする [#245](https://github.com/shuhei1101/mindstella/issues/245) と、アイコンのボタンの見た目を統一する。
