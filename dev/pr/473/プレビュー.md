## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ボタン | アイコンだけのボタン（React は `Button` の `size="icon"`）にし、`aria-label`「レビューに追加」と `title`「レビューに追加（Ctrl+Enter）」を持たせる | アイコンは今と同じ吹き出し（`comment`） |
| 配置 | 入力欄とボタンを 1 行に並べ、入力欄を残りの幅いっぱいに広げる。結果の行は入力欄の下に幅いっぱいで出し、空の間は高さを取らない | ボタンは入力欄の下端に合わせる |
| 狭い幅 | 部品の幅によらず同じ並びにし、結果を下の行に移すコンテナクエリ（`@max-send-narrow`・`.send-row` の折り返し）を不要にする | Narrow のストーリーは残し、390px・320px で入力欄がつぶれないことを確認する |
| 本文のコピー | コメントの入力の「本文を写す」を、コピーのアイコンだけのボタン（`aria-label`・`title` は「本文をコピー」）にする | 理由の文の下に置く |
| 押せない状態・キーの操作 | 変更しない | - |
| アクセシビリティ | 読み上げの名前とツールチップは変えず、フォーカスの輪は既存のボタンと同じにする。タップ領域は 1 行の入力欄と同じ高さの正方形で、タッチが主な端末では 44 x 44 CSS px にする | - |
| 既存機能への影響 | `get_by_role("button", name="レビューに追加")` で押す E2E・結合テストは読み上げの名前が変わらないため変更しない | - |
