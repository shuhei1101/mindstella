# lint の全件実行を全ての検査を回す 1 コマンドにまとめ、ruff の既存の違反を解消する

## 概要

開発者が、テスト実行方法の `lint` の全件実行 1 コマンドで Python（ruff）とプレビューの TypeScript（tsc の型検査）の両方の結果を受け取り、どちらかに違反があれば失敗で終わる。

## 背景

[Issue #256](https://github.com/shuhei1101/mindstella/issues/256) の要望で、[PR #255](https://github.com/shuhei1101/mindstella/pull/255) から切り出した。
その後 [PR #258](https://github.com/shuhei1101/mindstella/pull/258) で `ruff.toml` とテスト実行方法の `lint` 層が develop に入り、ruff を当てる範囲は `plugins tests` になった。
残っているのは、`run_all` の `&&` で ruff が違反を返すと型検査が回らないこと、ruff の既存の違反 21 件、ruff の版の固定と外部ライブラリのページが無いこと（PR #258 の要件.md の「スコープ外」で #256 へ回した項目）。
