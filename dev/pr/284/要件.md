# 要件

## 要望

テスト実行方法の `lint` の全件実行（`run_all`）を、ruff の check と tsc の型検査（`npm run typecheck`）のどちらが違反を返しても両方を最後まで回し、1 つでも違反があれば 0 以外で終える 1 コマンドにする。
develop の時点で ruff が返す違反（`ruff check plugins tests` で 21 件）を全て解消し、`run_all` が 0 で終わる状態にする。
ruff を開発用の依存として版を固定し、外部ライブラリの設計書に置く。

ruff の規則は [PR #258](https://github.com/shuhei1101/mindstella/pull/258) が置いた `ruff.toml` の選択をそのまま使い、当てる範囲は `plugins` と `tests` の Python とする。
違反は規則ごとに次のとおり直す。

| 規則 | 件数 | 直し方 |
| --- | --- | --- |
| RUF100（有効でない規則を指す `noqa`） | 14 | `A002`・`N802`・`S310` を指す `noqa` を外す（規則は足さない） |
| RUF100（違反の無い行の `noqa`） | 1 | `server.py` の `BLE001` の `noqa` を外す |
| RUF022（`__all__` の並び） | 4 | `__all__` を並べ替える |
| B905（`zip()` の `strict` 無し） | 1 | `html_body.py` の `mark_lines` の `zip` に `strict=True` を渡す（`marks` と `end_lines` は常に組で足すため、振る舞いは変わらない） |
| S604（`shell` に真の値を渡す呼び出し） | 1 | `test_register.py` の補助 `_run_main` の引数 `shell`（ログインシェルのパス）を別の名前に変える |

## 影響するユースケース

なし（利用者の動き・ツールと配信の入出力を変えない）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| import の並び（ruff の `I`）と formatter の検査 | PR #258 で `lint` 層に含めないと決めた（テスト実行方法の `lint` 層の説明）。develop で `I001` が 76 件あり、入れると多数のファイルの並び替えになる | 予定なし |
| `noqa` が指していた `A002`・`N802`・`S310` を規則に足す | PR #258 が置いた規則の選択を変えることになる。足すと `A002` 4 件・`S310` 4 件の新しい違反が出る | 予定なし |
| lint を CI で回す | リポジトリに CI（`.github/workflows/`）が無く、要望に含まれない | 予定なし |
