## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `lint` の全件実行 | ruff の check と `npm run typecheck` を、前の検査の結果によらず両方回し、どちらかが 0 以外なら 0 以外で終える 1 コマンドにする | 個別実行（`run_one`）は変えない |
| ruff の版 | `requirements-dev.txt` に版を固定して足し、テスト実行方法の `lint` 層の前提をその版にする | 版は外部ライブラリ『ruff』に書いた版 |
| 外部ライブラリ『ruff』 | 版・入れ方・使うコマンド（`ruff check`）・設定ファイル（`ruff.toml`）・動作確認を書く | `dependency_scope` は開発用 |
| `server.py` | 有効でない `A002` を指す `noqa` と、違反の無い行の `BLE001` の `noqa` を外す | コメントの残りの文言は変えない |
| `html_body.py` | `mark_lines` の `zip` に `strict=True` を渡す | `marks` と `end_lines` は常に組で足すため振る舞いは変わらない |
| `test_register.py` | 補助 `_run_main` のキーワード引数 `shell` を、ログインシェルのパスと分かる名前に変え、呼び出し側も合わせる | `_environ` へ渡す値は変えない |
| `register_helpers.py`・`external_access_helpers.py` | `__all__` を並べ替え、有効でない `A002` を指す `noqa` を外す | - |
| 回帰の確認 | `pytest tests/unit` と、触ったファイルの結合テスト（`tests/integration/skill/`・`tests/integration/server/`）を回す | - |
