# 詳細の全画面でも、本文の文字を選ぶと選んだ箇所のコメントの入口を出す

## 概要

プレビューの利用者が、詳細パネルから全画面に切り替えた後も、本文の文字を選んでその箇所へコメントを付けられるようにする。

## 背景

[Issue #142](https://github.com/shuhei1101/mindstella/issues/142) の報告。
詳細パネルでは本文を選ぶとコメントの入口が出るが、全画面に切り替えると出ない。
入口は [PR #78](https://github.com/shuhei1101/mindstella/pull/78) で入り、置く先を `document.querySelector("dialog.full[open], aside.panel")` で引いている。
全画面に切り替えた後も詳細パネル（`aside.panel`）が文書の先に残るため、置く先が詳細パネルになり、全画面の中の選択を弾く。
