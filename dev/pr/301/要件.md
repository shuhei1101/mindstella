# 要件

## 要望

詳細パネルから詳細の全画面に切り替えた後も、本文の文章か項目の値を選び終えたら、詳細パネルと同じく選んだ箇所のコメントの入口を全画面の中に出す。

- 詳細パネルを開いてから全画面に切り替え、本文の文を選ぶと、入口が全画面（`dialog.full`）の中に 1 つ出る。押すと全画面の下端のコメントの入力に箇所が添わる
- HTML の本文の枠の中を選んだときも、全画面に切り替えた後に入口が全画面の中に出る
- 全画面から詳細パネルに戻した後は、今までどおり詳細パネルの中の選択で入口を出す
- 図の拡大を開いている間は出さない、というこれまでの約束は変えない

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |

| 同上（`frameSelect` に同じ行を写した） | [fba697b](https://github.com/shuhei1101/mindstella/commit/fba697b7550968c348532efbed9c483c92c44efd)（`資料の本文を HTML でも書けるようにする (#214)`） | HTML の本文の枠で選んだときも、同じ置く先に入口を出すために写した | 2 回 | 全画面を開いていれば全画面を置く先にする直し方は、どちらの目的も壊さない。既存の結合テストは全画面のハッシュ（`full=1`）で直に開き、文書に `aside.panel` が無いため、この取り違えを確かめていなかった |
