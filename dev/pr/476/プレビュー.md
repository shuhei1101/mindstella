## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| マイクのボタン | 「レビューに追加」の左にアイコンだけのボタンを置き、`aria-label`「音声で入力」を持たせる | 部品設計『コメントの入力』『返信の入力』の `voice` |
| 録音 | ボタンを押したら `getUserMedia` でマイクを取り、`MediaRecorder` で録音する。録音中はマイクと「レビューに追加」の位置を × の「キャンセル」と ✓ の「文字起こし」のアイコンだけのボタンに切り替え、結果の行に丸と経過の時間だけを出す | 録音の上限の長さは資源の値として設計で決める |
| キャンセル | 録音を止めて捨て、マイクを解放し、元のボタンに戻す | 入力欄は変えない |
| 文字起こし | 録音を止めてサーバーへ送り、結果が返るまで文字起こし中を出す。`send` は結果をその 1 件の書き込みとして溜めずに Claude Code へ送信し、`insert` はカーソルの位置へ挿入する | 返信の入力では、その返信 1 件だけを送信する |
| 押せないとき | 画面を開いたときと、押せないマイクのボタンを押したときにサーバーから文字起こしの可否を読み、使えないときはボタンを押せなくし、理由をツールチップで出す。`getUserMedia` が無いときも同じ | 配る書き出しはコメント・返信の入力を持たないため対象外 |
| エラー表示 | 文字起こしの失敗・マイクの許可の拒否は、入力の結果の行に理由を出す | 入力欄の文字は残す |
| 設定の画面 | 文字起こし後の挙動（`send` / `insert`）と用語集のプリセットの入力を追加する | プリセットの候補はサーバーから読む |
