## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文字起こしのインターフェース | 音声とプリセットを受けて文字を返す・使えるかを返す・プリセットの一覧を返す抽象を置き、配信の処理はこの抽象だけに依存する | voice-paste の実装はこの抽象を満たす 1 つ |
| voice-paste の実装 | `POST /web/transcriptions` に音声を送って `job_id` を受け、`GET /web/transcriptions/{job_id}` で `done`・`failed` になるまで待つ | 待ちの間隔と上限は資源の値として設計で決める |
| 使えるかの判定 | voice-paste に届かない・`/web/` の下が 404 のとき、使えない理由つきで返す | 画面はこの理由をツールチップに出す |
| 音声を受けるエンドポイント | プレビューの配信に、音声を受けて文字起こしの結果を返すエンドポイントと、可否・プリセットの一覧を返すエンドポイントを追加する | 音声の大きさの上限を設ける |
| `send` の送信 | 文字起こしの結果を、その 1 件だけのスレッドの書き込みにして Claude Code へ入力する | 既存の『コメントをまとめて送る』の経路で 1 件を送るかを設計で決める |
| 設定 | `config.yaml` に文字起こし後の挙動（既定 `send`）と用語集のプリセットのキーを追加し、`update_settings` と設定の画面で書き換えられるようにする | 破壊的変更は無い（キーの追加だけ） |
| エラー返却 | 文字起こしの失敗・待ちの上限の超過・使えないときは、`detail` に理由を入れて返す | ステータスは設計で決める |
