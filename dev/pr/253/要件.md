# 要件

## 要望

幅 900px 以下で、詳細パネルを開いたままトップバーから表示の設定・コメントの一覧・絞り込みのドロワーを開いたとき、開いたパネルを詳細パネルの前に出し、詳細パネルを閉じずにパネルの中を操作できるようにする。
開いたパネルを閉じたら、開く前に見ていた詳細パネルの項目がそのまま見える。
前に出すのは後から開いた側にする。
コメントの一覧の行から詳細パネルを開いたときは、今と同じく詳細パネルをコメントの一覧の前に出し、詳細パネルを閉じるとコメントの一覧へ戻る（画面設計『コメントの一覧』）。
幅 900px 以下の Esc は前に出ている側から閉じる。
幅 901px 以上の Esc は今のまま詳細パネルから閉じる。
幅 901px 以上の重なり順と、パネルが覆った範囲の本文の部品を `inert` にする扱いは変えない。
