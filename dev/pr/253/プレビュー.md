## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 重なり順 | 幅 900px 以下で、詳細パネルを開いたまま表示の設定・コメントの一覧・絞り込みのドロワーを開いたら、開いたパネルを詳細パネルの前に出す | 後から開いた側を前に出す |
| 一覧から開いた詳細 | コメントの一覧の行から開いた詳細パネルは一覧の前に出し、閉じると一覧へ戻る | 今の振る舞いを保つ |
| 閉じる操作 | 幅 900px 以下で、Esc とトップバーのボタンは、前に出ている側から閉じる | 幅 901px 以上の Esc は今のまま詳細パネルから閉じる |
| アクセシビリティ | 後ろになった側の部品は `inert` にし、Tab で後ろのパネルへ入らない | 前に出たパネルが覆った範囲を止める今の扱いを、詳細パネルにも当てる |
| レスポンシブ対応 | 幅 901px 以上の重なり順は変えない | - |
