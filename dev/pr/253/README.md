# 幅 900px 以下で、詳細パネルを開いたまま開いた左のパネルを詳細パネルの前に出して操作できるようにする

## 概要

利用者が、幅 900px 以下のプレビューで、詳細パネルを開いたまま表示の設定・コメントの一覧・絞り込みのドロワーを開き、詳細パネルを閉じずにそのパネルを操作できるようになる。

## 背景

[#238](https://github.com/shuhei1101/mindstella/issues/238) の要望。
幅 900px 以下では、詳細パネル（`z-index: 35`）が表示の設定・コメントの一覧（`z-index: 34`）より前に来るため、詳細パネルを開いたまま左のパネルを開くと後ろに隠れて操作できない。
絞り込みのドロワー（`dialog.drawer.narrow`、`z-index: 34`）も同じ重なり順になっている（#238 の扱いの判断で task-reviewer が挙げた）。
[#237](https://github.com/shuhei1101/mindstella/pull/237)（起点 [#209](https://github.com/shuhei1101/mindstella/issues/209)）のモック作成で見つかり、対象外として切り出された。
