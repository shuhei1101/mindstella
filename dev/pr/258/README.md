# スレッドに利用者の既読・未読を持たせ、AI の返信が届いたことを画面で未読の印として示す

## 概要

利用者が、AI の返信や AI が立てたスレッドのうちまだ読んでいないものを、プレビューのコメントの一覧とトップバーのコメントのボタンで見分けられる。
スレッドを開くと、そのスレッドは利用者の既読になる。

## 背景

[#249](https://github.com/shuhei1101/mindstella/issues/249) の要望。
[PR #235](https://github.com/shuhei1101/mindstella/pull/235)（起点 [#208](https://github.com/shuhei1101/mindstella/issues/208)）でコメントがスレッドになり、AI が返信・スレッドを立てられるようになった。
スレッドの書き込みは AI の既読（`threads.yaml` の `posts[].read`）だけを持ち、利用者が読んだかは持たないため、AI の返信が届いても画面では見分けがつかない。
PR #235 の要件.md の「スコープ外」に残した項目の切り出し。
AI の返信を外のサービス・OS の通知で知らせる要望は [#157](https://github.com/shuhei1101/mindstella/issues/157) で、目的が別。
