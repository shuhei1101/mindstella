## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 記録の形 | `threads.yaml` の書き込みに、利用者の既読（真偽値）のキー `seen` を足す。AI の既読 `read` は変えない | ER 図『ワークスペース』の `posts[].seen` |
| 書き込みを足す処理 | `reply`・`new_thread` で足す AI の書き込みは利用者の未読、まとめて送るで足す利用者の書き込みは利用者の既読にする | - |
| 既読にする受け口 | 配信に、スレッド 1 件の利用者の未読の書き込みを全て利用者の既読にする受け口を足す。未読が無ければ書かずに返す。書いたら書き換えの知らせを流す | `POST /api/threads/{id}/seen`（インターフェース定義『画面からのスレッドの既読』） |
| 画面へ返す形 | `GET /api/threads` の書き込みに利用者の既読を足す | AI の既読と取り込み済みは今のまま返さない |
| 未読へ戻すフック | `reset_unread.py` は AI の既読だけを未読へ戻し、利用者の既読を変えない | 期待値を足す |
| MCP のツール | `threads`・`thread` の結果と絞り込みは変えない（未読は AI の未読のまま） | - |
| 移し替え | `seen` を必須にし、v0.8.0 の送信からスレッドへの移し替えで移した書き込みに `seen: true` を書く | #258 を #235 と同じリリースに入れる前提（[確認ログ](./確認ログ.md)） |
