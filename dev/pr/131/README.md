# プレビューのボードの列の見出しの階層を、画面の見出しから 1 段ずつ下がるようにする

## 概要

スクリーンリーダーの利用者が、プレビューのボード（検討事項・タスク・資料）の列を、画面の見出しから 1 段ずつ下がる見出しで辿れるようになる。

## 背景

[#125](https://github.com/shuhei1101/mindstella/issues/125) の要望。
ボードの列の見出しは `h3` で、概要以外の画面の見出しは読み上げ用の `h1` だけのため、間の `h2` が欠けている。
[#122](https://github.com/shuhei1101/mindstella/pull/122) の実装照合で検討事項の画面を崩れの検出にかけ、axe の `heading-order` と impeccable の `skipped-heading` に当たった。
ボードは [#21](https://github.com/shuhei1101/mindstella/pull/21) で入った `board()` を 3 つの画面が共用している。
