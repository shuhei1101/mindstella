## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| アクセシビリティ（見出しの段） | `board()` の列の見出しを `h3` から `h2` にする。画面の `h1` の直下に列が並ぶため、間に見出しは足さない | 検討事項・タスク・資料のボードに同時に効く |
| 閲覧機能（列の見出しの見た目） | `style.css` の `.board-col h3`・`.board-col h3 .n` のセレクタを `h2` に変え、宣言は変えない | 生成した `.js` も commit する |
| 画面設計 | タスク・検討事項・資料の要素「ボード」に、列の見出しが画面の見出し（`h1`）の 1 段下（`h2`）であることを書く | - |
| 既存機能への影響 | 概要の画面はボードを持たず、詳細パネル（`h2` の題名と `h3` の節）は変えない | - |
