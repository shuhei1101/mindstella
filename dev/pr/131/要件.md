# 要件

## 要望

プレビューのボード（検討事項・タスク・資料）の列の見出しを、画面の見出し（`h1`）の 1 段下の `h2` にする。
検討事項・タスク・資料のボードを開いた画面が、axe の `heading-order` と impeccable の `skipped-heading` に当たらないこと。
列の見出しの見た目（文字の大きさ・太さ・下線・縦に送ったときにボードの上に留まること）は変えない。
