# シナリオ『起動スクリプトで立ち上げる』『送信の取り込み』の空の title をファイル名で埋める

## 概要

単一ユースケースのシナリオ『起動スクリプトで立ち上げる』『送信の取り込み』の `title` を、ファイル名どおりの機能名で埋める。

## 背景

[#171](https://github.com/shuhei1101/mindstella/issues/171) の要望。
テンプレート『シナリオ』の `title` は「単一ユースケースは機能名…ファイル名に合わせる」だが、『起動スクリプトで立ち上げる』の `title` が空で、生成した Markdown の見出しも空になる。
[#165](https://github.com/shuhei1101/mindstella/pull/165) のレビューで reviewer が対象外の逸脱として報告した。
同じ逸脱が『送信の取り込み』にもあり、どちらも [#71](https://github.com/shuhei1101/mindstella/pull/71) で作られたときから空のまま。
