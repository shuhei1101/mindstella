# 要件

## 要望

単一ユースケースのシナリオのうち `title` が空の 2 つを、テンプレート『シナリオ』の `title`（単一ユースケースは機能名。ファイル名に合わせる）どおりに埋める。

| シナリオ | 埋める `title` |
| --- | --- |
| `起動スクリプトで立ち上げる.yaml` | `起動スクリプトで立ち上げる` |
| `送信の取り込み.yaml` | `送信の取り込み` |

埋めた後、`dev/設計書/` の YAML に `title: ""` が 1 つも残らず、生成した Markdown の見出しが `title` の機能名になる。
