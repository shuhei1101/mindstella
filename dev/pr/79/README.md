# 項目に変更履歴を持たせ、画面で前回からの差分を表示する

## 概要

利用者が、AI が書き換えた項目の前回からの変更を、プレビューで差分の表示に切り替えて読めるようになる。

## 背景

[#68](https://github.com/shuhei1101/mindstella/issues/68) の要望で、[#13](https://github.com/shuhei1101/mindstella/issues/13) から分けた変更履歴と差分の分。
話し合いの中で AI が資料などを頻繁に書き換えるが、今の項目は最後の値だけを持ち、どこが変わったかを画面で追えない。
前提のサーバーと MCP への移行（[#67](https://github.com/shuhei1101/mindstella/issues/67)、[#71](https://github.com/shuhei1101/mindstella/pull/71)）は develop に入っており、書き込みは MCP のツールが、画面の記録はサーバーの `GET /api/records` が担う。
保持する回数の設定は、後の [#24](https://github.com/shuhei1101/mindstella/issues/24)（設定の 2 段化）がこの設定を既定に持つ。
