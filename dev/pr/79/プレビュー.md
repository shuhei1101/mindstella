## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 差分の表示の切り替え | 全ての画面で同じ入り切りの状態を使い、端末の保存領域に残す。切り替えの置き場所はモック作成で決める | 既定は切り |
| 前の版の組み立て | 記録の変更履歴から、比べる回の項目のキーと本文を組み立てる | 比べる回を選べるかは要件の `未確定` |
| Markdown の差分 | 今の本文と前の版の行ごとの差分を取り、描いた段落・見出し・箇条書き・表の行へ、足した・消した印を付ける。消した行は描いた本文の中に消した印つきで差し込む | 印の見た目はモック作成 |
| 図の差分 | mermaid の記法の前後でノードと辺を突き合わせ、足した・変わったノードと辺を色で示す。消したものは図の外に一覧で示す | 消したものの見せ方はモック作成 |
| Raw の差分 | 図の拡大と本文の Raw の表示で、行ごとの差分（足した行・消した行）を出す | - |
| キーの差分 | 詳細パネルの各キーで、前の値と今の値を見分けられる形で出す | 見た目はモック作成 |
| 新規・変更の印 | 基準の時点（要件の `未確定`）より後に足された項目に新規、変わった項目に変更の印を、表・カード・ボード・マップ・概要のタイルに付ける | 差分の表示の間だけ出す |
| タブの印 | 印の付いた項目を持つタブに印を付ける | 件数との兼ね合いは要件の `未確定` |
| 差分が無いとき | 変更履歴の無い項目・保持する回数が 0 のワークスペースでは、差分の表示に切り替えても今の内容をそのまま出す | - |
| 配る書き出し | 見るだけの 1 枚の HTML でも、埋め込んだ変更履歴から同じ差分を出す | 前回見た日時はその端末で持つ |
| 差分の計算 | 行ごとの差分はブラウザで計算する。ライブラリを使うかは、モジュール構成設計でライブラリ選定を挟んで決める | 配る書き出しはネットにつながらない端末で開くため、使うなら同梱する |
| アクセシビリティ | 足した・消したを色だけで示さず、記号か下線・取り消し線を併せる | - |
