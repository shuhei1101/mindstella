## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマ | `plan`（`start`・`due`）と `actual`（`started`・`done`）を、どちらも任意のキーで持つオブジェクトとして `tasks.schema.json` に足す。値は `format: date` の文字列 | 広げるだけのため `no-steps.yaml` に載せ、移し替えの手順を足さない |
| 実績を渡させない | `actual` を `RESERVED_KEYS` と同じくツールが付けるキーにし、`item` で渡したら書き込まずにエラーを返す | - |
| 実績の記録 | `stage_update` で `status` が `進行中`・`完了` に変わったとき、`stage_add` で足す状態が `進行中`・`完了` のとき、`actual.started`・`actual.done` に記録した日の日付を入れる | `started` は書き直さず、`完了` で `started` が無ければ同じ日付を入れる。`完了` から戻したら `done` を消す |
| 予定の検証 | `plan.start` が `plan.due` より後なら、書き込まずに入力エラーを返す | - |
| 変更履歴 | 実績の変更も他のキーと同じく変更履歴とまだまとめていない変更に入れる | - |
| 既存機能への影響 | `plan`・`actual` を持たないタスクは今と同じに読み書きする | - |
