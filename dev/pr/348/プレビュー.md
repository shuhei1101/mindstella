## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 埋め込んだ HTML | mdmark の HTML の埋め込みの機能で、Markdown の資料の中の HTML を描いた結果のまま出す | `未確定`（要件.md の埋め込んだ HTML と操作できる部品の描き方） |
| 図・チャート | 埋め込んだ HTML の中の図・チャートを mdmark の部品で描き、チャートを拡大・縮小とドラッグで動かせる | `未確定`（要件.md のチャートの拡大・移動） |
| 操作できる部品 | スライダー・グラフ・今の値をコピーするボタンを mdmark の部品で描き、動かした値を JSON でクリップボードへコピーする | - |
| 用語・エイリアスの一致 | 一致と一致の前の正規化（NFKC・英字の大文字小文字・前後の空白）を mdmark に受け持たせ、`core/libs.ts` の一致の正規表現を外す。マーカーとツールチップは、mdmark の一致の結果（`collectMatches` の位置と参照先）へ部品『本文の印のツールチップ』を付け、今の振る舞い（全ての出現に付ける・項目の ID を持ち押すと詳細を開く・種類ごとの見出し・1 つの語が複数の項目に一致・開いている項目自身と取り下げた資料・調査を除く）を保つ | PoC 検証で 5 点をどちらで満たすかを確かめる |
| HTML の中のツールチップとリンク | 埋め込んだ HTML の中の文にも、用語・資料・調査のマーカーとツールチップ、項目の ID のリンクを付ける | - |
| 差分 | 埋め込んだ HTML の変更を、既定はソースの行と文字の色分け、切り替えで描いた結果の前と後で出す。今の HTML の本文の差分の「描いた結果」「原文の差分」の切り替えの並びに合わせる | 差分を mdmark へ寄せるのは #347 |
| 資料の書き出し | 詳細パネルと詳細の全画面に書き出しの操作を置き、Markdown か 1 枚の HTML を選ぶ。Markdown を選んだときは、埋め込んだ HTML が消えることと共通のスタイルが外れることを確かめてから書き出す | `未確定`（要件.md の書き出しを作る場所） |
| mdmark のバージョン | mdmark#102 を含むバージョンへ上げ、固定した jsDelivr の URL と `integrity` を替える | v0.8.0 がリリースされていなければ、実装の前に待つ |
| アクセシビリティ | 書き出しの操作と警告はキーボードで操作でき、部品の読み上げの名前は mdmark の部品の決まりに従う | - |
| 外部ライブラリ | 増やすライブラリはバージョンを固定し、配る書き出しが中に持つときはライセンスの表示に加える | - |
