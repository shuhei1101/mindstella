## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 既読にする | スレッドを利用者の既読にする受け口を呼ぶとき、手元のスレッドの写しのそのスレッドの `seen` が `false` の書き込みを既読にし、トップバーの未読の点が変わるなら描き直す | 応答を待たない |
| 一覧へ戻る | 戻った一覧は手元の写しから描くので、既読にしたスレッドの行に未読の札を出さない | 書き換えの知らせで読み直したときもサーバーの値で描き直す（今のまま） |
| 失敗したとき | 受け口が失敗しても画面に出さず、スレッドを読み直して手元の写しをサーバーの値に戻す。開いたままなら同じスレッドへ呼び直さず、次にそのスレッドを開いたときに呼び直す | 失敗し続けても要求を回し続けない |
| 既存機能への影響 | 開いている間に届いた返信を既読にする流れ（読み直したときの呼び出し）と、同じスレッドへ重ねて送らない控え（`seenSending`）は保つ | - |
| 写しの書き換え | 指したスレッドの書き込みを既読にした新しい並びを返す関数 `withSeen` を `thread-row.ts` に足し（`hasUnseen`・`anyOpenUnseen` と同じ置き場所）、`app.ts` の既読にする処理を開く・読み直しの 1 か所にまとめる | モジュール構成『画面と部品.ts』『入口.ts』 |
| テスト | 単体: `withSeen` が指したスレッドだけを既読にし、渡した並びを変えないことを足す。結合: 開いている間に届いた返信を既読にして一覧へ戻った直後に印が 0 件であることを足す。E2E: 既存の `test_normal_when_ai_reply_arrives` で確かめ、新しいケースは足さない | - |
