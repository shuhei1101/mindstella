# 要件

## 要望

プレビューでスレッドを利用者の既読にしたら、書き換えの知らせを待たずに、手元のスレッドの写しのその書き込みを既読として描く。

- 開いているスレッドに AI の返信が届き、`threads.yaml` の書き込みが全て `seen: true` になった後に「一覧へ戻る」を押すと、戻った直後の一覧のそのスレッドの行に未読の印（`.th-unread`）が 0 件で、トップバーのコメントのボタンに未読の点が出ない
- 一覧の行・レビュー中の書き込みから未読のスレッドを開いた場合も、既読にした後に戻った一覧とトップバーに印を出さない
- 手元の写しは、既読にする受け口を呼ぶ時点で既読にし、トップバーを描き直す（応答を待つ間に戻っても印を出さない）
- 既読にする受け口が失敗したときは、次にスレッドを読み直したときのサーバーの値で描く（失敗を画面に出さない今の振る舞いは変えない）

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| サーバーの既読にする受け口（`POST /api/threads/{id}/seen`）の振る舞い | ファイルの既読は正しく書けており、要望に含まれない | 予定なし |
| [docs/使い方/プレビューを見る.md](https://github.com/shuhei1101/mindstella/blob/release/v0.8.0/docs/%E4%BD%BF%E3%81%84%E6%96%B9/%E3%83%97%E3%83%AC%E3%83%93%E3%83%A5%E3%83%BC%E3%82%92%E8%A6%8B%E3%82%8B.md) の既読の説明 | 「返信が描かれた後に既読になる」は直した後も成り立つ | 予定なし |
