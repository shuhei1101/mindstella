# 開いていたスレッドから一覧へ戻った直後に、既読にした未読の印が残らないようにする

## 概要

利用者が、開いているスレッドに届いた AI の返信を読んでから一覧へ戻ったとき、そのスレッドの行とトップバーのコメントのボタンに未読の印が出ない。

## 背景

[#274](https://github.com/shuhei1101/mindstella/issues/274) の不具合。
release/v0.8.0 の E2E（[#194 の実行の結果](https://github.com/shuhei1101/mindstella/pull/194#discussion_r4285228807)）で `test_thread_talk.py::test_normal_when_ai_reply_arrives` が 7 回中 7 回 fail した。
`threads.yaml` の書き込みは全て利用者の既読になっているのに、戻った直後の一覧に未読の印が 1 つ出て、5 秒ほどで消える。
原因は [PR #258](https://github.com/shuhei1101/mindstella/pull/258)（スレッドの利用者の既読・未読）で、画面が既読にする受け口を呼んだ後も、手元のスレッドの写しを書き換えの知らせで読み直すまで古い未読のまま描いている。
