# プラグインの版をリポジトリの版 v0.9.0 に揃え、リリースで揃って上がるようにする

## 概要

プラグインの版を、リポジトリの版 v0.9.0 に揃える。
リリースでリポジトリの版を上げるときに、プラグインの版も揃って上がるようにする。

## 背景

[Issue #305](https://github.com/shuhei1101/mindstella/issues/305) の報告。
リリース v0.9.0（[PR #300](https://github.com/shuhei1101/mindstella/pull/300)）で直下の `version.ini` だけが `v0.9.0` になり、`plugins/mindstella/version.ini` は `v0.8.0` のまま残った。
そのため `test_plugin_version_not_behind_release_version` が develop で fail する。
[PR #301](https://github.com/shuhei1101/mindstella/pull/301) の実装照合で見つかった。
