# リポジトリの直下に rule-inject の索引 rules.yaml を追加し、プロジェクトの規約・テンプレートを記載する前に案内する

## 概要

エージェントが mindstella のリポジトリでファイルを記載する・ツールを呼ぶ前に、プロジェクト固有のテンプレート・規約と、使用しているスタックの knowledge の規約を、rule-inject から案内されるようになる。

## 背景

[Issue #423](https://github.com/shuhei1101/mindstella/issues/423) の要望。
rule-inject はセッションごとにリポジトリの直下の `rules.yaml` を参照しに行くが、ファイルが無く、`read_index` が `FileNotFoundError` で失敗し続けている（11-03 だけで 3034 回）。
[docs/rules.yaml](https://github.com/shuhei1101/mindstella/blob/develop/docs/rules.yaml) はあるが `rules: []` のままで、どの規約も案内されない。
後続の [#375](https://github.com/shuhei1101/mindstella/issues/375)（AI Monitor の配布物への追従）は、この索引があることを前提に行を追加する。
