# プレビューの全体の検索のモーダルの見出しの階層を、1 段ずつ下がるようにする

## 概要

スクリーンリーダーの利用者が、プレビューの全体の検索のモーダルの結果を、1 段ずつ下がる見出しで辿れるようになる。

## 背景

[#132](https://github.com/shuhei1101/mindstella/issues/132) の要望。
全体の検索のモーダルは結果の見出し（「完全に一致」・種類名）を `h3` で作り、モーダルの中に `h1`・`h2` が無い。
[#131](https://github.com/shuhei1101/mindstella/pull/131)（[#125](https://github.com/shuhei1101/mindstella/issues/125)）でボードの列の見出しを直したときに同じ型の箇所として見つかり、範囲外として切り出された。
モーダルを開いた状態は崩れの検出（axe の `heading-order`・impeccable の `skipped-heading`）にかけていない。
