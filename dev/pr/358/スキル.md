## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| タグを付ける条件 | 「話題のタグを付ける」を、規約『タグと用語の登録』の付ける条件・付けない条件の表（主題・別のキーで表せる語・評価の語・同義語）で書き直す。語彙に合うタグが無い主題は、説明の 3 点を書いた候補として `batch` の中で付ける | 候補を語彙へ登録するのは `update_settings`（`batch` の外）で、取り込みの途中では必須にしない |
| 用語を登録する条件 | 「用語を育てる」を、登録する条件・登録しない条件の表で書き直す。一般的な語でもプロジェクトで狭い意味で使う語と、調べた外部ライブラリ・外部サービスの名前を登録する側に入れる | 「一般的な技術の言葉は、利用者が指定したときだけ足す」を消す |
| エイリアスを登録する条件 | `SKILL.md` の「記録の書き方」の `aliases`・`description` を、登録する条件・登録しない条件の例つきの表にする | タグに入れない旨は残す |
| スレッドのタグ | 「スレッドの返し方」のタグを、記録のタグと同じ条件で付け、合うタグが無ければ候補のまま付ける | |
| 候補の採否 | 取り込みの最後（`commit` の前）に、その発言の書き込みの結果に返った未登録の候補ごとに、3 点の説明つきで語彙へ登録するか、`tag_map` で既存のタグへ付け替えるかを決める | 単一ユースケース設計で決めた（候補が溜まらず、付けた直後の文脈で決められる） |
