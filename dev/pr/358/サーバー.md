## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| タグの語彙 | 設定のスキーマから `tags` を削除し、`UnknownTagError` を削除する。`vocabulary.py` は表記の正規化と近いタグだけを持つ `tag_text.py` に置き換える。タグはどの文字列でも書ける | #333 の方針の変更（D-169） |
| 書き込みのタグの確かめ | `add`・`update`・`batch`・`new_thread`・`update_thread`・保存待ちの編集の保存は、渡した表記のままタグを書く。結果に候補のタグを返さない | 空・重なりのタグを弾く既存の検査は残す |
| `tags` | 項目とスレッドが使っているタグを NFKC と小文字でそろえた表記で、件数（項目 + スレッド）と種類つきで返す | インターフェース定義『タグの一覧』 |
| `find` のタグ | タグを NFKC と小文字でそろえて比べる。どの項目も使っていないタグは 0 件を返し、使われている近いタグを `hint` で案内する | 単一ユースケース『記録の検索』 |
| `check` | タグの警告（`warnings`）と `hint` を削除する | - |
| `update_settings` | `tags`・`tag_map` の引数と `UnmappedTagError` を削除する。保存待ちの編集の `map` も `tags` を受けない | - |
| 移行 | v0.11.0 の手順として `call`（`remove_tag_vocabulary`）で `config.yaml` から `tags` を削除する | インターフェース定義『記録の形式の移行』 |
| プレビューの画面 | 設定の画面からタグの語彙の入力と、外したタグの付け替え先を削除する。項目の編集のタグは、記録で使われているタグを候補に出し、候補に無いタグも入れられる | 画面設計『設定の画面』『詳細パネル』『表示の設定』 |
