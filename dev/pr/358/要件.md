# 要件

## 要望

タグのマスター（語彙）を持たない（[#333](https://github.com/shuhei1101/mindstella/issues/333) の「方針の変更（2026-10-29）」、D-169）。タグは自由な文字列にし、取り込みの手順を knowledge の規約『タグと用語の登録』に合わせる。

| 要望 | 終わりの条件 |
| --- | --- |
| 付ける条件と付けない条件 | 取り込みの手順（`steps/取り込み.md`）と session の `SKILL.md` に、タグ・用語・エイリアスそれぞれの付ける条件と付けない条件が例つきで書かれている。タグは「使われているタグを `tags` で引き、同じ意味のタグがあれば使い回し、無ければそのまま新しいタグを付ける」。「合うタグが無い新しい話題のときだけ登録してから付ける」「一般的な技術の言葉は、利用者が指定したときだけ足す」の書き方が無くなっている |
| タグの語彙をやめる | 設定の `tags[]`・`UnknownTagError`・`update_settings` の `tags` と `tag_map` が無くなっている。`add`・`update`・`batch`・`new_thread`・`update_thread` と画面からの保存待ちの編集の保存が、どのタグでも書き込む。`find` の `tags`・`any_tags` は項目に付いているタグで絞る |
| 使われているタグの一覧 | `tags` が、項目とスレッドに付いているタグを件数つきで返す |
| タグの正規化 | タグを比べる前に NFKC と大文字小文字を正規化する |
| 画面からタグの語彙を外す | ワークスペースの設定の画面（`workspace-settings.ts`）にタグの語彙の入力と、外したタグの付け替え先の選択が無い。項目の編集（`detail-edit.ts`）のタグの候補が、使われているタグになっている |
| 既存のワークスペースの移し替え | upgrade が既存のワークスペースの設定から `tags[]` を外す |

取り消した要望: 語彙に無いタグを未登録の候補として受け付けて点検で警告すること、語彙の説明を「含める / 含めない / 例」（`include`・`exclude`・`examples`）で持てるようにすること。
