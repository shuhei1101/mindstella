# 取り込みの手順にタグ・用語・エイリアスを付ける条件を書き、語彙に無いタグを候補として受け付ける

## 概要

AI が発言を取り込むとき、タグ・用語・エイリアスを付ける条件と付けない条件に沿って付けられるようにする。
語彙に無いタグは拒否せず未登録の候補として受け付け、点検で採否を決められるようにする。
タグの語彙の説明を「含める / 含めない / 例」で持てるようにする。

## 背景

[Issue #333](https://github.com/shuhei1101/mindstella/issues/333) の要望。
記録に付くタグ・用語・エイリアスが少なすぎる。
取り込みの手順が「合うタグが無い新しい話題のときだけ登録してから付ける」「一般的な技術の言葉は利用者が指定したときだけ足す」と、付けない方へ倒している。
語彙に無いタグを拒否する動きは [#303](https://github.com/shuhei1101/mindstella/issues/303)（[#308](https://github.com/shuhei1101/mindstella/pull/308)）で入った。
登録は `update_settings` で語彙を丸ごと渡し直すため、`batch` に含められない。
合わせる規約は knowledge の『タグと用語の登録』（[shuhei1101/knowledge#42](https://github.com/shuhei1101/knowledge/issues/42) で入った）。
