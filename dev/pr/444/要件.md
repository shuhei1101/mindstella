# 要件

## 要望

親 [#365](https://github.com/shuhei1101/mindstella/issues/365) の決定（D-8・D-13・D-14・D-16・D-20〜D-23）と、[#429](https://github.com/shuhei1101/mindstella/pull/429) で配置した React の土台の決まり（モジュール構成『プレビュー / React』）に従い、次の 2 つの子の画面を React へ移行する。
子 6（[#371](https://github.com/shuhei1101/mindstella/issues/371)）で切り替えるまで、今の画面（`/mindstella.html`）とその部品・ストーリー・テストはそのまま配信し、動かし続ける。

| Issue | 終わりの条件 |
| --- | --- |
| [#367](https://github.com/shuhei1101/mindstella/issues/367) | 検討事項（マップ・ボード・表）・タスク・資料・記録の表の画面が React へ移り、表を TanStack Table と shadcn の data-table のガイドで組んで絞り込み・表示形式の切り替えが動き、既存の機能が失われずに再現されている（D-23） |
| [#368](https://github.com/shuhei1101/mindstella/issues/368) | 詳細パネル・詳細の全画面・図の拡大の画面と、変更履歴のモーダル・差分の表示（差分のマーカー・消した項目の帯・本文の差分・差分のミニマップ）が React へ移り、本文の描画は mdmark の `mount` を `useEffect` の中で呼んで使用し続け、既存の機能が失われずに再現されている（D-23） |

| 対象 | 要件 |
| --- | --- |
| 一覧の画面 | 画面設計『検討事項』『タスク』『資料』『記録の表』の要素と操作を全て再現する。見た目は shadcn/ui・Tailwind とデザイン方針のトークンに合わせて一新してよい |
| 表 | 部品設計『表』の並べ替え・ピン留め・絞り込みのチップ・列の表示を、TanStack Table と shadcn の data-table のガイドで組む |
| 絞り込み・表示形式の切り替え | 部品設計『絞り込み』『表示形式の切り替え』の要素と操作を全て再現する。一覧の絞り込みは knowledge の ui のタグ・絞り込みの規約に合わせる |
| 画面の状態 | 画面・表示形式・開いている項目・絞り込み・並べ替え・差分の表示で比べる時点を、TanStack Router の `validateSearch` + Zod で URL の search に持つ |
| 詳細 | 画面設計『詳細パネル』『詳細の全画面』『図の拡大』の要素と操作を全て再現する（コメントは `## スコープ外`） |
| 画面での編集 | 詳細パネル・詳細の全画面の項目の編集、一覧の画面の項目を追加する入力、項目を削除する操作、画面設計『保存待ちのパネル』『設定の画面』の要素と操作を全て再現する（[確認ログ](./確認ログ.md)） |
| 本文の描画 | mdmark の `mount` を `useEffect` の中で呼んで描き、自前で描かない。marked は本文の差分の塊を分ける `marked.lexer` だけに使用する |
| 変更履歴と差分の表示 | 画面設計『変更履歴』と、部品設計『変更履歴』『差分の印』『消した項目の帯』『差分のミニマップ』『本文の差分の並べ方の切り替え』『左右に並べた本文の差分』『HTMLの本文の差分』の要素と操作を全て再現する |
| API | 移す画面が呼ぶ配信の API のうち OpenAPI の定義に無いもの（前回開いた日時 `POST /api/opened`、保存待ちの編集の `POST /api/edits`・`DELETE /api/edits/{id}`・`POST /api/edits/save` ほか）を定義に追加し、orval で生成する |
| Storybook | 共通の部品の状態ごとのストーリーを `@storybook/react-vite` の設定に追加する。データは MSW と props で差し込む |
