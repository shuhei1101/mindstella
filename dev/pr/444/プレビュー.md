## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ルート | 検討事項・タスク・資料・記録の表をそれぞれ TanStack Router のルートにし、表示形式・開いている項目・絞り込み・並べ替え・差分の時点を `validateSearch` + Zod の search に持つ | インターフェース定義『SPAを開く』 |
| フォルダ構成 | 画面を `features/{domain}/{screen}/` に、複数の画面が使用する部品（表・絞り込み・表示形式の切り替え・差分の印ほか）を `shared/components/` に配置する | モジュール構成『プレビュー / React』と knowledge の規約『フォルダ構成』 |
| 表 | TanStack Table と shadcn の data-table のガイドで、並べ替え・ピン留め・絞り込みのチップ・列の表示を組む | 部品設計『表』 |
| 検討事項のマップ | elkjs の配置の計算を React の側から呼び、ノードとエッジを描く | 外部ライブラリ『elkjs』 |
| 詳細 | 詳細パネル・詳細の全画面・図の拡大を、開いている項目の search から開く。本文は mdmark の `mount` を `useEffect` の中で呼んで描き、図は mermaid で描く | コメントの入力は `要件.md` の `## スコープ外` |
| 画面での編集 | 詳細の項目の編集・一覧の画面の項目を追加する入力・項目を削除する操作を移し、編集を `POST /api/edits` で保存待ちに溜める。保存待ちのパネルを search で開き、取り消しとまとめて保存を移す。設定の画面を移し、設定の編集を同じく保存待ちに溜める | [確認ログ](./確認ログ.md) |
| 変更履歴と差分の表示 | 変更履歴のモーダルで選んだ時点を search に持ち、差分の印・消した項目の帯・本文の差分・差分のミニマップを描く | 差分の計算（marked の `marked.lexer`・jsdiff）は DOM に触らない関数に分ける |
| API | `POST /api/opened`・保存待ちの編集の API ほか移す画面が呼ぶ API を OpenAPI の定義に追加し、orval で hook・Zod・MSW を生成し直す | - |
| Storybook | 共通の部品の状態ごとのストーリーを追加し、画面の本体のストーリーは MSW の handler でデータを差し込む | knowledge の規約『Storybook』 |
| 概要からの行き先 | 概要の画面とトップバーのタブから、React へ移した画面へは SPA の中で移り、移していない画面だけ今の画面を開く | モジュール構成『legacy-url』 |
| アクセシビリティ | Storybook の addon-a11y と、結合テストの Playwright の axe で WCAG の違反を検査する | - |
| 既存機能への影響 | 今の画面・部品・ストーリー・テストは触らない | 子 6 で削除する |
