# 差分の表示の E2E test_normal_when_added_then_removed_since を毎回同じ結果にする

## 概要

差分の表示の E2E テスト `test_normal_when_added_then_removed_since` が、同じコードなら毎回同じ結果になる。

## 背景

[#251](https://github.com/shuhei1101/mindstella/issues/251) の不具合。
[PR #248](https://github.com/shuhei1101/mindstella/pull/248) の reviewer が head `a70edb7f` で `tests/e2e/単一ユースケース/test_diff_view.py` の全体を 3 回流して 1 回 fail し、このテストだけでは 3 回とも pass した。
Issue の推測（開いて閉じた直後に待たずに書き換える）は現物と合わない。
`visit_and_close` は閉じた後に `OPENED_TICK_MS`（1,100ms）待ち、プレビューは `POST /api/opened` の応答を待ってから本文の領域を作るため、閉じる前に前回開いた日時は書かれている（[task-reviewer の指摘](https://github.com/shuhei1101/mindstella/issues/251#issuecomment-6158581170)）。
揺れの原因はまだ分かっていない。
