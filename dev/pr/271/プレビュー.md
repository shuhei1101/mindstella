## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の切り分け | develop（f7a88035）で `test_diff_view.py` の全体を 51 回流し、対象は 2 回 fail した。記録を足した回の fail では、`visit_and_close` を終えた時刻 16:03:28.09 より後に終えた 2 つの `commit` の時刻が 16:03:27.79 で、まとまりの `at` と前回開いた日時が同じ `16:03:27` になり、「前回開いてから」は `0 件` だった。壁時計と単調時計の差を 3 分間測ると、約 29 秒ごとに約 0.76 秒（0.3 秒と 0.46 秒の 2 段）戻っていた | 同じ 51 回の中で、`test_normal_when_rewritten_while_open` も 1 回 fail した |
| 境目を待つ部品 | `preview_helpers.py` に、境目の日時（ISO 8601）を受け、今の UTC の時刻がその秒の 2 秒先の秒に入るまで短い間隔で確かめて待つ関数を足し、`OPENED_TICK_MS` を消す | 2 秒先にするのは、実測の 0.76 秒の戻りがあっても境目より後の秒に残すため |
| `visit_and_close` | 閉じた後、`.mindstella-opened` の日時を境目にして待つ | ワークスペースの直下は呼び手から受ける |
| `test_normal_when_rewritten_while_open` | タブの sessionStorage の `mindmap-since`（タブを開いた日時）を境目にして待つ | - |
| `test_normal_when_first_open` | 書き換えのまとまりの `at` を境目にして待ってから開く | - |
| 確かめる中身 | 件数 `1 件`・消した N-2 と消した印・新規の印が無い・N-1 に印が無い、の期待値は残す。直したほかのテストの期待値も変えない | - |
| プレビューとサーバー | 変えない。同じ秒のまとまりを範囲から落とすことは [#272](https://github.com/shuhei1101/mindstella/issues/272) で扱う | - |
| 既存機能への影響 | `visit_and_close` を使う `test_diff_view.py`・`test_preview_reread.py` のテストを、期待値を変えずに pass させる | - |
