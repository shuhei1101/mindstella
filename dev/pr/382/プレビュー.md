## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 追加の入力の案の操作 | `submitAddField` で `input.op` を見て、`set` だけを `next[input.key]` に入れ、`option-add`・`option-edit`・`option-remove`・`adopt` は `next.options` を書き換えて同じ `item-add` を送信し直す。`adopt` では選んだ案だけを採用にし、`status` を決定済みにする | 追加の入力の案の区画では、採用している案の削除ボタンを出さない（採用をほかの案へ移すと出る）。既存の項目の案の削除の決まり（採用している案は消せない）と揃える |
| 書きかけの案 | 案を溜めたら、詳細パネルと同じくその記号の書きかけを `optionDrafts` から外す。仮の ID が振られる前に案を書いたときは、タイトルを書くまで手元（`addDraft`）に持つ | - |
| 追加の入力の描き直し | 溜めた案を `addedItem` の `options` から案の区画に描く | - |
