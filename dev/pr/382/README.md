# プレビューの項目を追加する入力で、「案を追加」の案を案として溜める

## 概要

利用者がプレビューの「項目を追加」で検討事項を追加するときに、「案を追加」で書いた案が、保存で案として書き込まれるようにする。

## 背景

[Issue #380](https://github.com/shuhei1101/mindstella/issues/380) の不具合。
追加の入力の `submitAddField` が `input.op` を見ずに `next[input.key] = input.value` にしているため、案の追加が、案の記号をキーにした属性（例 `C: {content}`）として `item-add` の `value` に入る。
[#378](https://github.com/shuhei1101/mindstella/pull/378) の実装レビューで reviewer が対象外の逸脱として報告した（[スレッド](https://github.com/shuhei1101/mindstella/pull/378#discussion_r4431251120)）。
項目を追加する入力は [#325](https://github.com/shuhei1101/mindstella/pull/325) で入り、まだリリースしていない。
