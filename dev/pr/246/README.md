# 図の拡大の結合テスト test_raw_scroll_by_keyboard を毎回同じ結果にする

## 概要

図の拡大の結合テスト `test_raw_scroll_by_keyboard` が、同じコードなら毎回同じ結果になる。

## 背景

[#225](https://github.com/shuhei1101/mindstella/issues/225) の不具合。
[PR #223](https://github.com/shuhei1101/mindstella/pull/223) の結合テスト作成で、このテストが同じコードで fail と pass に分かれた（HEAD で 4 回中 1 回 fail、変更前でも単独実行の 2 回中 1 回 fail）。
fail したときは、キーを押した後に記法の枠の `scrollTop` を待つ `Page.wait_for_function` がタイムアウトしている。
reviewer が対象外の逸脱として報告した（[合格報告](https://github.com/shuhei1101/mindstella/pull/223#discussion_r4240439307)）。
