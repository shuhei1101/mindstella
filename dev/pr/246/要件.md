# 要件

## 要望

図の拡大の結合テスト `test_raw_scroll_by_keyboard`（`tests/integration/preview/test_diagram_viewer_screen.py`）を、同じコードなら毎回同じ結果にする。

| 項目 | 要件 |
| --- | --- |
| 原因 | キーを押した後に記法の枠の `scrollTop` を待つところで `wait_for_function` がタイムアウトする原因を突き止め、完了報告に書く |
| 結果の揃い方 | 直した後、このテストだけを 20 回続けて流して 20 回とも pass する |
| 確かめる中身 | 画面設計『図の拡大』の `記法` の要素のとおり、Tab で上の帯のボタンの後に記法の枠へフォーカスが移り、矢印下・PageDown・End・Home で記法が送れることを確かめ続ける。確かめる操作と期待値を減らさない |

直す場所はテストの待ち方だけにし、記法の枠の実装は変えない。
キーを前のスクロールの動きが終わった直後（約 30 ms 以内）に押すと、ブラウザがそのキーを送りに使わないことがある。テストは最下端に着いた瞬間に次のキーを押すため、この間隔に入ったときだけ止まる（[実装の完了報告](https://github.com/shuhei1101/mindstella/pull/246#discussion_r4260710260)）。
