# E2E が表の行ではなくタイトルのボタンを押して詳細を開くようにする

## 概要

表の行を押している E2E を、詳細を開くタイトルのボタンの位置を押すように修正し、元のシナリオの手順の記述を合わせて、release/v0.12.0 の E2E が通るようにする。

## 背景

[#446](https://github.com/shuhei1101/mindstella/issues/446) の E2E の fail。
[release/v0.12.0 の E2E](https://github.com/shuhei1101/mindstella/pull/438) で 3 件が毎回 fail した。
表で詳細を開くのはタイトルの列のボタン `button.row-open` だけで、テストは行の中央か幅の 0.8 の位置を押してボタンの外に当たっている。
グレーアウトを押し抜く確認も同じ位置を押しており、押下を受け止めなくても詳細が開かないため確認になっていない。
製品のコードは変えない。
