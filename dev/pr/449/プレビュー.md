## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 詳細を開く操作 | `page.click` の対象を `tr[data-id="…"] button.row-open` にする | `test_item_detail_view.py`・`test_display_settings.py` |
| グレーアウトを押し抜く確認 | `press_through_scrim` の対象を `button.row-open` にし、`x_ratio` の指定を削除する | `test_thread_talk.py` の 344・413 行目、`test_table_filter_view.py` の 125 行目 |
| ピン止めの間の詳細を開く操作 | パネルが覆っていない `button.row-open` を押す | `test_thread_talk.py` の 398 行目 |
| 左のパネルにボタンが覆われる場合 | 画面の幅を、ボタンが覆われない幅まで広げ、シナリオの前提に幅を追記する | 押した点が左のパネルに当たると確認にならないため、`button.row-open` の位置がパネルの右にあることを測定して確認する |
| 使用しなくなる定数 | `OUTSIDE_X_RATIO` を使用する箇所が無くなったファイルから定数を削除する | - |
| シナリオ | 手順と期待の「行を押す」を「行のタイトルのボタン（の位置）を押す」にする | テスト関数の対応は変えない |
