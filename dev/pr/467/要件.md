# 要件

## 要望

プレビューの Markdown の本文のコードブロックとファイルツリーを、mdmark の既定どおり折り返さずに描き、長い行は枠の中で横にスクロールする。

- 対象: 今の画面（`plugins/mindstella/skills/mindmap/preview/`）と React の画面（`frontend/`）の両方で、`.md` の本文のコードブロック（`.md pre`）。詳細パネル・詳細の全画面・本文の差分・スレッドの書き込みのどれでも同じ
- 基準: 長い行を持つコードブロックで `pre` の `white-space` が `pre`（mdmark v0.9.0 の `export` と同じ）、`scrollWidth` が `clientWidth` より大きく、本文の区画（`.panel-body`）は横にスクロールしない。JSON のインデントとファイルツリーの罫線の並びが崩れない
- キーボード: 横にスクロールするコードブロックで axe の `scrollable-region-focusable` の違反が 0 件（[#128](https://github.com/shuhei1101/mindstella/pull/128) の基準を保つ）。非機能要件の `入力方式`（全ての操作にキーボードで届く）の決定値は変えない
- 届かせ方: mdmark がフェンスのコードブロックの `pre` に付ける `tabindex="0"` と読み上げの名前「コード: {言語}」（言語を書かないものは「コード」）を残す。mdmark が付けない字下げのコードブロックと、差分の表示の間の `html` のコードブロックの原文にだけ、同じ `tabindex="0"` と「コード」を付ける。横にスクロールしない短いコードブロックでも同じにする
- 図の原文と、ライブラリが読めないときの本文の原文（`.md-raw`）は折り返しのまま残す
- 言語の札とコピーのボタン・本文の印と ID のリンクを付けない扱いは今のまま

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 図の Raw（`.dg-raw`）・Raw の差分（`.df-raw`）・図の拡大の Raw（`.v-raw`）の折り返し | 判断が分かれる。Issue の対象はコードブロックとファイルツリーで、図の Raw は mdmark の既定を持たない。Raw の差分は折り返した続きを印の幅だけ下げる描き方を前提にしているため、折り返しのまま残すと判断した。確定はレビューで行う | 予定なし |
| 本文のインラインコードと長い URL の折り返し（`.md a:not(.idref), .md code { overflow-wrap: anywhere; }`） | コードブロックではなく、本文の区画を横にスクロールさせないための指定で、要望に含まれない。`pre` の中の `code` は `white-space: pre` で折り返さないため、この指定は影響しない | 予定なし |
| コードブロックごとに折り返しを選ぶ記法 | mdmark の側の機能で、この PR の範囲ではない | [shuhei1101/mdmark#294](https://github.com/shuhei1101/mdmark/issues/294) |
| `dev/mock/refs/` の過去のモックの `base.css` | 当時の画面のコピーで、今の画面の振る舞いを定めない | 予定なし |
