# プレビューの本文のコードブロックとファイルツリーを折り返さず、mdmark の既定どおり枠の中で横にスクロールする

## 概要

利用者が、プレビューの本文のコードブロックとファイルツリーを、JSON のインデントや罫線を崩さずに mdmark の既定どおり読めるようになる。

## 背景

[#421](https://github.com/shuhei1101/mindstella/issues/421) の要望。
詳細パネルで、コードブロックの長い行が折り返されて JSON のインデントが崩れる。
原因は `.md pre` の `white-space: pre-wrap; overflow-wrap: anywhere;` で、mdmark の既定（長い行は枠の中で横にスクロールする）を上書きしている。
この指定は [#128](https://github.com/shuhei1101/mindstella/pull/128)（[#93](https://github.com/shuhei1101/mindstella/issues/93)）で、横にスクロールするコードブロックへキーボードで届かない（axe の `scrollable-region-focusable`）のを解消するために入れた。
[#368](https://github.com/shuhei1101/mindstella/issues/368) で React の画面へ移した `frontend/src/shared/styles/body.css` も同じ指定を持つ。
