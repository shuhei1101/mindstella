## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閲覧機能 | 今の画面と React の画面の `.md pre` から `white-space: pre-wrap` と `overflow-wrap: anywhere` を削除し、mdmark の共通のスタイル（`white-space: pre`）と `overflow: auto` で枠の中を横にスクロールする | ファイルツリー（言語指定 `tree`）も `.md pre` で描くため同じ扱い |
| アクセシビリティ | 横にスクロールするコードブロックをキーボードのフォーカスで止まり矢印キーでスクロールできる要素にし、axe の `scrollable-region-focusable` の違反を 0 件に保つ | mdmark がフェンスの `pre` に付ける `tabindex="0"`・「コード: {言語}」を残し、付かない字下げのコードブロックにだけ `tabindex="0"`・「コード」を付ける |
| 既存機能への影響 | 言語の札とコピーのボタンの位置、本文の印と ID のリンクを付けない扱い、本文の区画を横にスクロールさせない決まりは変えない | 図の Raw（要件.md の `## スコープ外`）と、ライブラリが読めないときの本文の原文（`.md-raw`）は折り返しのまま。`.md pre` から外した後も、それぞれの規則で `pre-wrap` を持たせる |
| 部品設計 | 『Markdownの本文』（.ts・.tsx）のコードブロックのストーリーを「長い行は折り返さず、枠の中で横にスクロールする」にする | - |
