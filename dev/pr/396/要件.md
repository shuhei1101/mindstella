# 要件

## 要望

詳細パネルと詳細の全画面の要素「レビュー中のコメント」の行の並びを、新しい順（溜めた順の逆。コメントの ID の連番の大きい順）と古い順（溜めた順。連番の小さい順）で切り替えられるようにする。

- 既定の並びは新しい順にする（コメントを書くたびに一番上へ積まれる）
- 切り替えの操作は「レビュー中のコメント」の見出しの並びに置き、1 回の操作で並びが切り替わる
- 消した行の「元に戻す」は、選んでいる並びでの元の場所に残す
- 書き換えている行・消した行があっても、切り替えた後に同じ行がそのまま描かれる
- 切り替えはキーボードで操作でき、読み上げで今の並びが分かる

選んだ並びは端末の保存領域の個人の上書き（`Prefs`）に残し、ページを開き直しても保つ。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| コメントの一覧のレビュー中の書き込み・スレッドの中のレビュー中の返信の並び | 要望は詳細のサイドバーの「レビュー中のコメント」の欄に限る | 予定なし |
| サーバーの『レビュー中のコメントの読み取り』が返す並び | 並びは画面で切り替え、サーバーは今の溜めた順のまま返す | 予定なし |
| 詳細パネルの React への移行 | 別の Issue で扱う。移行の時点でこの PR の並びの切り替えを引き継ぐ | #368 |
