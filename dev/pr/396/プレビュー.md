## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閲覧機能 | 「レビュー中のコメント」の行を、選んでいる並び（既定は新しい順）で並べる。並びはコメントの ID の連番で決め、消した行もその並びの元の場所に残す | - |
| 並びの切り替え | 見出し「レビュー中のコメント」と件数の並びに、新しい順・古い順を切り替える操作を置く | 操作の見た目はモック作成で決める |
| 並びの保持 | 選んだ並びを端末の保存領域の個人の上書き（`Prefs`）に残し、描き直し・項目の移動・詳細パネルと全画面の行き来・ページの開き直しで保つ | - |
| アクセシビリティ | 切り替えをキーボードで操作でき、読み上げの名前か状態で今の並びが分かる | - |
| 既存機能への影響 | 0 件の表示・行の修正・削除・元に戻す・選んだ箇所のコメントの入口の振る舞いは変えない。配る書き出しでは要素ごと出さない（今と同じ） | - |
