# 詳細のレビュー中のコメントの並びを新しい順・古い順で切り替えられるようにする

## 概要

利用者が、詳細パネル（と詳細の全画面）の「レビュー中のコメント」を、新しい順・古い順で切り替えて読めるようになる。既定は新しい順にする。

## 背景

[Issue #140](https://github.com/shuhei1101/mindstella/issues/140) の要望。
詳細パネルの「レビュー中のコメント」は、その項目へのコメントを溜めた順（古い順）に並べるだけで、並びを変えられない。
ユーザーの[追記](https://github.com/shuhei1101/mindstella/issues/140#issuecomment-6061182904)で、既定の並びを新しいコメントを上にする並びにすることも求められている。
同じ欄への要望に [#134](https://github.com/shuhei1101/mindstella/issues/134)（修正・削除。対応済み）、詳細パネルの React 移行に [#368](https://github.com/shuhei1101/mindstella/issues/368) がある。
