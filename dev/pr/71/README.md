# サーバーと MCP を前提にした作りへ移し、tmux の起動コマンドで立ち上げたときだけ MCP を立てる

## 概要

利用者が、起動スクリプトで tmux と Claude Code を立ち上げたときだけ mindstella の MCP のツールを使い、サーバーが配るプレビューで記録の更新を見ながら、詳細パネルから項目ごとに回答・意見を送れるようになる。

## 背景

[#67](https://github.com/shuhei1101/mindstella/issues/67) の要望で、[#13](https://github.com/shuhei1101/mindstella/issues/13) から分けたサーバーと MCP への移行の分。
今はスキルがスクリプト（`mindmap.py`）のコマンドでワークスペースを読み書きし、`build` で記録を埋め込んだ `preview.html` を書き出して、ファイルとして開く。
#13 でユーザーが、スクリプトのモードを残さず MCP を前提にし（スクリプトの版はタグで残る）、MCP はプラグインで常に入れず起動スクリプトで立ち上げたときだけ立てると決めた。
起動スクリプトとサーバーでの配信・送信・取り込みは、#13 の受付で [#10](https://github.com/shuhei1101/mindstella/issues/10) から移した範囲。
配る書き出し（[#19](https://github.com/shuhei1101/mindstella/issues/19)、`export`）は残す。
