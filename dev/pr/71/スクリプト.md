## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| MCP のツール | `build` を除くコマンドを 1 コマンド = 1 ツールで移す。引数は今の `--json` の中身と同じキーを持つ入力にし、出力は今の標準出力の JSON を返す。失敗は今の標準エラーの内容をツールのエラーとして返す。公式の MCP SDK（`mcp` の `MCPServer`）で stdio のサーバーにする | - |
| `build` | ツールにしない。配信が YAML を読むたびに今の `collect_preview_data` と同じ形の記録を組み立てる | - |
| プレビューの配信 | MCP サーバーのプロセスで `127.0.0.1` の空きポート（OS に選ばせる）を待ち受け、プレビューの HTML・スクリプト・記録の JSON を返す。URL はツールで返す。ワークスペースの YAML の mtime を 250ms ごとに見て、変わったら Server-Sent Events で開いている画面へ知らせる | - |
| 送信 | 画面からの送信を受け、項目の ID・本文・送った時刻・取り込んだかをワークスペースに書く。取り込みのツールで未取り込みの一覧を返し、取り込み済みにする | 置き場所は `未確定`（要件） |
| 起動スクリプト | 依存を確かめ、`claude plugin list --json` の `installPath` からインストールしたプラグインの今の版の置き場所を引き、その版の MCP サーバーを `--mcp-config` で渡した Claude Code を tmux のセッションの中で起動してつなぐ。`CLAUDE_CONFIG_DIR` は `tmux new-session -e` で渡す | 置き場所と呼び名はインターフェース定義設計で決める |
| エラー返却 | tmux が無いとき・プラグインがインストールされていないときは、理由を示して止まる | - |
| 既存機能への影響 | `mindmap.py` のコマンドの入口を消す。`export` は MCP のツールで残す | 破壊的変更 |
| セキュリティ | 待ち受けは `127.0.0.1` だけにし、送信で受けるのは項目の ID と本文だけにする。本文はワークスペースへ書く前にスキーマと突き合わせる | - |
| 外部ライブラリ | MCP の SDK（`mcp`）の版を固定し、依存の確認の対象に足す | - |

成立。
反映の時間は 250ms の検知の間隔がほぼ全てで、1 秒に対して 4 倍の余裕がある。
時間は計測の側の単調な時計で、書く前から画面の描き直しを見つけるまでを測った（画面の時計は計測の側の時計と最大 319ms ずれたため使わない）。
本番に入れるときの注意:

- tmux のサーバーが先に立っていると呼び出し元の環境変数は渡らないため、`CLAUDE_CONFIG_DIR` は `tmux new-session -e` で渡す
- 計測は WSL2 の Ubuntu 24.04・Python 3.12.3・`mcp` 2.3.0・Claude Code 2.1.289・tmux 3.4・Chromium（Playwright）で行った
- ディレクトリのマーケットプレイスは版が `unknown` になるため、PoC では `plugin.json` に版を置いて上げ下げした（本番の GitHub のマーケットプレイスは commit の SHA が版になる）

最小再現コードの要点（[#73](https://github.com/shuhei1101/mindstella/pull/73) の `poc/marketplace/plugins/mindstella-poc/server/server.py`）:

```python
def start_preview(workspace: Path) -> str:
    """空きポートで配信を立て、URL を返す。"""
    httpd = ThreadingHTTPServer(("127.0.0.1", 0), make_handler(workspace))
    httpd.daemon_threads = True
    threading.Thread(target=httpd.serve_forever, daemon=True).start()
    host, port = httpd.server_address[:2]
    return f"http://{host}:{port}/"

# /events: mtime を 250ms ごとに見て、変わったら SSE で知らせる
while True:
    time.sleep(POLL_INTERVAL_SEC)
    current = signature(workspace)
    if current != last:
        last = current
        self.wfile.write(f"event: changed\ndata: {current}\n\n".encode())
        self.wfile.flush()

server = MCPServer("mindstella")

@server.tool()
def preview_url() -> str:
    """このプロセスが配るプレビューの URL を返す。"""
    return PREVIEW_URL

server.run("stdio")
```

diff の見どころ:

- `poc/marketplace/plugins/mindstella-poc/bin/mindstella-poc`: `claude plugin list --json` の `installPath` から版のフォルダを引き、この起動だけの `mcp.json` を書いて `tmux new-session -e CLAUDE_CONFIG_DIR=...` で `claude --mcp-config` を立てる
- `poc/marketplace/plugins/mindstella-poc/skills/write/SKILL.md`: `allowed-tools` に MCP のツール（`mcp__mindstella__*`）だけを書く
- `poc/measure.py` と `poc/results/`: 計測の手順と結果（`measure.json`）、Claude Code の画面の写し
