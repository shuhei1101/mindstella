## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `allowed-tools` | `Bash(python3 ...mindmap.py:*)` を、mindstella の MCP のツールの名前へ置き換える | - |
| コマンドの表 | 各 SKILL.md の「コマンド」の表を、MCP のツールと渡す引数の表へ置き換える | - |
| `build` | `session` の「ワークスペースを編集したステップは、最後に `build` を流す」と、`setup`・`upgrade` の `build` を除く | - |
| MCP が使えないとき | 各スキルの入力の確認で、mindstella の MCP のツールが無ければ、何も書き込まず起動スクリプトでの立ち上げを案内して止まる | - |
| 依存の確認 | `setup`・`upgrade` の `check-env` のステップを除く（起動スクリプトが確かめる） | - |
| 送信の取り込み | `session` の準備で、未取り込みの送信を取得し、1 件ずつ取り込みのステップで記録して取り込み済みにする | - |
| プレビュー | `steps/プレビュー.md` の書き出しを、サーバーの URL を示す形へ。配る書き出しは `export` のツールで残す | - |
