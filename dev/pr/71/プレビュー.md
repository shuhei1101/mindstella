## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 記録の読み込み | サーバーから記録の JSON を読む。配る書き出しは今のとおり埋め込みから読み、どちらで読んだかで送信の入口の出し分けを決める | - |
| 描き直し | 書き換えの知らせを受けたら記録を読み直し、開いている画面・URL のハッシュ・詳細パネルの項目を保ったまま描き直す | - |
| 回答・意見の送信 | 詳細パネルに入力と送るボタンを置き、項目の ID と本文をサーバーへ送る。送れたか・失敗したかを入力の近くに出す | 入力欄と送るボタンを詳細パネル・詳細の全画面の下端に留める（モックの `a-footer`）。失敗の印と枠には要見直しの赤を使い、デザイン方針に例外として書き足す |
| 配る書き出し | 送信の入口を出さない（記録を書き換える操作を持たない） | - |
| エラー表示 | サーバーにつながらないときは、つながらないことを画面に出し、最後に読めた記録で描き続ける | - |
| アクセシビリティ | 入力と送るボタンにキーボードで届き、送った結果を読み上げの対象にする | - |
