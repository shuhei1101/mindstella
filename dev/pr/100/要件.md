# 要件

## 要望

プレビューの検討事項のマップ（幅 901px 以上）で、項目を選んだまま背景のドラッグでマップを送った後に余白を 1 回押して選びを外したとき、マップの枠のスクロールの位置（`scrollLeft` / `scrollTop`）を押す前と同じ値に保つ。

- 満たす基準は、シナリオ『検討事項をマップで辿る』の `正常シナリオ（余白を押して選びを外す）` の期待値「余白を押す前後で、マップのスクロールの位置が変わらない」と、それを確かめる `test_normal_when_background_pressed` の pass
- 同じシナリオのほかの期待値（詳細パネルが閉じる・強調が消える・ハッシュから `id=` が消える・選ぶ前と同じ表示に戻る）と、ドラッグでは選びを保つ振る舞いは変えない
