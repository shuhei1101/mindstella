# 要件

## 要望

プレビューの検討事項のマップ（幅 901px 以上）で、項目を選んだまま背景のドラッグでマップを送った後に余白を 1 回押して選びを外したとき、マップの枠のスクロールの位置（`scrollLeft` / `scrollTop`）を、縦・横それぞれ、押す前の位置と、詳細パネルが閉じて広がった枠で送れる端の位置（`scrollWidth - clientWidth` / `scrollHeight - clientHeight`）のうち小さい方にする。

- 詳細パネルが閉じると枠が広がり、マップが広がった枠より小さいときは送れる幅が無くなるため、押す前の位置をそのまま保つことはできない。シナリオ『検討事項をマップで辿る』の `正常シナリオ（余白を押して選びを外す）` の期待値「余白を押す前後で、マップのスクロールの位置が変わらない」をこの基準に直す
- 満たす基準は、直した期待値を確かめる `test_normal_when_background_pressed` の pass
- 同じシナリオのほかの期待値（詳細パネルが閉じる・強調が消える・ハッシュから `id=` が消える・選ぶ前と同じ表示に戻る）と、ドラッグでは選びを保つ振る舞いは変えない
