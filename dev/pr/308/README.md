# MCP の読み取りのツールに、タグの語彙・複数タグの絞り込み・既定の件数とページ分けを入れる

## 概要

エージェントが MCP でワークスペースを読むとき、少ない呼び出しと少ないトークンで目当ての項目にたどり着けるようにする。
タグの語彙・複数のタグでの絞り込み・`find` の既定の件数とページ分けを入れる。

## 背景

[Issue #303](https://github.com/shuhei1101/mindstella/issues/303) の要望。
今の `find` は条件なしで全ての項目を上限なく返し、全体の件数と続きを取る値を返さない。
`find` のタグは 1 つしか渡せず、`tags` は項目が使っているタグだけを返すため、字面の近いタグを足しても書き込みで弾かれない。
タグの一覧を作ったのは [#47](https://github.com/shuhei1101/mindstella/issues/47)。
