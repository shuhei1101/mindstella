## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| タグの語彙 | `config.yaml` の `tags` に、`targets`・`categories` と同じ名前と説明の並びで持つ。名前は語彙の中で一意にし、説明は任意 | `update_settings` で書き換え、消す・名前を変えるタグは対応で項目とスレッドのタグを付け替える。対応の値が null のタグは外す |
| 語彙のモジュール | 語彙の読み取り・語彙にあるかの確かめ・近いタグの候補を、新しい `plugins/mindstella/skills/mindmap/scripts/vocabulary.py` にまとめ、検索・書き込み・スレッド・点検・設定の更新から使う | モジュール構成『タグの語彙』 |
| 語彙の検査 | `add`・`update`・`batch`・`new_thread`・`update_thread` の書き込みの前に、渡したタグが語彙にあるかを確かめ、無ければ書き込まずにエラーにする。エラーには字面の近い語彙のタグを候補として添える | `batch` は 1 つでも合わなければ全体を当てない（今の `batch` の扱いのとおり） |
| `tags` | 語彙の並びで、名前・説明・持つ項目の数・使っている種類を返す。数が 0 のタグも返す | 結果の形が変わる |
| `find` の引数 | `tag` を、全てを持つ項目に絞るタグの並び（AND）に置き換え、いずれかを持つ項目に絞るタグの並び（OR）・件数・続きの値・返す量を足す | 引数の名前はインターフェース定義設計で決める |
| `find` のページ分け | 種類の順・連番の順に並べた結果を、既定の件数で切る。続きの値は、読んだ位置を表す不透明な文字列にする | 既定 20 件・上限 100 件（インターフェース定義『項目の検索』の制約「件数」） |
| `find` の結果 | `items`（ID・種類・題名・状態・タグ）に、`total`・`next_cursor` を足す。切り詰めたときは絞り込める引数を案内する文を足す | `response_format` の `detailed` で足す中身はインターフェース定義設計で決める |
| 空の結果 | 0 件のときは空の `items` と `total: 0` に、外せる条件を案内する文を添える | 切り詰めたときの案内と同じ組み立てを使う |
| 登録外のタグで探す | 語彙に無いタグを渡した `find` を、字面の近い語彙のタグを候補に添えたエラーにする | |
| 正しくない続きの値 | 読めない `next_cursor` はエラーにする | |
| ツールの説明 | `find`・`tags` の説明に、使える絞り込みと、先に `tags` を呼ぶことを書く | |
| 点検 | 語彙に無いタグを持つ項目とスレッドを、設定に無いフェーズと同じく問題として返す | |
| 移し替え | 次の版の手順で、項目とスレッドが使っているタグを説明なしで語彙へ登録する | |
