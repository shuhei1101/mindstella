# 話し合いの中で、AI が案・タスク・納品物・用語集を確かめずに育てるよう、スキルの手順を直す

## 概要

利用者が、話し合いを進めるだけで、検討事項の案・タスク・納品物の資料・用語集が AI によって足され、育っていくようになる。

## 背景

[#50](https://github.com/shuhei1101/mindstella/issues/50) の要望で、手元の mindstella の話し合い（試し議論）で決めた分（D-21・D-28・D-41・D-49・D-51・D-52）。
試しに使った話し合いで、AI が案を画面に残さない・タスクを積まない・納品物の中身を育てない・用語集を育てない動きが見えた。
今の `session` の手順は、案（`options`）をヒアリングで答えを記録するときにしか書かず、用語集は利用者の言い方がずれたときと新しく決めた言い方しか足さず、納品物の資料は会話で図や文書を出したときにしか作らない。
受付で、話題のタグ（D-29）は [#47](https://github.com/shuhei1101/mindstella/issues/47) へ、タスクの担当（D-41 の担当の部分）は [#26](https://github.com/shuhei1101/mindstella/issues/26) へ渡した（[扱いの判断](https://github.com/shuhei1101/mindstella/issues/50#issuecomment-5980116510)）。
