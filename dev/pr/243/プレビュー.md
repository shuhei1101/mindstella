## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| リンクの押下の受け取り | `htmlBodyFrame` が、枠の文書の `load` の後に `click` の受け手を足す。押された要素から最も近い `href` を持つ `a`（SVG の `a` を含む）を引き、あれば既定の動作を止める | `selectable` の真偽によらず足す。枠の `sandbox` は変えない（`allow-popups` を足さない） |
| 新しいタブで開く | 親の画面の `window.open` に `_blank` と `noopener,noreferrer` を渡して開く | 詳細の項目の「リンク」（`links`）のリンク（`target="_blank"`・`rel="noopener"`）と同じ扱い |
| 開くリンクの範囲 | `http:`・`https:`・`mailto:` の URL だけを開き、ほかは移らない | `未確定`（[要件](./要件.md) の `## 要望`。決める段: インターフェース定義設計） |
| 本文の中の場所を指すリンク | `href` が `#` で始まるリンクは開かず、本文のスクロール領域をその `id` の要素まで送る | `未確定`（[要件](./要件.md) の `## 要望`。決める段: 単一ユースケース設計） |
| 中ボタン・修飾キーつきの押下 | 中ボタン（`auxclick`）と Ctrl・Shift・Meta つきの `click` も同じ受け手で受け、新しいタブで開く | 枠の中で移らないことを押し方によらず保つ |
| 文の選択との並び | 枠の中の選択が空でないときの `click` ではリンク先を開かず、既定の動作だけ止める | リンクの文をなぞって選んだ直後の `click` で開かない |
| ストーリー | 部品設計の状態に、リンクを持つ本文の状態を足し、ストーリーで押下を確かめる | - |
| セキュリティ | `javascript:` の URL は開かず、動かさない | - |
| 既存機能への影響 | `html-body-diff.ts`・`detail.ts`・配る書き出しは `htmlBodyFrame` を呼ぶだけで、変更しない | - |
