# 資料の HTML の本文の中のリンクを押すと、新しいタブで開くようにする

## 概要

利用者が、資料の HTML の本文の中のリンクを押すと、本文を詳細に残したまま、リンク先を新しいタブで開けるようになる。

## 背景

[Issue #224](https://github.com/shuhei1101/mindstella/issues/224) の要望。
[PR #214](https://github.com/shuhei1101/mindstella/pull/214)（起点 [Issue #151](https://github.com/shuhei1101/mindstella/issues/151)）のレビューで、reviewer の任意の指摘として挙がった（[スレッド](https://github.com/shuhei1101/mindstella/pull/214#discussion_r4240244153)）。
HTML の本文を描く枠（`sandbox="allow-same-origin"` の iframe）の中のリンクは、押すと枠の中がリンク先のページに置き換わって本文が消え、`target="_blank"` のリンクは `allow-popups` が無く開かない。
