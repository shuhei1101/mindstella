# 結合テスト test_diff_body_side_by_side_when_linked で、左の列の語の差分を待ってから参照する

## 概要

結合テスト `test_diff_body_side_by_side_when_linked` が、左右に並べた本文の左の列の語の差分を待ってから参照し、負荷が高いときにも毎回 pass するようにする。

## 背景

[Issue #434](https://github.com/shuhei1101/mindstella/issues/434) の要望。
右の列の `a.term` が出るのを待った直後に、待たずに左の列の `span.df-word` を参照しており、左の列の語の差分がまだ描かれていないと空になって `assert removed` で fail する。
[#433](https://github.com/shuhei1101/mindstella/pull/433) の結合テストの実行（複数のファイルをまとめて実行）で 1 回 fail し、単独では 4 回中 4 回 pass した。
