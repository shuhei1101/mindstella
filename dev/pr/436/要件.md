# 要件

## 要望

`tests/integration/preview/test_detail_panel_screen.py` の `test_diff_body_side_by_side_when_linked` を、負荷を掛けた状態（CPU を使い切る busy loop を並べ、他の画面のテストと一緒に実行）で繰り返し実行して全回 pass するようにする。

fail の原因は、Issue に書かれた「左の列の語の差分がまだ描かれていない」ではなく、語の差分の打ち切りにある。
語の面は、右の列の `a.term` を付けるのと同じ同期の処理の中で付き、`a.term` が出た時点で付け終えている。
語の差分（`diffInline`）の打ち切り時刻は、詳細パネルが本文の行の差分を呼ぶ直前の時刻に `LINE_DIFF_TIMEOUT_MS`（40ms）を足した時刻で、その後の描画（`renderMarkdown`・`linkBody`・`decorateMarkdown` 等）の時間も同じ枠を使う（モジュール構成『プレビュー / 差分』の `diffInline` の `deadline`）。
負荷で描画が遅れると、語の差分を始める時点で時刻を過ぎていて、左右どちらの列にも語の面が付かない（待っても出ない）。
`performance.now()` を呼ぶたびに 30ms 進める初期化スクリプトを当てると、修正前のテストは Issue と同じ `assert []` で fail した。

打ち切りは非機能要件「差分の表示の切り替えの時間」200ms から割り出した設計どおりの挙動なので、製品コードは変えない。
テストは、開く前に `performance.now()` を読み込んだ時刻で止める初期化スクリプトを当て、語の差分の打ち切り時刻が描画の時間で過ぎないようにする（打ち切りの挙動は単体テスト `test_diff_inline_when_deadline_passed` が確認する）。
