# トンネル・リバースプロキシの内側で使えるよう、ポートの固定・許可するホスト・起動と終了のフックを設定で足す

## 概要

利用者が、自分の端末のサーバーが配るプレビューを、トンネル・リバースプロキシを通して端末の外（スマホなど）から開いて読み、コメントを送れるようになる。

## 背景

[#138](https://github.com/shuhei1101/mindstella/issues/138) の要望。
今の配信は起動のたびに空きポートで待ち受け、`Host` と `Origin` は `127.0.0.1` / `localhost` だけを受けるため、外の入口にポートを登録しても次の起動で変わり、外のホスト名で開いた画面は表示も送信も断られる。
待ち受けと `Host` / `Origin` の確かめは、サーバーと MCP への移行（[#71](https://github.com/shuhei1101/mindstella/pull/71)）で、[#67](https://github.com/shuhei1101/mindstella/issues/67) の要件（端末の中だけで待ち受ける）に沿って入った。
公開範囲は [#25](https://github.com/shuhei1101/mindstella/issues/25)、共有サーバーを複数の人で使う要望は [#14](https://github.com/shuhei1101/mindstella/issues/14) が扱う。
