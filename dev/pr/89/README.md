# 話題のタグを付け、今ある画面を 1 つのドロワーで種類・状態・タグで絞り込めるようにする

## 概要

利用者が、1 つのワークスペースで関連する複数の話題を扱っても、AI が付けた話題のタグで項目を見分け、プレビューのどの画面でも 1 つの絞り込みのボタンから種類・状態・タグで探せるようになる。

## 背景

[#47](https://github.com/shuhei1101/mindstella/issues/47) の要望で、手元の mindstella の話し合いで決めた分（D-20・D-24・D-26・D-27・D-29・D-44）。
話が広がると、項目がどの話題のものか見分けられず、画面でも探せない。
項目はタグ（`tags`）を持てて、表の列と `find` の `tag` で使えるが、AI が話題ごとにタグを付ける決まりも、使っているタグを一覧する MCP のツールも無い。
絞り込みは表の列の見出しと資料のカード・ボードのポップオーバーにだけあり、検討事項のマップとつながりは帯の表示 / 非表示だけ、タスクのボードには無い。
受付でユーザーが前提を待たずに入れられる範囲を先に入れる案を選び、タスクの担当の条件は [#26](https://github.com/shuhei1101/mindstella/issues/26)、「ネットワーク」に改めた後の画面での絞り込みは [#28](https://github.com/shuhei1101/mindstella/issues/28) へ渡した（[扱いの判断](https://github.com/shuhei1101/mindstella/issues/47#issuecomment-5980057526)）。
タグのツールは [#45](https://github.com/shuhei1101/mindstella/issues/45)、取り込みのタグの決まりは [#50](https://github.com/shuhei1101/mindstella/issues/50) から移した。
