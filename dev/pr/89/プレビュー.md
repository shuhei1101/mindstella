## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 絞り込みの部品 | 絞り込みのボタン（件数のバッジつき）と、条件ごとに値を件数つきのチェックボックスで並べるドロワーを 1 つの部品にし、全ての画面で使う。値を 1 つも選んでいない条件では絞らず、条件ごとに選びを外す「解除」を置く | 値ごとの件数は、その条件以外の条件で絞った項目で数える（今の表の数え方） |
| 表 | 列の見出しの絞り込みのボタンとポップオーバーを外し、条件は絞り込みの部品から受け取る。並べ替え・ピン留め・表示する列・条件のチップは残す | 種類・状態・タグの列を条件にする |
| 検討事項のマップ | 状態の帯の表示 / 非表示の切り替えとまとめて切り替える箱を外し、ドロワーの状態・タグの条件に合う検討事項だけを描く。状態で要見直し・未決定・未整理・保留を選んだ状態で開く。状態の帯は外す | - |
| タスクのボード | ドロワーの種類・状態・タグの条件に合うタスクだけを列に並べる | - |
| 資料のカード・ボード | 今の絞り込みのポップオーバーを絞り込みの部品に置き換える | - |
| つながり | 種類の帯の表示 / 非表示の切り替えとまとめて切り替える箱を外し（帯も外す）、ドロワーの種類・状態・タグの条件に合う玉と、その間の線だけを描く。どの値も選んでいない状態で開く | - |
| ドロワーの出し方 | コメントの一覧と同じ出し方にする。どの幅でも幕を付けず、タブの帯の下から左に重ねる非モーダルのパネルで、重ねていない右側は見えたまま操作できる。閉じるボタン・Esc・絞り込みのボタンで閉じ、外側を押しても閉じない。コメントの一覧とは同時に開かず、どちらかを開くと他方を閉じる。開いている間、パネルが覆った範囲の本文の部品を `inert` にする（コメントの一覧も同じ） | 見えない部品にフォーカスが当たらないようにする（WCAG 2.2 の 2.4.11） |
| 絞り込みのボタンの位置 | トップバーのコメントのボタンの隣に置き、どちらのパネルにも覆われないようにする。概要には出さない。900px 以下では文字を隠してアイコンとバッジだけにする | - |
| ボードで外した列 | 状態の条件から外した状態の列も残し、列の中に「状態の条件で外しています。」と出す | - |
| 表示形式の切り替え | 同じ画面のマップ・ボード・カード・表で 1 つの条件を共有し、切り替えても保つ | - |
| 開いたときの絞り込み | URL のハッシュの `f.{列}` を、どの表示形式でもドロワーの条件として受け取る | - |
| 配る書き出し | 同じ画面のコードを使うため、書き出した 1 枚の HTML も同じドロワーで絞り込める | - |
| アクセシビリティ | ドロワーはキーボードで開閉でき、開いたら中へ、閉じたらボタンへフォーカスを戻す。バッジは読み上げで件数が分かる | - |
| 記録の型 | `tags` の型は今のまま使う | `.ts` を直し、tsc で生成した `.js` を commit する |
