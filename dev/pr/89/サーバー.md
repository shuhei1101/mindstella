## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| タグの一覧のツール | ワークスペースの全種類の項目の `tags` を集め、タグごとに付いている項目の数と種類を、タグの名前の順で返す読み取りのツールを足す | 出力の形は `attrs` に揃える。タグが 1 つも無いときは空の一覧 |
| タグで絞り込む検索 | `find` の `tag` をそのまま使う | - |
| 記録の形 | `tags` のスキーマは変えない。移し替えの手順は要らない | - |
