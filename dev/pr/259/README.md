# 設計書の ```mermaid で囲まれていない図を囲み、生成した Markdown で図として描かれるようにする

## 概要

開発者が、設計書の生成した Markdown で、シナリオ・インターフェース定義・モジュール構成の全ての Mermaid の図を図として読めるようになる。

## 背景

[#254](https://github.com/shuhei1101/mindstella/issues/254) の要望。
単一ユースケースのシナリオの一部の `flow` が ```mermaid のコードブロックで囲まれておらず、生成した Markdown で `sequenceDiagram` 以下が地の文として出て図として描かれない。
テンプレート『共通.schema』の `$defs.mermaid` から外れている。
[#253](https://github.com/shuhei1101/mindstella/pull/253)（起点 [#238](https://github.com/shuhei1101/mindstella/issues/238)）のレビューで reviewer が対象外の逸脱として報告した。
