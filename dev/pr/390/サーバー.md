## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 関連のスキーマ | `common.schema.json` の `related` の要素を `{to, type, when}` にし、3 つとも必須にする。`type` は `requires`・`references`・`replaces`・`part_of`・`change_together` の enum | 会話ログの扱いは要件の `未確定` |
| 件数の上限 | 種類のスキーマで `related` の `maxItems` を持つ | 値は要件の `未確定` |
| 書き込み | `add`・`update`・`batch`・保存待ちの編集の保存が関連を要素で受け、参照のキーの扱い（`$番号`・仮の ID の振り直し・参照切れ・削除の指している記録）は要素の `to` に当てる | 同じ `to` の要素を 2 件持つと SchemaMismatchError |
| 逆向き | `show`・`batch` の取得の `referenced_by` の `related` の行に、指している側の関連の `type`・`when` を加える | 他のキーの行は今のまま |
| 点検 | 片側だけに書いた `change_together` を、どちらの項目かを添えて返す | 参照切れの決まりは今のまま |
| 移し替え | 次の版の `migrations/`（#385 と同じ `v0.12.0`）に、ID の並びの `related` を要素の形へ移す手順を置き、前の版の形式の見分けに ID の文字列の要素を加える | 決め方は要件の `未確定` |
| `impact` | 関連をたどらないまま | 要件の `## スコープ外` |
