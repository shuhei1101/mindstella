## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 関連を張る手順 | 関連を張る各手順で、判定フローチャート『関連の張り方』（knowledge）に当てて `type` と片側・両側を決め、`when` を 1 文で書く。`when` を書けない相手と本文でリンクしている相手には張らない | 判定の本文は手順へ写さず、参照を置く |
| 各手順の例 | 取り込み・リサーチ・ゴール判定の `add`・`batch` の例の `related` を要素の形にする | - |
| 会話ログの関連 | 要件の `未確定` で決まった形で、会話ログを足す手順を合わせる | - |
| 移し替え | 要件の `未確定` で A になった場合、upgrade の手順に関連ごとに `type`・`when` を決めて書き換える操作を加える | - |
