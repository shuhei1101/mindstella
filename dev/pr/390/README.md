# 関連（related）に関係の種類といつ読むかを持たせる

## 概要

AI と利用者が、項目の関連ごとに関係の種類といつ読むかを見て、読むべき相手を読めるようにする。

## 背景

[Issue #336](https://github.com/shuhei1101/mindstella/issues/336) の要望。
全種類の項目の `related` は相手の ID の並びで、関係の種類といつ読むかが分からないため、AI が関連をたどらず、読むべき相手が読まれない。
合わせるのは knowledge の『ドキュメント管理』の「関連」（`related-01`〜`related-05`）と判定フローチャート『関連の張り方』で、[shuhei1101/knowledge#42](https://github.com/shuhei1101/knowledge/issues/42) で入った。
同じチェーンの [#335](https://github.com/shuhei1101/mindstella/issues/335)（[#385](https://github.com/shuhei1101/mindstella/pull/385)）が項目の `tags` を `{name, main?}` にし、移し替えの手順を `migrations/v0.12.0/` に置いた。
記録の読み取りを dev-docs へ任せる [#345](https://github.com/shuhei1101/mindstella/issues/345) は、この Issue の逆向きの関連を先に入れることを前提にしている。
