# 要件

## 要望

詳細パネルと詳細の全画面で、文字列の値（`renderValue` で描く値。検討事項の `lead`・`answer`・`reason`、案の `content`・`pros`・`cons`・`note`・`reason` など）の Markdown の見出しのうち最も上の段を、値を置く場所の直上の見出しの次の段にし、ほかの見出しはその段からの差を保って並べる。
h3 の節の中の値（案の値・採用した案と理由・説明・取り下げた理由）は h4、節に入らず題（h2）の後に並ぶ値（検討事項の `lead`・調査の `question`・`conclusion`・メモの `content`・タスクの `reason`・用語の `meaning`）は h3 にする。
段の差の決め方・h6 を超える段の扱い（h6 の要素と `aria-level`）・見た目（`data-md-level` で元の段のまま）は、本文の見出し（[#240](https://github.com/shuhei1101/mindstella/issues/240)）と揃える。
差分の表示の間で変わった値は文字で並べるため、見出しの要素を持たず対象にしない。

## スコープ外

| 項目 | 理由 | 対応予定 |
