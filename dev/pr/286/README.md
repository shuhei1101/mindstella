# 詳細パネルの文字列の値の見出しを、節の見出しより下の段（h4 から）に並べる

## 概要

読み上げで詳細パネルを読む利用者が、値（背景・案の内容など）に書いた見出しを、節の見出し（h3）より下の段から段を飛ばさずに辿れるようになる。

## 背景

[#266](https://github.com/shuhei1101/mindstella/issues/266) の要望。
詳細パネルの文字列の値を描く `renderValue` は Markdown の見出しを下げず、値に `#` を書くと節の見出し（h3）より上の段の h1 になる。
外部規約『操作とアクセシビリティ』の「見出しの段を飛ばさない」から外れている。
本文の見出しを直した [#240](https://github.com/shuhei1101/mindstella/issues/240)（[PR #265](https://github.com/shuhei1101/mindstella/pull/265)）の現状調査で見つけ、対象外として切り出した。
