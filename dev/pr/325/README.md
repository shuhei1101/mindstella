# 利用者が画面から項目を編集・追加・削除し、まとめて保存できるようにする

## 概要

利用者がプレビューの画面から設定と項目を直し・足し・消し・取り下げ、変えた分をまとめて保存できるようになる。
保存した変更は、AI が次の話し合いの最初に受け取る。

## 背景

[Issue #48](https://github.com/shuhei1101/mindstella/issues/48) の要望。
今の画面は見るだけで、利用者がタグ・メモ・案などを直せず、サーバーにも項目を書き換えるエンドポイントが無い。
項目の追加・削除の画面とエンドポイントは [#16](https://github.com/shuhei1101/mindstella/issues/16) から移した。
編集した人の記録（`updated_by`・変更履歴の `by`）は [#46](https://github.com/shuhei1101/mindstella/issues/46)、前回読んだ時点からの変更を返す `changes_since_read` は [#45](https://github.com/shuhei1101/mindstella/issues/45)、項目の削除は [#96](https://github.com/shuhei1101/mindstella/issues/96)、タグの語彙は [#47](https://github.com/shuhei1101/mindstella/issues/47)・[#303](https://github.com/shuhei1101/mindstella/issues/303) が入れた。
