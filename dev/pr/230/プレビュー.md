## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閲覧機能 | 本文のスクロール領域を送っても、見出しの帯で項目の ID とタイトルが読める。詳細パネルと詳細の全画面の両方に当てる | 本文の先頭のタイトルが見えなくなったときだけ出す（[要件](./要件.md) の `## 要望`） |
| レスポンシブ対応 | 見出しの帯に収まらないタイトルは 1 行で省略記号を付けて切り、見出しのボタンを押し出さない。省略したときは乗せると全文が読める | - |
| アクセシビリティ | 見出しに出すタイトルは読み上げで本文の先頭のタイトルと二重に読ませない。見出しのボタンの Tab の順は変えない | - |
| 既存機能への影響 | 差分の表示の間の新規の札・取り下げの札・納品物の印は本文の先頭のタイトルの横に残し、見出しには ID とタイトルの文字だけを出す | 帯の幅が狭いとタイトルが読めなくなるため、札は見出しに出さない |
