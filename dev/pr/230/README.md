# 詳細の本文を送っても、見出しに ID とタイトルを出して何の項目か分かるようにする

## 概要

利用者が、詳細パネルと詳細の全画面で本文を送っても、見出しの ID とタイトルで何の項目を読んでいるかが分かるようになる。

## 背景

[Issue #199](https://github.com/shuhei1101/mindstella/issues/199) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-174）。
詳細パネルの見出しは種類と ID だけを出し、タイトルはスクロールする本文の側の先頭にあるため、本文を送るとタイトルが隠れる。
画面設計『詳細パネル』はタイトルを見出しに置いており、実装とずれている。
