# 要件

## 要望

詳細パネルと詳細の全画面で、本文のスクロール領域を送ってタイトルが見えなくなっても、見出しの帯に項目の ID とタイトルを出し、どの項目を読んでいるかが分かるようにする。
全ての種類の項目（検討事項・タスク・調査・資料・用語集・メモ・会話ログ）に当てる。
タイトルが見出しの帯の幅に収まらないときは、1 行で省略記号を付けて切り、戻る・進む・全画面表示・閉じるのボタンを押し出さない。

`未確定`: 見出しの帯にタイトルを出す時機（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | 本文の先頭のタイトルが見えなくなったときだけ、見出しの帯の種類と ID の横にタイトルを出す。本文の先頭のタイトルは今のまま残す |
| B | 見出しの帯に常にタイトルを出す。本文の先頭のタイトルは今のまま残す |
| C | タイトルを見出しの帯へ移し、本文の先頭からは外す |

推奨: A

Issue の例（スクロールしたらヘッダーに ID とタイトルを出す）に合い、本文の先頭で同じタイトルを二重に読ませないため。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 本文の見出しから作る目次を、詳細の見出しのボタンから開く | 要望に含まれない（起点 Issue が別の話として挙げている） | [#160](https://github.com/shuhei1101/mindstella/issues/160) |
| 詳細パネルの幅を見出しか表示の設定から選ぶ | 要望に含まれない | [#150](https://github.com/shuhei1101/mindstella/issues/150) |
| 本文の中の見出しを送っても固定する | 要望に含まれない（本文の Markdown の表示の話） | [#135](https://github.com/shuhei1101/mindstella/issues/135) |
