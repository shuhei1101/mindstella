## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 送信の形 | 送信に箇所（本文は行の範囲と選んだ文、ほかの値はキーと選んだ文）を任意で持たせる。項目に紐づかないコメントは `target` を持たない | 既存の `submissions.yaml` はそのまま読める形にし、移し替えの手順を足さない |
| レビュー中の置き場所 | レビュー中のコメントと書きかけを、送った送信と分けてワークスペースに置き、読み・足し・書き換え・削除を受け付ける | 置き場所は[要件](./要件.md)で決めた |
| まとめて送る | チェックしたレビュー中のコメントを 1 回で受け、全てを送信に足してからレビュー中から外す。1 件でも足せないときは何も書き換えない | - |
| 検証 | 本文の箇所は、行の範囲が本文の行数に収まり、その行の範囲の文に選んだ文が含まれるかを確かめる。値の箇所は、キーがその項目にあり、その値に選んだ文が含まれるかを確かめる。合わなければ 400 を返す | 比べるのは、raw の行から書式の記号（強調・コード・取り消し線の記号、リンクの URL、行頭のリスト・見出し・引用の記号、表の `\|`、エスケープの `\`）を外した文と選んだ文で、どちらも空白と改行を除いて比べる |
| 取り込んでいない送信 | MCP の `submissions` が箇所を返し、項目に紐づかない送信は `target` を空で返す | - |
| 同時の書き込み | レビュー中の書き換えも送信と同じロックを取ってから読み・書く | - |
| 送り元の確かめ | 足すエンドポイントも、`Host`・`Origin`・`Content-Type` を今の送信と同じに確かめる | - |
| 本文の上限 | 今の送信と同じ 10000 文字。まとめて送る件数とリクエストの大きさの上限を非機能要件で決める | - |
