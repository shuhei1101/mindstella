# プレビューのコメントをレビュー中に溜めて選んで送り、選んだ箇所へコメントできるようにする

## 概要

利用者が、プレビューで項目や選んだ箇所へ書いたコメントをレビュー中に溜め、コメントの一覧で確かめて選んだものだけをまとめて送れるようになる。

## 背景

[#13](https://github.com/shuhei1101/mindstella/issues/13) の要望のうち、コメントの画面と選んだ箇所へのコメントの分（サーバーと MCP への移行は [#67](https://github.com/shuhei1101/mindstella/issues/67)、変更履歴と差分は [#68](https://github.com/shuhei1101/mindstella/issues/68) へ分けた）。
今は [#71](https://github.com/shuhei1101/mindstella/pull/71) で入った詳細パネルの入力欄から、開いている項目へ回答・意見を 1 件ずつ直接送る。
書きかけは sessionStorage にだけ残り、送る前に溜めて見直す場所と、項目に紐づかないコメント・選んだ箇所を指すコメントを書く入口が無い。
