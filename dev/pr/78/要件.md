# 要件

## 要望

プレビューで書いたコメントを直接送らず、レビュー中に溜めてから、コメントの一覧で選んだものだけをまとめて送る。
本文の文章や項目の値を選んで、その箇所を指すコメントを書けるようにする。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| コメントを溜める | 詳細パネルと詳細の全画面の入力で書いたコメントは、送らずにレビュー中に溜める。溜めたコメントはチェックした状態で一覧に入る |
| 書きかけとレビュー中の保持 | 書きかけとレビュー中のコメントは、パネルを閉じても・再読み込みしても・起動スクリプトで立ち上げ直しても消えない |
| コメントのボタン | トップバーかタブの帯に置き、レビュー中のコメントの件数を出す。押すとコメントの一覧を開く |
| コメントの一覧 | レビュー中のコメントを並べる。チェックしたものだけをまとめて送る。1 件を押すと元の項目（箇所があればその箇所）へ移る。一覧の中で編集・削除できる |
| 項目に紐づかないコメント | コメントの一覧から、項目を指さないコメントを書いてレビュー中に溜める |
| 選んだ箇所へのコメント | 詳細パネルと詳細の全画面で、本文の文章か項目の値を選ぶと、選んだ範囲の近くに角の丸いポップアップでコメントの入口を出す。コメントは項目の ID と箇所（本文は行の範囲と選んだ文、ほかの値はキーと選んだ文）を持つ。本文と値の外を選んだときは出さない |
| ポップアップの形 | AI Monitor の開発ドキュメントのサーバーの「選んだ箇所をコメントに足す」を参考に、角の丸い形の案をいくつか出して選ぶ |
| 送信の取り込み | `session` が取り込むとき、箇所と、項目に紐づかないコメントであることを示して記録する |
| 配る書き出し | コメントのボタン・一覧・入口を出さない（今と同じ） |

<!-- /table -->

`未確定`: レビュー中の状態の名前とボタンの文言（決める段: モック作成。画面に出る語彙のためユーザーへ確認する）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 状態を「レビュー中」、溜めるボタンを「レビューに追加」、送るボタンを「まとめて送る」 | GitHub の「Start a review」と同じく、送る前に溜めて見直す意味で読める | 「レビュー」が誰かの確認待ちとも読める |
| B | 状態を「送信待ち」 | 送る前であることがそのまま読める | 送るのを待っているだけで、見直す余地が読み取りにくい |
| C | 状態を「下書き」 | 書きかけと同じ扱いで分かりやすい | 書きかけ（溜める前の入力）と区別できない |

推奨: A

ユーザーが「レビュー中」を挙げ、GitHub の review と同じ「溜めて見直してから送る」の流れになる。

書きかけとレビュー中のコメントは、サーバーへ送ってワークスペースに置く（単一ユースケース設計で決めた）。
起動スクリプトは立ち上げるたびに空きポートで配り、オリジンが変わるため、ブラウザの localStorage では立ち上げ直した後に読めない。

`未確定`: コメントのボタンの置き場所と、全体の検索の入口の位置（決める段: モック作成）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | トップバーの右端に置き、全体の検索の入口を中央へ寄せる | 画面をまたぐ操作（検索・テーマ）と並び、どの画面からも同じ位置で押せる | トップバーの並びが変わる |
| B | タブの帯の右端（つながりの入口の隣）に置く | トップバーの並びを変えない | 画面を移るタブと、画面を移らない操作が混ざる |

推奨: A

コメントは画面をまたいで溜まるため、画面をまたぐ操作の並びに置く。

`未確定`: 詳細パネルを本文に並べて開いているときの、コメントの入力の置き場所（決める段: モック作成）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 今と同じパネルの下端 | 幅によらず置き場所が変わらない | 本文を読む場所と入力が同じ縦の幅を取り合う |
| B | パネルの左の空き（本文側）に入力の欄を出す | 空いている幅を使い、入力を広く取れる | 幅 1100px 未満（マップは 901px 未満）はパネルが本文に重なり左の空きが無く、置き場所が幅で変わる |

推奨: A

幅で置き場所が変わらず、詳細の全画面とも同じ置き場所になる。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 送ったコメントを tmux で Claude Code へまとめて送る | 要望はサーバーへまとめて送るまで。Claude Code へ届けるのは #10 に残したスコープ | [#10](https://github.com/shuhei1101/mindstella/issues/10) |
| 差分の表示と、差分の箇所へのコメント | 変更履歴と差分は分けた Issue が扱う | [#68](https://github.com/shuhei1101/mindstella/issues/68) |
| 送った後（取り込む前）のコメントの編集・取り消し | 一覧が扱うのはレビュー中のコメントまでとする判断。送ったコメントは次の話し合いの最初に取り込まれ、直すときは新しいコメントを送れば足りる（レビューで確定する） | 予定なし |
| 配る書き出しでのコメント | 配る書き出しはサーバーを持たず、送れない | 予定なし |
