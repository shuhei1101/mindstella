# 結合テスト test_normal_when_review_order_switched で、レビュー中のコメントの本文を末尾の改行を除いて比較する

## 概要

プレビューの結合テスト `test_normal_when_review_order_switched` が、詳細パネルのレビュー中のコメントの本文を末尾の改行を除いて比較し、develop で pass するようにする。

## 背景

[Issue #431](https://github.com/shuhei1101/mindstella/issues/431) の要望。
[#427](https://github.com/shuhei1101/mindstella/pull/427) でレビュー中のコメントの本文の描画が変わり、`.review-body` の `textContent` の末尾に改行が付くようになった。
`test_detail_panel_screen.py` は同じ PR で `.trim()` を付けて読むよう更新されたが、`test_open_preview.py` の `REVIEW_BODIES_JS`（[#396](https://github.com/shuhei1101/mindstella/pull/396) で追加）は変更されず、develop で毎回 fail する。
