# 要件

## 要望

公開ドキュメント [docs/リファレンス/コマンド.md](https://github.com/shuhei1101/mindstella/blob/develop/docs/%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9/%E3%82%B3%E3%83%9E%E3%83%B3%E3%83%89.md) の「ワークスペースを点検する」（`check`）を、インターフェース定義『[ワークスペースの点検](https://github.com/shuhei1101/mindstella/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%82%A4%E3%83%B3%E3%82%BF%E3%83%BC%E3%83%95%E3%82%A7%E3%83%BC%E3%82%B9%E5%AE%9A%E7%BE%A9/%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC/%E3%83%AF%E3%83%BC%E3%82%AF%E3%82%B9%E3%83%9A%E3%83%BC%E3%82%B9%E3%81%AE%E7%82%B9%E6%A4%9C.md)』の問題の種類 `stale_history`（変更履歴のずれ）に揃える。

| 箇所 | 揃える内容 |
| --- | --- |
| ページ冒頭のコマンドの一覧の `check` の行 | 洗い出すものに変更履歴のずれを足す |
| 節の冒頭の文 | 洗い出すものに変更履歴のずれを足す |
| 問題の種類の箇条書き | `stale_history` の行を足す（本文を持つ項目の変更履歴を新しい順に今の本文へ当て、`body_diff` の `now` の行が当てる先の行と合わない回があるもの。ツールを通さずに本文を書き換えたときに起きる） |
| 出力の `problems[].kind` | 列挙と説明に `stale_history`（変更履歴から前の本文を組み立てられない）を、インターフェース定義と同じく `unknown_phase` と `decision_state` の間に足す |
| 出力の `problems[].key` | 例に `history[0].body_diff` を足す |
| 出力の `problems[].detail` | 中身の例に、その回より前の本文の差分を出せないことを足す |

同じ型の逸脱（公開ドキュメントが点検の問題の種類を設計書より少なく載せている箇所）をリポジトリ全体から探した。
問題の種類を列挙している公開ドキュメントはこの節だけで、他に該当は無い。
