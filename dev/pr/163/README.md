# 公開ドキュメントのコマンドの点検（check）に問題の種類 stale_history を足す

## 概要

利用者が、公開ドキュメントのコマンドのリファレンスで、点検（`check`）が返す問題の種類 `stale_history` を読める。

## 背景

[#130](https://github.com/shuhei1101/mindstella/issues/130) の要望。
インターフェース定義『ワークスペースの点検』の `problems[].kind` は `stale_history` を持つが、公開ドキュメントの「ワークスペースを点検する」に載っていない。
`stale_history` は [#79](https://github.com/shuhei1101/mindstella/pull/79) で設計書と実装に入り、公開ドキュメントは直されなかった。
[#127](https://github.com/shuhei1101/mindstella/pull/127) のレビューで reviewer が対象外の逸脱として報告した。
