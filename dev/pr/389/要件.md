# 要件

## 要望

release/v0.11.0 の E2E で fail した次の 5 件と、その元のシナリオ 2 件を、今の画面の構造と挙動に合わせ、5 件が release/v0.11.0 の上で pass するようにする。
製品のコードは変えない。

| テスト | 今の画面 | 合わせ方 |
| --- | --- | --- |
| `test_item_detail_view.py` の `test_error_when_render_library_unavailable` | 本文は mdmark が描くため、marked と mermaid の配信を失敗させても、知らせに出る名前は `mermaid` だけ（[#342](https://github.com/shuhei1101/mindstella/pull/342)） | シナリオ『項目の詳細を読む』の異常シナリオ（本文の描画のライブラリが読めない）の `setup` と `expected` を、本文を描く mdmark に合わせて書き換え、テストを合わせる |
| `test_item_detail_view.py` の `test_normal_when_html_code_block` | 見出しの後ろの段落が `.md-section-body` に包まれる（[#327](https://github.com/shuhei1101/mindstella/pull/327)） | セレクタ `aside.panel .md > p` を、包まれた段落を指すセレクタに替える。シナリオの期待値は変えない |
| `test_diff_view.py` の `test_normal_when_side_by_side_in_panel` | どの種類の詳細パネルも既定の幅 640px で開き、検討事項の詳細パネルにも切り替えが出る（[#340](https://github.com/shuhei1101/mindstella/pull/340)） | 「本文の幅が 560px に満たない詳細パネルでは切り替えを出さず、インラインで出す」を確かめる条件を選び直し、シナリオ『前回からの差分を見る』の正常シナリオ（詳細パネルで左右に並べる）の `setup`・`flow`・`expected` とテストを書き換える |
| `test_comment_select_send.py` の `test_normal_when_edit_remove_restore` | レビュー中の書き込みの本文が `div.md.mdmark.review-body` の中の `<p>` で描かれる（[#342](https://github.com/shuhei1101/mindstella/pull/342)） | `.review-body` の `textContent` の完全一致の待ちを、描いた本文の文字を比べる待ちに替える。シナリオの期待値は変えない |
| `test_comment_select_send.py` の `test_normal_when_read_long_post` | 本文の要素が `div.review-body` の中の `<p>` になる（[#342](https://github.com/shuhei1101/mindstella/pull/342)） | セレクタ `p.review-body` を、今の本文の要素を指すセレクタに替える。シナリオの期待値は変えない |

`test_normal_when_side_by_side_in_panel` の本文の幅が 560px に満たない詳細パネルは、画面幅 1280px のまま、D-1 を開く前に詳細パネルの幅の区切りにフォーカスして Home を押し、下限の 480px まで狭めて作る。
画面設計『詳細パネル』の幅の区切りの下限 480px では本文の幅が 560px に満たず、`@container detail-body (width < 560px)` の条件を画面幅に頼らず満たせる。
