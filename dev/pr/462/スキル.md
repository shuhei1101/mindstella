## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 冒頭の文 | 確定版の概要の 2 文目と 3 文目を、記録を対象にした文で取り込む | 「足す・直す・消す」は「追加・修正・削除」にする |
| 確認表 | 確定版の確認表の行を順番どおりに取り込み、「同じものを別の言葉で呼んでいないか」を追加する | 列は「確認」「当てはまったら削除する理由」の 2 列 |
| 残してよい否定 | 現在の 1 文を維持する | - |
| `## 用語の選び方` | `## 語の選び方` を置き換え、文章でない所の用語の選び方・原則表・動詞は「する」を付ける・対応表の順に並べる | 対応表は NG と OK の 2 列で、`word-list-ai-slop` の行の順 |
| files.yml の `description` | 1 文目を合わせた本文の要約に修正する | - |
