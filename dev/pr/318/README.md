# キーの語の差分の結合テストのワークスペースで、項目のタグを語彙に登録する

## 概要

キーの語の差分の結合テスト 4 件が、テスト用のワークスペースの項目のタグを語彙に登録して pass する。

## 背景

[Issue #313](https://github.com/shuhei1101/mindstella/issues/313) の不具合。
タグの語彙を入れた [#308](https://github.com/shuhei1101/mindstella/pull/308) から、`add` / `update` は語彙に無いタグを「語彙に無いタグです」のエラーで止める。
`tests/integration/preview/preview_word_diff_helpers.py` の `build_key_word_diff_workspace` は語彙を持たない設定のワークスペースへ、タグ `要件`・`会議`（続く `update` で `運用`）の項目を足すため、`tests/integration/preview/test_detail_panel_screen.py` の `test_diff_keys_when_inline_words` 系 4 件が develop で fail している。
[#311](https://github.com/shuhei1101/mindstella/pull/311) の結合テスト作成で見つかった。
