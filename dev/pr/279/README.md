# 差分のミニマップと表示する種類の E2E を、見える帯と表示する種類の区画だけで確かめる

## 概要

差分のミニマップを足した後の E2E 2 ケース・3 テストが、部品設計どおりに動くプレビューで pass するようになる。

## 背景

[#275](https://github.com/shuhei1101/mindstella/issues/275) の `E2E失敗`。
release/v0.8.0 の E2E（[#194](https://github.com/shuhei1101/mindstella/pull/194)）で、`test_diff_view.py::test_normal_when_minimap_jump` と `test_display_settings.py::test_normal`・`test_normal_when_reset` が毎回 fail する。
原因は [#237](https://github.com/shuhei1101/mindstella/pull/237)（差分のミニマップ）で、テストが見えない `.df-map` を数え、区画「詳細に表示するもの」のミニマップのチェックも表示する種類に数えている。
develop で同じテストが落ちる #273 はこの Issue へ統合した。
