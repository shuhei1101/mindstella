## 要望

release/v0.8.0 の E2E で fail する次の 3 テストを、部品設計どおりに動く今のプレビューで pass するように直す。
製品のコードは変えない。

| テスト | 直す検証 |
| --- | --- |
| `test_diff_view.py::test_normal_when_minimap_jump` | 変わっていない A-2 の詳細パネルで、ミニマップの要素の数ではなく、ミニマップが見えないことを確かめる |
| `test_display_settings.py::test_normal`<br>`test_display_settings.py::test_normal_when_reset` | 印が付いた表示する種類を、区画「詳細に表示するもの」の差分のミニマップのチェックを除いて数える（`display_settings_helpers.py` の `checked_kind_count`） |
