## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| タブ | 左から出すパネルの上端に「レビュー中のコメント」と会話のタブを置き、切り替える。レビュー中のコメントのタブは今の一覧のまま | タブの名前・既定で開くタブはモック作成で決める |
| スレッドの一覧 | 会話のタブにスレッドを並べ、各行に要約か最初の書き込み・書き手・最後の書き込みの日時・状態・タグを出す。オープンとクローズで絞れる | 行に出す値と並びはモック作成で決める |
| スレッドを読む | 行を押すとスレッドの書き込みを書いた順に並べ、利用者と AI の書き込みを見分けられる形にする。AI の返信の中の項目の ID は、その項目の詳細パネルを開くリンクにする | パネルの中で一覧からスレッドへ切り替える（`### 画面一覧` の `comment-thread`） |
| 返信とクローズ | スレッドを読む画面の下端に返信の入力欄を置き、クローズ（とオープンへの戻し）のボタンを置く | 返信の送り方は要件の `未確定`（決める段: モック作成） |
| 反映 | AI の返信と AI が立てたスレッドを、書き換えの知らせで開いている画面へ反映する | - |
| アクセシビリティ | タブはキーボードで切り替えられ、読み上げでタブの名前と選んだ状態が分かる | - |

### 画面一覧

| 種別 | 画面 | 概要 | アクション | 判定の根拠 | 補足 |
| --- | --- | --- | --- | --- | --- |
| 変更 | `comments` | 左から出すパネル。上端の「レビュー中のコメント」と会話のタブで切り替え、会話のタブにスレッドの一覧を並べる | タブを切り替える<br>（レビュー中のタブ）今の一覧の操作のまま<br>（会話のタブ）オープン・クローズ・全部で絞る<br>行のタグを押してそのタグで絞る<br>タグの絞り込みを解除する<br>スレッドを開く<br>パネルを閉じる | レビュー中のコメントとスレッドは、同じコメントについて関連するが別のまとまりのため、画面内のタブにする。各タブに件数（レビュー中の件数・オープンのスレッドの件数）を出す。オープン・クローズ・全部は同じ一覧の絞り込みのため、会話のタブの中でセグメントで切り替える。タグの絞り込みは解除のチップを一覧の上に置く（選ぶ部品を結果より上に置く） | タブの名前・既定で開くタブ・行に出す値はモック作成で決める（`## 変更方針`） |
| 新規 | `comment-thread` | 会話のタブで開いたスレッド 1 件。書き込みを書いた順に並べ、下端に返信の入力欄、上端にクローズ（とオープンへの戻し）を置く | 書き込みを読む<br>返信の中の項目の ID を押す<br>返信する<br>クローズにする<br>オープンに戻す<br>一覧へ戻る<br>パネルを閉じる | 一覧から 1 件を選んで中身を見る関係だが、左のパネルは狭い幅の置き方（幅 900px 以下は画面いっぱい）で、右は項目の詳細パネルの置き場のため、パネルの中で一覧と切り替え、戻る操作で一覧へ戻す。戻ると一覧のスクロールと絞り込みを保つ。返信は 1 件をすばやく足すだけのため、その場（スレッドの下端）に置く。クローズはオープンへ戻せて取り消せない操作ではないため、確認のモーダルを挟まない | 返信の送り方は要件の `未確定`（決める段: モック作成）。オープンに戻すボタンを出すかは要件の `未確定`（決める段: 単一ユースケース設計） |

項目の ID から開く詳細パネル（`detail-panel`）は既存のまま使い、コメントの行から項目を開くときと同じく、パネルを開いたまま右に出す。

### 画面遷移

```mermaid
flowchart LR
  V[見ている画面] -->|トップバーのコメントのボタン| C[comments（レビュー中のタブ）]
  C -->|会話のタブを押す| CT[comments（会話のタブ）]
  CT -->|レビュー中のタブを押す| C
  CT -->|スレッドの行を押す| T[comment-thread]
  T -->|一覧へ戻る| CT
  T -->|返信の中の項目の ID を押す| D[detail-panel]
  D -->|詳細パネルを閉じる| T
  C -->|行の向けた項目を押す| D2[detail-panel]
  D2 -->|詳細パネルを閉じる| C
  C -->|閉じる・Esc・コメントのボタン| V
  CT -->|閉じる・Esc・コメントのボタン| V
  T -->|閉じる・コメントのボタン| V
```

- タブの切り替え・スレッドを開く・一覧へ戻るは履歴に積まない（パネルの中の切り替えのため）
- `comment-thread` の Esc は返信の入力欄にフォーカスがあるときは入力から外れるだけにし、それ以外は一覧へ戻る。詳細パネルを開いているときの Esc は詳細パネルを先に閉じる（今の `comments` と同じ）
- 返信を送った・クローズにした後は `comment-thread` に留まる。クローズにしたスレッドは、一覧へ戻ったときに絞り込みがオープンだけなら一覧から外れる
