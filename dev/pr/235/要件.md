# 要件

## 要望

### コメントをスレッドにする

プレビューでまとめて送ったコメントは、1 件ごとに 1 つのスレッドの最初の書き込みになる。
スレッドには利用者と AI の書き込みが書いた順に積まれる。
AI は利用者の書き込みを読み、返信するか、返信せずにクローズにするかを決める。
返事の要らない書き込み（「了解」など）には返信せず、話が済んでいればクローズにする。質問・依頼には返信し、クローズにしない。
資料・検討事項などを足したり直したりしたときは、その項目の ID を返信に書く（画面では項目を開くリンクになる）。
AI からもスレッドを立て、利用者に返事を求められる（Issue に起票してよいかの確認など）。
利用者の書き込み（新しいスレッドの最初の書き込みと、既存のスレッドへの返信）は、どれもまずレビュー中として溜め、まとめて送る（GitHub の PR のレビューと同じ形）。
送るときは、レビュー中の書き込みを全て送るか、選んだものだけを送るかを選べる。
項目の詳細パネルから書くコメント（今のレビュー中のコメント）は、その項目へ向けた新しいスレッドの最初の書き込みとして溜める。

まとめて送ったコメントはスレッドとして記録し、送信の記録（`submissions.yaml`）をスレッドへ置き換える。
利用者の書き込みごとに、AI が取り込んだか（取り込み済み）を持つ。AI は、書き込みを読んで記録し、返信するかクローズにするかを決めた時点で取り込み済みにする。
AI の既読はこれと分けて持つので、セッションを開いて未読に戻しても、取り込み済みの書き込みを取り込み直さない。
AI は、取り込んでいない利用者の書き込みを、スレッドがオープンでもクローズでも拾う（利用者が返信を送ってからクローズにしても、その返信は AI に届く）。
取り込んでいない利用者の書き込みを持つスレッドが指す項目は消せない。それ以外のスレッドは記録として残し、指している項目を消せる。点検はそのスレッドが消した項目を指していても参照切れにしない。
既存のワークスペースの送信は、移し替えの手順（`migrations/`）でスレッドへ移す（取り込み済みの送信はクローズ、取り込んでいない送信はオープンで取り込んでいない書き込み）。

### オープン・クローズ

スレッドはオープンとクローズの状態を持ち、利用者は画面で、AI は MCP のツールでクローズにする。
AI は、取り込んでいない利用者の書き込みのほかは、既定でオープンのスレッドだけを読み、要るときだけクローズのスレッドも読む。

クローズとオープンへの戻しは、利用者と AI のどちらも行える。AI は、クローズのスレッドに返信が要るときは、オープンに戻してから返信する。
クローズとオープンへの戻しには、任意で理由を書ける。書いた理由は、状態を変えた書き手・日時とともにスレッドに残し、利用者も AI も読める。

### タグ

スレッドにタグを付け、スレッドの一覧をタグで絞り込める。

タグは AI が MCP のツールで付け、画面はタグを表示してタグで絞る。利用者は画面でタグを付け外ししない。

### 要約

AI は返信のたびに、スレッドの要約（何の話で、どう決着したか。例: 「○○の質問。回答はこの方向で決まった」「取り下げになった」）を書き直す。
要約は本文と分けて持ち、一覧で本文を読まずに引ける。

### AI の既読・未読

スレッドの書き込みごとに、AI が読んだか（既読・未読）を持つ。
AI が MCP のツールでスレッドを読むと、読んだ書き込みが既読になる。
Claude Code のセッションを開いたときに、スクリプトで全ての書き込みを未読に戻す。

`未確定`: 未読に戻す契機（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | プラグインに Claude Code の `SessionStart` のフックを足し、新しい会話・再開・`/clear` のたびにスクリプトで戻す | 会話の文脈が変わるどの契機でも戻り、`session` を呼ばない会話でも戻る | プラグインに初めてフックを持たせる |
| B | 起動スクリプト（`bin/mindstella`）が Claude Code を立てる前に戻す | 今の起動の流れに足すだけで済む | `/clear`・再開と、既にあるセッションへつなぐときに戻らない |
| C | `session` の準備で MCP のツールを呼んで戻す | フックもスクリプトも足さない | `/clear` の後に `session` を呼び直すまで戻らない |

推奨: A

会話の文脈を失う契機（新しい会話・`/clear`）と未読へ戻す契機が一致するのは、Claude Code が会話の始まりに流すフックだけ。

### MCP のツール

- スレッドの一覧: 状態（オープンだけ・クローズだけ・全部。既定はオープンだけ）・タグ・未読だけか既読も含めるか・取り込んでいない利用者の書き込みを持つものだけかで絞り、キーだけ（ID・状態・タグ・要約・未読の件数など、書き込みの本文を含めない）でも返す。取り込んでいない利用者の書き込みを持つものだけで絞るときは、状態を渡さなくてもオープンとクローズの両方を返す
- スレッド 1 件を読む: 未読の書き込みだけか全部かを選び、返した書き込みを既読にする
- 返信・スレッドを立てる・クローズとオープンへの戻し・取り込み済みにする・要約とタグの書き換え（ツールの分け方はインターフェース定義設計で決める）

### 画面

左から出すパネル（今のコメントの一覧）は、タブを持たずにスレッドの一覧 1 つにし、オープン・クローズ・すべてで絞る。
スレッドを押すと書き込みを読めて、返信とクローズができる。
一覧の行には最後の書き手を出し、AI の返信を待っているかどうかの札は出さない。
パネルには新しいスレッドを立てる入口と、レビュー中の書き込み（新しいスレッドと返信）を確かめて送る入口を置く。
レビュー中の書き込みを持つスレッドは、一覧でそれと分かる印を出す。
AI の返信と AI が立てたスレッドは、開いている画面へ書き換えの知らせで反映する。
返信の入力欄の書きかけは、書きかけの保存（`PUT /api/drafts`）でスレッドごとに保ち、一覧へ戻る・別のスレッドを開く・パネルを閉じる・読み込み直すのどれでも消さない。

### AI から利用者への連絡のタブ（#206）との関係

AI から利用者への連絡は AI が立てるスレッドに寄せ、[#206](https://github.com/shuhei1101/mindstella/issues/206) は破棄の判断へ回す。
スレッドで聞くのは、ワークスペースの外へ書き込む前の確認と、話の流れと関係の無い知らせ。今の話の流れの中で答えが要る問いはターミナルで聞く。
