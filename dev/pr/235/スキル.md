## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 届いたコメントへの返信 | 取り込んでいない利用者の書き込みを読んで取り込みのステップで記録した後、返信するか、返信せずにクローズにするかを決めて取り込み済みにし、要約を書き直す。返事の要らない書き込み（「了解」など）には返信せず、話が済んでいればクローズにする。質問・依頼には返信し、クローズにしない。足した・直した項目があれば ID を返信に書く | 準備と、`[mindstella]` の 1 行が入力されたときの両方 |
| AI からスレッドを立てる | ワークスペースの外へ書き込む前の確認（起票してよいか など）と、話の流れと関係の無い知らせは、スレッドを立てて返事を求める | 今の話の流れの中で答えが要る問い（ヒアリング・方針転換の確認・リサーチを始めてよいか）はターミナルで聞く |
| 読む範囲 | 取り込んでいない利用者の書き込みはオープンでもクローズでも読む。そのほかは、既定はオープンのスレッドの未読だけを読み、過去の経緯が要るときだけクローズのスレッドや既読の書き込みを読む | 一覧はキーだけで引き、要約で読むかを決める |
| タグ | スレッドに付けるタグは、記録の話題のタグと同じく `tags` の一覧から使い回す | AI だけが付ける |
| `allowed-tools` | スレッドの MCP のツールを足す。送信のツール（`submissions`・`take_submission`）は外す | - |
