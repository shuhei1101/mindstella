## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スレッドの記録 | ワークスペースの `.mindstella/` にスレッドのファイルを足し、スレッドごとに ID・状態（オープン・クローズ）・タグ・要約・書き込みの並びを持つ。書き込みは書き手（利用者・AI）・本文・書いた日時・AI の既読を持つ。最初の書き込みは向けた項目と箇所を持てる | 送信の記録との関係は要件の `未確定`（決める段: 単一ユースケース設計） |
| スレッドを作る | まとめて送る処理が、送ったコメント 1 件ごとにオープンのスレッドを作り、コメントを最初の書き込みにする | `POST /api/comments/send` の副作用に足す |
| 一覧の MCP のツール | 状態（既定はオープンだけ）・タグ・未読だけかで絞り、キーだけ（本文を含めない）でも返す | 並びは最後の書き込みの新しい順を候補に、インターフェース定義設計で決める |
| 1 件を読む MCP のツール | 未読の書き込みだけか全部かを選び、返した書き込みを既読にする | 既読の書き込みは記録の書き換えと同じ鍵を取る |
| AI が書く MCP のツール | 返信・スレッドを立てる・要約とタグの書き換え。返信と要約の書き換えは 1 回の呼び出しで書けるようにする | 「返信するたびに要約を書き直す」を 1 回で済ませる |
| 未読へ戻す | 全てのスレッドの書き込みを未読に戻すスクリプトを置く | 呼ぶ契機は要件の `未確定`（決める段: インターフェース定義設計） |
| プレビューの受け口 | スレッドの読み取り・利用者の返信・クローズ（とオープンへの戻し）の HTTP の受け口を足し、書き換えを `GET /api/events` で知らせる | 利用者の返信を Claude Code へ入力するかは要件の送り方の `未確定`（決める段: モック作成） |
| 既存のワークスペース | スレッドのファイルが無いワークスペースはスレッド 0 件として読む | 送信をスレッドへ移し替える（要件の案 A）ときは、`migrations/` に版の手順を足す |
| 長さの上限 | 書き込みの本文は送信の本文と同じ上限、要約は別の上限を非機能要件に足す | 値は非機能要件で決める |
