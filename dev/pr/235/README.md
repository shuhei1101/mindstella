# コメントをスレッドにし、AI が返信・質問でき、オープン・クローズと要約を持てるようにする

## 概要

利用者がプレビューから送ったコメントがスレッドになり、AI がそのスレッドへ返信できる。
AI からもスレッドを立てて利用者に返事を求められ、スレッドはオープン・クローズ・タグ・要約・AI の既読を持つ。

## 背景

[#208](https://github.com/shuhei1101/mindstella/issues/208) の要望。
今のコメントは、利用者が送ったものを AI が資料や検討事項に取り込むだけで、AI から返事ができない。
資料を作るほどではない質問や相談と、AI からの質問（起票してよいか など）を、コメントのやり取りで済ませたい。
送ったコメントを話し合いの途中の Claude Code へ届ける仕組みは [#117](https://github.com/shuhei1101/mindstella/issues/117)（作業 PR [#201](https://github.com/shuhei1101/mindstella/pull/201)）で入った。
AI から利用者への連絡のタブ（[#206](https://github.com/shuhei1101/mindstella/issues/206)）は、スレッドに寄せるかを設計で決める。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-196・S-197）。
