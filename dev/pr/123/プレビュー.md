## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 名前 | 画面設計『つながり』・単一ユースケース『つながりを辿る』を「ネットワーク」「ネットワークを辿る」に改名し、参照元を直す。URL のハッシュの `tab=graph`・`display.network_look`・ファイル名の `graph` は変えない | 既存の URL と `config.yaml` をそのまま読めるようにする |
| 見た目 | 5 つの見た目をキャンバスの入れ物の `data-look` ごとに描き分け、ライト / ダークで地・星・線を変える。見本の `stella.js` は参考にして、モジュール構成に沿って作り直す | 見た目を選ぶ場所は `未確定`（要件.md） |
| 自動で動くもの | 星のまたたきと広がる輪だけを自動で動かし、回転・寄りの既存の動きは変えない | デザイン方針の例外として書く |
| 状態の印 | 注目中の起点とつながるノードの名前の左に、一覧と同じ印を名前と同じ遠近・濃さで描く | 文字の高さの 8 割 |
| ロック | ネットワークと検討事項のマップで同じ判定（押したノード・詳細を開いているノード・ロックしたノード）を共有し、鍵の震えは毎コマ当てる | 保つ範囲は `未確定`（要件.md） |
| タブの移動 | 詳細パネルで項目を開いたままネットワークのタブを押すと、その項目を選んだ状態で開く | 詳細パネルにボタンは足さない |
| 性能 | 5 つの見た目それぞれで 1000 件の計測を PoC 検証でやり直し、非機能要件の決定値に収まらない見た目は描き方を変える | 結果を `## PoC 結果` に書く |
