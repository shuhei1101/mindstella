# 「つながり」の画面を「ネットワーク」に改め、星の見た目の選択とノードのロックを足す

## 概要

利用者が、プレビューの「ネットワーク」（旧「つながり」）で項目を星としてつながった 5 つの見た目から選んで眺め、注目の起点のノードをロックして辿れるようになる。

## 背景

[Issue #28](https://github.com/shuhei1101/mindstella/issues/28) の要望。
mindstella の名前のとおり、項目が星としてつながって見える画面にし、ノードを辿るうちにどこから派生してきたかを見失わないようにする。
見た目の既定と個人の選択の置き場所は [#95](https://github.com/shuhei1101/mindstella/pull/95)（起点 [#24](https://github.com/shuhei1101/mindstella/issues/24)）で入っており、見た目ごとの描き分けはこの PR で作る。
絞り込みは [#89](https://github.com/shuhei1101/mindstella/pull/89) のドロワーで入っている。
描画の負荷は [#21](https://github.com/shuhei1101/mindstella/pull/21)・[#23](https://github.com/shuhei1101/mindstella/pull/23) で測っており、ユーザーの[コメント](https://github.com/shuhei1101/mindstella/issues/28#issuecomment-5946317024)で見た目を足した後に測り直す。
