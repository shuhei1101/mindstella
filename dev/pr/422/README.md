# 詳細の全画面と左のパネルを開いたとき、ほかの部分をグレーアウトし、押したら閉じる

## 概要

利用者が、詳細の全画面と左のパネル（絞り込み・表示の設定・コメントの一覧）を開いている間、どこを操作しているかが分かり、グレーアウトした所を押して閉じられるようになる。
コメントの一覧はピン止めで今の挙動を残せ、開き直すと閉じる前の位置に戻る。

## 背景

[Issue #141](https://github.com/shuhei1101/mindstella/issues/141) の要望。
詳細の全画面は後ろの幕が薄く、左のパネルは幕が無く外側を押しても閉じないため、後ろの画面がそのまま見えて触れ、どこを操作しているかが分かりにくい。
追記（[送信 S-196](https://github.com/shuhei1101/mindstella/issues/141#issuecomment-6095148385)・[スレッド TH-72](https://github.com/shuhei1101/mindstella/issues/141#issuecomment-6602070045)）で、コメントの一覧を外側の押下で閉じること・開き直したときに閉じる前の位置へ戻すこと・ピン止めのボタンが加わった。
