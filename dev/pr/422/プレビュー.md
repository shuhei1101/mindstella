## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 詳細の全画面の幕 | 薄い幕（`--scrim-soft`）を、後ろの画面が見えたまま操作の対象でないと分かる濃さのグレーアウトに改める。押すと詳細パネルに戻すのは今のまま | 濃さはモック作成で決める |
| 左のパネルの幕 | 絞り込みのドロワー・表示の設定・保存待ち・コメントの一覧のパネルを開いている間、パネル以外を 1 枚の幕で覆い、幕を押したらパネルを閉じる。幕の下の部品には `inert` を付け、押下・フォーカスを届けない | トップバーと、パネルから開いた詳細パネルは幕で覆わない |
| ピン止め | コメントの一覧の見出しの帯にピン止めの切り替えのボタン（`aria-pressed`）を置く。ピン止め中は幕を出さず、今と同じく覆った範囲だけに `inert` を付けて外側の押下で閉じない | ピン止めの状態は端末の保存領域に残す |
| 開き直したときの戻り方 | コメントの一覧を閉じるときに、パネルの中の画面・開いていたスレッド・スクロールの位置を保ち、次に開いたときに戻す。戻す先のスレッドが無ければスレッドの一覧へ | - |
| キーボード操作 | Esc で閉じる順序は今のまま。幕はフォーカスを受けず、パネルの閉じるボタンが同じ操作を持つ | - |
| レスポンシブ対応 | 幅 900px 以下は左のパネルが画面の幅いっぱいに出るため、幕は見えない範囲を覆う。詳細パネルとの前後の決まり（`StackState`）は保つ | - |
| 既存機能への影響 | 絞り込みのドロワーを開いたままマップ・表の結果を操作する使い方が無くなる（結果は幕越しに見える）。マップの余白を押したときは、ドロワーを閉じるだけで選びを外さない | 検討事項をマップで辿るの E2E で確認する |
