# 要件

## 要望

詳細の全画面と左のパネルを開いている間、操作できる範囲以外をグレーアウトし、グレーアウトした所を押したら閉じる。

| 対象 | 開いている間 | グレーアウトを押したとき |
| --- | --- | --- |
| 詳細の全画面 | モーダルの外側をグレーアウトする（今の薄い幕を、後ろの画面が操作の対象でないと分かる濃さにする。後ろの画面は透けて見える） | 元の大きさ（詳細パネル）に戻す（今と同じ） |
| 絞り込みのドロワー | ドロワーとトップバー以外（詳細パネルを含む）をグレーアウトし、押しても後ろの部品へ操作を届けない | ドロワーを閉じる |
| 表示の設定のパネル | 絞り込みのドロワーと同じ | パネルを閉じる |
| 保存待ちのパネル | 絞り込みのドロワーと同じ | パネルを閉じる |
| コメントの一覧（ピン止めなし。既定） | 絞り込みのドロワーと同じ | パネルを閉じる |
| コメントの一覧（ピン止めあり） | グレーアウトせず、今と同じく覆っていない部分を操作できる | 閉じない |

- トップバーはグレーアウトせず、左のパネルを開いたままトップバーのボタンで別のパネルへ切り替えられる
- 左のパネルの中から開いた詳細パネル（スレッドの書き込みの項目の ID から開いたとき等）はグレーアウトせず、パネルと詳細パネルの両方を操作できる
- コメントの一覧の見出しの帯に、ピン止めを切り替えるボタンを追加する。ピン止めの状態は端末の保存領域に残す
- コメントの一覧を閉じて開き直したとき、閉じる前のパネルの中の画面（スレッドの一覧・スレッド・レビュー中の書き込み）と開いていたスレッド、スクロールの位置に戻す（今の「次に開くときはいつもスレッドの一覧から始める」を改める）
- コメントの一覧を開くボタンは、トップバーの今の場所のままにする。モック作成で良い置き場所の案があれば添える
