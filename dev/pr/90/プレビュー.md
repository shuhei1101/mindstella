## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 余白の押下 | マップの枠で、項目の節（`button`）の上でない所の左ボタンの押下を、押してから離すまでの移動が上限以内のときだけ選びを外す操作とみなす | 上限は縦・横とも 5px（`PRESS_SLOP_PX`）。判定は `enableDragScroll` の `onPress` が持つ |
| 選びを外す | 詳細パネルの閉じるボタンと同じ処理（`closeDetail`）を呼ぶ | 何も選んでいないときは呼ばない |
| マップの位置 | 外した後もスクロールの位置と、拡大・縮小で決めた倍率を保つ。「全体を表示」のときは閉じるボタン・Esc と同じく広がった枠に合わせて求め直す | 選んだ項目を中央へ送る処理は、選んだ項目が無いときに走らない |
| ドラッグでの移動 | 今の背景のドラッグでの移動はそのまま | 移動が上限を超えたら選びを外さない |
| 狭い幅 | 幅 900px 以下の字下げの一覧は変えない | - |
