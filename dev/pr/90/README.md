# 検討事項のマップで余白を押したら選びを外し、全体の表示に戻す

## 概要

利用者が、プレビューの検討事項のマップで余白を 1 回押すと、項目の選びを外して何も選んでいない全体の表示に戻れるようにする。

## 背景

[Issue #84](https://github.com/shuhei1101/mindstella/issues/84) の要望。
[#79](https://github.com/shuhei1101/mindstella/pull/79) のモックへのユーザーの返信で、項目を 1 回押すと、何も選んでいない全体の表示にマップの上で戻れないと挙がった。
今のマップは、選んでいる項目を URL の項目の ID（詳細パネルで開いている項目）で決め、余白にはスクロールの保存と背景のドラッグでの移動だけが付いている。
[#28](https://github.com/shuhei1101/mindstella/issues/28)（ロック）は「ロックしていなければ、余白を押すと全体の表示へ戻る」を前提にしており、この PR がその動きを作る。
