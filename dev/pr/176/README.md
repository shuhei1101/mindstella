# シナリオ『話し合いのセットアップ』の古いワークスペースの期待値を、プラグインの版までの手順に合わせる

## 概要

シナリオ『話し合いのセットアップ』の `正常シナリオ（直下に版を記録した古いワークスペース）` とその E2E テストで、当てる手順の期待値をプラグインの版までの手順に合わせる。

## 背景

[Issue #169](https://github.com/shuhei1101/mindstella/issues/169) のテスト不備。
release/v0.7.0（`798c84b`）の E2E（[#164 の実行の結果](https://github.com/shuhei1101/mindstella/pull/164#discussion_r4225621041)）で、`tests/e2e/単一ユースケース/test_discussion_setup.py::test_normal_when_version_recorded_at_top` が fail した（当てる手順の版が `{"v0.6.0"}` の期待に対して `{"v0.6.0", "v0.7.0"}`）。
[#127](https://github.com/shuhei1101/mindstella/pull/127) でプラグインの版が v0.7.0 になり v0.7.0 の移し替えの手順が足されたが、シナリオとテストは「当てる手順が v0.6.0 の手順だけ」のまま残った。
インターフェース定義『記録の形式の移行』はプラグインの版までの手順を並べると定めており、実装の返り値は定義どおり。
直さないと v0.7.0 を master へ入れられないため、release/v0.7.0 を base にする。
