# 要件

## 要望

シナリオ『話し合いのセットアップ』の `正常シナリオ（直下に版を記録した古いワークスペース）` と、それを確かめる `test_normal_when_version_recorded_at_top` で、版 v0.5.0 のワークスペースに当てる手順の期待値を、ワークスペースの版より新しくプラグインの版までの手順にする。

- 期待値は特定の版の並びを書かず、インターフェース定義『記録の形式の移行』の決め方（ワークスペースの版より新しく、プラグインの版まで）で書く。プラグインの版が上がって手順が足されても、シナリオとテストを直さずに済むようにする
- テストは `plugins/mindstella/skills/mindmap/migrations/` にある手順の版のうち、v0.5.0 より新しくプラグインの版（`version.ini`）までの版の集まりと、返った `steps` の版の集まりを比べる
- 満たす基準は、直したシナリオの期待値を確かめる `test_normal_when_version_recorded_at_top` の pass
- 同じシナリオのほかの期待値（`status` が呼ばれない・ワークスペースの全てのファイルの中身が呼ぶ前と同じ）と、同じファイルのほかのテストは変えない
- `migrate` の実装は変えない
