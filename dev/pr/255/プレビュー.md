## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| リンクの見分け | 本文の `#` のリンクのうち、`#` の後ろを `URLSearchParams` で読んで `diff` を持つものをまとまりのリンクとし、それ以外は今と同じく見出しのリンクとして扱う | `diff` 以外の引数は読まない |
| 押したとき | まとまりの ID を使う側へ知らせ、使う側は変更履歴で選んだときと同じ `selectPoint` で差分の表示に切り替える（端末の保存領域とハッシュの `diff` を書き換え、履歴に積まない） | 既定の動作（アドレス欄の書き換え）は止める |
| 記録に無いまとまり | `resolveDiffPoint` で引けないまとまりを指すリンクは、押しても差分の表示を変えない | 見出しが無い `#見出し` のリンクと揃える |
| 時点の種類 | リンクで指せるのはまとまりの ID だけにし、`since`・`pending` を指すリンクは見出しのリンクとしても扱わず何もしない | 開く端末・時刻で中身が変わるため（PR #241 と揃える） |
| 描く場所 | 詳細パネルと詳細の全画面の Markdown の本文。差分の表示の間に描く本文も同じく扱う | HTML の本文の枠は対象外（要件.md の `## スコープ外`） |
| 配る書き出し | 書き出しも同じ本文の描画と変更履歴を持つため、同じく動く | `プレビューを配る` を実行のみで回す |
| 既存機能への影響 | `diff` を持たない `#見出し` のリンクと、見出しの右の # は今と同じ | 破壊的変更なし |
