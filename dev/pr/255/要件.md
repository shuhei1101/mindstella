# 要件

## 要望

記録の本文（Markdown）に、書き換えのまとまり（`V-{番号}`）の差分の表示を指すリンクを、ホストとポートを含まない `#` で始まる形で書けるようにする。
書き方はハッシュの引数と同じ `[文言](#diff=V-2)` にする。
`#` の後ろが `diff=` の引数を持たない今の `[文言](#見出し)` のリンクは、今と同じく見出しを指す。

詳細パネルと詳細の全画面の本文でこのリンクを押すと、変更履歴でそのまとまりを選んだときと同じく、開いている画面と項目のままそのまとまりの差分の表示に切り替え、ハッシュの `diff` を書き換える（履歴に積まない）。
記録に無いまとまり（保持する回数を超えて消えたまとまりを含む）を指すリンクは、押しても差分の表示を変えない。
配る書き出し（ネットにつながらない 1 枚の HTML）でも同じく動く。

AI（`session`）が記録の本文（会話ログ・メモ・資料など）に直したまとまりを書くときは、`preview_url` が返す絶対の URL ではなくこのリンクを書く。
ワークスペースの外（Issue のスレッドなど）と利用者への応答には、今と同じく `preview_url` が返す絶対の URL を添える。

`未確定`: `#` の後ろに `diff` 以外の引数（`tab`・`id` など）を並べたリンクの扱い（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `diff` だけを読み、他の引数は無視する | 要望の範囲に収まり、画面の移動の振る舞いを足さない | 別の項目のまとまりの差分を本文から開けない |
| B | ハッシュとして全ての引数を読み、その画面・項目・時点へ移る | 項目と時点を合わせて指せる | 本文のリンクで画面を移る振る舞い（履歴に積むか等）を新しく決める必要がある |

推奨: A

要望は本文からまとまりの差分を指すことで、画面・項目を移るリンクは別の要望になるため。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 資料の HTML の本文の枠の中のリンクでまとまりを指す | HTML の本文の枠は見出しのリンク・本文の印を付けず、`#` のリンクを枠の中の `id` への移動として扱う別の箇所 | [#224](https://github.com/shuhei1101/mindstella/issues/224) |
| 差分の表示の間に、本文の用語・項目の ID をリンクにする | 本文の印とリンクの付け方の別の事象で、この対応では直らない | [#154](https://github.com/shuhei1101/mindstella/issues/154) |
| 本文の中から項目・画面を指すリンク（`#id=D-1` など） | 要望はまとまりの差分を指すことで、画面・項目を移るリンクは別の要望。`未確定` の論点で B を選んだときは含める | 予定なし |
| ワークスペースの中のスレッドの返信（`reply`・`new_thread`）でまとまりを指す | スレッドの書き込みは Markdown の本文として描かず、`[文言](#diff=V-2)` がリンクにならない。書き込みの描き方を変えるのは別の作業。それまでは今と同じく絶対の URL を添え、ポートが変わると開けないまま残る | 起票予定 |
| 本文に書いたまとまりのリンクが、保持する回数を超えて消えたまとまりを指していることを点検で洗い出す | 要望に含まれない。押しても差分の表示を変えないだけで、記録は壊れない | 予定なし |
