# 本文の中から書き換えのまとまりの差分を指す、ポートによらないリンクを書けるようにする

## 概要

記録の本文（Markdown）の中から、書き換えのまとまり（`V-{番号}`）の差分の表示を指すリンクを、配信のポートによらない形で書けるようにする。

## 背景

[Issue #242](https://github.com/shuhei1101/mindstella/issues/242) の要望。
[PR #241](https://github.com/shuhei1101/mindstella/pull/241)（起点 [Issue #210](https://github.com/shuhei1101/mindstella/issues/210)）で、選んだ時点を URL のハッシュの `diff` に持たせ、`preview_url` に `diff` を渡すとまとまりを指す絶対の URL（`http://127.0.0.1:{ポート}/mindstella.html#diff=V-2`）が返るようにした。
本文の中の `[文言](#...)` のリンクは見出しを指すため、本文からまとまりを指す書き方が無い。
ポートを固定していないワークスペースでは、配信を立て直すとポートが変わり、本文や会話ログに貼った絶対の URL が開けなくなる。
