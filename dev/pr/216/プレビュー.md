## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 並びの段 | `searchItems` が、当たった項目ごとに 1. ID かタイトルが言葉と完全に一致 → 2. タイトルが語を全て含む → 3. それ以外の段を決め、段の順 → 種類の順 → 連番の順に並べて返す | 語の照合は今と同じく小文字にそろえて行う |
| 結果の見出し | 種類ごとのまとまりをやめ、段ごとに「完全に一致」「タイトルに一致」「ほかの所に一致」の見出しの下に並べ、結果ごとに種類の札を添える | 確認ログ |
| 完全に一致する項目 | 先頭の「完全に一致」の見出しの下に 1 回だけ出す | 確認ログ |
| キー操作 | Enter で先頭の結果、↑ ↓ で結果を選ぶ今の動きを保つ | - |
| アクセシビリティ | 見出しは今と同じく画面の見出し（`h1`）の 1 段下（`h2`）にする | - |
| 既存機能への影響 | 当たる条件・該当なしの表示・結果を押したときの動きは変えない | - |
