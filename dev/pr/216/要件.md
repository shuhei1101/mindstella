# 要件

## 要望

プレビューの全体の検索（`Ctrl+K`）で、タイトルに当たった項目を、本文などほかの所だけに当たった項目より上に並べる。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| 並びの段 | 当たった項目を、1. ID かタイトルが言葉と完全に一致する項目 → 2. タイトルが語を全て含む項目 → 3. それ以外（ID・本文・ほかの値で当たった項目）の順に並べる。完全に一致の判定は今と同じく大文字・小文字と前後の空白を区別しない |
| 段の中の並び | 同じ段の中は、今と同じ種類の順 → 連番の順 |
| 当たる条件 | 空白で区切った語を全て含む項目を返す今の条件は変えない |
| 完全に一致する項目 | 結果の中に必ず出し、どこに出たかを利用者が探さずに読める |
| Enter | 先頭の結果を開く今の動きのまま。先頭は 1 の段があれば 1 の段、無ければ 2 の段の項目になる |
| 結果の見出し | 種類ごとのまとまりをやめ、段ごとに「完全に一致」「タイトルに一致」「ほかの所に一致」の見出しの下に並べ、結果ごとに種類の札を添える。当たった項目の無い段の見出しは出さない |

<!-- /table -->

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 検索の言葉が絞り込みの値と一致したときに、結果の先頭へ絞り込みの候補を出す | 同じ結果の場所を触る別の要望。項目の結果の並びだけをこの PR で決める | [#143](https://github.com/shuhei1101/mindstella/issues/143) |
| タイトルの部分一致の中を、一致の位置（先頭か途中か）や語の数で並べ分ける | 要望に含まれない | 予定なし |
