# 全体の検索の結果を、タイトルの完全一致 → タイトルの部分一致 → ほかの所の一致の順に並べる

## 概要

利用者が、プレビューの全体の検索（`Ctrl+K`）で、タイトルに当たった項目を本文などほかの所だけに当たった項目より上に見つけられるようになる。

## 背景

[#195](https://github.com/shuhei1101/mindstella/issues/195) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-158）。
[#126](https://github.com/shuhei1101/mindstella/pull/126) で、ID かタイトルが言葉と完全に一致する項目を結果の一番上の「完全に一致」に出すようにしたが、残りの結果は種類ごとのまとまりの中で連番の順に並ぶ。
タイトルの部分一致と本文だけの一致を区別しないため、探したい項目がタイトルに当たっていても、本文だけに当たった項目より下に出ることがある。
