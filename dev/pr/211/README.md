# ネットワークの画面の結合テスト test_lock_when_quick_double_press を、玉の配置によらず pass させる

## 概要

ネットワークの画面の結合テスト `test_lock_when_quick_double_press` が、サンプルの玉の配置によらず毎回 pass するようにする。

## 背景

[Issue #191](https://github.com/shuhei1101/mindstella/issues/191) の報告。
このテストは develop（e2e08355）で 4 回中 4 回、[#165](https://github.com/shuhei1101/mindstella/pull/165) のブランチでも単独実行で 3 回中 2 回 fail した。
1 回目を押して詳細が開きキャンバスが縮んだ後、押した位置に玉が残っていると、前提の確認 `ball_after_shrink is False` で落ちる。
テストは [#123](https://github.com/shuhei1101/mindstella/pull/123) で足されてから変わっておらず、規約『テスト実行方法』の結合テストの全 pass を満たさない。
