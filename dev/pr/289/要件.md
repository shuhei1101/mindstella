# 要件

## 要望

表示幅 320px（iPhone SE の 320 x 568）で、プレビューのトップバー以外の全ての画面と部品が、横にスクロールせず、見切れなく最後まで操作できるようにする。

- 対象の画面（概要・検討事項のマップ / ボード / 表・タスク・資料・記録の表・ネットワーク・詳細パネル・詳細の全画面・全体の検索・図の拡大・変更履歴・コメントの一覧（スレッド・レビュー中の書き込みを含む）・表示の設定・既定の保存の確かめ・絞り込みのドロワー）を 320 x 568 で開き、`document.documentElement.scrollWidth` が表示幅以下になり、下の表・マップ・ネットワーク・図・本文のコードブロックのほかに `scrollWidth` が `clientWidth` を超える区画が無い（`body` が `overflow: hidden` のため、ページの幅だけでは区画の中のはみ出しを測れない）
- 同じ幅で、各画面の要素が表示幅の外へ見切れず、ボタン・入力欄・閉じるボタンが横にスクロールせずに見えて押せる
- 同じ幅で、各画面のシナリオの操作が最後まで済む
- 中身が表示幅を超える表・マップ・ネットワーク・図・本文のコードブロックは、その要素の中でだけ横にスクロールさせ、ページ全体は横にスクロールさせない
- 幅 390px 以上の見た目は、詳細パネル・詳細の全画面の本文の幅を超える URL・インラインコード・表の見せ方のほかは変えない（本文の長い URL・インラインコードは全ての幅で本文の幅で折り返し、本文の表は全ての幅で表の中だけで横に送る）

320 x 568 で各画面を開いて、はみ出す箇所・見切れる要素・押せないボタンを洗い出し、計画書の `## 変更方針` に画面ごとの直し方を書く。

直し方は、はみ出す要素だけを 389px 以下で詰める・折り返す・要素の中のスクロールにする（本文の長い URL・インラインコード・表は全ての幅）。
