## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文の印付け | 用語のタイトルに資料・調査のエイリアスを加えた語の集まりを、今の規則（長い語から・英数字の語は語の切れ目で）で当てる。1 つの語に一致した項目（用語・資料・調査）を印から引けるようにする | 開いている項目自身の語には付けない。取り下げた資料・調査の語は当てない |
| ツールチップ | 一致した項目を用語 → 資料 → 調査の順に、種類ごとの見出しと項目の間の区切り線で分けて並べる。資料・調査はタイトル・ID・説明と詳細へのリンクを出す。高さに上限を持たせ、超えた分は中でスクロールする | ツールチップを部品に切り出し、部品設計とストーリーを持たせる |
| 印を押したときの動き | 用語だけに一致した印は今のまま用語の詳細へ移る。資料・調査にも一致した印はツールチップを残し、中のリンクで移る先を選ぶ | - |
| 詳細の資料・調査 | エイリアスと説明を、用語の別名と同じ節の出し方で出す | - |
| アクセシビリティ | ツールチップの中のリンクへキーボードで移れ、Esc で閉じる。印の `aria-describedby` は今のままツールチップを指す | 中にリンクを持つため、`role` の当て方は部品設計で決める |
| 既存機能への影響 | 用語だけに一致した語の印・ツールチップの中身・押したときの動きは今と同じにする | 印付けの単体テストを回帰に使う |
