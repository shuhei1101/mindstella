# 資料・調査にエイリアスと説明を持たせ、本文の一致した語に用語と同じツールチップで出す

## 概要

利用者が、本文に出てきた資料・調査の名前にカーソルを合わせて、一致した資料・調査のタイトル・説明をツールチップで読み、その項目へ移れるようになる。

## 背景

[Issue #196](https://github.com/shuhei1101/mindstella/issues/196) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-160・S-161）。
本文の語は用語集の用語（項目のタイトル）と一致したときだけ点線の印とツールチップが付き、資料・調査は本文に ID を書かない限りつながらない。
資料・調査にはタイトル以外に中身を一言で表すキーも無い。
