# 要件

## 要望

資料・調査に、本文で一致させる語（エイリアス）と中身の説明を持たせ、本文の一致した語に用語と同じツールチップで出す。

- 資料（`docs.yaml`）・調査（`research.yaml`）の項目に、任意のキーを 2 つ足す
  - エイリアス（`aliases`）: 本文で一致させる空でない語の配列。タグ（`tags`）とは別のキーにする
  - 説明（`description`）: タイトルだけでは中身が分からないときに、中身を表す短い文
- 足したキーは既存のワークスペースに無くても点検・読み込みが通り、ワークスペースの移し替えを要さない
- 本文の文中で、資料・調査のエイリアスに一致した語にも、用語と同じ点線の印を付ける。当てる範囲（コードブロック・図・リンク・見出しの外）と、長い語から当てる・英数字の語は語の切れ目でだけ当てる規則は、用語と同じにする
- 印に乗せる・フォーカスすると、その語に一致した全ての項目を 1 つのツールチップに並べる
  - 並びは、用語 → 資料 → 調査の順。種類ごとに見出し（用語・資料・調査）を置き、項目の間を区切り線で分ける
  - 用語は今と同じく用語・ID・意味を出す。資料・調査は、タイトル・ID・説明（無ければ出さない）と、その項目の詳細へ移るリンクを出す
  - ツールチップは最大の高さを持ち、項目が収まらないときは、ツールチップの中をスクロールして下まで読める
  - 一致した項目が多いときは、ツールチップの中の入力で、項目をタイトル・説明で絞り込める
- 開いている項目自身は、その項目の本文の中の印とツールチップに含めない（用語の扱いと同じ）
- 取り下げた資料・調査は、ツールチップに出さない
- 資料・調査の詳細（詳細パネル・詳細の全画面）に、その項目のエイリアスと説明を出す（用語の詳細の別名と同じ出し方）
- AI は資料・調査を足す・直すとき、本文から呼ばれそうな名前をエイリアスに、タイトルで中身が分からないときは説明を、MCP の項目の追加・更新で付ける

`未確定`: 資料・調査だけに一致した語の印を押したときの動き（決める段: モック作成）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 用語の印と同じく、並びの先頭の項目の詳細へ移る | 用語の印と押したときの動きが揃う | 一致した項目が複数あると、押して移る先が選べない |
| B | 押すとツールチップを出したままにし、移る先はツールチップの中のリンクで選ぶ | 一致した項目が複数でも移る先を選べる | 用語の印と押したときの動きが変わる |

推奨: B

資料は 1 つの語に複数が当たる（「〜ノード」の設計書が並ぶ）ことが要望の前提で、先頭へ移ると目当ての資料に届かない。用語だけに一致した印は今の動き（用語の詳細へ移る）のままにする。

`未確定`: ツールチップの中の絞り込みの入力を出す条件（決める段: モック作成）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 一致した項目が一定の件数を超えるときだけ出す | 項目が少ないときにツールチップが今と同じ大きさで済む | 件数の境目を決める必要がある |
| B | 資料・調査が 1 件でも一致したら常に出す | 出す・出さないの分かれが無い | 1〜2 件でも入力欄がツールチップを大きくする |

推奨: A

要望は「当たる資料が多いとき」に絞り込みたいというもので、用語だけ・数件のときのツールチップは今の大きさのまま読める。

決まったら、『項目の詳細を読む』の『正常シナリオ（本文の語に一致した資料・調査へ移る）』の資料の件数と、絞り込みの入力の有無の期待値を合わせる。

## スコープ外

<!-- table: data -->

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 検討事項・タスクのエイリアス | 資料・調査から参照をたどれば分かるため、対象にしない（起点 Issue の補足） | 予定なし |
| 用語集の `aliases`（同じものを指す別の言い方）を本文で一致させること | 要望は資料・調査のエイリアスで、用語集は今もタイトルだけを当てている。エイリアスのキー名を `aliases` に揃えると同じ扱いにしたくなるため、スコープに含めるか判断が分かれる。設計のレビューで確定する（今の判断: 含めない） | 起票予定 |
| 本文の項目の ID のリンクのツールチップ | 別の Issue の範囲で、この PR の後に入れる計画 | [#147](https://github.com/shuhei1101/mindstella/issues/147) |
| 変更履歴の差分の表示で本文の印とツールチップを出すこと | 別の Issue の範囲 | [#154](https://github.com/shuhei1101/mindstella/issues/154) |
| HTML の本文・Markdown に埋め込んだ HTML の中の印とツールチップ | 別の Issue の範囲 | [#212](https://github.com/shuhei1101/mindstella/issues/212) |
| 資料・調査の一覧（カード・ボード・表）にエイリアス・説明を出すこと、全体の検索でエイリアス・説明に当てること | 要望は本文のツールチップに出すこと | 予定なし |
