# コメントを書いた項目に、ボード・表・マップ・つながりで吹き出しの印と件数を出す

## 概要

プレビューの利用者が、ボード・表・マップ・つながりの画面で、どの項目にコメントを書いたかと、その件数を見分けられるようにする。

## 背景

[Issue #118](https://github.com/shuhei1101/mindstella/issues/118) の要望。
手元の設計のワークスペースでプレビューからコメントを書いていて、どの項目にコメントを書いたかが一覧の画面から分からないことに気づいた。
今のプレビューは、レビュー中のコメントの件数をトップバーのコメントのボタンに総数で出すだけで、項目ごとの件数はその項目の詳細パネルを開かないと分からない。
コメントを溜める仕組みは [Issue #13](https://github.com/shuhei1101/mindstella/issues/13) で入った。
