# 詳細のコメントの入力欄を、既定で 1 行にする

## 概要

利用者が、詳細のコメントの入力欄を、空のときは 1 行の高さで、打った分だけ広がる形で使えるようになる。

## 背景

[Issue #149](https://github.com/shuhei1101/mindstella/issues/149) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-45）で、詳細のコメントの入力欄が空でも 2 行ほどの高さを取り、縦幅を取りすぎている。
入力欄は部品設計『コメントの入力』で「2 行から始まり、中身に合わせて 8 行まで伸び」と決めており、打った分だけ広がる動きは既にある。
