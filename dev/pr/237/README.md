# 変更履歴の差分を見ているときに、変わった箇所の印を並べたミニマップを出す

## 概要

利用者が、詳細パネルで変更履歴の差分を見ているときに、変わった箇所の印を並べたミニマップで変わった場所を見渡し、印を押してその箇所へ飛べるようになる。
ミニマップを表示する・しないは、表示の設定で選べる。

## 背景

[Issue #209](https://github.com/shuhei1101/mindstella/issues/209) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-198）。
詳細パネルの差分の表示は、変わった箇所の印を本文の中のその位置にだけ出すため、長い資料では本文を送りきるまでどこが変わったかが分からない。
