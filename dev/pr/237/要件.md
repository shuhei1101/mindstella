# 要件

## 要望

詳細パネルと詳細の全画面で、差分の表示の間、本文のスクロール領域に変わった箇所の印が 1 つ以上あるとき、ミニマップを出す。
ミニマップは本文のスクロール領域の全体を縮めた帯で、スクロール領域の中の差分の印（キーの差分・本文の差分・図の差分・HTML の本文の差分）の位置に印を並べる。
ミニマップの印は、足した・消した・変わったを見分けられる。
ミニマップの印を押すと、その箇所が本文のスクロール領域の見える位置まで送られる。
差分の表示でないときと、変わった箇所の印が無いとき（差分を出せない旨を出しているときを含む）は、ミニマップを出さない。
表示の設定で、ミニマップを表示する・しないを選べる。既定は表示する。
選んだ値は個人の上書きとして端末の保存領域に残し、「既定に戻す」で外れる。`config.yaml` は変えない。
配る書き出しでも同じく出す。

ミニマップは本文のスクロールバーの外側に縦の帯として並べ、変わった箇所の高さに印を置く（[確認ログ](./確認ログ.md)）。
PC では、ミニマップを押したまま上下にドラッグすると、スクロールバーと同じように本文が送られる（[ユーザーの返信](https://github.com/shuhei1101/mindstella/pull/237#discussion_r4258482012)）。
ミニマップの印の無い所を押すと、その位置に当たる本文の箇所がすぐ見える位置まで送られる（[ユーザーの返信](https://github.com/shuhei1101/mindstella/pull/237#discussion_r4258913619)）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 本文の差分を左右に並べる表示 | 要望に含まれない | [#220](https://github.com/shuhei1101/mindstella/issues/220) |
| 図の拡大の Raw の差分にミニマップを出す | 要望は詳細のパネルの差分で、図の拡大は 1 つの図の記法だけを出すため対応しない | 予定なし |
| 幅 900px 以下で詳細パネルを開いたまま表示の設定・コメントの一覧を開くと、詳細パネルの後ろに開いて操作できない（`style.css` の `.panel` と `.settings-drawer`・`.comments-panel` の重なり順） | 今の実装の不具合で、今回の要望に含まれない | [#238](https://github.com/shuhei1101/mindstella/issues/238) |
| 幅 320px でトップバーが画面幅に収まらず、ページ全体が横にスクロールする（`style.css` の `.topbar`） | 外部規約『業務画面のUI要素』の最も狭い端末での見切れから外れているが、今回の要望に含まれない | [#239](https://github.com/shuhei1101/mindstella/issues/239) |
| 詳細パネルの本文の見出しの段が飛ぶ（`detail.ts` の本文の見出し。「本文」の h3 の次に本文の `##` が h5） | 外部規約『操作とアクセシビリティ』の「見出しの段を飛ばさない」から外れているが、今回の要望に含まれない | [#240](https://github.com/shuhei1101/mindstella/issues/240) |
