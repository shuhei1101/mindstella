## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閲覧機能 | 差分の表示の間、詳細パネルと詳細の全画面に、本文のスクロール領域の中の差分の印（キーの差分・本文の差分・図の差分・HTML の本文の差分）の位置を並べたミニマップを出す。印の位置は、スクロール領域の全体の高さに対するその箇所の位置の割合で置く | 置き場所と形は `未確定`（[要件](./要件.md) の `## 要望`。決める段: モック作成） |
| 閲覧機能 | ミニマップの印を押すと、その箇所が本文のスクロール領域の見える位置まで送られる。履歴には積まない | - |
| 状態表示 | 差分の表示でないとき・変わった箇所の印が無いとき・表示の設定で表示しないにしたときは、ミニマップを出さない | - |
| 状態表示 | 図の描き終わり・HTML の本文の枠の高さの確定・「原文の差分」への切り替え・図の Raw の切り替え・パネルの幅の変化で本文の高さが変わったら、印の位置を置き直す | - |
| 編集機能 | 表示の設定のパネルに、ミニマップを表示する・しないの切り替えを足す。既定は表示する。選ぶとその場で画面に当て、個人の上書きとして端末の保存領域に残す。「既定に戻す」で外れ、「この端末で変えている項目」に並ぶ | `config.yaml` とサーバーは変えない |
| アクセシビリティ | ミニマップの印はキーボードで届き、Enter / Space で押せる。読み上げの名前で印の種類（足した・消した・変わった）を伝える。印の種類は色だけに頼らず見分けられる | 非機能要件の入力方式（全ての操作にキーボードで届く） |
| レスポンシブ対応 | 幅 390px でも本文の文字と見出しのボタンを隠さない | - |
| 性能 | 印の位置の計算は、本文の高さが変わったときだけ行い、スクロールのたびには行わない | - |
| 既存機能への影響 | 本文のスクロール領域のキーボードでのスクロール・選んだ箇所のコメントの入口・示す箇所・見出しのタイトルの出し入れを変えない | - |
| 既存機能への影響 | ミニマップを本文のスクロールバーの外側に並べる枠を足すと、本文のスクロール領域（`.panel-body`）が詳細パネル・詳細の全画面の直下でなくなる。直下を前提にしたスタイル・スクリプト・テストを画面設計・モジュール構成設計で洗い出す | [designer の補足](https://github.com/shuhei1101/mindstella/pull/237#discussion_r4253696724) |
