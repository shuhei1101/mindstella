# 起動スクリプトのテストが、MCP のツールの数を固定値で数えず、サーバーが登録するツールの一覧と突き合わせる

## 概要

起動スクリプトの E2E・結合テストが、MCP のツールを足しても書き換えずに通るようになる。

## 背景

[#170](https://github.com/shuhei1101/mindstella/issues/170) の不具合。
release/v0.7.0（[#164](https://github.com/shuhei1101/mindstella/pull/164)）の E2E で、[test_launch_script.py](https://github.com/shuhei1101/mindstella/blob/release/v0.7.0/tests/e2e/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/test_launch_script.py) の `test_normal` が `TOOL_COUNT = 25` で落ちた。
[#129](https://github.com/shuhei1101/mindstella/pull/129) が MCP のツール `readme` を足し、サーバーのツールは 26 になっている。
このテストの固定値の食い違いは [#104](https://github.com/shuhei1101/mindstella/issues/104) に続く再発で、結合テストの [test_launch.py](https://github.com/shuhei1101/mindstella/blob/release/v0.7.0/tests/integration/server/test_launch.py) もツールを足すたびに固定値を直している。
