# 要件

## 要望

起動スクリプトのテストが、MCP のツールの数を固定値で持たず、設定どおりに立てたサーバーが返すツールの名前の一覧を、[server.py](https://github.com/shuhei1101/mindstella/blob/release/v0.7.0/plugins/mindstella/skills/mindmap/scripts/server.py) の `TOOL_NAMES` と突き合わせる形にする。
ツールを足す PR が `TOOL_NAMES` に名前を足せば、起動スクリプトのテストは書き換えずに通る。

対象は次の 2 つ。

- E2E: [test_launch_script.py](https://github.com/shuhei1101/mindstella/blob/release/v0.7.0/tests/e2e/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/test_launch_script.py) の `test_normal`（`TOOL_COUNT = 25` で、サーバーの 26 と合わず落ちている）
- 結合: [test_launch.py](https://github.com/shuhei1101/mindstella/blob/release/v0.7.0/tests/integration/server/test_launch.py) の `test_normal`（`len(server.list_tools()) == 26` の固定値で、今は通るが次にツールを足すと落ちる）

release/v0.7.0 で両方のテストが pass する。
