# 結合テスト test_add_item_with_keys_when_sent_before_response の tags の期待値を {name} の並びに合わせる

## 概要

結合テスト `test_add_item_with_keys_when_sent_before_response` の `tags` の期待値を、項目のタグの今の構造（`{name, main?}` の並び）に合わせ、develop で pass させる。

## 背景

[Issue #393](https://github.com/shuhei1101/mindstella/issues/393) の不具合。
作業 PR [#392](https://github.com/shuhei1101/mindstella/pull/392) の結合テストの全件実行で、このテストが `_wait_added_value` の `wait_for_function` のタイムアウトで fail し、develop でも同じく fail する。
このテストは [#388](https://github.com/shuhei1101/mindstella/pull/388) で release/v0.11.0 に入り、バックマージで develop に入った。
develop には先に [#385](https://github.com/shuhei1101/mindstella/pull/385) で項目の `tags` が `{name, main?}` の並びになっており、テストは文字列の並び `["画面"]` を待つため一致しない。
