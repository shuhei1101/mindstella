# 要件

## 要望

差分の表示の間に、詳細パネル・詳細の全画面のキーの差分で文字で並べる前の値（`del.df-was`）と今の値（`ins.df-now`）の中の改行を、改行として出す。
対象は、キーの差分で前後を文字で並べる値の全て（題と、画面設計『詳細パネル』の要素「文字列の値の描画」が描く値: 検討事項の `lead`・`answer`・`reason`・案の各値、タスクの `reason`、調査の `question`・`conclusion`、用語の `meaning`、メモの `content`、調査・資料の `description`、取り下げた理由 `reason`）にする。
値の面・取り消し線・下線・矢印と、変わった語だけに付ける語の面（`span.df-word`）は今のまま付け、変わった語の範囲が改行をまたぐときは、改行の前後の行それぞれでその範囲の文字に面が付く。
前の値と今の値を並べる順（前の値 → 矢印 → 今の値）と、状態のキー・配列のキーの出し方は変えない。

記録の形は変えない。
