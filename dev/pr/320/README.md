# 差分の表示の間にキーの差分で並べる前の値と今の値の改行を、改行として出す

## 概要

利用者が、差分の表示の間に詳細パネルのキーの差分で並ぶ前の値と今の値を、書かれた改行のとおりに改行された形で読めるようになる。

## 背景

[Issue #314](https://github.com/shuhei1101/mindstella/issues/314) の要望。
[#311](https://github.com/shuhei1101/mindstella/pull/311)（Issue [#153](https://github.com/shuhei1101/mindstella/issues/153)）で、差分の表示でないときの文字列の値は段落の中の改行も改行として出すようにした。
差分の表示の間で変わった値は別の経路（`detail.ts` の `textOf` → `keys.showWords`）で、前後の値を文字のまま `del.df-was` / `ins.df-now` に並べて語の差分の面（`span.df-word`）を付けており、`.df-was`・`.df-now` に `white-space` の指定が無いため改行が空白に潰れる。
#311 の要件.md の `## スコープ外` から切り出した。
