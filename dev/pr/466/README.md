# Claude Code へ届いたかの確認の上限を測り直し、貼り付けの打ち切りと分ける

## 概要

プレビューでコメントをまとめて送信し、Claude Code へ入力が届いたときに、利用者が送信結果で「入力しました」と確認できるようになる。

## 背景

[Issue #403](https://github.com/shuhei1101/mindstella/issues/403) の不具合。
2026-11-03 に、入力が会話の記録（jsonl）に入っていたのに「{件数} 件を送りましたが、Claude Code には入力できませんでした（{HH:mm}）。」と複数回表示された。
送信した時刻から記録の user の行までは約 0.8 秒・約 1.1〜2.1 秒で、[claude_input.py](https://github.com/shuhei1101/mindstella/blob/develop/plugins/mindstella/skills/mindmap/scripts/claude_input.py) の `INPUT_DEADLINE_SEC = 0.5`（非機能要件『ClaudeCodeへの入力を確かめる上限』）を超えている。
この上限は、生きているかの確認・tmux の 3 つのコマンド・記録の確認の全体を 1 つの期限で打ち切る。
誤判定のままだと [#222](https://github.com/shuhei1101/mindstella/issues/222)（入力できなかったことの Webhook の通知）が誤って通知する。
