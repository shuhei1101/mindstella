## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 準備のステップ | 版が `same` のとき、送信の取り込みの前に前回読んだ時点からの差分のツールを呼び、足した・変えた項目を踏まえて話し合いを始める | - |
| 発言の取り込み | 1 つの発言から出た記録（検討事項・未整理・タスク・用語集など）を、まとめての読み書きのツールで 1 回に書く | - |
| 案の書き換え | 検討事項の案を足す・消す・直すときは、案を書き換えるツールを使い、`update` で案の配列を丸ごと渡さない | - |
| 設定の書き換え | 対象・カテゴリー・関連する場所・保持する回数も、設定を書き換えるツールで書き換え、Edit ツールで `mindmap.yaml` を直さない | - |
| 許可するツール | 足したツールを `allowed-tools` に並べる | - |
