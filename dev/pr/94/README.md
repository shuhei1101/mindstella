# ワークスペースのすべてのデータを AI が MCP で変え、前回読んだ時点からの差分とまとめての読み書きを使えるようにする

## 概要

AI が、話し合いの途中でワークスペースのすべてのデータ（設定・検討事項の案を含む）を MCP のツールで変え、話し合いの最初に前回読んだ時点からの変更を差分で読み、発言ごとの記録をまとめて書けるようになる。

## 背景

[#45](https://github.com/shuhei1101/mindstella/issues/45) の要望で、手元の mindstella の話し合いで決めた分（D-19・D-46・D-50）。
設定を書き換える `update_settings`（[#81](https://github.com/shuhei1101/mindstella/pull/81)）は題名・概要・プレイブック・フェーズ・最上位の軸の呼び名・ゴールだけを扱い、対象・カテゴリー・関連する場所・保持する回数は書き換えられない。
検討事項の案は `update` で配列ごと置き換えるしかなく、記録は 1 項目ずつ書く。
項目の変更履歴と保持する回数（[#79](https://github.com/shuhei1101/mindstella/pull/79)）は入っているが、AI がどこまで読んだかを持たず、保持する回数を超えた回は AI が読む前に消える。
タグのツールは [#47](https://github.com/shuhei1101/mindstella/issues/47) へ、テンプレートの有効 / 無効を変えるツールは [#49](https://github.com/shuhei1101/mindstella/issues/49) へ移した（[扱いの判断](https://github.com/shuhei1101/mindstella/issues/45#issuecomment-5979961364)）。
