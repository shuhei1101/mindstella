## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定の残りのキー | 対象・カテゴリー・関連する場所・保持する回数を MCP のツールで書き換える。必須のキー（対象・カテゴリー）は `null` で消せない | `未確定`（要件.md の 1 つ目の論点。決める段: インターフェース定義設計） |
| 対象・カテゴリーの付け替え | 古い名前 → 新しい名前の対応を受け、項目の `target`・`category` とカテゴリーの `target` を 1 回の書き込みで付け替える。残る項目があれば `UnmappedPhaseError` と同じ形のエラーにし、何も書き込まない | 付け替えた項目は変更履歴に 1 回分積む |
| 案の書き換え | 検討事項の ID と案の記号で、案を 1 つ足す・消す・中身を直す。足すときに同じ記号があれば、直す・消すときに記号が無ければエラー。書き換えは変更履歴に `options` の前の値を積む | 採用している案を消すときは `未確定`（要件.md の 4 つ目の論点） |
| まとめての読み書き | 追加・更新・取得を 1 回で受け、全てを当ててから 1 回だけ検証して書く。失敗したら何も書き込まず、どの操作で失敗したかを返す | `未確定`（要件.md の 2 つ目の論点） |
| AI が最後に読んだ時点 | ワークスペースに、AI が最後に読んだ書き換えの通し番号を記録する。置き場所とキーは ER 図で決める | プレビューの `.mindstella-opened` とは別 |
| 前回読んだ時点からの差分 | AI が最後に読んだ通し番号より後の書き換えで足した・変えた項目を、変わったキーと前の値（本文は行の差分）つきで返し、AI が最後に読んだ時点を今の最後の通し番号に書き換える | 記録が無いときは `未確定`（要件.md の 3 つ目の論点） |
| 変更履歴の消し方 | 保持する回数を超えた古い回のうち、AI が最後に読んだ通し番号より後の回は消さない。消した回の `history_dropped_seq` の扱いは今のまま | 保持する回数が 0 でも未読の回は残す |
| 既存のワークスペース | AI が最後に読んだ時点が無いワークスペースも、移し替えなしで読み書きできる | 版を上げる手順は足さない |
