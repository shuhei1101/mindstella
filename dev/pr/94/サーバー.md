## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定の残りのキー | 対象・カテゴリー・関連する場所・保持する回数を MCP のツールで書き換える。必須のキー（対象・カテゴリー）は `null` で消せない | `update_settings` が受けるキーに足す |
| 対象・カテゴリーの付け替え | 古い名前 → 新しい名前の対応を受け、項目の `target`・`category` とカテゴリーの `target` を 1 回の書き込みで付け替える。残る項目があれば `UnmappedPhaseError` と同じ形のエラーにし、何も書き込まない | フェーズの付け替えと同じく、付け替えは変更履歴にも書き換えのまとまりにも入れず、項目の通し番号も進めない |
| 案の書き換え | 検討事項の ID と案の記号で、案を 1 つ足す・消す・中身を直す。足すときに同じ記号があれば、直す・消すときに記号が無ければエラー。書き換えは変更履歴に `options` の前の値を積む | 採用している案は消さずにエラーにする |
| まとめての読み書き | 追加・更新・取得を 1 回で受け、全てを当ててから 1 回だけ検証して書く。失敗したら何も書き込まず、どの操作で失敗したかを返す | 新しいツール `batch`。先に足した項目は `$番号` で指す |
| AI が最後に読んだ時点 | ワークスペースに、AI が最後に読んだ変更履歴の通し番号（`changes.yaml` の `last_seq`）を記録する。置き場所とキーは ER 図で決める | プレビューの `.mindstella-opened` とは別 |
| 項目の通し番号 | `add` と、保持する回数が 0 で変更履歴を積まない `update`・`adopt`・案の書き換えでも `last_seq` を 1 つ進め、項目に最後に振った通し番号を持たせる。まとめての書き込みも同じ場所で番号を振る | `last_seq` は「最後に振った通し番号」の意味に変わる。項目のキー名は ER 図で決める |
| 前回読んだ時点からの差分 | 項目が持つ最後に振った通し番号が AI が最後に読んだ通し番号より大きい項目（足した・変えた項目）を、変わったキーと前の値（本文は行の差分）つきで返し、AI が最後に読んだ時点を今の最後の通し番号に書き換える。保持する回数が 0 のときは、足した・変えた項目の ID だけを返し、前の値は返さない | 読んだ時点の記録が無いときは差分を返さず、記録が無かったことを返して今の時点を記録する |
| 変更履歴の消し方 | 保持する回数を超えた古い回のうち、AI が最後に読んだ通し番号より後の回は消さない。消した回の `history_dropped_seq` の扱いは今のまま | 保持する回数が 0 のときは今のまま積まない |
| 既存のワークスペース | AI が最後に読んだ時点が無いワークスペースも、移し替えなしで読み書きできる | 版を上げる手順は足さない |
