## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閲覧機能（マップの拡大・縮小） | マップの枠に `wheel` を `passive: false` で付け、既定のスクロールを止めて倍率を `ZOOM_MIN`〜`ZOOM_MAX` の範囲で変える。倍率を変えた後、マウスの下の点が動かないよう枠のスクロールの位置を合わせる | 1 回のホイールで倍率を 1.12 倍・1 / 1.12 倍にする（図の拡大と同じ刻み） |
| 閲覧機能（全体を表示） | ホイールで倍率を変えたら `mapState.zoom` を数値にし、「全体を表示」の `aria-pressed` を外す。「全体を表示」のボタンは残す | - |
| 閲覧機能（縮小・拡大のボタン） | 残す | 動作環境の「全ての操作にキーボードで届く」 |
| 閲覧機能（ドラッグ） | `enableDragScroll` の左ボタンのドラッグと余白の押下は変えない | - |
| 閲覧機能（既定の表示形式） | `DEFAULT_VIEW` の `decisions` を `board` にする | - |
| 閲覧機能（表示形式の並び） | `VIEWS_OF` の `decisions` と、検討事項の画面の 2 か所の切り替えの並びをボード・マップ・表にする | - |
| トップバー | ライト / ダークのボタンを、表示の設定・絞り込み・コメントのボタンの後（右端）へ移す。コメントのボタンを出すときの検索の入口の中央寄せは変えない | 部品設計『トップバー』の「右端」「左隣」の記述を合わせて直す |
| アクセシビリティ | ライト / ダークのボタンの読み上げ名は変えない。ホイールはマウスの操作を足すだけで、キーボードの操作は今のボタンで保つ | - |
| 既存機能への影響 | ハッシュに `view` の無い `#tab=decisions` はボードで開くようになる。既定と同じ表示形式は `view` を書かないため、マップを開いたハッシュは `view=map` を持つようになる | ボード・表を指す既存のハッシュはそのまま開ける |
