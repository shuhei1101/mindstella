# プレビューの検討事項のマップをホイールで拡大・縮小し、検討事項の既定をボードに、テーマの切り替えをトップバーの右端にする

## 概要

利用者が、プレビューの検討事項のマップをマウスのホイールで拡大・縮小でき、検討事項の画面を開くとボードが出て、ライト / ダークの切り替えをトップバーの右端で押せるようになる。

## 背景

[#116](https://github.com/shuhei1101/mindstella/issues/116) の要望。
手元のワークスペースを使っていて、マップの拡大・縮小が枠の外のボタン（縮小・拡大・全体を表示）でしかできず、ホイールでは拡大・縮小できないことに気づいた。
検討事項の画面は開くとマップが出て、表示形式はマップ・ボード・表の順に並ぶ。
ライト / ダークの切り替えのボタンはトップバーの右から 4 番目にあり、右に表示の設定・絞り込み・コメントのボタンが並ぶ。
左ボタンのドラッグでマップを動かす操作は、[#21](https://github.com/shuhei1101/mindstella/pull/21) で入った `enableDragScroll` が既に持つ。
