# 要件

## 要望

プレビューの検討事項の画面とトップバーを、次のとおりに変える。

- 検討事項のマップの枠の上でホイールを回すと、マップを拡大・縮小する。倍率の範囲は今の拡大・縮小のボタンと同じ 40%〜150% で、範囲の端で止める
- ホイールで拡大・縮小しても、倍率を変える前にマウスの下にあった点がマウスの下に残る
- ホイールで倍率を変えたら「全体を表示」の押された状態を外す。「全体を表示」と縮小・拡大のボタンは残す（動作環境の「全ての操作にキーボードで届く」を満たすため）
- 左ボタンのドラッグでマップを上下左右に動かす操作と、余白を 1 回押して選びを外す操作は今のまま保つ
- 検討事項の画面を、URL のハッシュに表示形式が無いときはボードで開く
- 検討事項の表示形式の切り替えを、ボード・マップ・表の順に並べる
- ライト / ダークの切り替えのボタンを、トップバーの右端に置く。ほかのボタン（変更履歴・表示の設定・絞り込み・コメント）の並びの順は変えない
- 全体の検索の入口は、コメントのボタンを出すときに中央へ寄せる今の置き方を保つ
