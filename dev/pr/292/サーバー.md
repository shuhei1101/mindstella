## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 前回開いた時点の記録 | `.mindstella-opened` に、開いた日時と、開いた時点の先頭のまとまりの `until_seq`（まとまりが無ければ 0）を持つ | 1 行目が日時、2 行目が通し番号 |
| `POST /api/opened` の応答 | `previous` と `opened` で、日時（`at`）と通し番号（`seq`）を返す。書き換えるのは `.mindstella-opened` だけで、記録（種類ごとの YAML・本文・`changes.yaml`）は書き換えない（今までどおり） | - |
| 今の形のファイル | 1 行の日時だけの `.mindstella-opened` を読んでも 500 を返さず、`previous` を `null` にして返し、2 行の形で書き換える | - |
| 書き換えの知らせ・点検・移し替え | `.mindstella-opened` を対象にしない（今までどおり） | - |
