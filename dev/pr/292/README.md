# 差分の表示の「前回開いてから」の範囲を、時計の戻りと秒の切り捨てに左右されない決め方にする

## 概要

利用者が差分の表示で「前回開いてから」を選ぶと、前回プレビューを開いた後に作った書き換えのまとまりが、開いたのと同じ秒に作ったものや端末の時計が戻った後に作ったものも含めて全て範囲に入る。

## 背景

[#272](https://github.com/shuhei1101/mindstella/issues/272) の不具合。
「前回開いてから」は前回開いた日時（`.mindstella-opened`）より後の `at` を持つまとまりだけを範囲にし、どちらの日時も秒で切る。
そのため、プレビューを開いたのと同じ秒に `commit` したまとまりと、端末の時計が後ろへ戻った後に作ったまとまりが範囲から落ちる（WSL の端末で、時計が約 29 秒ごとに約 0.76 秒戻ることを実測した）。
同じ原因で揺れていた E2E は [#251](https://github.com/shuhei1101/mindstella/issues/251) / [PR #271](https://github.com/shuhei1101/mindstella/pull/271) がテストの側だけを直し、製品の範囲の決め方はこの Issue へ切り出された。
[#156](https://github.com/shuhei1101/mindstella/issues/156)（変更履歴を時系列の一覧にする）が入れば「前回開いてから」の区切りが無くなるが、着手の見込みが立っていない。
