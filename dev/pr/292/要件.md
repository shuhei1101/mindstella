# 要件

## 要望

差分の表示の「前回開いてから」の範囲を、端末の時計の戻りと日時の秒の切り捨てに左右されない決め方にする。

| 項目 | 内容 |
| --- | --- |
| 範囲に入るまとまり | 前回プレビューを開いた後に `commit` した書き換えのまとまりは、開いたのと同じ秒に作ったときも、端末の時計が後ろへ戻ったときも、全て「前回開いてから」に入る |
| 範囲に入らないまとまり | 前回プレビューを開く前に `commit` したまとまりは「前回開いてから」に入らない（今までどおり） |
| 範囲の決め方 | 日時の比べ合いではなく、開いた時点の通し番号（その時点の先頭のまとまりの `until_seq`。まとまりが無ければ 0）と、まとまりの `until_seq` を比べて決める |
| 配る書き出し | 端末に持つ前回開いた時点も、同じく時計に左右されない値で範囲を決める |
| 既存のワークスペース | 今の形（1 行の日時）の `.mindstella-opened` を持つワークスペースでも、プレビューを開けて「前回開いてから」を選べる。通し番号を持たない前回開いた時点は、前回開いた時点なしとして扱う（移し替えは足さない） |
| 範囲の始まりの表示 | 変更履歴の「前回開いてから」の行・トップバーの札・詳細パネルの冒頭の `{日時} より後` は今までどおり出す |
| 共有の範囲 | 前回開いた時点はワークスペースごとに 1 つで、同じワークスペースを開いた全てのブラウザで共有し、Claude Code を立て直しても残る（今までどおり） |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 変更履歴の画面を時系列の一覧にし、まだ見ていない変更を未読の印で知らせる | 「前回開いてから」の区切りそのものをやめる別の要望で、この範囲の決め方の不具合とは別に成り立つ | [#156](https://github.com/shuhei1101/mindstella/issues/156) |
| E2E の `visit_and_close` から、前回開いた日時の秒を越えるまでの待ち（`wait_past_boundary`）を外す | 範囲を通し番号で決めるこの PR の後に要らなくなる待ちで、外すのはテストの所要時間の改善。この PR のテストは待ちがあっても通る | [#293](https://github.com/shuhei1101/mindstella/issues/293) |
