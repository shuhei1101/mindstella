## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文の切り分け | 書き込みの本文を、文字・記録にある項目の ID・まとまりのリンクの部分に切り分ける。まとまりのリンクは `[文言](#...)` の形で、`#` の後ろの `diff` の値が記録にあるまとまりの ID のものに限る | 記録にあるまとまりかは、使う側が渡す引き（項目のタイトルの引き `titles` と同じ形）で決める |
| 描き方 | まとまりのリンクは `文言` だけを出す。`文言` の中の項目の ID はボタンにしない | 詳細の本文のまとまりのリンクと同じく、色の付いた文字と下線で出す |
| 押したとき | まとまりの ID を使う側へ知らせ、使う側は変更履歴で選んだときと同じ `selectPoint` で差分の表示に切り替える | スレッドの画面は開いたまま |
| 描く場所 | スレッドの画面の書き込みとレビュー中の書き込みの画面の行 | レビュー中の書き込みの行は、項目の ID を今と同じく文字のまま出す |
| 既存機能への影響 | 項目の ID のボタンと、まとまりのリンクにならない `[文言](...)` の文字は今と同じ | 破壊的変更なし |
