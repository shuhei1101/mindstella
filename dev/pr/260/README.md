# スレッドの書き込みでも、書き換えのまとまりの差分を指すポートによらないリンクを使えるようにする

## 概要

ワークスペースの中のスレッドの書き込みでも、書き換えのまとまりの差分を指すポートによらないリンク `[文言](#diff=V-2)` を使えるようにする。

## 背景

[Issue #257](https://github.com/shuhei1101/mindstella/issues/257) の要望。
[PR #255](https://github.com/shuhei1101/mindstella/pull/255)（起点 [Issue #242](https://github.com/shuhei1101/mindstella/issues/242)）で、記録の本文（Markdown）に `[文言](#diff=V-2)` と書くと、詳細パネルでそのまとまりの差分の表示に切り替わるようにした。
スレッドの書き込みは Markdown として描かず、`[文言](#diff=V-2)` が文字のまま出るため、AI はスレッド（`reply`・`new_thread`）には今も `preview_url` が返す絶対の URL を添えている。
ポートを固定していないワークスペースでは、配信を立て直すとポートが変わり、スレッドに貼った URL が開けなくなる。
