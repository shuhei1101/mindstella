# 要件

## 要望

スレッドの書き込みの本文（利用者と AI の書き込み・レビュー中の書き込み）の中の `[文言](#diff=V-2)` を、書き換えのまとまりの差分を指すリンク（まとまりのリンク）として描く。
リンクには `文言` だけを出し、`[`・`](#diff=V-2)` は出さない。
リンクの見た目は、書き込みの中の項目の ID のボタンと同じにする。
`文言` の中に項目の ID があっても、リンクの中では項目を開くボタンにしない。

まとまりのリンクにするのは、`#` の後ろを `URLSearchParams` で読んだ `diff` の値が記録にあるまとまりの ID のときだけにする。
記録に無いまとまりの ID（保持する回数を超えて消えたまとまりを含む）・`since`・`pending`・空の値を指すもの、`diff` の引数を持たない `[文言](#...)`、`#` で始まらない `[文言](...)` は、今と同じく書いた文字のまま出す。
`#` の後ろは `diff` の引数だけを読み、他の引数（`tab`・`id` など）は無視する（PR #255 の制約『本文のまとまりのリンク』と揃える）。

まとまりのリンクを押すと、変更履歴でそのまとまりを選んだときと同じく差分の表示に切り替え、端末の保存領域とハッシュの `diff` を書き換える（履歴に積まない）。
開いているスレッドの画面は閉じない。

AI（`session`）がワークスペースの中のスレッド（`reply`・`new_thread`）に直したまとまりを書くときは、`preview_url` を呼ばず `[文言](#diff={id})` のリンクを書く。
利用者への応答とワークスペースの外（Issue のスレッドなど）には、今と同じく `preview_url` が返す絶対の URL を添える。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| スレッドの書き込みを Markdown として描く（強調・見出し・まとまり以外のリンク） | 要望はまとまりの差分を指すリンクだけで、書き込みは改行を保った文字のまま出す | 予定なし |
| スレッドの要約（一覧の行）の中のまとまりのリンク | 要約は一覧で読むかを決める短い文で、AI はリンクを本文に書く | 予定なし |
| 既に書き込まれた絶対の URL を、まとまりのリンクへ書き換える | スレッドの書き込みは書いた後に変えない記録で、要望は今後の書き方 | 予定なし |
