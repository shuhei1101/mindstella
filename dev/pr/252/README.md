# 幅 720px 以下でも、詳細パネルのレビュー中のコメントの修正・削除のボタンを行の中に出す

## 概要

利用者が幅 720px 以下でプレビューを開いても、詳細パネルのレビュー中のコメントの「修正」「削除」が、その行の右上に出る。

## 背景

[#236](https://github.com/shuhei1101/mindstella/issues/236) の報告。
幅 720px 以下で詳細パネルを開くと、レビュー中のコメントの行の「修正」「削除」が、詳細パネルの見出しの右（次の項目・全画面のボタンの上）に重なって出る。
コメントの一覧の行向けの狭い幅の規則（[#78](https://github.com/shuhei1101/mindstella/pull/78)）が、後から詳細パネルに置いた同じボタン（[#190](https://github.com/shuhei1101/mindstella/pull/190)）にも当たっている。
作業 PR [#235](https://github.com/shuhei1101/mindstella/pull/235) のモックの撮影で見つかった。
