## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 起動時の指示 | mindstella のセッションの起動時に必ず読み込まれる指示に、ターミナルに記載したことは利用者に届かないことと、質問を検討事項・資料・スレッドで出すことを入れる | 起動スクリプトが `claude` を `--append-system-prompt` 付きで立ち上げて渡す |
| 指示の本文 | プラグインの中の 1 ファイルに配置し、起動スクリプトがインストールした今の版のフォルダからそのファイルを参照する | 本文を起動スクリプトに直に記載しない |
| 指示の中の例外 | setup・upgrade のスキルの中の質問はターミナルで聞くことを、起動時の指示に入れる | session の外で呼ぶスキルで、画面では回答できない |
| リリースの資料の書き出し | `.mindstella/release/` の下へ資料を書き出す MCP のツールを足し、ゴール判定は Write ツールでなくこのツールで書く。`release/` の外のパスは拒む | `write_release`（`workspace`・`path`・`content`）。`clear_release` と同じく `release/` だけを扱う |
