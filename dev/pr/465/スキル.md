## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 決まりの置き場所 | SKILL.md に、ターミナルに記載したことは利用者に届かない前提と、質問の出し先（検討事項・資料・スレッド）のセクションを 1 つ配置し、各ステップはそのセクションを指す | 起動時の指示（[サーバー](./サーバー.md)）にも同じ決まりを要約して入れる |
| ヒアリング | 選んだ質問を、検討事項の案と推奨に記録してから、検討事項ごとにその検討事項を向けたスレッドを `new_thread` で立てて知らせる。回答は送信の取り込みで拾い、`adopt` と `answer`・`reason` の記録へ進む | 1 質問 = 1 スレッド。検討事項ごとに回答・クローズできる |
| リサーチ・方針転換・範囲の見直し・ゴール判定・記録の削除・配る書き出しの先 | 確認をスレッドで取り、回答が届くまでその先の作業をしない | 範囲の見直しのたたき台は資料に起こしてスレッドから指す |
| 回答を待つ間 | 回答に左右されない取り込み・記録を続け、ターミナルには何も記載しない | - |
| スレッドの返し方の最後の行 | 「今の話の流れの中で答えが要る問い…はターミナルで聞く」を削除し、立てられなかったときだけ同じことをターミナルで聞く退避を残す | - |
| ターミナルに記載してよいもの | 準備のステップの、MCP のツールが無いときの案内と、`new_thread` が失敗したときの同じ質問だけ | - |
| 質問の書式 | 書式は変えず、出す先がスレッドの本文と検討事項の `options` であることを冒頭に記載する | - |
