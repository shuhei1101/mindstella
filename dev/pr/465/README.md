# 利用者への質問はターミナルに記載せず、検討事項・資料・スレッドに記録して聞く

## 概要

mindstella の話し合いで、利用者がターミナルを見ずにブラウザの画面だけで話し合いを進められるようになる。

## 背景

[Issue #205](https://github.com/shuhei1101/mindstella/issues/205) の要望。
画面から送信したコメントは Claude Code のセッションへ届く（[#117](https://github.com/shuhei1101/mindstella/issues/117)）が、Claude Code はターミナルで質問を返すため、ターミナルを確認していない利用者に質問が届かない。
[追加のコメント](https://github.com/shuhei1101/mindstella/issues/205#issuecomment-6231013141) で、画面から届いた発言に限らずターミナルに記載したことは利用者に届かない前提にし、この決まりをセッションの起動時に必ず読み込まれる指示にも入れるよう範囲が広がった。
今の session のスキルは、話の流れの中で回答が要る質問（ヒアリング・方針転換の確認・リサーチを始めてよいか）をターミナルで聞くと定めている（[#235](https://github.com/shuhei1101/mindstella/pull/235)）。
