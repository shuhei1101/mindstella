# 表の「表示する列」のボタンの文言と置き場所を直す

## 概要

利用者が、プレビューの表の画面で、表に出す列を選ぶボタンを自然な文言で見つけ、表から離れた落ち着いた位置で押せるようになる。

## 背景

[#197](https://github.com/shuhei1101/mindstella/issues/197) の要望。
aituber のワークスペースの話し合いで、画面から送られた要望（送信 S-172）。
調査の画面など表の画面で、表の上に「表示する列」のボタンがある。
文言が UI として不自然で、ボタンが表にぴったりくっついて置かれている。
