## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ボタンの文言 | 列のアイコンと、決めた文言にする。読み上げ名（`aria-label`）とポップオーバーの題も同じ文言にする | `未確定`（要件.md） |
| ボタンの置き場所 | 決めた置き場所へ置く。表の上に残すときは、帯と表の間に余白を取る | `未確定`（要件.md） |
| 狭い幅 | 幅 720px 以下で文言を隠してアイコンだけにする今の `.toolbar .btn .lbl` の扱いに揃え、読み上げ名は残す | - |
| 列の選びの動き | 付け外し・タイトルの列を外せない・初期設定に戻す・端末に残すは変えない | - |
| 既存機能への影響 | 絞り込みのボタン・条件のチップ・並べ替え・ピン留めは変えない | - |
