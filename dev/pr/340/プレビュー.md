## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 既定の幅 | 全ての種類の詳細パネルを `--panel-w` の 1 つの値で開く。資料の `wide` の出し分けを消す | 値は `未確定`（要件.md の `## 要望`） |
| 端のドラッグ | 幅 901px 以上で、詳細パネルの左端につかむ所を置き、ポインターのドラッグで幅を変える。下限・上限で止める。上限は、寄せる幅（1100px 以上、マップは 901px 以上）では画面の幅から本文に残す幅を引いた値、重なる幅（901〜1099px のマップ以外）では画面の幅から左に残す幅を引いた値 | 下限・上限の値は `未確定`（要件.md の `## 要望`）。幅 900px 以下はつかむ所を出さない |
| 本文の寄せ | 寄せる幅（1100px 以上、マップは 901px 以上）で、本文・マップ・パンくずの帯の `margin-right` を変えた幅に合わせる。重なる幅（901〜1099px のマップ以外）では寄せない | 今は `--panel-w` か `.panel.wide` の 760px。境目は `style.css` の今の値のまま |
| 幅の保持 | 変えた幅を `sessionStorage` に 1 つのキーで残し、詳細パネルを開くたびに読む。種類で分けない。保存領域が使えないときは既定の幅で開く | 配る書き出しでも同じ |
| 窓の幅の変化 | 窓を狭めて保った幅が上限を超えたら上限に収めて出す（保った値は書き換えない） | - |
| アクセシビリティ | つかむ所はキーボードで操作できる区切り（`role="separator"`・`aria-valuenow`）にし、左右の矢印キーで幅を変える。読み上げの名前は「詳細パネルの幅」 | - |
| 既存機能への影響 | 本文の差分の「左右に並べる」の切り替え（本文の幅 560px 以上で出す）と、マップの寄せは、変えた幅に追従する | - |
