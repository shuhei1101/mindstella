# 詳細のサイドバーを既定の幅で開き、ドラッグで幅を変えられるようにする

## 概要

利用者が、詳細のサイドバーをどの種類の項目でも同じ既定の幅で開き、端のドラッグで好きな幅に変え、変えた幅のまま開き直せるようになる。

## 背景

[Issue #150](https://github.com/shuhei1101/mindstella/issues/150) の要望。
詳細のサイドバーは、資料のときは画面の半分ほど、ほかの種類は 3 分の 1 ほどの幅で開く。
開くたびに幅が変わり、3 分の 1 は目線を右に寄せないと読めない。
前の追記の「1/2・2/3・1/3 から選ぶ」案はやめ、ドラッグで変える形にした（knowledge のワークスペース `tmp/mcpベストプラクティス検討` の TH-35）。
