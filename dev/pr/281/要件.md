# 要件

## 要望

E2E『項目の詳細を読む』の `test_normal_when_body_scrolled` を、シナリオの期待値どおりの検証に揃え、画面幅 1920×1080 の全画面のモーダルでも通るようにする。

- 全画面の側は、シナリオの期待値（モーダルの見出しの帯に「A-3」と「話し合いの進め方の手引き」で始まるタイトルが出る）と、ボタンが帯に収まって押せることを確かめる
- 全画面の側の「タイトルが省略記号付きで切れる」検証（`assert full["truncated"] is True`）を外す。シナリオの期待値で省略を求めているのは詳細パネルの側だけで、全画面のモーダルでの省略は結合テスト `test_detail_full_screen.py` の `test_head_title_on_scroll` が確かめている
- 詳細パネルの側の検証（ID・タイトル・省略・ボタン）は変えない
