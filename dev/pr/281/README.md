# E2E『項目の詳細を読む』の見出しの帯のテストを、全画面のモーダルの幅でも成り立つ検証に直す

## 概要

E2E『項目の詳細を読む』の見出しの帯のテストが、全画面のモーダルの幅でもシナリオの期待値どおりに確かめて通るようにする。

## 背景

[#277](https://github.com/shuhei1101/mindstella/issues/277) の不具合。
release/v0.8.0 の E2E で `test_normal_when_body_scrolled` が fail した（[#194 の実行の結果](https://github.com/shuhei1101/mindstella/pull/194#discussion_r4285228807)）。
画面幅 1920×1080 では全画面のモーダルの幅が 1600px になり、テストのタイトルが見出しの帯に収まって省略されず、全画面の `assert full["truncated"] is True` が落ちる。
テストは [#230](https://github.com/shuhei1101/mindstella/pull/230) で足され、そのマージの時点から fail している。
