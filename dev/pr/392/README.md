# MCP サーバーを stdio から HTTP の常駐サーバーに移す（既定のポート 8784・MINDSTELLA_PORT）

## 概要

利用者が、並行する複数の Claude Code のセッションから、1 つの常駐の MCP サーバー（HTTP、既定のポート 8784）で複数のワークスペースを扱えるようになる。

## 背景

[#338](https://github.com/shuhei1101/mindstella/issues/338) の要望。
MCP サーバーは stdio で動き、起動スクリプトが起動ごとに MCP の設定を書くので、セッションごとにサーバーのプロセスが立つ。
knowledge の話し合いで、全リポジトリの MCP サーバーを HTTP の常駐サーバーにし stdio を禁止すると決め（D-60・D-61）、規約『MCP サーバー作成ルール』へ入った（[shuhei1101/knowledge#50](https://github.com/shuhei1101/knowledge/issues/50)）。
今のサーバーは Claude Code の子プロセスとして `TMUX_PANE` を受け継ぎ、コメントをまとめて送った後にそのペインへ貼っている。
常駐サーバーはペインを受け継がないため、貼る先の受け取り方も同じ PR で決め直す。
