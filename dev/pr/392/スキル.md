## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ツールが無いときの案内 | mindstella のツールが無いときは、常駐サーバーが落ちていることを示し、`ensure_server.py` を叩いて `/mcp` でつなぎ直す手順を案内する。`allowed-tools` のツールの名前を `mcp__plugin_mindstella_mindstella__{ツール}` に書き換える | 起動スクリプトを通さずに立ち上げた Claude Code もツールを持つので、起動スクリプトの登録を持ちかける条件を、tmux の外で立ち上げたとき（`register.py show` の `in_tmux` が偽）にする |
| 外から見る設定の渡し先 | 外から見る設定の環境変数を、常駐サーバーを起動する環境へ渡す | 登録した環境変数はログインシェルから Claude Code へ受け継がれ、`ensure_server.py` が起動する常駐サーバーへそのまま渡る。登録できる環境変数に `MINDSTELLA_PORT` を追加する |
