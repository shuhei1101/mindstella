# 新しいワークスペース

進め方ガイドを選び、軸とゴールを決めて、新しいワークスペースを作る。
問いは `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/質問の書式.md` の書式で書き、文章は `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/文章の書き方.md` に従う。

## 手順

### 進め方ガイドを決める

何を話し合うかを尋ね、進め方ガイドを決める。
進め方ガイドは `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/playbooks/` にある（システム開発・調査・資料作り・壁打ち）。
話題に合うガイドを 1 つ以上選び、選んだガイドをすべて Read で読む。
どのガイドにも当てはまらないときは、進め方ガイドが無いことを伝え、近いガイドで進めてよいかを尋ねる。

### たたき台を作って確認する

選んだガイドから、次のたたき台を作る。

| 項目 | たたき台の元 |
| --- | --- |
| タイトル（`summary`） | 話題から、何についての話し合いかを 1 文で。プレビューのトップバーに出る。必ず決める |
| 話し合いの概要（`description`） | 話題から、何についての話し合いかを 1 文の短い文（60 字以内）で。プレビューの概要の画面の題名の上に出る |
| プレイブック（`playbooks`） | 選んだガイドの名前の並び |
| 最上位の軸の呼び名（`target_label`） | ガイドの `## 最上位の軸の呼び名`。複数選んだときは、話題に合うものを選んだガイドの呼び名から選ぶ |
| フェーズ（`phases`） | ガイドの `## フェーズと観点` の並び。複数選んだときは、各ガイドのフェーズから 1 本の並びのたたき台を作る |
| 対象（`targets`） | 話題から、名前と概要を 1 件以上 |
| カテゴリー（`categories`） | ガイドの `## カテゴリーの分け方` と話題から。各カテゴリーは `target` で対象を指す |
| ゴール（`goal`） | ガイドの `## ゴールの候補` の既定。`phase` と、納品物のタイトル（`deliverables[].title`）。決めずに始めるときは持たない |

ゴールの候補が複数あるので、候補に「決めずに始める」を足して案の表にし、既定を推奨にして確認を取る。
「決めずに始める」が選ばれたら、`goal` を渡さない。
タイトル・話し合いの概要・対象・カテゴリー・複数選んだときのフェーズの並びのたたき台は、直してもらう前提で示す。
利用者が確定するまで、ワークスペースを作らない。

### ワークスペースを作る

確定した設定を `settings` に渡して `init` を呼ぶ。

```json
{"workspace": "{ワークスペースのフォルダ}", "settings": {"summary": "家計簿アプリの要件を決める", "description": "家計簿アプリの要件を、作り始められるところまで決める話し合い。", "playbooks": ["システム開発"], "target_label": "機能", "phases": ["目的", "要件"], "targets": [{"name": "家計簿アプリ", "summary": "支出を記録する"}], "categories": [{"name": "機能", "target": "家計簿アプリ", "summary": "利用者ができること"}], "goal": {"phase": "要件", "summary": "要件が決まる", "deliverables": [{"title": "要件定義書"}]}, "links": []}}
```

`init` がエラーを返したときは、本文のエラーを示して止まる。

### 話し合いへ渡す

作ったワークスペースのフォルダを示し、`/mindstella:session {ワークスペースのフォルダ}` で話し合いを続けるよう案内する。
