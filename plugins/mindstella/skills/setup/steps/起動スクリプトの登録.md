# 起動スクリプトの登録

起動スクリプトを呼ぶ alias と、起動スクリプトが読む環境変数を、ログインシェルの設定に登録する。
ワークスペースは書かない。MCP のツールは使わず、登録のスクリプトを Bash で呼ぶ。
問いは `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/質問の書式.md` の書式で書き、文章は `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/文章の書き方.md` に従う。

## 登録のスクリプト

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/skills/setup/scripts/register.py {show|set|add-account|remove-account|remove} [--env KEY=VALUE]... [--unset-env KEY]... [--name {アカウントの名前}] [--config-dir {フォルダ}]
```

標準出力の JSON を読む。

| フィールド | 中身 |
| --- | --- |
| `registered` | alias `mindstella` が登録されているか |
| `env` | 登録した環境変数 |
| `accounts` | 登録したアカウント（`name`・`config_dir`） |
| `aliases` | 登録した alias の名前 |
| `error`・`manual_lines` | 失敗したときの理由と、手で書けば同じ登録になる行（終了コード 1） |

登録できる環境変数は、`MINDSTELLA_VENV`（MCP サーバーを動かす仮想環境のフォルダ）・`MINDSTELLA_ALLOWED_HOSTS`（外から見るホスト名）・`MINDSTELLA_PREVIEW_START_HOOK`・`MINDSTELLA_PREVIEW_STOP_HOOK`（配信を立てた直後・止めるときに呼ぶコマンド）。

## 手順

### 登録を読む

`show` を呼び、登録済みの alias・環境変数・アカウントを読む。
登録済みなら、値を示してから進む。

### 登録する

利用者が設定したいと言った環境変数だけを尋ね、既定のままでよい値は尋ねない。
登録済みの値は示し、変えたいものだけを書き換える。外したいものは `--unset-env` で外す。
決まった値を `set` に `--env KEY=VALUE` で渡す（環境変数が要らなければ、渡さずに `set` だけを呼ぶ）。
値に改行は入れられない。秘密の値は持たない。

### アカウントを足す・外す

Claude Code のアカウントを複数持つ利用者に、アカウントの名前（英小文字・数字・`-` の 1〜32 文字で、英小文字か数字で始まる）とそのアカウントの Claude Code の設定のフォルダを尋ねる。
`add-account --name {名前} --config-dir {フォルダ}` で、alias `mindstella-{名前}` を足す（同じ名前なら設定のフォルダを書き換える）。
外すときは `remove-account --name {名前}`。

### 外す

登録を全て外したいと言われたときは、外してよいかを確かめてから `remove` を呼ぶ。

### 失敗したとき

終了コードが 1 のときは、何も書き換えられていない。
`error` の理由と、`manual_lines` があればその行を示す。`manual_lines` はログインシェルの設定ファイルに手で書けば同じ登録になる。
終了コードが 2 のときは、引数を直して呼び直す。

### 案内して終える

登録・書き換え・外したあとは、新しいシェルから効くことを伝え、次のどちらかを案内して止まる。

- 登録した（外していない）: 新しいシェルで `mindstella {ワークスペースのフォルダ}` で立ち上げる。アカウントごとの alias があれば `mindstella-{名前} {ワークスペースのフォルダ}` も示す
- 外した: 起動スクリプト（`{プラグインのフォルダ}/bin/mindstella {ワークスペースのフォルダ}`）で立ち上げる
