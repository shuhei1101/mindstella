# 既存のワークスペース

既存のワークスペースの状況を読み、続きを推奨する。
どのファイルも書き換えない。

## 手順

### 版を比べる

`migrate` を `plan: true` で呼び、結果の `relation` を読む。

- `older`: `/mindstella:upgrade {ワークスペースのフォルダ}` で移し替えるよう案内して止まる（以降は実行しない）
- `newer`: プラグインを更新するよう案内して止まる（以降は実行しない）
- `same`: 「状況を読む」へ進む

### 状況を読む

`status` を呼ぶ。
出力の `needs_review`（要見直し）・`in_progress`（進行中）・`resumable`（再開可能）・`next`（次の候補）を読む。
`waiting`（決定待ち）と `on_hold`（保留）は、利用者が尋ねたときだけ示す。

### 続きを推奨する

次の順で、続きの候補を示す。

1. 要見直しの検討事項（方針が変わって見直しが要るもの）
2. 進行中のタスク
3. 再開可能な検討事項・タスク（保留で、依存先が全て決着したもの）
4. 次の候補（前提が揃った未決定。フェーズ → 影響度 → 後続の件数の順）

利用者が話題を言っているときは、`status` の候補から話題に合うものを選び、そこから続ける推奨にする。
各候補は、ID とタイトルを並べて示す。
推奨は 1 つに絞り、理由を添える。

### 話し合いへ渡す

`/mindstella:session {ワークスペースのフォルダ}` で話し合いを続けるよう案内する。
