# リサーチ

調べる必要のある検討事項について、利用者の確認を取ってサブエージェントで調べ、結果を調査に書いて検討事項に繋ぐ。
問いは `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/質問の書式.md` の書式で書き、文章は `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/文章の書き方.md` に従う。

## 手順

### 調べる内容を決める

調べる検討事項を決め、何を・どの観点で調べるかを書き出す。
調査のタスクが無ければ、`add`（`kind: task`）で積む（`kind`: `調査`・状態 `未着手`・`for` に検討事項）。
外部ライブラリ・外部 API を決める検討事項は、次の 2 つを必ず調べる。

- ベストプラクティス（公式の資料）
- 候補の比較（技術の選定）

調べ方は `${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/リサーチの調べ方.md` の `## 使い分け` で選ぶ。
体数は、観点を重ならないように割った数にする。
既に調べた内容は、`find`（`kind: research`）で調査の `question` を読み、除外の一覧にする。

### 確認を取る

利用者が自分から調べるよう頼んだときは、この手順を省く。
それ以外は、サブエージェントを起動する前に、「何を・どの観点で・何体で」調べるかを質問の書式で示し、確認を取る。

- 承認されたら、「サブエージェントで調べる」へ進む
- 断られたら、サブエージェントを起動せず、調査のタスクを未着手のまま残し、「会話ログを書き足す」へ進む

### サブエージェントで調べる

`${CLAUDE_PLUGIN_ROOT}/skills/mindmap/references/リサーチの調べ方.md` を Read で読む。
Agent ツールで `general-purpose` を、体数ぶん起動する。
1 つの応答の中で、全ての起動を並べる。
各サブエージェントには、次を全て渡す。

- 調べる題材と観点
- 除外の一覧
- 同じファイルの `## 共通` と、選んだ節の本文

サブエージェントが返した結論・確度・出典を待つ。

### 結果を調査に書いて検討事項に繋ぐ

観点のまとまりごとに、`add`（`kind: research`）で調査を足す。

- `question`: 調べたこと
- `conclusion`: 結論
- `confidence`: 確度（`高`・`中`・`低`）
- `angles`: 調べた観点
- `related`: 元の検討事項の ID
- `body_markdown`: 出典つきの詳細

続けて、`update` で調査のタスクを `完了` にし、`result` に結果を書く。
結果は、検討事項の案（`options` の `pros`・`cons`・新しい案）と派生の問いに反映する。
調べた結果や読んだコード・ドキュメントにある固有の言葉（システムの名前・業務や製品の固有の言葉）は、`add`（`kind: term`）で用語集に足す。

### 会話ログを書き足す

`add`（`kind: log`）で会話ログを 1 件足し、`related` に今回足した・直した項目を指す。

### 書き換えをまとめる

記録を書き換えたら、このステップで何をしたかを一言の説明（1〜200 文字）にして `commit`（`summary`）を呼ぶ。

### 結果を示す

結論と、検討事項の案への反映を示す。
