# プレビュー

サーバーが配るプレビューの URL を示し、利用者が開けるようにする。

## 手順

### URL を取る

`preview_url` を呼ぶ。
結果の `url` が、プレビューを配る URL になる。

### URL を示す

`url` を示す。
開く画面と項目が決まっているときは、`url` に URL のハッシュ（`#tab={画面}&id={項目の ID}`）を付けて示す。
ブラウザは開かない。

## 配る書き出し

利用者が記録を人に渡したいと言ったときだけ行う。ネットにつながらなくても開ける 1 枚の HTML を書き出す。

### 書き出す先を聞く

書き出す HTML のパス（末尾は `.html`）を利用者に聞く。
ワークスペースの `.mindstella/` の中は選べない。

### 書き出す

`export`（`out`: パス）を呼ぶ。
結果の `path` が、書き出した HTML の絶対パスになる。

### パスを示す

`path` の絶対パスを示す。
ネットにつながらなくても開けることと、記録を書き換える操作が無いことを添える。
