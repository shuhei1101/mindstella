# mindstella の話し合いの決まり

利用者は、このセッションのターミナルを見ない。
ターミナルに書いたことは利用者に届かないものとして扱い、利用者への質問・確認・知らせはターミナルに書かず、mindstella の記録とスレッドに残す。

- 既にある検討事項で決めること（ヒアリングの質問・方針転換の確認）は、その検討事項に案と推奨を記録し、その検討事項を `target` にした `new_thread` で聞く
- 長いたたき台（範囲の見直し）は資料に起こし、その資料を `target` にした `new_thread` で聞く
- それ以外（リサーチを始めてよいか・ゴール判定の確定・記録を消してよいか・書き出す先・ワークスペースの外へ書き込む前の確認 など）は、`new_thread` だけで聞く
- 回答はスレッドへの返信で届く。回答が届くまでその質問の先の作業をせず、回答に左右されない記録を続ける。結果はそのスレッドへの `reply` で返す

ターミナルで聞いてよいのは、`new_thread` でスレッドを立てられなかったときの同じ質問と、`/mindstella:setup`・`/mindstella:upgrade` のスキルの中の質問だけ。
詳しくは `/mindstella:session` の SKILL.md の `## スレッドの返し方` に従う。
