# HTMLの書き方

資料の `body_markdown` に、HTML・図・チャート・操作できる部品を埋め込むときの書き方。
記法と決まりの詳細は、mdmark の使い方集を MCP `read_guide` で読む。

## 使いどころ

| 描くもの | 書き方 | 読む使い方集（`read_guide` の `names`） |
| --- | --- | --- |
| 文章・表・手順・リスト | Markdown | - |
| フロー図・シーケンス図・グラフ・操作できる部品 | `<!-- html -->` の範囲の中の `<mdmark-flow>`・`<mdmark-sequence>`・`<mdmark-chart>`・`<mdmark-param>` に、部品の定義（JSON）を書く | `diagrams`・`interactive-parts`・`html-blocks` |
| 部品で描けない、見た目のあるもの | `<!-- html -->` の範囲に `html` のコードブロックを置く | `html-blocks`・`html-rules` |
| 本文の全体がモックや図 | `body_html` | - |

`html` のコードブロックは、1 つの範囲に 1 つだけ置く。
範囲のコードブロック以外の Markdown は、描いた本文に残らない。

## プレビューでの扱い

| 項目 | 決まり |
| --- | --- |
| スクリプト | `<script>`・`on` で始まる属性は動かない。`button` は押しても何も起きない。動きは mdmark の部品だけが持つ |
| 外のもの | 外のファイル・CDN・フォントを読まない。色と書体は `--mdmark-` の CSS 変数で書く |
| 拡大・縮小 | チャートだけに付く。段落・スライダーなどには付かない |
| 用語・項目の ID | 範囲の中の文にも、本文と同じ用語のマーカーとツールチップ、項目の ID のリンクが付く |
| Markdown での書き出し | 範囲は除かれる。範囲の外にも要点を文章で書く |

## 値を受け取る

`<mdmark-param>` の「今の値をコピー」は、キーごとに名前と今の値を持つ JSON をクリップボードへ入れる。

```json
{ "rps": { "name": "ピーク時のリクエスト数", "value": 800 } }
```

利用者はこの JSON をその資料へのコメントに貼って送る。
貼った JSON はコメントの書き込みの文として届くので、送信の取り込みの流れのまま取り込む。
キーと名前から、その値を確かめていた検討事項を選び、`answer` に値を書く。
選べないときは、利用者に確かめる。
