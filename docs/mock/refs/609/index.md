# 609

コメントのペインに項目での絞り込みを追加し、詳細ペインのボタンからその項目のコメントを一覧できるようにする（[PR #609](https://github.com/shuhei1101/mindstella/pull/609)・起点 [Issue #536](https://github.com/shuhei1101/mindstella/issues/536)）。
画面は、develop のプレビューのスクリプトを `builder.py` の順につないだものにこの PR の変更を当てたもの（`assets/app.js`、当てた箇所に「609:」のコメント）と、#127 の見本の記録（`../127/assets/data.js`）を読む。
サーバーの代わり（`assets/mock.js`）は #422 と同じスレッド・レビュー中の書き込みで、クローズの TH-5 を D-12 へ向け、D-12 へのまだ送っていない新しいスレッド C-45 を加えた。D-12 へ向けたのはオープンの TH-1・クローズの TH-5・C-45 の 3 件。
スタイルは今のプレビューの `style.css` の上に、この PR の分とモック専用の操作列（`assets/style.css`）を重ねる。
モック専用の操作列の「案」でボタンの見た目（A アイコンだけ・B アイコンと件数）を、「見本」でボタンを押した後の状態を切り替える。

| 画面 | 中身 |
| --- | --- |
| [detail-panel](../../pages/detail-panel/609/index.md) | 詳細パネルの見出しの、項目で絞ったコメントの一覧を開くボタンの 2 案 |
| [comments](../../pages/comments/609/index.md) | コメントの一覧の項目の絞り込みのチップと、状態の絞り込みとの組み合わせ |
