# 396

詳細のレビュー中のコメントの並びを新しい順・古い順で切り替えられるようにする（[PR #396](https://github.com/shuhei1101/mindstella/pull/396)）。
画面は、develop のプレビューのスクリプトをつないだものに、この PR のレビュー中のコメントの並びと並びの切り替えを当てたもの（`assets/app.js`、当てた箇所に「396:」のコメント）と、#237・#385 の見本の記録（`../237/assets/data.js`・`../385/assets/data.js`）を読む。
サーバーの代わり（`assets/mock-server.js`）が記録とレビュー中のコメントの読み書きに応える。D-1 へ 3 件、D-13 へ 1 件、D-27 へ 0 件のコメントを溜めた状態で開く。
スタイルは今のプレビューの `style.css` の上に、この PR の分とモック専用の操作列（`assets/style.css`）を重ねる。
並びの切り替えは、ボタンの組の案 A（`a-segment`）と 1 つのボタンの案 B（`b-toggle`）を、各画面のモック専用の操作列のタブで切り替える（採用は案 B）。
選んだ並びは端末の保存領域に残り、読み込み直しても保つ（操作列の「見本に戻す」で新しい順に戻す）。
