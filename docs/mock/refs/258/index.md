# 258

スレッドに利用者の既読・未読を持たせ、AI の返信が届いたことを画面で未読の印として示す（[PR #258](https://github.com/shuhei1101/mindstella/pull/258)・起点 [Issue #249](https://github.com/shuhei1101/mindstella/issues/249)）。
画面は、develop のプレビューのスクリプトをつないだものにこの PR の変更を当てたもの（`assets/app.js`、当てた箇所に「258:」のコメント）と、#127 の見本の記録（`../127/assets/data.js`）を読む。
サーバーの代わりに `assets/mock.js`（#235 の `mock.js` に利用者の既読と既読にする受け口を足したもの）が記録・レビュー中の書き込み・スレッドの受け口と書き換えの知らせを返す。
書き込みの利用者の既読のキーと既読にする受け口の形は決まっていないため、モックでは仮に `seen` と `POST api/threads/{ID}/seen` にした。
見本の記録では、AI が立てた TH-2・オープンの TH-4 の最後の返信・クローズの TH-6 の最後の返信が利用者の未読。
モック専用の操作列の「見本」で未読の有無と一覧の開き方を、「操作」で AI の返信・AI が立てたスレッド・AI のオープンへの戻しの届き方を切り替える。
