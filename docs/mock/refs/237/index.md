# 237

変更履歴の差分を見ているときに、変わった箇所の印を並べたミニマップを出す（[PR #237](https://github.com/shuhei1101/mindstella/pull/237)・起点 [Issue #209](https://github.com/shuhei1101/mindstella/issues/209)）。
画面は、develop のプレビューのスクリプトをつないだものにこの PR の変更を当てたもの（`assets/app.js`、当てた箇所に「237:」のコメント）と、#214 の見本の記録にミニマップの見本の資料と書き換えのまとまりを足したもの（`assets/data.js`）を読む。
サーバーの代わり（`../214/assets/mock-server.js`）が記録とレビュー中のコメントの読み書きに応え、プレビューをサーバーにつながった状態で開く。
スタイルは今のプレビューの `style.css` の上に、この PR の分とモック専用の操作列（`assets/style.css`）を重ねる。
見本の記録でミニマップを見るのは、A-14「プレビューの差分の読み方（手引き）」（本文が長く、V-6「差分の手引きを書き直す」で状態とタグ・段落・箇条書きの項目・表の行・図を足し、消し、変えた）、A-16（60 個の段落のうち 30 か所を足し、消し、変えた）、A-15（本文が短く送れない）、A-11（本文が HTML。V-5 で段落を書き換えた）。
A-2 は V-6 で変わっておらず、A-17 は保持する回数を超えて前の版を組み立てられないため、どちらもミニマップが出ない。
モック専用の操作列で、ミニマップの置き場所の案・見本の資料・時点（差分を出さない）・ミニマップを表示する / しないを切り替える。
