文字起こしの設定

設定の画面に足す「音声入力」のまとまり（文字起こし後の挙動と用語集のプリセット。PR #476）。

既定（設定を持たない）

設定の画面の「変更履歴」のまとまりの後に「音声入力」のまとまりを足す。挙動の既定は「入力欄へ挿入する」、プリセットの既定は「サービスの既定」（プリセットを指定しない）。

音声入力
文字起こし後の挙動

「送信する」は文字起こしの結果をその書き込みだけで Claude Code へ送信します。「入力欄へ挿入する」はカーソルの位置に挿入し、送信しません。

文字起こしの補正に使用する用語集です。候補は文字起こしのサービスから取得します。

書き換えた（保存待ち）

挙動とプリセットを変えると、ほかの設定と同じく保存待ちに溜め、名前の右に保存待ちの印、入力を破線の枠にする。

音声入力
文字起こし後の挙動保存待ち

「送信する」は文字起こしの結果をその書き込みだけで Claude Code へ送信します。「入力欄へ挿入する」はカーソルの位置に挿入し、送信しません。

保存待ち

文字起こしの補正に使用する用語集です。候補は文字起こしのサービスから取得します。

候補を取得できない（文字起こしのサービスが起動していない）

プリセットのセレクトを今の値のまま押せなくし、すぐ下に理由を出す。挙動は書き換えられる。

音声入力
文字起こし後の挙動

「送信する」は文字起こしの結果をその書き込みだけで Claude Code へ送信します。「入力欄へ挿入する」はカーソルの位置に挿入し、送信しません。

文字起こしのサービスが起動していないため、候補を取得できません。サービスを起動してから設定の画面を開き直してください。
