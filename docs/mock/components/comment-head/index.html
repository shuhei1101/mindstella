コメントの一覧の見出しの帯

レビュー中が 3 件

左に見出し、右にレビュー中を確かめる入口と閉じるボタン。入口の件数は、トップバーのコメントのボタンと同じ丸い札で出す。

レビュー中が 0 件

入口は消さず、件数の塗りを外す。押すと「レビュー中の書き込みはありません。」を出す。

件数が多い

2 桁でも閉じるボタンを押し出さない。

レビュー中を確かめる画面を開いている

見出しの帯の入口は出さず（押しても何も変わらない）、その下に「戻る」と題・件数を出す。

ホバー・フォーカス

ホバーは面の色を変え、キーボードのフォーカスは枠の全体に出す。
