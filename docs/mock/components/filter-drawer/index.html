絞り込みのボタンとドロワー

絞り込みのボタン

トップバーの右端に、コメントのボタンと並べて 1 つだけ置く（どちらも左から重ねるパネルを開閉し、パネルに覆われない）。概要には出さない。絞っていないときはバッジを出さず、絞り込み中だけ印の色のバッジを付ける。ドロワーを開いている間は押された見た目にし、もう一度押すと閉じる。

件数のバッジに出す数（未確定）

同じ条件（状態で 4 つ・タグで 1 つを選び、36 件中 3 件）を、案ごとのバッジで出す。推奨は C。

ドロワー

条件ごとに値を件数つきのチェックボックスで並べる。値を選んだ条件にだけ「解除」を出し、今の条件では 0 件になる値は文字を薄くする。どの幅でも見ている画面に重ね、下端のボタンは絞った件数を添えて閉じる。

狭い幅（390px）

ボタンは文字を隠してアイコンとバッジだけにし、名前は読み上げで渡す。ドロワーはコメントの一覧と同じく、トップバーの下から全幅で重ねる。

表の列の見出し

列の見出しの絞り込みのボタンを外し、並べ替えとピン留めだけを残す。

文字を含む（B 案・推奨）

値を選ぶ条件より上に、値を選ぶ条件にしない列（ID・タイトル・用語・意味など）ごとに文字の欄を並べる。打ち終えて少し待つと、その列の値に文字を含む行に絞る（大文字・小文字を区別しない）。値を選ぶ条件の件数は、文字で絞った行で数える。初めて開くと先頭の欄にフォーカスを置く。
