## 色の役割

<!-- table: {"kind": "data"} -->

| 役割 | 使う場所 | トークン | 補足 |
| --- | --- | --- | --- |
| 地 | 画面の地 | `--background` | ライトは灰色、ダークは墨色 |
| 面 | タイル・表・詳細パネル | `--card` / `--card-foreground` / `--muted` / `--thead` | 地との明るさの差で区切る |
| 文字 | 本文・補足・控えめな補足 | `--foreground` / `--muted-foreground` / `--subtle-foreground` | どれも置く面の上で 4.5:1 以上 |
| 線 | 部品の枠・入力欄の枠・表の行の境 | `--border` / `--input` / `--border-soft` | `--border-soft` は `--border` を面へ 55% 混ぜた派生 |
| マーカー | 選択中・進み具合・リンク | `--mark` / `--mark-weak` / `--mark-line` | 強い色はこの 1 色だけ。`--mark-weak`・`--mark-line` はマーカーの色を面へ 8%・45% 混ぜた派生 |
| フォーカスの輪 | キーボードのフォーカス | `--ring` | マーカーと同じ色 |
| 主なボタン | 主な操作のボタン・選んでいる表示形式 | `--primary` / `--primary-foreground` | 文字色で塗り、マーカーの色を使わない |
| 補助のボタン | 初期設定に戻すなどの補助の操作 | `--secondary` / `--secondary-foreground` | 面よりわずかに暗い面 |
| 取り消せない操作 | 項目を削除するボタン | `--destructive` / `--destructive-foreground` | 要見直しの赤と同じ色相 |
| 重ねるメニュー | 表示する列などのメニュー・ポップオーバー | `--popover` / `--popover-foreground` | 面と同じ色に重ねる面の影 |
| ホバー | 押せるものに乗せたとき・キーボードのフォーカスがある表のセル | `--accent` / `--accent-foreground` / `--row-hover` | 面だけを変え、全ての画面で同じ値を使う。`--row-hover` は文字色を面へ 4% 混ぜた派生 |
| 選択中 | 選んだ行・項目 | `--row-selected` | マーカーの色の薄い面（`--mark-weak`）と細い枠 |
| 状態 | 状態のマーカー（決定済み・未決定・要見直し・保留・未整理・取り下げ） | `--st-done` / `--st-open` / `--st-review` / `--st-hold` / `--st-loose` / `--st-off` | 状態の表示だけに使い、色に加えて形状でも分ける |
| 失敗 | 回答・意見の本文が空・送信できなかった・サーバーにつながらないときのマーカーと入力欄の枠 | `--st-review`（トップバーの上は `--red-300`） | 状態の表示の外で要見直しの赤を使う例外。文言は赤くせず、色に加えてマーカーのアイコンと文言でも伝える |
| 種類 | 種類の点と種類の切り替え | `--k-dec` / `--k-task` / `--k-res` / `--k-doc` / `--k-term` / `--k-note` / `--k-log` | 検討事項・タスク・調査・資料は色、用語集は濃い灰・メモは茶・会話ログは薄い灰 |
| トップバー | トップバー | `--topbar-bg` / `--topbar-fg` / `--topbar-fg-2` / `--topbar-line` / `--topbar-hover` | 明暗どちらでも暗い帯 |
| 当たった語 | 検索の強調 | `--hit` | 黄色 |
| 本文の Markdown | 詳細パネル・詳細の全画面・本文の差分の本文と、スレッドの書き込みの本文 | `--foreground` / `--muted-foreground` / `--border` / `--card` / `--thead` / `--mark` | mdmark の共通スタイルのまま、色の変数（`--mdmark-color-*`）の文字・補足・線・面・表の見出し・リンクにプレビューのトークンを当てる。地は置かれた面の色のままにする。ライト / ダークはプレビューのテーマに従い、mdmark の既定の色（ライトだけ）は使わない |
| 本文の Alert | 本文とスレッドの書き込みの `> [!NOTE]` 等 | `--mdmark-color-callout-*` | 補足・ヒント・重要・警告・注意の種類の色。種類は色に加えて見出しの文言とアイコンでも分け、ダークは明るい値に替える |
| 重ねる面の影 | 詳細パネル・検索・全画面・図の拡大・ポップオーバー | `--shadow-panel` / `--shadow-pop` | 本文に重ねる面だけに付ける |
| 幕 | 検索・図の拡大・詳細の全画面・左のパネル（絞り込みのドロワー・コメントの一覧・表示の設定・保存待ち）の後ろ | `--scrim` | どれも同じ濃さにし、後ろの画面は透けて見える。左のパネルの幕はトップバーとタブの帯を覆わない |

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 見出し | サンセリフの太字（IBM Plex Sans JP） | 題名は本文の 2.4 倍（`--fs-h1`）、大きな数字は 3.1 倍（`--fs-big`） |
| 本文 | サンセリフ（IBM Plex Sans JP） | 14px（`--fs-body`）。補足は 13px・12px の 2 段階まで。本文の Markdown も同じ書体・大きさに揃える。英字と和文を 1 つの書体で描く（[確認ログ](./pr/674/確認ログ.yaml)） |
| ID・数値 | 等幅（JetBrains Mono） | 桁を揃える。表の数値の列は右揃え。本文のコードも等幅 |
| 読み込み | Google Fonts から読む | 端末によらず字形を揃える（[確認ログ](./pr/21/確認ログ.md)） |

## 形状と奥行き

<!-- table: {"kind": "data"} -->

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| タイル | 地より明るい面だけ。線と影は使わない | 角丸 4px（`--radius`） |
| 表 | 行の境を薄い線で区切る | 見出し行と押した列までを留め、留めた列の境だけに影 |
| 部品（ボタン・入力・切り替え） | 1px の線 | 高さは `--control-h` に揃える |
| ID のボタン | 1px の線 | 見えている枠を縦横 `--target-min` 以上にする |
| 詳細パネル・検索 | 面と線、重ねる面には影（`--shadow-panel` / `--shadow-pop`） | 詳細パネルはどの種類の項目も既定の幅（640px）で開き、ドラッグで変えた幅をそのタブで保つ。検索は地を暗くして重ねる |
| 図（本文の mermaid） | 面と線 | ノードの面・線・辺のラベルの地と文字をトークンから決める |
| 本文の引用・Alert | 引用は面の色だけ、Alert は種類の色の薄い面と細い枠 | 角丸は mdmark の角丸（`--mdmark-radius`）を `--radius` に揃える |
| フォーカス | マーカーの色の 2px の輪 | ホバー（面の色）・選択中（マーカーの色の薄い面）と見分ける |

<!-- /table -->

## 動き

<!-- table: {"kind": "data"} -->

| 場所 | 動き | 補足 |
| --- | --- | --- |
| 詳細パネル | ゆっくりすべり込む | 本文の寄せは開閉と同時に切り替え、パネルだけを動かす |
| 詳細の見出しのタイトル | 本文を送信して本文の先頭のタイトルが隠れると 0.15 秒で薄く現れ、先頭へ戻すと薄く消える | 利用者のスクロールでだけ動く |

<!-- /table -->

動きを減らす設定では、全て止める。

## 使わないもの

| 使わないもの | 理由 | 補足 |
| --- | --- | --- |
| マーカーの色以外の強い色 | マーカーが目立たなくなる | 状態と種類の色は表示にだけ使う。本文の Alert の種類の色は本文の中だけ |
| タイルの影 | 奥行きの表し方を面の色の差 1 つに揃える | 本文に重ねる面の影（`## 形状と奥行き`）とは別 |
| 光る影・文字のグラデーション・左端だけの太い色線 | 飾りが情報より先に目に入る | - |
| 入ったときに自動で動くアニメーション | 読み返す画面で目を散らす | - |
| 絵文字のアイコン | 線のアイコン 1 セットで揃える | - |
