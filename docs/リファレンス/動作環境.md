# 動作環境

mindstella を使う端末に要る条件の一覧。
値の根拠は開発ドキュメントの[非機能要件](https://github.com/shuhei1101/mindstella/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E9%9D%9E%E6%A9%9F%E8%83%BD%E8%A6%81%E4%BB%B6/%E9%9D%9E%E6%A9%9F%E8%83%BD%E8%A6%81%E4%BB%B6.yaml)にある。

## スキルとサーバー

| 項目 | 条件 | 補足 |
| --- | --- | --- |
| Claude Code | 2.1.287 以上 | これより古い版は確かめていない |
| OS | Linux・macOS・Windows（WSL を含む） | 確かめたのは WSL2 の Ubuntu 24.04 |
| Python | 3.12 以上 | 古いときは、起動スクリプトが依存の確認で作り直すコマンドを返して止まる |
| tmux | 3.4 以上 | 3.4 より古い版は確かめていない。起動スクリプトは版を確かめず、`new-session` が失敗すると tmux の標準エラーをそのまま出して止まる |
| 通信 | サーバーは `127.0.0.1` だけで待ち受ける。`export` を使うときだけ jsDelivr へ HTTPS で届くこと | ポートは OS が選んだ空きポートで、端末の別のアドレスからはつながらない。`export` 以外の MCP のツールと配信は、外へ通信しない |

## プレビュー

| 項目 | 条件 | 補足 |
| --- | --- | --- |
| ブラウザ | Chrome と Edge の最新版（PC）。スマートフォンは閲覧できれば足りる | Edge・Firefox・Safari の実機では確かめていない |
| 画面サイズ | 幅 390px 以上 | 幅 900px 以下は狭い幅の作りになる（マップは字下げした縦の一覧、詳細パネルは本文に重なる）。幅 1100px 以上（マップは 901px 以上）は、詳細パネルの分だけ本文を寄せる |
| 入力方式 | マウスとキーボード（PC） | 全ての操作にキーボードで届く。タッチでの回転・拡大は対象にしない |
| 通信 | サーバーが配るプレビューを開くには、配信（`127.0.0.1`）と jsDelivr（描画のライブラリ）・Google Fonts（文字）へ HTTPS で届くこと。配る書き出しを開くのは通信が要らない | 描画のライブラリと文字は開いたときに読む。届かないときは、読めなかったライブラリの名前が画面に出る。配る書き出しを書き出す（`export`）には jsDelivr へ HTTPS で届くことが要る || つながりで扱う項目の数 | 1000 件まで | 超えても全て描く。1000 件を超えたときの速さとメモリは確かめていない |
| 使うメモリ | 2GB 以上の空きメモリ | ブラウザ全体の値。1000 件のつながりを開いたときの最大 1,462MB に余裕を足した |
| つながりの描画の速さ | 1000 件で、25ms を超えたコマが 1% 以下、1 コマの処理時間が p95 で 8ms 以下 | 拡大・縮小・回転・押下で測った |

描画の速さとメモリは、Windows・Chrome 154・Ryzen 7 9800X3D・RTX 5070・画面 143Hz の端末で測った。
これより低い性能の端末は確かめていない。
