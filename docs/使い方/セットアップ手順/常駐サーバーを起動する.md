# 常駐サーバーを起動する

mindstella のツールが Claude Code に無いとき、常駐サーバーの状態を確かめたいとき、常駐サーバーを止めたいとき、待ち受けのポートを変えたいときに実行する。

## 前提

- [プラグインをインストールする](./プラグインをインストールする.md)
- [スクリプトの依存を入れる](./スクリプトの依存を入れる.md)で、スキル専用の仮想環境に依存がそろっている

mindstella のツールは、端末に 1 つの常駐サーバーが持つ。
並行する複数の Claude Code のセッションが、同じ常駐サーバーを共有する。
Claude Code を立ち上げると、プラグインのフックが常駐サーバーを確かめ、落ちていれば起動する。
[起動スクリプトで立ち上げる](./起動スクリプトで立ち上げる.md)ときも、起動スクリプトが同じように起動する。

## 手順

### 常駐サーバーを起動する

```bash
python3 {プラグインのフォルダ}/skills/mindmap/scripts/ensure_server.py
```

`{プラグインのフォルダ}` の引き方は [起動スクリプトで立ち上げる](./起動スクリプトで立ち上げる.md#プラグインのフォルダを引く)。
常駐サーバーが落ちていれば起動し、標準エラーに `[mindstella]` で始まる、起動したポートの行を出す。
既に待ち受けていれば、何も出さずに終わる。
起動した後は、開いている Claude Code で `/mcp` を実行し、mindstella につなぎ直す。

依存が足りないと、足りないものとそろえるコマンドを出して、終了コード 1 で止まる。
[スクリプトの依存を入れる](./スクリプトの依存を入れる.md)を実行してから叩き直す。

### ポートを変える

常駐サーバーは `127.0.0.1` の 8784 で待ち受ける。
ほかのプロセスが 8784 を使っていると、使われているポートと `MINDSTELLA_PORT` の案内を出して、終了コード 1 で止まる。
別のポートを、環境変数 `MINDSTELLA_PORT` で渡す。

```bash
MINDSTELLA_PORT=8790 python3 {プラグインのフォルダ}/skills/mindmap/scripts/ensure_server.py
```

Claude Code も同じ `MINDSTELLA_PORT` でつなぐので、Claude Code を立ち上げるシェルにも同じ値を設定する。
[起動スクリプトを登録する](./起動スクリプトを登録する.md)で `MINDSTELLA_PORT` を登録すると、新しいシェルの全てに入る。

### 状態を確かめる

Claude Code に、mindstella の常駐サーバーの状態を見るよう頼む。
ツール `server_status` が、待ち受けのポート・バージョン・プロセスの PID と、配信しているワークスペースごとのポートを返す（[常駐サーバーの状態を読む](../../リファレンス/コマンド.md#常駐サーバーの状態を読む)）。

### 止める

Claude Code に、mindstella の常駐サーバーを止めるよう頼む。
ツール `server_stop` が、配信ごとに終了時のフック（`MINDSTELLA_PREVIEW_STOP_HOOK`）を呼び、全てのプレビューの配信を止めて、常駐サーバーを終える（[常駐サーバーを止める](../../リファレンス/コマンド.md#常駐サーバーを止める)）。
並行する全てのセッションから mindstella のツールが使えなくなる。
次に Claude Code を立ち上げたとき、そのときにインストールされているバージョンで起動する。

### プラグインを上げた後

古いバージョンの常駐サーバーが待ち受けていると、Claude Code を立ち上げたときに、バージョンの差と起動し直す手順が会話に出る。
常駐サーバーを止めてから、Claude Code を立ち上げ直す。

## 反映

即時。

## 確認

#### 常駐サーバーが待ち受けている

```bash
curl -s http://127.0.0.1:${MINDSTELLA_PORT:-8784}/_admin/status
```

`"name": "mindstella"` を持つ JSON が出る。

#### Claude Code がつながっている

```bash
claude mcp list
```

`plugin:mindstella:mindstella` がつながった状態で出る。

## 元に戻す

常駐サーバーを止める。
Claude Code を立ち上げると、また起動する。

止めた後に残るものは、次のとおり。

| 残るもの | 扱い |
| --- | --- |
| `~/.mindmap/server.log` | 常駐サーバーの標準出力と標準エラーの記録。要らなければ手で削除する |
| ワークスペースのフォルダ | 削除されずに残る |
