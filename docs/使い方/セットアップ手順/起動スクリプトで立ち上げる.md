# 起動スクリプトで立ち上げる

mindstella のスキルを使い始めるとき、話し合いを再開するとき、止まったサーバーを立ち上げ直すときに実行する。

## 前提

- [プラグインをインストールする](./プラグインをインストールする.md)
- Python 3.12 以上（`venv` を含む）、`tmux`、`claude` が `PATH` にある

## 手順

### プラグインのフォルダを引く

```bash
claude plugin list --json
```

出力の `mindstella@mindstella` の `installPath` が `{プラグインのフォルダ}`。
出なければ、プラグインがインストールされていない。

### 起動スクリプトを叩く

```bash
{プラグインのフォルダ}/bin/mindstella {ワークスペースのフォルダ}
```

依存を確かめ、tmux のセッション `mindstella-{フォルダ名}-{ハッシュ}` を立て、その中で mindstella の MCP サーバーを渡した Claude Code を起動して、そのセッションへつなぐ。
ワークスペースのフォルダが無ければ作る。
同じフォルダのセッションが既にあれば、新しく立てずにそのセッションへつなぐ。
標準出力が端末でないときは、つながずに、つなぐコマンドを標準出力に出して終わる。

依存が足りないと、標準エラーに足りないものとそろえるコマンドを出して、終了コード 1 で止まる。
tmux も Claude Code も立たないので、[スクリプトの依存を入れる](./スクリプトの依存を入れる.md)を実行してから叩き直す。

### スキルを呼ぶ

つないだ Claude Code で、スキルを呼ぶ。

```
/mindstella:setup {ワークスペースのフォルダ}
```

起動スクリプト以外で立ち上げた Claude Code には、MCP のツールが載らない。
載っていない会話でスキルを呼ぶと、何も書き込まれず、この手順が案内される。

## 反映

即時。

## 確認

#### セッションが立っている

```bash
tmux list-sessions
```

`mindstella-{フォルダ名}-{ハッシュ}` が出る。
ハッシュは、ワークスペースのフォルダの絶対パスの SHA-256 の先頭 6 桁で、別の場所にある同じ名前のフォルダは別のセッションになる。

## 元に戻す

Claude Code を閉じる。
標準入力が閉じて、MCP サーバーがプレビューの配信を止めてプロセスを終えるので、プロセスは残らない。
閉じた後に残るものは、次のとおり。

| 残るもの | 扱い |
| --- | --- |
| ワークスペースのフォルダ | 消えずに残る。要らなければ手で消す |
| 一時フォルダの `mindstella-{ランダム}/mcp.json` | 数百バイトの MCP の設定。一時フォルダの片付けに任せる |
