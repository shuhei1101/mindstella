# 起動スクリプトで立ち上げる

mindstella のスキルを使い始めるとき、話し合いを再開するとき、止まったサーバーを立ち上げ直すときに実行する。

## 前提

- [プラグインをインストールする](./プラグインをインストールする.md)
- Python 3.12 以上（`venv` を含む）、`tmux`、`claude` が `PATH` にある

## 手順

### プラグインのフォルダを引く

```bash
claude plugin list --json
```

出力の `mindstella@mindstella` の `installPath` が `{プラグインのフォルダ}`。
出なければ、プラグインがインストールされていない。

### 起動スクリプトを叩く

```bash
{プラグインのフォルダ}/bin/mindstella {ワークスペースのフォルダ}
```

依存を確かめ、mindstella の常駐サーバーが落ちていれば起動してから、tmux のセッション `mindstella-{フォルダ名}-{ハッシュ}` を立て、その中で Claude Code を起動して、そのセッションへつなぐ。
Claude Code は、プラグインの接続の設定から常駐サーバーへつなぐ。
常駐サーバーについては[常駐サーバーを起動する](./常駐サーバーを起動する.md)を参照。
ワークスペースのフォルダが無ければ作る。
同じフォルダのセッションが既にあれば、新しく立てずにそのセッションへつなぐ。
標準出力が端末でないときは、つながずに、つなぐコマンドを標準出力に出して終わる。

依存が足りないと、標準エラーに足りないものとそろえるコマンドを出して、終了コード 1 で止まる。
tmux も Claude Code も立たないので、[スクリプトの依存を入れる](./スクリプトの依存を入れる.md)を実行してから叩き直す。

常駐サーバーを起動できない（待ち受けのポートがほかのプロセスに使われている）と、標準エラーに使われているポートと `MINDSTELLA_PORT` の案内を出して、終了コード 1 で止まる。
別のバージョンの常駐サーバーが待ち受けているときは、起動し直さずにバージョンの差と手順を標準エラーに出し、Claude Code は立ち上げる。

### 登録した alias から叩く

[起動スクリプトを登録する](./起動スクリプトを登録する.md)と、`{プラグインのフォルダ}` を引かずに、新しいシェルで alias にワークスペースのフォルダを渡して立ち上げられる。

```bash
mindstella {ワークスペースのフォルダ}
```

alias は、叩くたびに今の `installPath` を引く。
Claude Code のアカウントごとの alias `mindstella-{アカウントの名前}` は、そのアカウントの設定のフォルダを `CLAUDE_CONFIG_DIR` で渡して立ち上げる。

### 外から見る設定を渡す

[プレビューを外から見る](./プレビューを外から見る.md)の設定は、起動スクリプトを叩くシェルの環境変数で渡す。
[起動スクリプトを登録する](./起動スクリプトを登録する.md)で登録すると、新しいシェルに入っているので、叩くたびに打たなくてよい。
登録しないときは、叩くときに環境変数を前に置く。

```bash
MINDSTELLA_ALLOWED_HOSTS=preview.example.com {プラグインのフォルダ}/bin/mindstella {ワークスペースのフォルダ}
```

渡せる環境変数は、`MINDSTELLA_PORT`（常駐サーバーの待ち受けのポート）・`MINDSTELLA_ALLOWED_HOSTS`（許可するホスト名）・`MINDSTELLA_PREVIEW_START_HOOK`（配信を立てたときのフック）・`MINDSTELLA_PREVIEW_STOP_HOOK`（配信を止めるときのフック）。
常駐サーバーを起動するときに、叩いたシェルの環境のまま渡し、Claude Code の環境には追加しない。
常駐サーバーが既に待ち受けていると、新しい値は効かない。
[常駐サーバーを起動する](./常駐サーバーを起動する.md)の手順で常駐サーバーを止めてから叩き直す。

### スキルを呼ぶ

つないだ Claude Code で、スキルを呼ぶ。

```
/mindstella:setup {ワークスペースのフォルダ}
```

起動スクリプト以外で立ち上げた Claude Code でも、常駐サーバーが待ち受けていれば MCP のツールが載る。
tmux の外で立ち上げた Claude Code では、プレビューから送ったコメントが Claude Code へ入力されない。
その会話でスキル `setup` を呼ぶと、未登録なら[起動スクリプトを登録する](./起動スクリプトを登録する.md)が持ちかけられる。

## 反映

即時。

## 確認

#### セッションが立っている

```bash
tmux list-sessions
```

`mindstella-{フォルダ名}-{ハッシュ}` が出る。
ハッシュは、ワークスペースのフォルダの絶対パスの SHA-256 の先頭 6 桁で、別の場所にある同じ名前のフォルダは別のセッションになる。
`CLAUDE_CONFIG_DIR` が空でないときは、絶対パスの後ろに改行と `CLAUDE_CONFIG_DIR` の絶対パスをつないだ文字列の SHA-256 になり、同じフォルダを別のアカウントで開くと別のセッションになる。
先にあったセッションは立ち上げ直されない。

## 元に戻す

Claude Code を閉じる。
閉じた後に残るものは、次のとおり。

| 残るもの | 扱い |
| --- | --- |
| ワークスペースのフォルダ | 消えずに残る。要らなければ手で消す |
| 常駐サーバーとプレビューの配信 | ほかのセッションと共有しているため、止まらずに残る。止めるときは[常駐サーバーを起動する](./常駐サーバーを起動する.md)の手順で止める |
