# スクリプトの依存を入れる

起動スクリプトを初めて叩くとき、起動スクリプトが依存の不足を示して止まったときに実行する。

## 前提

- [プラグインをインストールする](./プラグインをインストールする.md)
- Python 3.12 以上（`venv` を含む）が入っている

## 手順

### Python の版を確かめる

```bash
python3 --version
```

`Python 3.12` 以上と出る。
これより古いと、起動スクリプトが 3.12 以上の Python を入れるよう示して止まり、仮想環境を作るコマンドを出さない。

### 依存の不足を出させる

```bash
{プラグインのフォルダ}/bin/mindstella {ワークスペースのフォルダ}
```

`{プラグインのフォルダ}` の引き方は [起動スクリプトで立ち上げる](./起動スクリプトで立ち上げる.md#プラグインのフォルダを引く)。
依存が足りないと、足りないものとそろえるコマンドが標準エラーに出て、終了コード 1 で止まる。
tmux も Claude Code も立たない。

### 仮想環境を作ってライブラリを入れる

出たコマンドを、そのまま実行する。
スキル専用の仮想環境 `~/.mindmap/venv`（Windows は `%USERPROFILE%\.mindmap\venv`）を作り、PyYAML・jsonschema・mcp を入れる。
Ubuntu・Debian で `ensurepip is not available` と出たら、`sudo apt install python3-venv` を実行してから入れ直す。

## 反映

即時。

## 確認

#### 依存が揃っている

```bash
python3 {プラグインのフォルダ}/skills/mindmap/scripts/check_env.py
```

終了コード 0 で、出力の `venv_ok`・`python_ok` と全ての `packages[].ok` が `true`、`install` が `null` になる。
足りないものがあると終了コード 1 で、`install` に入れるコマンドが出る。
そのコマンドを実行してから、この確認をやり直す。

## 元に戻す

仮想環境のフォルダを消す。

```bash
rm -rf ~/.mindmap/venv
```

外すと、起動スクリプトは依存の不足を示して止まる。
ワークスペース（話し合いを記録したフォルダ）は消えずに残る。
