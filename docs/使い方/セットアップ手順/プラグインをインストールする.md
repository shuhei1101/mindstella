# プラグインをインストールする

mindstella を初めて使うときに実行する。

## 前提

Claude Code 2.1.287 以上が入っている。

## 手順

### マーケットプレイスを登録する

```bash
claude plugin marketplace add shuhei1101/mindstella
```

登録しないと、次のインストールで `mindstella@mindstella` が見つからない。

### プラグインをインストールする

```bash
claude plugin install mindstella@mindstella
```

`@` の後ろを省くと、同じ名前のプラグインを持つ別のマーケットプレイスから入ることがある。

### 常駐サーバーを起動する

インストールした後、[常駐サーバーを起動する](./常駐サーバーを起動する.md)を実行する。
mindstella のツールは、常駐サーバーが待ち受けているときだけ使える。

## 反映

`/reload`（起動中の Claude Code のセッションで `/reload-plugins` を実行する）。

## 確認

#### マーケットプレイスが登録されている

```bash
claude plugin marketplace list
```

`mindstella` が出る。

#### プラグインが有効になっている

```bash
claude plugin list
```

`mindstella@mindstella` が有効で出る。

## 元に戻す

インストールを戻してから、マーケットプレイスの登録を外す。

```bash
claude plugin uninstall mindstella@mindstella
claude plugin marketplace remove mindstella
```

ワークスペース（話し合いを記録したフォルダ）は消えずに残る。
要らなければ手で消す。
