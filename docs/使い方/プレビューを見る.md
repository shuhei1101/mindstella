# プレビューを見る

話し合いの記録を、サーバーが配るプレビューをブラウザで開いて読み返す。
項目と設定は、画面から直して保存待ちに溜め、まとめて保存できる。
項目や選んだ箇所へのコメントもレビュー中に溜め、まとめて送れる。送ったコメントはスレッドになり、AI の返信をスレッドで読める。

## 前提

- [セットアップから始める](./話し合い/セットアップから始める.md)で作った、`.mindstella/config.yaml` があるワークスペース
- [起動スクリプトで立ち上げる](./セットアップ手順/起動スクリプトで立ち上げる.md)で立ち上げた Claude Code
- [動作環境](../リファレンス/動作環境.md#プレビュー)を満たすブラウザ

## 手順

### プレビューの URL を示してもらう

`session` にプレビューを頼む。
`session` が、サーバーが配るプレビューの URL（`http://127.0.0.1:{ポート}/mindstella.html`）を示す。ブラウザは自動では開かない。
ポートは、起動のたびに空いているものが選ばれる。`config.yaml` の `preview.port` で固定したときはそのポートになる。
示された URL は、ワークスペースの直下の `README.md` のプレビューの節にも書かれる。
スマートフォンなど端末の外から開くときは、[プレビューを外から見る](./セットアップ手順/プレビューを外から見る.md)。

### ブラウザで開く

示された URL をブラウザで開く。
開くと概要が出る。

ワークスペースの YAML が書き換わると、再読み込みの操作なしで画面に反映される。
Claude Code を閉じるとサーバーも止まり、開いたままの画面には「サーバーにつながりません（{日時} に読んだ記録）」が出て、前に読んだ記録のまま残る。
幅 900px 以下では、文言の代わりに印だけが出る。
読み返したいときは、起動スクリプトで立ち上げ直して、示された新しい URL で開く。

描画のライブラリと文字を、開いたときにネットから読む。
読み込めなかったライブラリがあると、それを使う箇所に名前が出る。

### 画面を移る

上のトップバーに、話し合いのタイトル・検索・変更履歴・表示の設定・絞り込み・保存待ち（溜めた編集があるときだけ）・コメント・ライトとダークの切り替えのボタンと、画面を移るタブの帯がある。
タブの帯で、概要・検討事項・タスク・調査・資料・用語集・メモ・会話ログを移る。タブには、アイコンと項目の件数が付く。
[表示の設定](#表示の設定を変える)で外した種類のタブは出ない。
ネットワークは、帯の右端から開く。
タブを移っても、開いていた詳細パネルは閉じない。
トップバーとタブの帯は、どの画面でもどこまで送っても見えたまま残る。
表・ボード・マップは帯の下の領域の中で縦・横に送れ、ページ全体は送らない。幅 720px 以下（マップは 900px 以下）では、帯の下の領域ごと送る。

URL のハッシュに、画面と開いている項目が入る。
同じ URL を開き直すと、同じ画面と項目が開く。
ブラウザの戻る・進むで、見てきた画面へ戻れる。

| 画面 | 見方 |
| --- | --- |
| 概要 | タイルで状況を見る |
| 検討事項 | ボード（既定）・マップ・表を切り替える |
| タスク | ボード（既定）・表を切り替える |
| 調査・用語集・メモ・会話ログ | 表で見る |
| 資料 | カード（既定）・ボード・表を切り替える |
| ネットワーク | 全種類の項目を星として 3D でつないで見る |

### 概要で状況を見る

題名の上に、設定の話し合いの概要（何についての話し合いかを 1 文で書いたもの）が出る。
概要を持たない設定では、行が出ない。

概要は、次のタイルを並べる。

| タイル | 中身 |
| --- | --- |
| 次に検討する項目 | 前提が全て決着した未決定の検討事項。タイルに収まるだけ並ぶ |
| ゴールまでの進捗 | ゴールのフェーズまでの決定済みの数・フェーズごとの棒・納品物のチェックリスト。ゴールが無いときは、見出しが「フェーズ別の進捗」になり、「ゴールは決まっていません」と、全フェーズの決定済みの数・フェーズごとの棒だけが出る（納品物は出ない） |
| 要見直し | 要見直しの検討事項 |
| 保留 | 保留の検討事項の名前 |
| 進行中のタスク | 進行中のタスク |
| カテゴリー別の進捗 | カテゴリーを行、フェーズを列にした表 |

項目を押すと、詳細パネルが開く。
「すべて表示」と、進捗のセルを押すと、その条件で絞った表を開く。ドロワーにその条件が選ばれ、絞り込みのボタンにバッジが付く。
納品物が 5 件を超えたときは、「すべて表示」で納品物の資料を開く。

### 絞り込みのドロワーで絞り込む

概要を除く、項目を並べる画面（検討事項・タスク・調査・用語集・メモ・会話ログ・資料・ネットワーク）で、同じ操作で絞り込める。
トップバーのコメントのボタンの隣にある「絞り込み」を押すと、見ている画面に重ねて左からドロワーが開く。
条件ごとに、値を件数つきのチェックボックスで選ぶ。
値の条件の上の「文字を含む」には、ID・タイトル・用語・意味など値を選ばない列の欄が並び、入れた文字を含む項目に絞る。大文字・小文字は区別しない。

| 画面 | 条件 |
| --- | --- |
| 検討事項 | 状態・タグ・対象・カテゴリー・フェーズ・影響度・着手可否 |
| タスク | 種類・状態・タグ・対象・カテゴリー・フェーズ |
| 資料 | 種類・状態・タグ・納品物・対象・カテゴリー・フェーズ |
| 調査 | タグ・確度 |
| 用語集・メモ・会話ログ | タグ |
| ネットワーク | 種類（項目の種類）・状態・タグ |

同じ条件の中で複数の値を選ぶと、どれかに合う項目を出す。条件どうしは、全てに合う項目を出す。
値を 1 つも選んでいない条件では、絞らない。
値の右の件数は、その条件以外の条件で絞った項目のうち、その値を持つ項目の数で、0 件になる値は薄く出るが選べる。
見出しの右には、何も選んでいなければ「{件数} 件」、選んでいれば「{件数} 件中 {合う件数} 件」が出る。
値を選んだ条件には「{件数} 件を選択」と「解除」が付き、下端の「すべて解除」で全ての条件を外せる。
選んだ条件は、ツールバーの下（ネットワークはキャンバスの上）にチップでも出て、× で 1 つずつ、「すべて解除」で全てを外せる。文字の条件のチップは「用語に「移し」を含む」の形で出る。

「絞り込み」のボタンには、値を 1 つ以上選んでいる条件の数がバッジで出る。選んだ値の数ではない。
状態で 4 つ、タグで 1 つ選んでいれば、バッジは 2 になる。何も選んでいなければ、バッジは出ない。
幅 1100px 以下では、ボタンの文字が隠れ、印とバッジだけが出る。

開いたときの条件は、画面で決まる。

- 検討事項は、マップ・ボード・表とも、状態で要見直し・未決定・未整理・保留を選んだ状態で開く
- ほかの画面は、何も選んでいない状態で開く
- 概要のタイルの「すべて表示」や進捗のセルから開いたときは、URL のハッシュの `f.{列}` の条件だけが選ばれた状態で開く

サーバーの配信で開いたときは、選んだ条件が画面ごとにこの端末に残り、読み込み直しても開き直しても同じ条件で開く。
残した条件は上の画面ごとの条件より先に当たるが、`f.{列}` で開いたときはその条件で開き、残した条件は変わらない。
残した条件は、[表示の設定](#表示の設定を変える)の「既定に戻す」で外れる。配る書き出しでは残らない。

マップ・ボード・カード・表を切り替えても、選んだ条件は保たれる。
ボードでは、状態の条件から外した状態の列も残り、列の中に「状態の条件で外しています。」と出る。
条件に合う項目が無いときは、画面に、条件のせいで空になっている旨が出る。

閉じるには、ドロワーの見出しの ×・下端の「{件数} 件を表示」・Esc のどれかを使う。トップバーの「絞り込み」をもう一度押しても閉じる。外側を押しても閉じない。
ドロワーに重ならない右側は、見えたまま操作できる。
コメントの一覧とは同時に開かず、どちらかを開くと他方が閉じる。
幅 900px 以下では、ドロワーは画面の幅いっぱいに出る。
詳細パネルを開いていても、ドロワーは詳細パネルの前に出る。閉じると、開く前の詳細パネルが見える。

### 検討事項のマップを辿る

マップは、対象・カテゴリー・フェーズ・検討事項を木で描く。
検討事項の画面はボードで開くので、表示形式の切り替えでマップを選ぶ。
次の操作ができる。

- 絞り込みのドロワーで状態・タグなどを選んで、マップに描く検討事項を絞る。既定では要見直し・未決定・未整理・保留が選ばれ、決定済み・対象外・取り下げが隠れている。
  条件に合う検討事項が無いと、「表示する検討事項はありません。」と出る
- キーワードを入れて、タイトルに含む項目を黄色で強調する。一致した項目がある状態の値に、一致した件数がドロワーで付く。非表示の状態の項目も数える
- 項目を押して、根までの枝と前提・後続の線を強調する。ほかは薄くなり、詳細パネルが開く
- 詳細を開いている節をもう一度押して、ロックする。押したときの動きは[ネットワークと同じ](#起点をロックする)で、鍵は節の右上に出る。ロックはネットワークとは別に持ち、`L` キーはネットワークだけで効く
- 余白を 1 回押して、選びを外す。詳細パネルが閉じ、何も選んでいない全体の表示に戻る。マップの位置と、拡大・縮小で決めた倍率は変わらない。「全体を表示」のときは、広がった枠に合わせて倍率が変わる
- ホイールを回して、マウスの位置を中心に拡大・縮小する。40%〜150% の範囲で止まる
- 背景をドラッグして動かす。拡大・縮小・全体を表示のボタンは、マップの枠の外にある

幅 900px 以下では、マップは字下げした縦の一覧になる。

### 表で絞り込む

どの表でも、同じ操作ができる。

| 操作 | やり方 |
| --- | --- |
| 並べ替える | 列の見出しを押す。昇順 → 降順 → 解除の順に変わる |
| 絞り込む | 絞り込みのボタンを押し、ドロワーで値を選ぶか、列の文字を入れる（[絞り込みのドロワーで絞り込む](#絞り込みのドロワーで絞り込む)）。かかっている条件は表の上にチップで出て、1 つずつ・全部を解除できる |
| 列を固定する | 列の見出しのピンのボタンを押す。左端から押した列までが、横に送っても固定される。固定中の列をもう一度押すと外れる |
| 表示する列を選ぶ | 表の右上の「列の表示」のボタンを押し、列を付け外しする。タイトルの列は外せない |
| 初期設定に戻す | 「列の表示」のボタンから、列・並べ替え・固定を初期設定に戻す |

操作しても、スクロールの位置は変わらない。
表で絞り込んだ条件は保存されない。概要から絞って開いたときだけ、ドロワーでその条件が選ばれ、チップが付いた状態で開く。
列の表示で選んだ列は、この端末に残る。表示の設定の「既定に戻す」で外れる。

### 資料を読む

資料のカードは、納品物を先頭に、納品物の印付きで並ぶ。
カードと表に、資料の状態（下書き・確認中・完成）が出る。
カード・ボードのカードの種類の右と、表の「形式」の列に、本文の形式の札が付く。HTML の資料は `HTML`、Markdown の資料は `MD`。表の「形式」の列では、形式で絞れる。
カード・ボード・表のどれでも、絞り込みのドロワーで、納品物・状態・種類・対象・カテゴリー・フェーズ・タグで絞れる。
ボードは、資料を状態（下書き・確認中・完成）の列に並べる。
資料が 0 件の列も出る。
ボードの列の中も、納品物を先頭に並ぶ。

### 詳細を読む

項目を押すと、詳細パネルが右から出る。
幅 1100px 以上（マップは 901px 以上）では、本文を寄せて並べる。それより狭いと、本文に重なる。
どの種類の項目も、同じ既定の幅（640px）で開く。
幅 901px 以上では、詳細パネルの左端をドラッグして幅を変えられる。
変えた幅は、そのタブで詳細パネルを開き直しても、別の項目を開いても、読み込み直しても保たれる。
幅 900px 以下では画面の幅いっぱいに出て、ドラッグの操作は出ない。

詳細パネルは、次を出す。

- 項目の ID・タイトル・状態。納品物の資料にはタイトルの右に印が付く。資料には、種類と ID の右に本文の形式の札（`HTML` / `MD`）も付く
  本文を送って先頭のタイトルが見えなくなると、見出しの ID の右にもタイトルが出る。先頭へ戻すと隠れる
  長いタイトルは見出しで 1 行に省略され、乗せると全文が出る
- 検討事項の背景（`lead`。何を決めるか）。タイトルの下に出す
- 検討事項の案。カードの縦並びで、見出しに記号と内容、その下にメリット・デメリット・備考・理由を出す。採用した案に「採用」、不採用の案に「不採用」が付き、どちらでもない案には何も付かない。
  AI が推す案のカードには、見出しの右に星と「推奨」のバッジが付く。採用した案があるときは、推奨のバッジを出さない
- 検討事項の採用した案と理由。案の後に、決定内容（`answer`）と理由（`reason`）を、値のあるものだけ出す
- 本文。Markdown と mermaid の図を描く。本文の中の用語・項目の ID・見出しから移れる（[本文のリンクで移る](#本文のリンクで移る)）。表とセクションは、[本文の表とセクションを読む](#本文の表とセクションを読む)の操作で読みやすくできる
- HTML の資料の本文。本文の代わりに、HTML を描いた結果を枠の中に出す。本文のスクリプトは動かず、本文の CSS は画面へ漏れない。用語の印・項目の ID・見出しのリンクは付かない。本文の中の `http`・`https` のリンクを押すと、本文を残したまま、リンク先が新しいタブで開く。`mailto` のリンクはメールのアプリで開く。`#` で始まるリンクは、本文の中のその `id` の場所まで送る。ほかのリンク（相対の URL など）は、押しても移らない。Markdown の本文の中の言語指定 `html` のコードブロックも、コードではなく描いた結果で出る
- 前提・後続の項目・関連タスク・経緯・関連・参照元。押すとその項目へ移る
- その項目へのレビュー中のコメント。各行の右上の印のボタンで、その場で修正する・消す・元に戻す（[コメントをレビュー中に溜める](#コメントをレビュー中に溜める)）。チェックとまとめて送るはコメントの一覧のレビュー中の書き込みの画面で行う
- コメントの入力欄と「レビューに追加」のボタン。下端に留まり、本文だけがスクロールする

背景・決定内容・理由・案の各値のほか、タスクの理由、調査の問いと結論、用語の意味、メモの内容も、本文と同じく Markdown として描く。
本文と違い、値の段落の中の 1 つの改行も改行として出す。
資料・調査は、説明とエイリアスを持っていれば「説明」「エイリアス」の節に出す。

項目を移ると履歴に積まれ、見出しの「← →」とブラウザの戻る・進むで、見てきた項目を行き来できる。
閉じるには、閉じるボタンか Esc を使う。
検討事項のマップでは、余白を押しても閉じる。

「全画面表示」を押すと、画面の中央に大きく出る。本文は全画面の幅いっぱいに広がり、全画面の中を送っても後ろの画面は動かない。
全画面でも、本文を送ると見出しに ID とタイトルが出る。
全画面の間は、ボタンが縮小の印の「元の大きさに戻す」に替わる。これを押すか、外側を押すと元の大きさに戻る。

#### 本文の表とセクションを読む

Markdown の本文には、詳細パネル・詳細の全画面・本文の差分（インライン・左右に並べる）のどれでも、同じスタイルが当たる。配る書き出しも同じ。
本文に特別な書き方は要らず、普通の Markdown のまま見せ方が変わる。HTML の資料の本文には当たらない。

表は、列ごとにセルの最大の文字数を数えて（全角を 1、半角を 0.5 と数える）、幅と折り返しを決める。

| 列 | 折り返し |
| --- | --- |
| 8 文字以下 | 折り返さない |
| 25 文字以上 | 一定の幅で折り返す |
| その間 | 文節の区切りでだけ折り返す |

表が本文の幅に収まらないときは、表の中だけで横に送れ、本文の区画は横に送らない。横に送れる側の端は、薄くなって続きがあることを示す。表にフォーカスを置くと、矢印キーでも送れる。

| 操作 | やり方 |
| --- | --- |
| 列を固定する | 表の見出しのセルに乗せると出る固定のボタン（タッチの端末では常に出る）を押す。押した列から左が、表を横に送っても見えたまま残る。もう一度押すと外れる。押すまでは固定されない |
| 見出しの行を残す | 本文を縦に送ると、表の見出しの行が本文の区画の上端に残る |
| 行を見分ける | 「表のしま模様」を付けると、表の行が 1 行おきに塗り分けられる。本文の差分では、差分の印の行は差分の色のままになる |
| セクションを畳む・開く | 見出しの頭の矢印を押すと、その見出しの下（次の同じか上の階層の見出しまで）が畳まれる。もう一度押すと開く |

セクションの矢印は、本文で使っている上位 2 つの階層の見出しだけに付き、開いた状態で描かれる。
見出しの文言は、これまでどおり選んでコメントできる。矢印を押しても URL は変わらない。
畳んだ中身は、ページ内の検索・本文のリンク・URL のハッシュで飛んだときに開く。
本文の差分には矢印が付かず、畳めない。

幅 720px 以下では、列の固定と固定のボタンは出ない。見出しの行を残す動きは変わらない。
4 つの切り替えは、[表示の設定](#表示の設定を変える)で付け外しできる。

コードブロックには、言語の札とコピーのボタンが付く。
GitHub の Alert の記法（`> [!NOTE]` など）は、囲みで出る。囲みの見出しは、補足・ヒント・重要・警告・注意。

#### 本文のリンクで移る

| 本文の中 | 見え方と操作 |
| --- | --- |
| 用語集の用語（タイトルと別名） | 文字の色は変わらず、点線の下線が付く。乗せるかフォーカスすると、用語の意味が出る。押すとその用語の詳細へ移る。同じ語に用語が 2 つ以上一致したときは、資料・調査のエイリアスと同じく「用語」の見出しの下に並び、タイトルを押してその詳細へ移る。印を押すとツールチップが残り、外を押すか Esc で閉じる |
| 資料・調査のエイリアス | 用語と同じ点線の下線が付く。乗せるかフォーカスすると、印の上のツールチップに、その語に一致した用語・資料・調査が「用語」「資料」「調査」の見出しごとに並ぶ。資料・調査はタイトル・ID・説明が出て、タイトルを押すとその詳細へ移る。押すとツールチップが残り、外を押すか Esc で閉じる。項目が多いときはツールチップの中を送って読む |
| 記録にある項目の ID（`D-95` など） | 等幅の色の文字と下線のリンクになる。押すとその項目の詳細へ移る。記録に無い ID はリンクにならない |
| 見出し | 乗せるかフォーカスすると、右に # が出る。押すとその見出しまで送り、URL がその見出しを指す。この URL を開くと、その見出しまで送った詳細が開く |

コードブロックと図の中には、用語の印も ID のリンクも付かない。見出しの中の用語にも印は付かない。
本文の `[文言](#見出し)` のリンクを押すと、その見出しまで送る。
本文の `[文言](#diff=V-2)` のリンクを押すと、開いている項目のまま、そのまとまりの差分の表示に切り替わる（変更履歴でそのまとまりを選んだときと同じ）。
記録に無いまとまりと、`since`・`pending` を指すリンクは、押しても何も変わらない。

### コメントをレビュー中に溜める

詳細パネルと全画面の下端の入力欄「{ID} へのコメント」に書いて、「レビューに追加」を押す。入力欄で Ctrl+Enter（macOS は Cmd+Enter）を押しても追加できる。
追加したコメントは、送らずにレビュー中に溜まり、トップバーのコメントのボタンの件数が増える。
溜めた項目には、吹き出しとその項目へのレビュー中のコメントの件数の印が出る。
項目へのコメントは、送ると、その項目へ向けた新しいスレッドの最初の書き込みになる（[コメントの一覧からスレッドを読む](#コメントの一覧からスレッドを読む)）。

| 画面 | 印の置き場所 |
| --- | --- |
| ボード・カード・マップ | メタ情報の並びの右端 |
| 字下げの一覧・表 | タイトルの右（差分の印の後ろ） |
| ネットワーク | 名前が読める距離まで寄ったときだけ、名前の右（鍵が出ているときは鍵の右） |

件数が 100 以上のときは「99+」と出る。
コメントを消す・戻す・送ると、画面を開き直さずに件数が変わる。送ったコメントの分だけ件数が減り、レビュー中のコメントが無くなった項目からは印が消える。
本文は、前後の空白を除いて 1 文字以上 10000 文字以下。

| 結果 | 画面の出方 |
| --- | --- |
| 溜まった | 入力欄が空になり、「レビューに追加しました（レビュー中 {件数} 件）。」が出る |
| 本文が空 | 入力欄の枠が赤くなり、「コメントを入れてから追加してください。」が出る。入力欄の中身は残る |
| サーバーが理由を返した | 入力欄の中身が残り、「レビューに追加できませんでした。{理由}」が出る |
| サーバーにつながらない | 入力欄の中身が残り、起動スクリプトで立ち上げ直して新しい URL で開くよう出る。「本文を写す」を押すと、入力欄の中身をクリップボードに写せる |

溜めたコメントは、詳細パネルと全画面の「レビュー中のコメント」の各行の右上にある鉛筆とごみ箱の印のボタンで、コメントの一覧を開かずに直せる。

| 操作 | やり方 |
| --- | --- |
| 修正 | 行の鉛筆の印を押し、本文をその場で直して「修正」を押す。「キャンセル」か Esc で捨てる。書き換えられるのは、コメントの一覧のスレッドの画面・レビュー中の書き込みの画面と合わせて 1 行だけで、別の行の鉛筆の印を押すと前の書き換えを捨てる |
| 消す | 行のごみ箱の印を押す。確認は出ず、行が「コメントを削除しました。」と「元に戻す」に変わる |
| 元に戻す | 消した行の「元に戻す」を押す。別の項目へ移るか、パネルを閉じるまで押せる |

| 修正の結果 | 画面の出方 |
| --- | --- |
| 直せた | 行が直した本文に戻る |
| 本文が空 | 入力欄の枠が赤くなり、「コメントを入れてから直してください。」が出る。入力欄の中身は残る |
| サーバーが理由を返した | 入力欄の中身が残り、その理由が出る |
| サーバーにつながらない | 入力欄の中身が残り、「サーバーが止まっています。立ち上げ直してから直してください。」が出る |

書きかけとレビュー中のコメントは、ワークスペースの `drafts.yaml`・`comments.yaml` に残る。
パネルを閉じても、再読み込みしても、起動スクリプトで立ち上げ直しても消えない。
配る書き出しには、入力欄も印も出ない。

### 選んだ箇所へコメントする

詳細パネルと全画面で、本文の文章か項目の値（タイトル・案の中身・長所・短所・理由など）を選ぶ。
選び終えると、選んだ範囲の始まりの上に、コメントのアイコンだけの丸いボタンが出る（上に収まらないときは、選んだ範囲の終わりの下に出る）。
ボタンに乗せるかフォーカスすると、「選んだ箇所にコメント」の名前が出る。
ボタンを押すと、下端の入力欄に、選んだ箇所（「本文 {行} 行目」かキーの名前）と選んだ文の引用が添えられる。
コメントを書いて「レビューに追加」を押すと、その箇所を指すコメントとして溜まる。
添えた箇所は、× を押すと外れ、項目へのコメントに戻る。
HTML の資料も、描いた結果の文を選ぶと同じボタンが出る。箇所は「本文 {行} 行目」で、HTML の原文の行になる。

本文と値の外（節の見出し・関係する項目・図・レビュー中のコメント・入力欄）を選んだときは、ボタンは出ない。
ボタンは Esc で閉じる。

### コメントの一覧からスレッドを読む

トップバーのコメントのボタンを押すと、見ている画面に重ねて左からコメントの一覧が開く。
一覧はスレッドの一覧で、1 行が 1 つのスレッドになる。
ボタンには、レビュー中の書き込みの件数が出る。スマホの幅では、印と件数だけが出る。
オープンのスレッドに、まだ開いていない AI の書き込みがあるときは、ボタンの吹き出しの印の右上に点が重なる。件数はそのまま出る。
幅 900px 以下では、一覧は画面の幅いっぱいに出る。
詳細パネルを開いたままトップバーから開くと、一覧は詳細パネルの前に出る。一覧の行から詳細パネルを開くと、詳細パネルが一覧の前に出る。

| 操作 | やり方 |
| --- | --- |
| 状態で絞る | 「オープン」「クローズ」「すべて」を押す。件数が添えられる。開いたときはオープンで、パネルを開いている間は保たれる |
| タグで絞る | スレッドの行のタグを押す。もう一度押すか、絞り込みの × を押すと外れる。タグは AI が付け、画面では付け外しできない |
| スレッドを読む | 行を押す。行には要約と最後の書き手が出る |
| 新しいスレッドを立てる | 下端の「新しいスレッド」を押して書く。項目を指さないスレッドの最初の書き込みとして、レビュー中に溜まる |
| 閉じる | 閉じるボタン・Esc・コメントのボタンのどれかを押す。幅 901px 以上で詳細パネルを開いているときの Esc は、詳細パネルを先に閉じる。幅 900px 以下の Esc は、前に出ている側から閉じる |

まだ送っていない新しいスレッドは、一覧の先頭に「レビュー中」の札で並ぶ。
返信をレビュー中に溜めたスレッドの行には、それと分かる印が出る。
AI の返信と AI が立てたスレッドは、画面を開いたまま一覧に現れる。
まだ開いていない AI の書き込みを持つスレッドの行には、2 行目の先頭に塗りつぶしの「● 未読」の札が出る。クローズのスレッドの行にも出る。
スレッドを開くと、そのスレッドは既読になり、札と点が消える。開いているスレッドに AI の返信が届いたときも、返信が描かれた後に既読になる。

スレッドの画面では、書き込みと、クローズ・オープンへの戻しの記録が、書いた順に並ぶ。
向けた項目を押すと、一覧を開いたまま右にその項目の詳細パネルが開き、箇所があれば本文か値のその箇所を色の地で示す。
書き込みの中の `[文言](#diff=V-2)` は文言だけのリンクになり、押すとスレッドを開いたまま、そのまとまりの差分の表示に切り替わる。レビュー中の書き込みの画面の行でも同じ。
記録に無いまとまりと、`since`・`pending` を指すものは、書いた文字のまま出る。
「一覧へ戻る」か、入力欄にフォーカスが無いときの Esc で一覧へ戻る。

### スレッドに返信してまとめて送る

スレッドの画面の下端の入力欄に書いて、「レビューに追加」を押す。Ctrl+Enter（macOS は Cmd+Enter）でも追加できる。
返信は送らずにレビュー中に溜まり、スレッドの末尾にレビュー中の印つきで並ぶ。
書きかけは、スレッドごとに保たれ、一覧へ戻る・別のスレッドを開く・パネルを閉じる・読み込み直すのどれでも消えない。

新しいスレッドと返信は、見出しの帯の「レビュー中（{件数}）」で開くレビュー中の書き込みの画面でまとめて確かめる。

| 操作 | やり方 |
| --- | --- |
| 送るものを選ぶ | 行のチェックを付け外しする。「すべて選ぶ」の箱で、まとめて付け外しする。開いたときと、新しく溜めた書き込みは、チェックした状態で入る |
| 元のスレッドや項目へ移る | 返信の行は返信先のスレッドを、新しいスレッドの行は向けた項目を押す |
| 長い書き込みを読む | 5 行を超える書き込みは 5 行までで畳まれている。「続きを読む」で全文を開き、「折りたたむ」で畳み直す。開いた行は、修正しても開いたまま |
| 修正 | 行の鉛筆の印を押し、本文をその場で直して「修正」を押す。「キャンセル」か Esc で捨てる |
| 消す | 行のごみ箱の印を押す。確認は出ず、行が「コメントを削除しました。」と「元に戻す」に変わる。「元に戻す」は、パネルを閉じるかまとめて送るまで押せる |
| 戻る | 「戻る」か、入力欄にフォーカスが無いときの Esc を押す |

「まとめて送る（{件数} 件）」を押すと、チェックした書き込みだけが送られる。
チェックしなかった書き込みは、レビュー中に残る。
新しいスレッドの書き込みは 1 件ごとに新しいスレッドの最初の書き込みになり、返信は向けたスレッドの末尾に足される。

| 結果 | 画面の出方 |
| --- | --- |
| 送れて、Claude Code に入力できた | 送った行が外れ、コメントのボタンの件数が減る。「{件数} 件を送り、Claude Code に入力しました（{HH:mm}）。」が出る |
| 送れたが、Claude Code に入力できなかった | 送った行の外れ方と件数の減り方は同じで、注意の印と「{件数} 件を送りましたが、Claude Code には入力できませんでした（{HH:mm}）。送った内容は保存されていて、次に話し合いを始めたときに取り込まれます。」が出る |
| チェックが 0 件 | 「送る書き込みにチェックを付けてください。」が出る |
| 箇所が合わない | どれも送らない。本文が書き換わるなどして箇所が合わない書き込みの行に理由が出て、枠が赤くなる。「箇所を外す」で項目へのコメントにするか、消してから送り直す。項目が無くなった書き込みは、消すだけができる |
| クローズのスレッドへの返信がある | どれも送らない。その行はチェックできず、「クローズのスレッドへの返信は送れません。オープンに戻すと送れます。」が出る。「スレッドを開く」から「オープンに戻す」で戻してから送る |
| サーバーが理由を返した | 「送れませんでした。{理由}」が出る |
| サーバーにつながらない | 「送れませんでした。サーバーが止まっています。立ち上げ直してから送ってください。」が出る |

起動スクリプトで立てた Claude Code には、送った直後に「[mindstella] ユーザーからのコメントが {件数} 件届きました。読み直してください。」の 1 行が入力される。
`session` が、取り込んでいない書き込みを持つスレッドを読んで記録し、返信するか、返信せずにクローズにする。
tmux の外で立てた Claude Code や、入力が会話に入らなかったときは、入力できなかったと出る。
入力欄に打ちかけがあるときや選択の表示（ツールの許可の確認など）が出ているときも、入力は止まらずに貼られる。
打ちかけとつながったり、選択の表示で入力が失われたりしたら、tmux のセッションを見て直す。

送ったコメントは、ワークスペースの `threads.yaml` に残り、サーバーを止めても消えない。
Claude Code に入力できなかった書き込みは、次に `session` を呼んだときの最初に取り込まれる（[続きを再開する](./話し合い/続きを再開する.md#話し合いへ進む)）。
配る書き出しには、コメントのボタン・一覧・選んだ箇所のコメントのボタンは出ない。

### スレッドをクローズにする

スレッドの画面の見出しの「クローズにする」を押すと、見出しの下に理由の入力（任意）が出る。
「クローズにする」で確定すると、状態と理由が 1 回で書かれる。確認のモーダルは出ない。「キャンセル」か Esc で閉じられる。
クローズにしたスレッドは、状態の絞り込みがオープンのときは、一覧へ戻ると外れる。
クローズのスレッドには返信の入力が出ず、「オープンに戻す」で戻してから返信する。戻すときも理由を書ける。

クローズにしても、返信を送ってからクローズにしたときのその返信は、AI に届く。
AI も、返信が要らず話が済んだスレッドをクローズにし、クローズのスレッドに返信が要るときは理由つきでオープンに戻す。
クローズとオープンへの戻しは、誰が・いつ・なぜ行ったかが、スレッドの書き込みの間に並ぶ。


図の文字は、拡大表示を開かなくても選んでコピーできる（図を押しても拡大しない）。
図には、次のボタンがある。

| ボタン | 動き |
| --- | --- |
| 拡大表示 | 図を大きく開く。ホイールで拡大・縮小し、背景のドラッグで動かす。図の文字は選んでコピーできる |
| Raw | 図と mermaid の原文を切り替える |
| コピー | mermaid の原文をクリップボードに写す |

### 前回からの差分を読む

トップバーの「変更履歴」を押すと、差分の表示で比べる時点を選ぶモーダルが開く。
時点は、次の行が上から並ぶ。

| 行 | 中身 |
| --- | --- |
| 差分を出さない（今の内容） | 差分の表示をやめる。既定はこの行で、今の内容だけを読む |
| まだまとめていない変更 | AI がまだ区切っていない書き換え。あるときだけ出る |
| 前回開いてから | 前回開いた後に `commit` した書き換えのまとまりと、まだまとめていない変更 |
| 書き換えのまとまり | `session` がステップを終えるたびに付ける一言の説明と日時、変わった項目の件数。新しい順 |

行を押すとモーダルが閉じ、どの画面も、選んだ時点の差分の表示になる。
選んだ時点は、URL のハッシュ（`diff`）とこの端末に残り、画面を移っても読み込み直しても保たれる。
アドレス欄の URL を人に渡すと、端末の保存領域を持たないブラウザでも、同じ時点の差分の表示で開く。
記録に無いまとまりを指す URL と、まだまとめていない変更が空のときの `pending` を指す URL は、差分を出さずに開く。
「前回開いてから」と「まだまとめていない変更」は、開く端末や時刻で中身が変わる。
開いたまま記録が書き換わっても、同じ時点の差分の表示のまま描き直される。

差分の表示の間は、トップバーの「変更履歴」の右に、選んだ時点の札が出る。
抜けるには、札の × を押すか、モーダルの「差分を出さない（今の内容）」を押す。

選んだ時点で足された項目には新規（+）、変わった項目には変更（●）の印が付く。
表・ボード・カード・マップ・概要のタイルでは印だけで、詳細パネルでは題の横に「新規」の札が付く。
差分のある項目を持つタブには、件数を残したまま、右上に点が付く。

選んだ時点で消した項目は、その種類の画面の一覧（マップ・ボード・カード・表）の上の「消した項目」の帯に、消した印・ID・消したときのタイトルで並ぶ。
消した項目は中身が残らないので、帯の項目は押せず、詳細パネルも開かない。
選んだ時点で消した項目だけを持つ種類のタブにも点が付く。タブの件数は、今ある項目の数のまま変わらない。
モーダルの時点の件数には、その時点で消した項目も入る。
「前回開いてから」のように複数のまとまりを合わせた範囲で、足した後に消した項目は、新規の印が付かず、消した項目の帯にだけ出る。

取り下げた調査・資料・用語集・メモ・会話ログは、差分の表示によらず、表・カード・ボード・詳細パネルで、タイトルの右に枠付きの「取り下げ」の札が付き、行・カードの文字が薄くなる。
詳細パネルには、見出し「取り下げた理由」の節に理由が出る。
選んだ時点で取り下げた項目は、変更（●）の印と取り下げの札で読め、「取り下げた理由」は前の値（なし）と今の値が並ぶ。

詳細パネルと資料では、選んだ時点の前後の差分を読める。

| 見るもの | 差分の出方 |
| --- | --- |
| キー（状態・答え・案 など） | 前の値は消した色の面と取り消し線、今の値は足した色の面と下線で並ぶ。状態のキーだけは面を塗らず、取り消し線・下線と矢印で示す。前に無かったキーは、今の値だけが足した印で出る。前の値と今の値の中の改行は、改行として出る。題と、背景・答え・理由・案などの文の値は、本文と同じく変わった語だけに、値の面より濃い赤・濃い緑の面が付く |
| 本文 | Markdown として描いたまま、足した部分に足した色の面と +、消した部分に消した色の面と −・取り消し線が付く。変えていない部分には印が付かない。書き換えた行は、消した方と足した方の中で変わった語だけに、行の面より濃い赤・濃い緑の面が付く |
| HTML の本文 | 描いた結果の上で、足した要素に実線、変わった要素に破線の枠と面の色が付く。「描いた結果」と「原文の差分」で切り替えられ、原文の差分では足した行（+）と消した行（−）が出る。消しただけの箇所は描いた結果に出ないため、原文の差分で見るよう案内が出る。選んだ時点の本文が Markdown のとき（形式を替えた）は、原文の差分だけが出る |
| 図 | flowchart・sequenceDiagram・classDiagram・erDiagram・stateDiagram-v2 は、足した・変えたノードと辺に色が付き、図の下に凡例と「消したもの」の札が並ぶ。それ以外の種類は、変わった図の枠に色が付き、Raw で見るよう案内が出る |
| 図の Raw | 記法の行ごとに、足した行（+）と消した行（−）が出る。図の拡大の Raw でも同じ。行の差分を打ち切ったときは、今の記法が差分なしで出る。書き換えた行は、本文と同じく変わった語だけに濃い面が付く |

本文の差分は、インラインと、選んだ時点の本文を左・今の本文を右に並べる表示で切り替えて読める。
切り替えの「インライン」「左右に並べる」は、詳細パネルと詳細の全画面の本文の差分の頭に出る。選んだ時点から本文が変わっていない項目には出ない。
既定はインラインで、「左右に並べる」では左の列に消した印、右の列に足した印が付き、変えていない部分は左右の同じ高さに並ぶ。
HTML の本文では、切り替えを「描いた結果」「原文の差分」の組の前に別の組で置き、描いた結果と原文の差分のどちらも左右に並べられる。
本文の幅が 560px に満たないとき（資料以外の詳細パネル・狭い画面幅）は、切り替えが出ず、左右に並べる表示を選んでいてもインラインで出る。
選んだ並べ方はこの端末の個人の上書きとして残り、項目をまたいで保たれる。[表示の設定](#表示の設定を変える)の「この端末で変えている項目」に並び、「既定に戻す」でインラインに戻る。

詳細パネルと詳細の全画面では、変わった箇所を[差分のミニマップ](#差分のミニマップで変わった箇所へ飛ぶ)でも見渡せる。

「前回開いてから」の範囲の始まりは、ワークスペースに残る前回開いた時点（[前回開いた日時](../リファレンス/ワークスペースの書式.md#前回開いた日時)）で、同じワークスペースを開いた全てのブラウザで共有する。
範囲は開いた時点の通し番号で決まり、日時は範囲の始まりの表示（`{日時} より後`）にだけ使う。
タブを開いたときの値をそのタブで使い、同じタブで読み込み直しても変えない。
前回開いた時点が無いときと、ワークスペースを戻して前回の通し番号が今より先にあるときは、そのタブを開いた時点からになる。

項目が持つ変更履歴は、設定の `history_limit` の回数分（既定は 5）までで、それより古い書き換えとは比べられない（[設定](../リファレンス/ワークスペースの書式.md#設定)）。
差分を出せないときは、次のようになる。

| 状況 | 画面の出方 |
| --- | --- |
| 選んだ時点の範囲の中の変更履歴が、保持する回数を超えて消えている（範囲の中で同じ項目を回数より多く書き換えたときを含む） | 項目に印だけが付き、詳細パネルの本文の頭に「このまとまりの前後を組み立てられません。保持する回数を超えた古い変更履歴は消えています。今の内容を出しています。」が出る |
| 書き換えの後に、本文のファイルが直接書き換えられている | 本文の頭に「本文の差分を出せません。書き換えの後に、本文のファイルが直接書き換えられています。今の本文を出しています。」が出る。キーの差分は出る |
| 書き換えが大きく、本文の差分を計算しきれない | 本文の頭に「本文の差分を出せません。書き換えが大きく、差分を計算しきれませんでした。今の本文を出しています。」が出る。キーの差分は出る |
| 差分の計算に使うライブラリ jsdiff を読み込めない | 本文の頭に「本文と図の差分を表示できません。読み込めなかったライブラリ: jsdiff」と「通信を確認して、ページを再読み込みしてください。」が出て、本文・図・図の Raw は差分なしで出る。キーの差分は出る |
| `history_limit` が 0 | 変更履歴を持たないので、差分が出ない |
| 変更履歴を持たない既存のワークスペース | そのまま読めて、差分が出ないだけ |

配る書き出しでも、同じ差分の表示を使える。
「前回開いてから」の範囲の始まりは、前回開いた時点（日時と通し番号）をその端末に持ち、同じ決め方で範囲を決める。

#### 差分のミニマップで変わった箇所へ飛ぶ

詳細パネルと詳細の全画面で、差分の表示の間、本文のスクロールバーの外側に、変わった箇所の印を並べた縦の帯が出る。
帯は本文の全体を縮めた形で、印は本文の中のその箇所と同じ高さに並ぶ。
見えている範囲は、帯の中の面で示す。
本文に変わった箇所の印が 1 つも無いときと、[表示の設定](#表示の設定を変える)で外したときは、帯が出ない。

印は、色だけでなく形でも見分けられる。

| 印 | 形 |
| --- | --- |
| 足した | 塗りつぶし |
| 消した | 中抜き |
| 変わった | 斜めの縞 |

前に無かったキーは足した、値が変わったキーは変わったの印になる。
続く同じ種類の箇所は 1 つにまとまり、消した塊のすぐ後ろの足した塊は、変わった 1 つになる。

| 操作 | 動き |
| --- | --- |
| 印を押す | その箇所が本文の上から 4 分の 1 の位置に来るまで本文を送り、その箇所を 1.6 秒だけ枠で示す。URL のハッシュは変わらない |
| 印の無い所を押す | 押した位置に見えている範囲の中央が来るまで、本文をすぐに送る。スマートフォンなどのタッチの端末でも同じ |
| PC で押したまま上下に動かす | スクロールバーと同じように本文が送られる。面の中を押したときはつかんだ位置を保ち、面の外を押したときは面の中央が押した所に合う。押した位置から 5px 動くまでは押しただけとして扱い、動かした後に離しても印へは飛ばない |

### ネットワークを辿る

ネットワークは、全種類の項目を星として、依存・関連・根拠・進めるタスクの関連でつないで 3D で描く。
次の操作ができる。

- 上下左右にドラッグして回す。操作が止まってしばらくすると、ゆっくり自動で回る
- ホイールで、マウスの位置へ寄る。背景をダブルクリックすると、元の位置に戻る
- 玉にカーソルを乗せると、つながる玉が少し寄ってきて、ほかは薄くなる
- 玉を押すと、そこへ寄って詳細パネルが開き、つながる線の上を小さな玉が流れる
- 絞り込みのドロワーで種類・状態・タグを選んで、描く玉を絞る。状態を持たない種類の玉は、状態の値を選ぶと外れる。
  条件に合う項目が無いと、「表示する項目はありません。」と出る
- キャンバスの右上のドロップダウンで、見た目を選ぶ
- 詳細パネルで項目を開いたままタブの帯のネットワークを押すと、その項目を選んだネットワークが開く

扱える項目は 1000 件まで。
描画の速さの条件は、[動作環境](../リファレンス/動作環境.md#プレビュー)にある。

#### 見た目を選ぶ

見た目は、グロウ・星の光・星図・深宇宙・星屑の 5 つから 1 つ選ぶ。
ワークスペースの既定の見た目には「（既定）」が付く。
選んだ見た目は、この端末の個人の上書きとして残り、[表示の設定](#表示の設定を変える)の「この端末で変えている項目」に並ぶ。
地・星・線は、見た目ごとにライト（昼）とダーク（夜）で描き分ける。
星のまたたきと、選んだ星から広がる輪は、ゆっくり自動で動く。
動きを減らす設定では、自動で回る動き・星のまたたき・広がる輪・線を流れる光が止まり、選んだ項目につながる線は強調した線で出る。

#### 状態の印を見る

項目を選んだとき・ロックしたときだけ、その項目と、つながる項目の名前の左に、一覧と同じ状態の印が出る。
資料の成果物は箱の印になる。
名前が読めない遠さでは、印も出ない。何も選んでいないときは出ない。

#### 起点をロックする

辿るうちにどこから派生したかを見失わないよう、注目の起点を 1 つの項目に留められる。

- 詳細を開いている項目をもう一度押すか、`L` キーを押すと、その項目をロックして、閉じた鍵が名前の右に出る
- ロック中にほかの項目を押すと、詳細だけがその項目に切り替わる。中心・強調・線を流れる光はロックした項目のままで、押した項目には選択の輪だけが付く
- ロックした項目の詳細を開いた状態で、その項目をもう一度押すか `L` キーを押すと、ロックが外れる。ほかの項目を開いているときにロックした項目を押すと、詳細がロックした項目に戻るだけで、ロックは外れない
- ロック中に、詳細を開いている別の項目をもう一度押したときと余白を押したときは、ロックも詳細も表示も変わらず、鍵が赤く光って左右に振れる。動きを減らす設定でも振れる
- 開いた鍵は、詳細を開いている項目にカーソルを乗せたときだけ出る。鍵を押しても何も起きない

ロックは、ほかのタブへ移って戻っても残り、ページを読み込み直すと外れる。
絞り込みでロックした項目が描かれなくなった間は、ロックしていないときと同じに動き、条件を戻して描かれるとロック中に戻る。
幅 900px 以下では、ロックできない。
`L` キーは、修飾キーを押しているとき・入力欄にフォーカスがあるとき・変換中・ダイアログやポップオーバーを開いているときは効かない。

### 項目を検索する

トップバーの検索を押すか、Ctrl+K（macOS は Cmd+K）を押す。入力欄で文字を入れている間も開ける。
ID・タイトル・本文を、空白で区切ったキーワードを全て含むもので検索する。大文字・小文字は区別しない。
HTML の資料の本文と、Markdown の本文の中の `html` のコードブロックは、描いた文で当たる。タグや属性の名前・値では当たらない。
結果は「完全に一致」（ID かタイトルがキーワードとちょうど同じ）→「タイトルに一致」（タイトルがキーワードを全て含む）→「ほかの所に一致」の見出しの順に並び、それぞれの結果に種類が付く。
結果を押すか、矢印で選んで Enter を押すと、その項目のタブと詳細パネルが開く。
閉じるには、Esc か外側の押下を使う。

### ライトとダークを切り替える

トップバーの右端のボタンで、ライトとダークを切り替える。
選んだほうは、この端末に残る。
選ぶまでは、端末のライト / ダークに従う。

### 表示の設定を変える

トップバーの「表示の設定」を押すと、見ている画面に重ねて左から表示の設定が開く。
コメントの一覧とは片方だけが開き、開くともう片方が閉じる。右の詳細パネルは開いたままになる。
幅 900px 以下では、画面の幅いっぱいに出る。
詳細パネルを開いていても、表示の設定は詳細パネルの前に出る。閉じると、開く前の詳細パネルが見える。
閉じるには、見出しの × か Esc、またはもう一度「表示の設定」を押す。

選んだ値は、その場で画面に当たり、この端末の個人の上書きとして残る。
サーバーへは送らず、同じワークスペースを見るほかの人の表示は変わらない。
値は項目ごとに、個人の上書きがあればそれを、無ければワークスペースの既定（`config.yaml` の `display`）を使う。

| 操作 | やり方 |
| --- | --- |
| 表示する種類を選ぶ | 検討事項・タスク・調査・資料・用語集・メモ・会話ログのチェックを付け外しする。「すべて」で全てを付け外しし、一部だけのときは途中の印と `5/7` の形の件数が出る。外した種類のタブは、トップバーから外れる。概要とネットワークは常に出る |
| 差分のミニマップを選ぶ | 「表示する種類」の下の区画「詳細に表示するもの」の「差分のミニマップ」のチェックを付け外しする。既定は表示する。外すと、開いている詳細パネル・詳細の全画面からその場でミニマップが消える |
| 本文の表とセクションの見せ方を選ぶ | 同じ区画「詳細に表示するもの」の「表の列の固定」「表の見出しの固定」「表のしま模様」「セクションの折りたたみ」のチェックを付け外しする。既定は、しま模様だけ外れていて、ほかの 3 つは付いている。付け外すと、開いている詳細パネル・詳細の全画面の本文がその場で描き直され、固定した列と畳んだセクションは初めの状態に戻る（[本文の表とセクションを読む](#本文の表とセクションを読む)） |
| ワークスペースの設定を編集する | 下端の「設定を編集する」を押す。サーバーが配るプレビューで、差分の表示をしていないときだけ出る（[設定を編集する](#設定を編集する)） |
| 既定に戻す | 「この端末で変えている項目」に並んだ項目（ネットワークの見た目・表示する種類・ライト / ダーク・表の列・絞り込みの条件・差分のミニマップ・本文の表とセクションの見せ方・本文の差分の並べ方）の上書きを全て外し、ワークスペースの既定の表示に戻す。上書きが無いときは「ワークスペースの既定のまま表示しています。」が出て、ボタンは出ない |

開いている画面の種類を外したときは、概要へ移る。
外した種類のタブを指す URL は、概要で開く。検索の結果から開いた詳細と、外した種類の項目を指す URL は、そのまま開く。
概要のタイルは、外した種類のものも残り、その種類の画面へ移る「すべて表示」と進捗のセルのリンクだけが外れる。

ライト / ダークはトップバー、表の列は表の上で変える。どちらも個人の上書きで、「既定に戻す」で外れる。

端末に保存できないときは、パネルの先頭に「この端末に保存できません。選んだ表示は、このページを開いている間だけ当たります。」が出る。

#### ワークスペースの既定にする

選んだ見た目と表示する種類を、同じワークスペースを見る全員の既定として保存できる。
サーバーが配るプレビューだけで、選びが今の既定と違うときに、「この端末で変えている項目」の下に線で区切って「ワークスペースの既定にする」が出る。
同じときは、ボタンの代わりに「見た目と表示する種類は、ワークスペースの既定と同じです。」が出る。
差分のミニマップと本文の表とセクションの見せ方はワークスペースの既定にならず、`config.yaml` は変わらない。これらだけを変えているときも、同じ文言が出る。

押すと、確かめのモーダル「ワークスペースの既定を書き換えますか」が開き、今の既定と保存する値が並ぶ。

| 操作 | 結果 |
| --- | --- |
| 保存する | `config.yaml` の `display` が書き換わり、モーダルが閉じる。パネルに「ワークスペースの既定にしました（{MM/DD HH:mm}）。」が残る。個人の上書きはそのまま残る |
| 取り消す・Esc | 何も書かずにモーダルが閉じる |
| 保存できなかった | モーダルの中に理由が出る。`config.yaml` も画面の表示も保存の前のまま。サーバーが止まっているときは、起動スクリプトで立ち上げ直し、示された新しい URL で開いてから保存する |

保存は誰でもできる。
他の人が保存したときと、`config.yaml` を手で直して[設定を再読み込みする](../リファレンス/コマンド.md#設定を再読み込みする)で効かせたときは、上書きを持たない項目にだけ新しい既定が当たる。
画面の下に「ワークスペースの既定が変わりました。」が 6 秒出て、同じ知らせが時刻つきでパネルに残る。
`config.yaml` が検査に通らないときは、最後に検査に通った設定のまま表示する。

### 項目と設定を編集して保存する

項目の追加・直し・削除・取り下げと、ワークスペースの設定の書き換えは、その場では書かず、保存待ちに溜める。
溜めた編集は、保存待ちのパネルでまとめて 1 回で保存すると、ワークスペースに書かれる。
保存待ちの編集はワークスペースの `edits.yaml` に残り、パネルを閉じても、再読み込みしても、起動スクリプトで立ち上げ直しても、保存するか取り消すまで消えない。
編集できるのは、サーバーが配るプレビューだけで、配る書き出しには編集の操作が出ない。
差分の表示の間は、編集の操作・保存待ちの印・トップバーの保存待ちのボタンが出ず、保存待ちのパネルが開いていれば閉じる。差分の表示をやめると、印とボタンが出し直される。

保存待ちの編集の件数は、項目のキー 1 つ・本文・案 1 つの追加と書き換えと削除・採用する案の切り替え・設定のキー 1 つをそれぞれ 1 件と数え、項目の追加と削除は項目ごとに 1 件と数える。

#### 項目を編集する

詳細パネルと詳細の全画面の見出しの「編集する」を押すと、読む表示が編集の表示に替わる。もう一度押す（「編集を終える」）か、別の項目を開くと、読む表示に戻る。溜めた編集は保存待ちに残る。
編集の表示は、編集できないキー（ID・作成・更新）を頭に並べ、その種類のキーを入力にする。ID・作成日時・更新日時・編集した人・変更履歴は編集できない。

| キー | 入力 |
| --- | --- |
| 状態・フェーズ・カテゴリー・対象 | 選ぶ |
| タグ | 設定のタグの語彙から選ぶチップ |
| 参照のキー | ID を入れるチップ |
| 取り下げ・納品物 | チェック |
| 答え・理由・結果など | 何行も書く欄 |
| 本文 | 等幅の何行も書く欄 |

入力欄を離れたとき（選ぶ・チェックは選んだとき）に、そのキーの編集を 1 件溜める。溜めたキーの入力欄は、枠が破線になる。
元の値に戻すと、保存待ちから外れる。
タイトルは空にできない。空のまま入力欄を離れると、溜めずに「タイトルを書いてください。」が出る。
届かない・エラーのときは入力が残り、キーの下に理由が出る。

検討事項は、案も編集する。
案ごとに、記号・「採用」のラジオ・中身の入力欄・「案 {記号} を削除」があり、末尾の「案を追加」で次の記号の空の案が増える。
中身を離れたときに案の追加か書き換えを、採用を選んだときに採用する案の切り替えを、削除を押したときに案の削除を溜める。削除を溜めた案は、中身に取り消し線が引かれる。

やめた項目は、消さずに取り下げる。

| 種類 | 取り下げ方 |
| --- | --- |
| 検討事項 | 状態を `対象外` か `取り下げ` にする |
| タスク | 状態を `中止` にする |
| 調査・資料・用語集・メモ・会話ログ | 取り下げのチェックを付ける |

#### 項目を追加する

検討事項・タスク・調査・資料・用語集・メモ・会話ログの画面の「項目を追加」を押すと、開いていた詳細パネルが閉じ、その種類の追加の入力が詳細パネルと同じ置き方で開く。
タイトルを書いて入力欄を離れると、項目を追加する編集が 1 件溜まる。残りのキーは、その 1 件の中に溜まる。
ID は保存したときにサーバーが振るので、溜めている間は付かない。

溜めた項目は、一覧の先頭（ボードは状態の列の先頭）に破線の枠で出る。マップには出ない。
ID の場所には「ID は保存で決まる」（表は「—」）が出て、タイトルが空なら「（タイトル未入力）」が出る。
押すと、追加の入力が開き直る。

#### 項目を削除する

詳細パネルの編集の表示の末尾の「項目を削除」を押すと、項目の削除が溜まる。確認は出ない。
溜めた後は、同じ場所が「削除を取り消す」に替わり、押すと削除が取り消される。削除を溜めた項目は、入力が読むだけになる。

ほかの項目が指している項目でも削除は溜まるが、保存のときに書き込めない編集になる。
ボタンの下に「{指している項目の ID} が指しているため、保存のときに削除できません。指している項目から外すと削除できます。」が出る。指している項目も同じ保存で削除するときは、書き込める。

#### 設定を編集する

表示の設定のパネルの下端の「設定を編集する」を押すと、パネルが閉じ、設定の画面が開く。
閉じるボタンで、開く前の画面に戻る。溜めた編集は保存待ちに残る。

設定の画面は、設定のキーを次のまとまりに分けて並べる。

| まとまり | キー |
| --- | --- |
| 話し合い | 題名・説明・プレイブック・ゴール |
| 進め方 | フェーズ・最上位の軸の呼び名・対象・カテゴリー |
| タグと関連 | タグの語彙・関連する場所 |
| 変更履歴 | 保持する回数 |

入力欄を離れたとき（選ぶ・チップ・行の追加と削除は操作したとき）に、そのキーの編集が 1 件溜まる。
項目が使っているフェーズ・対象・カテゴリー・タグを外すと、「{値} を使っている {n} 件の付け替え先」が出る。
付け替え先を選んだときに、付け替えつきの編集が溜まる。選ぶまでは溜まらない。
タグだけは「タグから外す」も選べる。対象・カテゴリーの名前を書き換えたときは、古い名前から新しい名前への付け替えが自動で付き、選ぶ欄は出ない。使われていない値を外したときも出ない。

#### 保存待ちの印で変えた箇所を見る

保存待ちの編集がある項目・キー・案に、破線の枠と印が付く。印は 3 種類ある。

| 印 | 文言 | 意味 |
| --- | --- | --- |
| 重ねた紙 | 保存待ち | 書き換え・追加の編集がある |
| ゴミ箱 | 保存で削除 | 削除の編集がある |
| 警告 | 書き込めない | 直前の保存で書き込めなかった編集がある |

印は、一覧（ボード・カード・表・マップの節）の項目のタイトルの後ろと、詳細パネルの見出しと、変えたキー・案の名前の後ろに付く。
マップの節と、詳細パネルの見出し・キー・案は、印だけになる。幅 480px 以下では、見出しの印は出ず、キー・案の印だけが出る。
読む表示は、保存待ちの編集を当てた値で描かれる。

トップバーの保存待ちのボタンは、絞り込みとコメントのボタンの間に出て、保存待ちの編集の件数を持つ。100 件以上は「99+」と出る。
直前の保存で書き込めなかった編集が残っているときは、件数の色が失敗の赤になる。
幅 1100px 以下では、「保存待ち」の文字が隠れ、印と件数だけが出る。

#### 保存待ちの編集を取り消す

保存待ちのボタンを押すと、保存待ちのパネルが左から開く。パネルは、編集を項目（設定は「設定」、追加する項目は「{種類}を追加」）ごとにまとめ、溜めた順に並べる。
行は、編集した内容（キーの名前・「案 {記号}」・「採用する案」・「項目を追加」・「項目を削除」）と、前の値 → 後の値を出す。本文と削除は値を出さない。

編集は、1 件ずつ取り消せる。
行の「取り消す」を押すと、その 1 件が保存待ちから外れる。詳細パネルで元の値に戻しても外れる。削除は、詳細パネルの「削除を取り消す」でも取り消せる。
まとまりの見出しを押すと、その項目が詳細パネルの編集の表示で開く（設定は設定の画面、追加する項目は追加の入力）。

#### 保存待ちの編集をまとめて保存する

保存待ちのパネルのフッターに、「{件数} 件（うち削除 {件数} 件）をワークスペースに書きます」と「まとめて保存する」が出る。削除を含むときは、ボタンが「まとめて保存する（{件数} 件を削除）」になる。
押すと、保存待ちの編集が 1 回でワークスペースに書かれる。1 件でも書き込めない編集があるときは、何も書かない。

保存待ちのパネルは、コメントの一覧・表示の設定のパネルと片方だけが開く。幅 900px 以下では、画面の幅いっぱいに出る。
閉じるには、見出しの ×・Esc・もう一度保存待ちのボタンを使う。保存待ちの編集は残る。

| 結果 | 画面の出方 |
| --- | --- |
| 全て書けた | パネルが閉じ、詳細パネルは読む表示に戻り、画面の下に「{件数} 件を保存しました。」が 5 秒出る。画面を開き直さずに、印と保存待ちのボタンが消える |
| 書き込めない編集がある | 何も書かず、パネルを開いたまま、「{件数} 件の編集を書き込めないため、何も保存していません。」と書き込めない編集の一覧が出る。その項目・キーに「書き込めない」の印と理由が付く |
| サーバーにつながらない | 「サーバーにつながらないため、保存できませんでした。」が出る。保存待ちの編集は残るので、起動スクリプトで立ち上げ直し、示された新しい URL で開いてから、もう一度保存する |

書き込めない編集は、取り消してから、もう一度保存する。理由ごとの直し方は次のとおり。

| 理由 | 直し方 |
| --- | --- |
| 溜めた後に AI がその項目を書き換えた（設定は、溜めた後に値が変わった） | その編集を取り消し、今の値を見て入れ直す |
| 編集する項目が無くなった | その編集を取り消す |
| 消す項目をほかの項目が指している | 理由に出た項目を押して開き、指している側から外すか、その項目も同じ保存で削除する |
| 書いた値が、タグの語彙・案と状態の決まり・参照の指す先などに合わない | 理由に出た内容を見て、その編集を取り消し、値を直して入れ直す |

保存した項目は、最後に編集した人と変更履歴の書き換えた人が `user` になり、変更履歴に説明「画面からの編集」のまとまりで残る（[編集した人を項目ごとに残す](../はじめに/コアコンセプト/ワークスペース.md#編集した人を項目ごとに残す)）。
保存した変更は、AI が次に `session` を始めたときの最初に、利用者が画面で変えた分として受け取る（[話し合いを進める](../リファレンス/スキル.md#話し合いを進める)）。

### 配る書き出しを頼んで渡す

ワークスペースもサーバーも持たない人へ記録を見せるときは、`session` に配る書き出しを頼む。
`session` が書き出す先のパスを聞き、画面と描画のライブラリを全て中に持つ 1 枚の HTML を、そのパスへ書き出して絶対パスを示す。
`session` は書き出す先に、ワークスペースの `.mindstella/` の中を使わない。
書き出すときは、jsDelivr へ届いている必要がある。

渡された人は、その HTML をブラウザで開くだけで読める。
ネットにつながらなくても、本文の Markdown・mermaid の図・検討事項のマップ・ネットワークが描かれる。
文字は端末の文字で描く。

配る書き出しは見るだけの画面で、項目の追加・編集・削除、回答・コメントの送信、設定の保存の操作は出ない。
見るための操作は、サーバーが配るプレビューと同じ。
書き出した HTML は、書き出したときのワークスペースの既定を中に持ち、開いた人の個人の上書きと合わせて表示する。
表示の設定で見た目と表示する種類は変えられるが、「ワークスペースの既定にする」は出ない。
中に持つライブラリのライセンスの表示は、HTML の中に入るが画面には出ない。
