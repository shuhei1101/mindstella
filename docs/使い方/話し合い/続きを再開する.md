# 続きを再開する

途中まで進んだ話し合いを再開するとき、セットアップのスキル `setup` で状況を読んで、続きから進める。

## 前提

- [プラグインをインストールする](../セットアップ手順/プラグインをインストールする.md)
- [セットアップから始める](./セットアップから始める.md)で作った、`mindmap.yaml` があるワークスペース
- tmux が入っている

## 手順

### 起動スクリプトで立ち上げる

ワークスペースのフォルダを渡して、起動スクリプトを叩く。

```bash
{プラグインのフォルダ}/bin/mindstella {ワークスペースのフォルダ}
```

同じフォルダの tmux のセッションが既にあれば、新しく立てずにそのセッションへつながる。
手順は [起動スクリプトで立ち上げる](../セットアップ手順/起動スクリプトで立ち上げる.md)。

### スキルを呼ぶ

起動スクリプトで立ち上げた Claude Code で、ワークスペースのフォルダを渡して呼ぶ。

```
/mindstella:setup {ワークスペースのフォルダ}
```

`mindmap.yaml` があるフォルダは既存のワークスペースとして扱われ、どのファイルも書き換えられない。

### 版を比べる

`setup` が、ワークスペースの版とプラグインの版を比べる。
同じなら、そのまま状況を読む。
`session` を直接呼んだときも、同じ比較で止まる。

| ワークスペースの版 | `setup` の動き |
| --- | --- |
| 古い（版を記録する前の形式を含む） | 何も書き換えずに、`/mindstella:upgrade` を案内して止まる。[ワークスペースを今の版へ移し替える](../セットアップ手順/ワークスペースを今の版へ移し替える.md)を済ませてから、もう一度 `setup` を呼ぶ |
| 新しい | プラグインの更新を案内して止まる。プラグインを更新してから、もう一度 `setup` を呼ぶ |

### 状況を読む

`setup` が、次の状況を示し、続きを推奨する。
再開したい話題を伝えていれば、そこから続ける推奨になる。

| 状況 | 中身 |
| --- | --- |
| 要見直し | 方針転換で見直しが要る検討事項 |
| 進行中 | 進めているタスク |
| 再開可能 | 保留で、依存先が全て決着した検討事項・タスク |
| 次の候補 | 前提が揃った未決定。フェーズ → 影響度 → 後続の件数の順 |

状況の元は [再開時の状況を読む](../../リファレンス/コマンド.md#再開時の状況を読む)。

### 話し合いへ進む

`setup` の案内のとおり、話し合いを進めるスキルを呼ぶ。

```
/mindstella:session {ワークスペースのフォルダ}
```

`session` が、版を比べた後に最初に、前回読んだ時点からの変更を読む。
前回読んだ後に足された・変わった項目があれば、変わったキーと前の値つきで示し、話し合いの前提にする。
前回読んだ時点の記録が無いワークスペースでは何も示さず、今の時点を記録する。

続けて、プレビューのコメントの一覧から送られて取り込んでいないコメントを拾う。
届いていた分を示し、送った順に記録してから、取り込み済みにする。
0 件なら飛ばす。

既存の項目の ID は変わらず、続きの番号で項目が足される。

### 途中で題名・ゴール・進め方ガイドを変える

話し合いの範囲が広がったら、題名・話し合いの概要・ゴール・進め方ガイド・最上位の軸の呼び名を変えたいと `session` に伝える。
話の中身と最上位の軸の呼び名が合わなくなったときは、`session` が見直しを持ちかける。

`session` が、書き換えのたたき台を示す。
進め方ガイドを変えてフェーズが変わるときは、古いフェーズから新しいフェーズへの対応の表も示す。
たたき台と対応を確かめて確定すると、`session` が設定を書き換え、項目のフェーズを付け替える。
確定するまでは、設定も項目も書き換えられない。

書き換えの内容は会話ログに残り、項目の ID は変わらない。
