# ゴールでリリースする

ゴールに届いたかを確かめ、決まったことと納品物を確定して、リリースの資料を `release/` に書き出す。

## 前提

- 話し合いを進めるスキル `session` で話し合っている（[セットアップから始める](./セットアップから始める.md)・[続きを再開する](./続きを再開する.md)）

## 手順

### ゴールに届いたかを確かめる

`session` に、ゴールに届いたかを尋ねる。
前提が揃った未決定が無くなったときも、`session` が確かめる。

ゴールに届いたのは、次の両方を満たすとき。

- 設定の `phases` の先頭からゴールのフェーズまでの検討事項が、全て `決定済み`・`対象外`・`取り下げ` のどれかである
- ゴールの納品物の資料が、全て完成（状態が `完成`）している

ゴールより後ろのフェーズの未決定は、判定に入らない。
届いていないと、残っている検討事項と納品物が示され、`release/` には何も書かれない。

ゴールを決めずに始めた話し合いは、届いたかを判定されず、決着していない検討事項が示されて、ゴールを決めるかを尋ねられる。
決めると答えると、`session` が範囲の見直しでゴールを書き、続けて判定する（[続きを再開する](./続きを再開する.md)）。
決めなければ、`release/` には何も書かれない。

判定の元は [ゴールに届いたかを読む](../../リファレンス/コマンド.md#ゴールに届いたかを読む)。

### 確定する

届いていると、決まった検討事項と納品物が示され、確定を求められる。
確定を返すと、`session` が `release/` にリリースの資料を書き出す。
書き出す前に、`release/` の中のファイルとフォルダが全て消える（自分で置いたものも含む）。
残るのは最新の確定版の一式だけで、版ごとのフォルダは作られない（[リリースを片付ける](../../リファレンス/コマンド.md#リリースを片付ける)）。

資料の書き出しのとき、Claude Code が書き込みの確認を出す。

### リリースの資料を渡す

`release/` に、決まった検討事項の一覧と納品物の本文が書き出される。
受け取り手は、`release/` だけを読めば、決まったことと納品物が分かる。
書き出しの形は、分野の進め方ガイドが決める（[話し合いの進め方](../../はじめに/コアコンセプト/話し合いの進め方.md#進め方ガイド)）。

話し合いの途中で終えても、記録は残り、[続きを再開する](./続きを再開する.md)で続けられる。
