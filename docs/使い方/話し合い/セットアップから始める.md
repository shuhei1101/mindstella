# セットアップから始める

新しい話し合いを始めるとき、セットアップのスキル `setup` でワークスペースを作る。

## 前提

- [プラグインをインストールする](../セットアップ手順/プラグインをインストールする.md)
- tmux が入っている
- 話し合いの記録を置く、まだ `.mindstella/config.yaml` が無いフォルダ

## 手順

### 起動スクリプトで立ち上げる

ワークスペースにするフォルダを渡して、起動スクリプトを叩く。
フォルダが無ければ作られる。

```bash
{プラグインのフォルダ}/bin/mindstella {ワークスペースのフォルダ}
```

起動スクリプトが最初に、サーバーの依存を確かめる。
足りないと、足りないものとそろえるコマンドが示されて止まる。
示されたコマンドを実行してから、もう一度叩く（[スクリプトの依存を入れる](../セットアップ手順/スクリプトの依存を入れる.md)）。
`{プラグインのフォルダ}` の引き方と、つなぎ方は [起動スクリプトで立ち上げる](../セットアップ手順/起動スクリプトで立ち上げる.md)。

### スキルを呼ぶ

起動スクリプトで立ち上げた Claude Code で、ワークスペースにするフォルダを渡して呼ぶ。

```
/mindstella:setup {ワークスペースのフォルダ}
```

フォルダを渡さないと、指定を求められる。
指定が決まらないうちは、何も書かれない。
MCP のツールが載っていない Claude Code で呼ぶと、何も書かれず、起動スクリプトでの立ち上げが案内される。

### 進め方ガイドと題名を決める

`setup` が、話題に合う進め方ガイドを 1 つ以上選び、選んだガイドから、タイトル・話し合いの概要・最上位の軸の呼び名・フェーズ・カテゴリー・ゴールのたたき台を示す。
ガイドを複数選んだときは、各ガイドのフェーズから 1 本の並びのたたき台も示す。
ゴールは、候補のほかに「決めずに始める」を選べる。タイトルは必ず決める。
たたき台を直して確定すると、ワークスペースが作られる。

分野ごとの既定は [話し合いの進め方](../../はじめに/コアコンセプト/話し合いの進め方.md#進め方ガイド) にある。

### 話し合いへ進む

`setup` の最後の案内のとおり、話し合いを進めるスキルを呼ぶ。

```
/mindstella:session {ワークスペースのフォルダ}
```

## 結果

フォルダにサブフォルダ `.mindstella/` ができ、その中に `config.yaml`・種類ごとの空の YAML・`docs/`・`release/` が入る。
フォルダの直下には `.mindstella/` だけが並ぶ。
ファイル構成は [ワークスペースの書式](../../リファレンス/ワークスペースの書式.md#ファイル構成) にある。
