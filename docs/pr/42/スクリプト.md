## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 書き出しの入口 | コマンド `export` を足し、`--workspace` と `--out` を受け、書き出したパスを JSON で返す | `dev/設計書/インターフェース定義/スクリプト/配る書き出し.yaml`（新規） |
| 書き出す先 | `--out` は必須で既定を持たない。ワークスペースの外のパスも受ける。既にあるファイルは、一時ファイルに書いてから置き換える（`build` と同じ）。親のフォルダが無いときは作らずにエラーにする。ワークスペースの `preview.html` を指すと引数の誤りにする | - |
| ライブラリの差し込み | 雛形の CDN の `<script src>` を外し、その URL から取った配布ファイルの中身を `<script>` の中身として、アプリの JavaScript より前に差し込む | 取った配布ファイルは `integrity` と突き合わせる。外の読み込みは `template.html` の `EXTERNAL_START`・`EXTERNAL_END` の間に置き、その間を置き換える |
| 文字 | Google Fonts の `<link>` を外す。端末の文字で描く | [要件](./要件.md)のスコープ外 |
| 埋め込みの安全 | 取った配布ファイル・ライセンスの本文が `</script`・`<script` を含むときは、書き出さずにエラーにする（大文字・小文字を区別しない） | 書き出すたびに取った中身を確かめる |
| ライセンスの表示 | ライブラリごとの名前・版・著作権の表示・ライセンスの本文を、配る書き出しの中に持つ | `<script type="text/plain" id="mindmap-licenses">` に持ち、画面には出さない（インターフェース定義『配る書き出し』） |
| 見るだけ | 書き込む操作を持たない今の画面を、そのまま差し込む | 書き込む操作を足すときの出し分けは [#16](https://github.com/shuhei1101/mindmap/issues/16) |
| `build` | 書き出す中身を変えない（CDN から読む） | 雛形の組み立てを共用するので、既存の単体・結合・E2E を流して確かめる |
| 異常系 | ワークスペースが無い・スキーマに合わない・書き込めないときは `build` と同じ例外・終了コードで終える | - |
| 通信 | `export` だけが jsDelivr から配布ファイルとライセンスの本文を取る。1 回の要求の待ちは 30 秒、取り直さない | 取れなければ `DownloadFailedError`（終了コード 1）で何も書かない |
