## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配る書き出しを開く | ネットを断ったブラウザで開いて、本文の Markdown・mermaid の図・検討事項のマップ・つながりが描け、ライブラリの知らせが出ないことを結合テストと E2E で確かめる | ブラウザの通信を全て止めて開く |
| 見るための操作 | タブ・表示形式の切り替え・絞り込み・検索・詳細パネル・つながりの回転と拡大・ライトとダークを、`build` の `preview.html` と同じに動かす | 画面の JavaScript は `build` と同じものを差し込む |
| 見るだけ | 書き込む操作を持たない今の画面のまま | 書き込む操作を足すときの出し分けは [#16](https://github.com/shuhei1101/mindmap/issues/16) |
| 文字 | Google Fonts を読まず、端末の文字で描く | [要件](./要件.md)のスコープ外 |
| ライセンスの表示 | 配る書き出しが中に持つライブラリの著作権とライセンスの表示を、開いた人が読める形で持つ | `mindmap-licenses` の要素に持ち、画面には出さない（インターフェース定義『配る書き出し』）。画面設計に要素は足さない |
| ブラウザ対応 | 動作環境の対象（Chrome と Edge の最新版）で、`file://` で開いて動く | `build` の `preview.html` と同じ |
