# プレビューを、見るだけの 1 枚の HTML に書き出して配れるようにする

## 概要

利用者が、プレビューの画面を描画のライブラリまで中に持つ 1 枚の HTML に書き出し、ワークスペースもサーバーも持たない人へ配れるようにする。

## 背景

[Issue #19](https://github.com/shuhei1101/mindmap/issues/19) の要望。
お客さんなど、ワークスペースもサーバーも持たない人へ記録を見せたい。
今の `build` が書き出す `preview.html` は 1 枚の HTML だが、描画のライブラリ（marked・DOMPurify・elkjs・mermaid）を jsDelivr から、文字を Google Fonts から開いたときに読み、ネットにつながらないと本文・図・つながりを描けない。
`build` を作った [Issue #3](https://github.com/shuhei1101/mindmap/issues/3) は「描画のライブラリは CDN から読む（埋め込みの選択肢は作らない）」と決めており、#19 は配る用途に限ってこれを覆す。
受付の判断で、[Issue #13](https://github.com/shuhei1101/mindmap/issues/13)（`build` を無くしサーバーが YAML を読む）はこの書き出しを残した上で移り、[Issue #16](https://github.com/shuhei1101/mindmap/issues/16)（書き込む操作を足す）はこの書き出しで書き込む操作を出さないと決めた（[扱いの判断](https://github.com/shuhei1101/mindmap/issues/19#issuecomment-5966011479)）。
