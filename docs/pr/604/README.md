# ワークスペースの設定（進め方の文書・追加の MCP・プラグイン）を書き換え、起動し直しで反映できるようにする（PATCH /workspaces/{id}）

## 概要

外部のアプリ（aituber など）と利用者が、作ったワークスペースの進め方の文書・追加の MCP・プラグインを API で書き換え、MindStella のセッションを起動し直して反映できるようになる。

## 背景

[Issue #524](https://github.com/shuhei1101/mindstella/issues/524) の要望（[#481](https://github.com/shuhei1101/mindstella/issues/481) の子。資料 A-107 の「シナリオを作る順」の No 9。API の原本は資料 A-119 の「MindStella の API」の表、反映の時期は検討事項 D-324）。

- MindStella の API は、ワークスペースの作成・状態の取得・一覧・クローズ・開き直し・削除と、MindStella のセッションの作成・一覧・停止・起動し直しを持つ。設定の書き換え（`PATCH /workspaces/{id}`）は資料 A-119 で決めたが未実装
- 今は、進め方の文書と追加の MCP・プラグインを指定できるのがワークスペースの作成だけで、記録が既にあるフォルダでは今回の指定を使用しない（D-283・D-321）。作成の応答が指定を記録しなかったと示したとき（D-341）と、状態の取得で記録が無いと分かったときに、外部のアプリが指定し直す手段が無い
- 追加の MCP とプラグインは Claude Code の起動のオプションなので、起動中の MindStella のセッションでは有効にならない。反映は既存の起動し直し（`POST /workspaces/{id}/sessions/{session}/restart`）で行う（D-324）
