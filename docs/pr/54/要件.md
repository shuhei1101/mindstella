# 要件

## 要望

E2E テスト `test_graph_trace_view.py::test_normal_when_toggle_all_kinds` が develop で pass するようにする。
つながりのキャンバスで、記録にある 8 件の項目の玉を全て見つけて押せることを、玉の置き方やカメラの向きによらず確かめられるようにする。

develop（c8a288c）で再現し、原因を次のとおり確かめた。

- 開いた直後の向きでは、キャンバスの走査で見つかる玉が 7 つで、N-1 の玉に当たらない（N-1 の玉が他の玉の後ろか、すぐ隣に重なっている）
- キャンバスをドラッグして向きを変えると、玉が 8 つ見つかり、N-1 を含む全ての項目の玉を押して詳細を開ける
- 画面は玉を描いており、利用者は回して押せるため、直すのはテストの補助（`click_item_ball`）の探し方とする
