# つながりの E2E で、種類ごとの玉を全て見つけて押せるようにする

## 概要

つながりの E2E が、他の玉に隠れた項目の玉も見つけて押せるようにし、develop で fail している `test_normal_when_toggle_all_kinds` を pass させる。

## 背景

[Issue #51](https://github.com/shuhei1101/mindmap/issues/51) の不具合。
[PR #41](https://github.com/shuhei1101/mindmap/pull/41) の作業中に、implementer と reviewer がそれぞれ develop で同じ fail を見つけた。
[PR #38](https://github.com/shuhei1101/mindmap/pull/38) で、種類をまとめて切り替えた後に 7 種類の玉を 1 つずつ押して確かめる手順が入り、N-1 の玉を見つけられずに落ちている。
