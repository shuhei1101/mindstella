## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 変更履歴 | 外部の変更のまとまりを、MindStella のセッション・利用者のまとまりと見分けられる表示にする | 表示の文言とマーカーはモック作成で決める |
| 重なった ID の通知 | 変更の検知が通知した重なった ID を、画面に表示する | 表示する場所と文面はモック作成で決める |
| 画面の書き込み | 保存待ちの編集をまとめて保存したときの履歴の記録は変えない | - |
| 関連の表示・入力 | 詳細パネルの関連・概要とマップの依存と親子・ボードとネットワークのつながりを、種類つきの `related` から読む。関連の入力は種類を選んで足す | #390 の関連の表示・入力のモックを材料に、モック作成で決める（確認ログの決着） |
