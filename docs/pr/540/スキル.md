## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 移し替えの手順 | 次のバージョンの `migrations/{バージョン}/steps.yaml` で、記録のフォルダに配信の設定を配置する。参照のキーの対応を変えるときは、既存の項目も同じ手順で移し替える | 配信元の行が無いワークスペース（#516 より前に作成したもの）に行を登録するかは、単一ユースケース設計で決める |
| 移し替えのスキル | 手順を追加し、移し替えの後の補正で呼ぶ `batch`・`update` を `write_docs` に書き換える。ほかの手順は変えない | 移し替えを常駐サーバーの読み込みへ移す（D-288）のは #518 |
| 話し合いを進めるスキル | 削除するツール（`find`・`show`・`add`・`update`・`remove`・`batch`・`tags`・`impact`）を呼ぶ箇所だけを、SC-489-52 の対応のとおり project-index の `search_docs`・`write_docs`・`delete_docs`・`trace_related` と `next_id` に書き換える。手順の流れは変えない | 確認ログの決着。スキルごとの削除は #518 |
