# 要件

## 要望

- MindStella のセッションが 1 回の作業（1 回の応答）を終えたときに、常駐サーバーが利用者の Discord のチャンネルへ Webhook で通知する
- 通知するのは、応答の間に AI がスレッドに書き込んだか commit した応答だけにする。1 回の応答で届く通知は 1 件にする
- 通知の本文は、ワークスペースの名前・作業が完了したこと・プレビューの URL だけにし、絵文字を使用しない
- 止まったとき（エラー・利用上限・無操作の上限・停止の依頼）は通知しない
- 常駐サーバーは、利用者が用意した Webhook の設定のファイル（中身は Webhook の URL の 1 行）を参照する。ファイルの場所は環境変数で指定し、指定が無い・ファイルが無いときは通知しない
- Webhook の URL は、ログ・応答・リポジトリ・Issue・PR に記載しない
- 通知の送信に失敗しても、出来事の記録・スレッドの書き込み・commit は失敗させない
