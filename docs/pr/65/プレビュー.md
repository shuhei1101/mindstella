## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 狭い幅のボード | 幅 720px 以下で、ボードの列を縦に 1 列に積む。`.board` の 290px の固定幅と `grab` のカーソルを `@media (min-width: 721px)` の中へ移す | モックは `dev/mock/pages/{decisions,tasks,docs}/65/stack/` |
| 広い幅のボード | 幅 721px 以上は列を 290px の固定幅で横に並べ、はみ出た分を横に送る今の作りを保つ | - |
| 画面設計 | 検討事項・タスク・資料のボードの要素に、幅 721px 以上と 720px 以下の列の並べ方を書く。`mock` は付け替えない | 65 のモックは 52 の写しから作っており、#60（タスク・資料）と #38（検討事項）の採用済みの見た目を持たないため |
| 結合テスト | 検討事項・タスク・資料の結合テストに、390x844 でボードの列が画面の幅に収まる・1280x800 で列が 290px で横に並ぶ、の確かめを足す | - |
| 既存機能への影響 | 幅 721px 以上のボードの横の送りと背景のドラッグは変えない | 回帰の確認でプレビューの結合テストを全て流す |
