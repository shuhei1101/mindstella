# 要件

## 要望

幅 720px 以下で、検討事項・タスク・資料のボードの列が最初の画面からはみ出さないようにする。
幅 721px 以上のボード（列を 290px の固定幅で横に並べ、はみ出た分を横に送る）は変えない。

確かめ方: 検討事項・タスク・資料のボードを `detect_screen_issues` に 390x844 でかけ、`first-viewport-column-overflow` が 0 件。1280x800 では列が 290px で横に並ぶ。

幅 720px 以下では、列を縦に 1 列に積む（[確認ログ](./確認ログ.md)）。
幅 721px 以上でだけ、つかんで動かす印のカーソル（`grab`）を出す。
