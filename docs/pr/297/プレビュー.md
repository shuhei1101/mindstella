## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 画面設計の要素の `status` | 現状の表の `planned` の要素を画面の実装と突き合わせ、実装にある要素（画面に描いている・操作を受けている）を `implemented` にする。実装に無い要素は `planned` のまま残す | 書き換えは `write_design_doc_screen` の `update` で行う |
| モジュール構成の関数の `status` | `htmlLinkAction` を実装と突き合わせ、実装にあれば `implemented` にする | 書き換えは `write_design_doc_module` の `update` で行う |
| 項目の中身 | `status` 以外のキーは変えない | - |
