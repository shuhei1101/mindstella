## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| mdmark の読み込み | 今の画面・React の画面・Storybook が、`latest` のとき、サーバーが解決した develop の最新の配布物の URL で mdmark を読み込む | `未確定`（[要件](./要件.md) の `latest` の解決の仕方。決める工程: インターフェース定義設計） |
| mdmark の部品への CSS | 画面の CSS のうち、mdmark が描いた表・差分・図・囲みの見た目と動きを上書きする規則を、規則ごとに残す / 削除するを判定して一覧にし、削除する。CSS 変数でテーマを指定する規則は残す | 一覧は部品設計で作る |
| 表の列の固定と横スクロール | MindStella の表の列の固定・右端のフェード・包む要素の横スクロールのうち、mdmark の表の機能と重なるものを削除し、mdmark の表の機能で描く | 幅 320px で本文の区画が横にスクロールしないことを画面設計で確認する |
| 背景の不透明の色 | `.mdmark` で `--mdmark-color-bg` を透明にしている箇所と `:root` に `--mdmark-color-bg-opaque` を周りの面の色で指定する | 今の画面は `var(--surface)`、React の画面は同じ役割のトークン |
| 既存機能への影響 | 本文の差分の実装（MindStella の差分）は変えず、差分の CSS のうち mdmark の部品の見た目を上書きする規則だけを対象にする | 差分の実装の入れ替えは [#347](https://github.com/shuhei1101/mindstella/issues/347) |
| 外部ライブラリ | mdmark の `latest` の解決の仕方を外部ライブラリ『mdmark』に反映する | 更新ドキュメントの表 |
