# 検討事項のマップで余白を押して選びを外しても、マップのスクロールの位置を保つ

## 概要

利用者が、プレビューの検討事項のマップで項目を選んでマップを送った後に余白を押して選びを外したとき、詳細パネルが閉じて広がった枠で送れる範囲で、押す前の位置のままマップを見続けられるようにする。

## 背景

[Issue #98](https://github.com/shuhei1101/mindstella/issues/98) の不具合。
release/v0.5.0（`03a3589`）の E2E（[#97 の実行の結果](https://github.com/shuhei1101/mindstella/pull/97#discussion_r4182801758)）で、`tests/e2e/単一ユースケース/test_decision_map_view.py::test_normal_when_background_pressed` が fail した（余白を押した後に `scrollLeft` が 224 から 0 に戻る）。
シナリオ『検討事項をマップで辿る』の期待値「余白を押す前後で、マップのスクロールの位置が変わらない」を満たしていない。
原因は、余白を押して選びを外す動きを足した [#90](https://github.com/shuhei1101/mindstella/pull/90)（`5f426cd`）。
直さないと v0.5.0 を master へ入れられないため、release/v0.5.0 を base にする。
