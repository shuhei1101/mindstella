# プレビューの資料を、状態（下書き / 確認中 / 完成）の列で並べるボードでも見られるようにする

## 概要

利用者が、プレビューの資料の画面で、資料を状態（下書き / 確認中 / 完成）の列で並べるボードでも見られるようにする。

## 背景

[Issue #36](https://github.com/shuhei1101/mindmap/issues/36) の要望。
資料の画面は [PR #21](https://github.com/shuhei1101/mindmap/pull/21) でカード（既定）と表の表示形式で入り、同じ PR で資料の `done` を状態（下書き / 確認中 / 完成）に置き換えた。
資料のボード表示は、その議論の中で別のタスクで扱うとした（[スレッド](https://github.com/shuhei1101/mindmap/pull/21#discussion_r4163773519)）。
状態の列のボードは、タスク・検討事項の画面に既にある。

## 計画書

| ファイル | 中身 |
| --- | --- |
| [要件](./要件.md) | 要望の整理と影響する UC 一覧 |
| [プレビュー](./プレビュー.md) | プレビューの計画書 |
| [確認ログ](./確認ログ.md) | ユーザーへの確認事項の決着 |

## タスク一覧

- [x] ~~初期構築~~（既存リポジトリのため対象外）
- [x] ~~リバースエンジニアリング~~（資料の画面の設計書が揃っている）
- [x] ~~方針決め~~（方針決めを依頼する Issue ではない）
- [x] ~~PoC 検証~~（タスク・検討事項の画面にある状態の列のボードを使い、未検証の技術機構に依存しない）
