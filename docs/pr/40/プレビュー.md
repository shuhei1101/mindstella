## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 表示形式 | 資料の画面の表示形式をカード・ボード・表の順の 3 つにし、既定はカードのまま | `VIEWS_OF` の資料を `["cards", "board", "table"]` |
| ボードの列 | 資料の状態の並び（下書き・確認中・完成）で 3 列にし、0 件の列も出す | `boardColumns` に `DOC_STATUSES` を渡す |
| ボードの作り | タスク・検討事項のボード（`board`）を使い、横に送る・背景のドラッグで動かす・列の見出しの件数を揃える | - |
| ボードのカード | 成果物を先頭に連番の順で並べ、成果物の印・種類・カテゴリー・フェーズ・タグを出す。押すと詳細パネルを開く | 状態の印は出さない（列で分かる） |
| ボードの枠 | `tabindex`・`role`・`aria-label` を付けない | 全ての列が 0 件の横に送れる枠は、Chrome / Edge 130 以降が自分で Tab で選べるようにする |
| 絞り込み | カードの表示形式と同じ絞り込みのボタンと条件のチップをボードにも出す | 絞り込める項目は成果物・状態・種類・カテゴリー・フェーズ・タグ |
| 状態表示 | `docs.schema.json` で資料の状態は必須かつ 3 値の列挙のため、どの列にも入らない資料は無い | - |
| 既存機能への影響 | タスク・検討事項のボードの見た目と動きを変えない | タスクをボードで見るの E2E を実行のみで回す |
