## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 登録・解除 | カード・ボードのカードの右上の星のボタンを押すと、その項目をお気に入りに登録・解除する。押してもカードの詳細は開かない | 登録・解除は利用者の操作だけで行う |
| カードの一覧 | お気に入りのカードに星を出し、一覧の先頭に並べる。お気に入りの中と、それ以外の中の並びは、今の並べ替え（連番・作成日時・更新日時）のまま | 「お気に入りを一番上にする」が切のときは先頭に寄せない |
| ボード | カードの右上に星を出すだけで、列の中の並びは変えない | - |
| 表 | 一番左に星の列を出し、その列の見出しで並べ替えられる。星の列は列の表示の付け外しの対象にするか、常に出すかを画面設計で決める | 部品『表』のピン留め（列の固定）とは別の機能 |
| 表示の設定 | 区画「お気に入り」で「お気に入りを一番上にする」（既定オン）「お気に入りだけを表示する」（既定オフ）を切り替える。ワークスペースの既定には含めない | 絞り込み中は一覧のチップ「お気に入りのみ」で解除できる |
| 置き場所 | 端末の保存領域（`mindmap-preview`）の `favorites`（項目の ID の並び）・`favoritesFirst`・`favoritesOnly` に持つ | 確認ログで決定 |
| 状態表示 | 「お気に入りだけを表示する」が入でお気に入りが 1 件も無いときの空の表示を画面設計で決める | - |
| アクセシビリティ | 星のボタンに、登録済みか（`aria-pressed`）と項目のタイトルを含む名前を付け、キーボードで押せるようにする | - |
