## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 圧縮のときのフック | `session_hook.py` から `pre-compact` の出来事と `BLOCK_COMPACT` の出力を削除し、圧縮を止めない | フックの登録はプラグインの計画書 |
| 圧縮のときの再起動 | 常駐サーバーは出来事 `pre_compact` を受けず、契機 `compact` の再起動（`MINDSTELLA_LAUNCH_REASON=compact` の付与と再起動の失敗の通知）を削除する | 利用上限・しきい値・落ちた後のコメント・再起動の依頼の契機は変えない |
| 圧縮の後の再開の注入 | SessionStart（`source: compact`）で、今と同じく再開として再開の状況と `mindstella/startup` の案内を注入する | `source: startup` を `compact` に読み替える分岐は不要になるため削除する |
| 既存機能への影響 | 古いプラグインのフックが `pre-compact` を送信しても、常駐サーバーは再起動しない | 出来事の `event` から `pre_compact` を外したため、受け取りは検証で拒む。古いフックは送信できたときだけ圧縮を止めるので、拒まれると圧縮を止めない |
