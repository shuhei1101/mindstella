## 要望

### #709 圧縮のときに MindStella のセッションを再起動しない

終了の条件: 圧縮のときに MindStella のセッションを止めず起動し直さない。自動の圧縮の設定は変えない。利用上限・しきい値・落ちた後・再起動の依頼の起動し直しは残す。圧縮の後も `mindstella/startup` の再開の注入が届く。設計書・コード・テストを合わせ、マージの前にワークスペース側の設計と突き合わせる

- 圧縮のときに、PreCompact のフックは圧縮を止めず、常駐サーバーは MindStella のセッションを止めず起動し直さない。Claude Code の圧縮を、通常のセッションと同じく走らせる
- 自動の圧縮の設定（`autoCompactEnabled`・`autoCompactWindow`）は変えない
- 利用上限・利用枠のしきい値・落ちた後のコメント・再起動の依頼をきっかけにした再起動は、今の振る舞いのまま残す
- 圧縮の後の SessionStart（`source: compact`）で、起動と再開のエージェントフロー（`mindstella/startup`）の案内と再開の状況が注入される
- 最後のマージの前に、[#709](https://github.com/shuhei1101/mindstella/issues/709) の「やりたいこと」と突き合わせ、圧縮のほかの再起動を落としていないかを確かめる

### #353 項目をお気に入りに登録し、一覧の先頭に並べる・お気に入りだけを表示する

終了の条件: 利用者がカードの右上の星で登録・解除でき、カードの一覧では先頭に並び、ボードは星を出すだけ、表は一番左の星の列で並べ替えられ、表示の設定で「お気に入りを一番上にする」「お気に入りだけを表示する」を切り替えられる（置き場所は設計で決める）

- 登録: 利用者だけが設定する。カードの右上の星のボタンを押すと登録・解除する
- カード: お気に入りはカードの右上に星を出し、カードの一覧では一番上に並べる
- ボード: カードの右上に星を出すだけで、並びは変えない
- 表: 一番左の列に星を出し、その列で並べ替えられる
- 表示の設定: 「お気に入りを一番上にする」と「お気に入りだけを表示する」を切り替えられる

お気に入りの置き場所: プレビューの端末の保存領域（表示の個人の上書きと同じ場所）に、ワークスペースごとの項目の ID の並びで持つ（[確認ログ](./confirmations.yaml)）。
