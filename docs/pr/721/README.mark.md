# 圧縮のときに MindStella のセッションを再起動せず、項目をお気に入りに登録して一覧の先頭に並べる

## 概要

利用者が、MindStella のセッションの会話が長くなっても、圧縮のたびに会話を切られずに同じ会話のまま話し合いを続けられるようになる。
利用者が、よく見る項目をお気に入りに登録し、一覧の先頭に並べたり、お気に入りだけを表示したりできるようになる。

## 背景

束の親 [Issue #719](https://github.com/shuhei1101/mindstella/issues/719) の子 2 件をまとめて対応する。

- [#709](https://github.com/shuhei1101/mindstella/issues/709): [#582](https://github.com/shuhei1101/mindstella/pull/582) で、PreCompact のフックが圧縮を止め、常駐サーバーが MindStella のセッションを新規の会話で起動し直す作りにした。2026-11-26 に約 33.5 万トークンで圧縮が走りかけたとき、起動し直した MindStella のセッションが進め方の文書・制作の設定・約 14 万文字の動画・タスク・スレッドを最初から読み直した。利用者は再起動を依頼しておらず、最優先での対応を指示した
- [#353](https://github.com/shuhei1101/mindstella/issues/353): 資料が 180 件を超え、カードの一覧からよく見る資料を探しにくくなった。プレビューは React（`frontend/`）の画面で、お気に入りの仕組みはまだ無い
