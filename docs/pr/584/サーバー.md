## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 不具合 1 | Git 管理外のワークスペースへの `write_docs` の作成・更新・置き換えが検査に通るようにする | `未確定`（[要件](./要件.md)。project-index#195 の完了後に、MindStella の側の残りを決める） |
| 不具合 2 | 移し替えを適用した後と、ワークスペースのバージョンが最新で手順を適用しないときにも、スキーマの複製をプラグインのスキーマと比べて違うファイルを再配置する | 既に v0.14.0 に移し替えたワークスペースも、次に開いたときに一致させる |
| 不具合 3 | `body` を持たない項目を配信から除かない | `未確定`（[要件](./要件.md)。project-index#195 の完了後に、MindStella の側の残りを決める） |
| 既存機能への影響 | MindStella 自身の読み込み・検証（`validate_workspace`）も同じスキーマを使用するので、`created`・`updated` を持つ項目を読み込めることを単体テストで確認する | - |
| テスト | 結合テストに、Git 管理外のワークスペースへの project-index の `write_docs` の作成・更新、移し替えの後の書き込み、本文を持たない項目の検索を追加する | 実際の project-index を使用する結合テスト（`tests/integration/plugin/test_agent_flows.py` と同じ準備）で検出する |
