# 設定をワークスペースの既定（config.yaml）と個人の上書き（localStorage）の 2 段にする

## 概要

リモートで複数人が同じワークスペースのプレビューを見ても、各自が見た目・ライト / ダーク・表示する種類・表の列を自分の端末だけで変えられ、他の人の表示に影響しないようになる。

## 背景

[#24](https://github.com/shuhei1101/mindstella/issues/24) の要望。
今のワークスペースの設定は `mindmap.yaml` 1 つで、表示の好みのうちライト / ダークと表の列だけが端末の保存領域に残り、見た目・表示する種類にはワークスペースの既定も個人の選びも無い。
前提のサーバーと MCP への移行（[#71](https://github.com/shuhei1101/mindstella/pull/71)）と、`mindmap.yaml` の `history_limit`（変更履歴の回数。[#79](https://github.com/shuhei1101/mindstella/pull/79)）は develop に入っている。
ネットワークの見た目の描き分けは [#28](https://github.com/shuhei1101/mindstella/issues/28)、メンバーと管理者の役割は [#25](https://github.com/shuhei1101/mindstella/issues/25)、YAML をまとめるサブフォルダは [#46](https://github.com/shuhei1101/mindstella/issues/46) が、この PR の置き場を前提に作る。
