# 次の Sprint の 6 件の束（作業の完了の通知のきっかけ・スレッドのクローズ・更新のボタン・トップバーのアイコン化・スレッドの横のはみ出し・詳細パネルの結合テスト）

## 概要

利用者に手番が返ったときだけ作業の完了の通知が 1 件届き、画面ではスレッドのクローズ・オープンが押したらすぐ変わり、トップバーの更新のボタンでページを再読み込みせずに最新の記録へ復帰できるようになる。
あわせて、トップバーを幅に関わらずアイコンと件数だけにし、iPhone の幅でスレッドの画面が端末の幅に収まるようにする。

## 背景

[Issue #702](https://github.com/shuhei1101/mindstella/issues/702) の束。次の Sprint の未着手の 6 件を 1 つの作業 PR で対応する。
