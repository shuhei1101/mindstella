### 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 通知 | MindStella のセッションの `commit` が成功したときに 1 件送信し、`stop` では送信しない | 方法は `未確定`（[要件](./要件.mark.md) の論点。決める工程: インターフェース定義設計） |
| 返信だけの応答 | その間に `reply`・`new_thread` があり、まとめる書き換えが無い `commit` でも成功として通知を送信する。まとまりは追加しない | 返信の画面への表示の時期は変えない（#698） |
| 通知しないもの | 停止の工程・画面の保存・変更の検知が作るまとまりでは今までどおり送信しない | - |
| 既存機能への影響 | 本文・送信の方法・Webhook の設定・URL の秘匿は変えない | - |
