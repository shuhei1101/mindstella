# 要件

## 要望

E2E『項目の詳細を読む』の詳細パネルの本文の見出しを、要素の段（h1〜h6）ではなく元の Markdown の段（`data-md-level`）で探す。
詳細パネルで下げた後の段が release と develop で違っても、同じ検証で通るようにする。

- `test_normal_when_html_code_block`: コードブロックの前後の Markdown の見出し（本文の `# 見出し`）が 1 つ以上描かれることを、`data-md-level` を持つ見出しで確かめる
- `test_normal_when_body_links`: 見出しとコードブロックの中に用語の印・ID のリンクが付かないことを、`h2` ではなく `data-md-level` を持つ見出しで確かめる（下げた後は h2 にならないため、今は見出しの側を確かめずに 0 件で通っている）
- 結合テスト `tests/integration/preview/test_detail_panel_screen.py` の `test_html_code_block`: 同じ「コードブロックの前後の Markdown の見出しが描かれる」を `h4, h1, h2` で探しているのを、`data-md-level="1"` の見出しが本文の `# 見出し` であることを確かめる形に揃える
