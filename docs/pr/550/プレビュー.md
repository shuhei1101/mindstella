## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 版の受け取り | 今の画面は、サーバーが雛形へ入れた設定の版の URL を読む。React の画面は、記録の取得で受け取る設定の版から URL を組み立てる。どちらも版を直に持たない | 受け取り方はインターフェース定義設計で決める |
| 中身の確かめ | 要件.md の `未確定`「タグを指定したときの中身の確かめ方」の推奨 A のとき、`integrity` を外して `crossorigin="anonymous"` だけで読む | `未確定` |
| 読めないとき | 今と同じく、mdmark を使う箇所に名前を出し、本文は原文で出す | 変えない |
| mdmark の口の変化 | `v0.8.0` から develop の最新までで変わった口（`mount` の `features` の名前・描いた要素の属性と class・`collectMatches`）に合わせる | PoC 検証で差を洗い出す |
| Storybook | 雛形から取り出すのをやめ、既定の版（latest）の URL を同じ組み立てで入れる | - |
| 外部ライブラリの設計書 | `LIB-489-13` の版を「設定で指定。既定は develop の最新」にし、`catalogs`・`limitations`・`license`（LICENSE の有無）を latest の内容に合わせる | 外部ライブラリの設計書は『ドキュメント修正』で直す |

### 変換

`mdmark.config.yaml`（`version: v0.10.0`・`build.include: docs/**/*.md`）を配置し、`upgrade --yes` で `v0.11.0`・`v0.13.0` の手順を当てた。ワークスペースの資料 836 件と mdmark の試験の入力 2 件で、flow・sequence の範囲 275 件中 274 件が map に、引数のマーカー 35 件中 32 件が JSON の記載になった（残る 1 件は試験の入力のコードブロックの中の例で、残る 3 件の引数のマーカーは報告に挙がらない）。報告 560 行は写さない値（`scope`・`updated` ほか）の通知で、変換できなかった範囲ではない。変換した試験の入力は mdmark の期待値と一致した。

| 事象 | 回避策（PoC だけ） |
| --- | --- |
| `npx github:shuhei1101/mdmark#develop upgrade` が `docs/guide/変更履歴.md` を読めず終了コード 1。develop の `dist/cli.js`（2026-11-14）が `.md` を探し、文書は `.mark.md` に改名済み | クローンの `変更履歴.mark.md` を `.md` へ複製し、クローンの `dist/cli.js` で実行 |
| 変換した map の文字列に `--` があると点検が 7 件のずれを出し、全ての変更をコピーから戻す（ワークスペースの 4 件の資料のノードの `sub` の `--mcp-config` ほか） | 4 件の資料の図の中の `--` を `‐‐` へ置換 |

### 配る書き出し

`dist/index.js` を `text/plain` で持たせ Blob の URL から `import()` した 1 枚の HTML は、map の部品を `new URL("./map.js", import.meta.url)` で読もうとして `Invalid URL` で止まる。部品を差し替える `setPartModuleLoader` は mdmark の公開の API に無い。map を含まない資料は描けるが、mdmark が mermaid を jsDelivr から読みに行く。

### 結論

不成立（No 5・No 6）。latest の参照とインターフェースの差は設計で合わせられるが、移し替えと配る書き出しは mdmark の側の修正が無いと成り立たない。[確認事項](https://github.com/shuhei1101/mindstella/pull/550#discussion_r4587856152)の案 A で、mdmark の [#606](https://github.com/shuhei1101/mdmark/issues/606)（No 5 の `upgrade` の停止。既存）・[#623](https://github.com/shuhei1101/mdmark/issues/623)（No 5 の `--`）・[#624](https://github.com/shuhei1101/mdmark/issues/624)（No 6）の完了を待ち、待つ間に設計を進める。PoC のコードと記録: [dev/poc/551-mdmark-latest](https://github.com/shuhei1101/mindstella/blob/55844546/dev/poc/551-mdmark-latest)。
