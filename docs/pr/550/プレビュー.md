## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 版の受け取り | 今の画面は、サーバーが雛形へ入れた設定の版の URL を読む。React の画面は、記録の取得で受け取る設定の版から URL を組み立てる。どちらも版を直に持たない | 受け取り方はインターフェース定義設計で決める |
| 中身の確かめ | 要件.md の `未確定`「タグを指定したときの中身の確かめ方」の推奨 A のとき、`integrity` を外して `crossorigin="anonymous"` だけで読む | `未確定` |
| 読めないとき | 今と同じく、mdmark を使う箇所に名前を出し、本文は原文で出す | 変えない |
| mdmark の口の変化 | `v0.8.0` から develop の最新までで変わった口（`mount` の `features` の名前・描いた要素の属性と class・`collectMatches`）に合わせる | PoC 検証で差を洗い出す |
| Storybook | 雛形から取り出すのをやめ、既定の版（latest）の URL を同じ組み立てで入れる | - |
| 外部ライブラリの設計書 | `LIB-489-13` の版を「設定で指定。既定は develop の最新」にし、`catalogs`・`limitations`・`license`（LICENSE の有無）を latest の内容に合わせる | 外部ライブラリの設計書は『ドキュメント修正』で直す |
