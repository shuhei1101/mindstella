# 要件

## 要望

詳細パネルで HTML の本文の差分を左右に並べ、選んだ時点の本文が Markdown のとき、左の列に描く本文の見出しを、右の今の本文と同じ決め方で節の見出し「本文」（h3）の次の段から下げる。

- 左の列の見出しのうち最も上の段を h4 にし、段の差を保って並べる（h6 を超える段は h6 にして `aria-level` で段を伝える）
- 見出しの見た目は元の段のまま（`data-md-level`）
- 下げ方は詳細パネルの本文・左右に並べた本文の差分と同じ `headingShift`・`lowerHeadings` を使う

## 更新ドキュメント

なし

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 左の列の HTML の本文（`beforeFormat` が `html`）の見出し | 枠（iframe）の中の別の文書に描くため、詳細パネルの見出しの段に入らない | 予定なし |
