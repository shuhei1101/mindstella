## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| マップの項目の 2 行目の文字 | `.n-item .r2` をデザイン方針の補足の下の段（12px）にし、等幅の ID を 11px 以上にする | 値はモック作成で確定 |
| ボードの列の余白 | `.board` の列の内側に余白を置き、カードが列の左端に接しないようにする | 余白の量はモック作成で確定。同じ `.board` を使う資料のボードにも当たる |
| 表のセルの面の色 | `table.grid` のセルの面の色を外して `.table-wrap` に持たせ、固定した列（`.pinned`）と選んだ行（`tr.selected`）だけが面の色を持つ。ホバーの色は選んだ行に当てない | 見た目は変えない |
| 本文の寄せ | 詳細パネルの開閉で `.content` の `margin-right` を transition で動かさない。`.crumbs-bar` の寄せと揃える。本文の寄せは開閉と同時に切り替え、詳細パネルだけをすべり込ませる | - |
| 画面設計 | タスク・資料・詳細パネルの `mock` をこの PR のモックへ付け替え、ボードの余白・マップの項目の 2 行目・詳細パネルの本文の寄せの動きを要素と冒頭リードに書く | 検討事項の `mock` は #38 の採用案（`decisions/38/b-check`）のままにする（60 のモックは 21 を元にしており、#38 の状態の印の全選択のチェックを持たない） |
| 結合テスト | 検討事項・タスク・資料・詳細パネルの結合テストに、2 行目の ID の計算後の文字の大きさが 11px 以上・カードと列の左端の間に余白がある・表のセルが静止時に面の色を持たず、選んだ行はホバー中も選んだ行の色・`.content` の transition にレイアウトの値を含まない、の確かめを足す | - |
| 既存機能への影響 | ボードの横のスクロールとドラッグ、詳細パネルを並べる幅の切り替え（1100px / 901px）は変えない | 回帰の確認でプレビューの結合テストを全て流す |
| 動きを減らす設定 | 動きを減らす設定で全ての動きを止める今の扱いは変えない | - |
