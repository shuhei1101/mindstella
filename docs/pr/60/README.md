# プレビューの画面の崩れの検出（小さい文字・カードの左端・余白の transition）を解消する

## 概要

プレビューの画面を開いた利用者が、検討事項のマップ・タスクのボード・詳細パネルを、画面の崩れの検出の無い見た目で読めるようにする。

## 背景

[Issue #58](https://github.com/shuhei1101/mindmap/issues/58) の要望。
[PR #52](https://github.com/shuhei1101/mindmap/pull/52)（[Issue #6](https://github.com/shuhei1101/mindmap/issues/6)）のモックを `detect_screen_issues` にかけたところ、[PR #21](https://github.com/shuhei1101/mindmap/pull/21) の見た目から引き継いだ検出が見つかり、reviewer が対象外の逸脱として報告した（[報告](https://github.com/shuhei1101/mindmap/pull/52#discussion_r4173856580)）。
PR #52 は文言の点検だけを扱い、見た目は変えない。
