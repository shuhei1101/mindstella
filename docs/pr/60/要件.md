# 要件

## 要望

プレビューの画面から、次の 3 種の画面の崩れの検出をなくす。
見た目の方向（[デザイン方針](https://github.com/shuhei1101/mindmap/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%83%87%E3%82%B6%E3%82%A4%E3%83%B3%E6%96%B9%E9%87%9D.md)）は変えない。

| 検出 | 今の箇所 | 直した後の状態 |
| --- | --- | --- |
| `undersized-ui-text` | 検討事項のマップの項目の 2 行目（ID・状態・影響度）。[style.css](https://github.com/shuhei1101/mindmap/blob/develop/plugins/mindstella/skills/mindmap/preview/style.css) の `.n-item .r2` の 11px に、ID の `.mono` の `.92em` が掛かって 10.12px になる | 押せる項目の中の文字が、等幅の ID を含めて 11px 以上 |
| `edge-flush-cards` | タスクのボードの列。`.board` の列にカードが左端の余白なしで接する | カードと列の左端の間に余白がある |
| `edge-flush-cards` | 検討事項・タスク・資料の表。`table.grid` のセルが面の色を持ち、表の枠の左端に接したカードとして当たる | セルは静止時に面の色を持たず、表の枠（`.table-wrap`）が面の色を持つ。固定した列と選んだ行は今の色のまま、選んだ行はホバー中も選んだ行の色のまま |
| `layout-transition` | 詳細パネルの開閉。`.content` の `margin-right` を transition で動かす | レイアウトの値（`margin-right` 等）を transition で動かさない。詳細パネルがゆっくりすべり込む動き（デザイン方針の `## 動き`）は保つ |

確かめ方: プレビューの全ての画面（検討事項のマップ・ボード・表、タスクのボード・表、詳細パネルを開いた状態を含む）を `detect_screen_issues` に 1280x800 と 390x844 でかけ、上の 3 種の検出が 0 件。

詳細パネルを開閉するとき、本文の寄せは動かさず開閉と同時に切り替え、詳細パネルだけをすべり込ませる。
