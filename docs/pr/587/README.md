# 動画などのファイルをワークスペースに配置し、資料に埋め込んで画面で再生できるようにする

## 概要

MindStella のセッションと利用者が、動画などのファイルをワークスペースに配置して資料に mdmark の `![キャプション](パス)` で埋め込み、画面で再生できるようになる。

## 背景

[Issue #519](https://github.com/shuhei1101/mindstella/issues/519) の要望（[#481](https://github.com/shuhei1101/mindstella/issues/481) の子。資料 A-107 の「シナリオを作る順」の No 4）。

- aituber の動画作成ノード（資料 A-103）は、書き出した mp4 をワークスペースのフォルダに配置し、資料にパスを記載して埋め込み、commit する（D-267）。ワークスペースには、ファイルを配置するフォルダが無い
- mdmark@v0.10.0 は、画像の記法の拡張子が動画・音声のとき再生バーを持つ `video`・`audio` で描く（[shuhei1101/mdmark#199](https://github.com/shuhei1101/mdmark/issues/199)）。画面が参照する mdmark を v0.10.0 へ上げる [#475](https://github.com/shuhei1101/mindstella/issues/475) は close 済み
- mdmark の `mount` は相対パスをページの URL を基準に解決し、設定の `assets.root` は CLI・VS Code だけが参照する。サーバーの配信は記録・画面・SPA の出力だけを返却し、ワークスペースのファイルを返却するパスが無い
