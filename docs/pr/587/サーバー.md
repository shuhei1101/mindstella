## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ファイルのフォルダ | ワークスペースの記録のフォルダの下にファイルのフォルダ `.mindstella/files/` を追加し、ER 図に記載する | 資料からは `../files/{名前}` で指す |
| ファイルの配信 | 配信に、ファイルのフォルダの中のファイルを返却するパスを追加する。拡張子から `Content-Type` を決め、動画の再生位置の移動のために `Range` の要求に部分の応答（206）で返却する | フォルダの外を指すパス（`..`・シンボリックリンク）は 404 |
| 点検 | 資料の本文の画像の記法が指すワークスペースの中のファイルが無いとき、参照切れの問題として返却する | 絶対 URL は調べない |
| 変更の検知 | ファイルのフォルダの書き換えを、項目の追加・変更・削除として記録しない | 自動の commit にファイルを含めるかは `未確定`（要件.md） |
| 配る書き出し | 埋め込んだファイルの扱いを、要件.md の `未確定` の決定に合わせる | - |
| 記録のエージェントフロー | ファイルをファイルのフォルダへ配置し、資料に `![キャプション](パス)` で埋め込む手順を追加する | - |
| 非機能 | 配信が返却するファイルの大きさに上限を設けず、ファイルを読み込みきらずに分けて送信する | 動画で常駐サーバーのメモリを使用し切らない |
