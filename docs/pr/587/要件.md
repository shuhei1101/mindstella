# 要件

## 要望

動画・画像・音声などのファイルをワークスペースのファイルのフォルダに配置し、資料の本文に mdmark の `![キャプション](パス)` で埋め込むと、サーバーが配る画面（今の画面と React の画面）の詳細パネル・詳細の全画面で、動画・音声を再生でき、画像を表示できる。

| 項目 | 値 |
| --- | --- |
| 配置する人 | MindStella のセッション（動画作成ノードなど）と利用者 |
| 埋め込みの記法 | mdmark の `![キャプション](パス)`。動画・音声の再生バーとキャプションは mdmark@v0.10.0 の部品『動画と音声』が描く |
| 画面での確認 | ファイルのフォルダに配置した mp4 を資料に埋め込み、詳細パネルで開くと再生バーが出て再生できる。ファイルが無いときも本文のほかの部分は描かれる（どのファイルが無いかは点検が通知する） |
| 点検 | 資料の本文が埋め込んだファイルがワークスペースに無いことを、ワークスペースの点検が参照切れとして返却する |
| 変更の検知 | ファイルのフォルダへの配置・差し替え・削除を、項目の変更として記録しない |
| 配信の範囲 | ファイルの配信は、ワークスペースのファイルのフォルダの中だけを返却し、フォルダの外のパスは返却しない |
| ファイルのフォルダとパス | `.mindstella/files/` に配置し、資料（`.mindstella/docs/`）からの相対パス `../files/{名前}` で指す。画面は資料のフォルダを基準にパスを解決する（mdmark の `mount` は `assets.root` を参照しないため、`assets.root` は使用しない） |
| Git | mindstella はワークスペースの Git を操作しない（記録の YAML と同じ）。Git のリポジトリの中のワークスペースでも Git 管理外のワークスペースでも、配置・配信・再生・点検は同じに動く |
| 書き出し | 資料を書き出す・配る書き出しは今のまま変えない。埋め込んだ動画・音声を書き出した先で再生できるようにするのは #589 で mdmark の書き出しに合わせる |
