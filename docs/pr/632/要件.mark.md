# 要件

## 要望

ネットワークの画面と、検討事項の表示形式のマップを削除する。
完了の条件は、今の画面と React の画面のどちらにも 2 つの機能とそこへ移る導線が無く、2 つの機能だけが使用する設定・コード・依存・設計書・公開ドキュメントの記載・テストが残っていないこと。

<!-- table: {"kind": "data"} -->

| 対象 | 要件 |
| --- | --- |
| ネットワークの画面 | 今の画面（`preview/graph/`）と React の画面（`frontend/src/features/graph/`）から削除する |
| 検討事項の画面 | 表示形式の切り替えからマップを削除し、ボード（既定）と表を残す |
| ネットワークへ移る導線 | タブの帯の右端のネットワークと、詳細パネルからネットワークへ移る操作を削除する |
| 起点のロック | ネットワークとマップだけが使用する起点のロック（`core/lock.ts`）を削除する |
| ネットワークの見た目 | 見た目の選択と、端末の保存領域・ワークスペースの既定・表示の設定のパネル・既定の保存の確かめに持つ見た目を削除し、表示の設定を表示する種類だけにする |
| サーバーの表示の設定 | `config.yaml` の `display.network_look` と、設定の更新・既定の書き換え・設定の再読み込み・記録の取得の API が持つ `network_look` を削除する |
| 既存のワークスペース | 次のバージョンの移し替えの手順（`migrations/{バージョン}/`）で `config.yaml` から `display.network_look` を削除する |
| 依存 | 2 つの機能だけが使用するライブラリ（elkjs など）を、ほかの描画（mermaid の図）で使用していないことを確認してから、`package.json`・描画のライブラリの読み込み・配る書き出しの同梱から削除する |
| 削除した画面を指す URL | ネットワークを指す URL は概要を、マップを指す URL は検討事項のボードを開く |
| 文書・テスト | シナリオ・画面・部品・インターフェース定義・モジュール構成・データ・ライブラリの設計書と公開ドキュメント・モック・単体・結合・E2E のテストとストーリーから、2 つの機能と見た目の記載を削除する |
| 差分のミニマップ | 削除しない |
