## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定のスキーマ | `display` から `network_look` を削除し、`display` を `visible_kinds` だけにする | - |
| 設定の更新・既定の書き換え | 要求の本文の `display` を `visible_kinds` だけにし、`network_look` を受け取ったら知らないキーとしてエラーを返却する | 既存の知らないキーの扱いに合わせる |
| 設定の再読み込み・記録の取得 | 返却する設定から `network_look` を削除する | - |
| 配る書き出し | 同梱する描画のライブラリから elkjs を削除する | プレビューの計画書の描画のライブラリの確認の結果に従う |
| 既存のワークスペース | 次のバージョンの移し替えの手順で `config.yaml` の `display.network_look` を削除する。`display` が空になったら `display` も削除する | 移し替えは、ワークスペースを開く前に『記録の形式の移行』が利用者に確認せずに適用する |
| API の定義 | `frontend/openapi.yaml` から `NetworkLook` を削除し、生成した API の定義を再生成する | - |
