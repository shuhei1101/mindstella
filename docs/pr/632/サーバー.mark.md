## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定のスキーマ | `display` から `network_look` を削除し、`display` を `visible_kinds` だけにする | - |

| 設定の再読み込み・記録の取得 | 返却する設定から `network_look` を削除する | - |
