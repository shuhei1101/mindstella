## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ID のリンクの処理 | `linkBody` の項目の ID・スレッドの ID のリンクと、post-links の `buttonizeItemIds`・`linkThreadIds` を 1 つの処理にまとめ、記録に無い ID は文字のままにする | 本文のマーカー・見出しのリンク・まとまりのリンクは今の関数に残す |
| 記録の文字を描く部品 | 記録の文字（Markdown で描く本文・値と、プレーンテキストで描くタイトル）を描く部品を 1 つにし、まとめた処理を適用する | 名前と配置先はモジュール構成設計で決める |
| 詳細・スレッドの見出し | 詳細パネル・詳細の全画面・スレッドの見出しのタイトルと、詳細パネルの「関連する項目」「更新した項目」の関係する項目のタイトルを、まとめた部品で描き、ID をリンクにする | 関係する項目のタイトルは押せない `span` のためリンクにできる |
| リンクを入れ子にできない場所 | 一覧の行・カード（関係する ID とタイトルの行を含む）・表のセル・検索の結果・保存待ちのパネルの行と、詳細パネルの「リンク」のセクションの `link.title` など、押す要素の中のタイトルの ID は、押す操作を変えずに別の見せ方にする | `未確定`（[要件](./要件.mark.md) の論点。決める段: モック作成） |
| 配る書き出し | スレッドの参照を `null` にし、スレッドの ID を文字のままにする今の振る舞いを保つ | - |
| 呼び忘れの検出 | 記録の文字をまとめた部品を使用せずに描く記載を、ESLint の `no-restricted-syntax` で失敗させる | - |
| アクセシビリティ | リンクにできない場所の ID は、中にフォーカスできる要素を配置しない。行のボタン（検索の結果は `option`）にフォーカスしたとき、行の中の ID の項目・スレッドのタイトルと状態を `aria-describedby` で読み上げ、ツールチップを出す | `<button>` の content model は interactive content と `tabindex` を持つ子孫を許可しない。`option` の中にフォーカスできる要素を配置すると axe の `nested-interactive` に該当する |
