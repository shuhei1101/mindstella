# 要件

## 要望

結合テスト `tests/integration/preview/test_graph_screen.py::test_lock_when_quick_double_press` を、サンプルの玉の配置によらず毎回 pass させる。
単独実行で 10 回続けて pass することを基準にする。

- テストが確かめる振る舞いは変えない: 何も選んでいないときに玉を素早く同じ位置で 2 回押すと、1 回目で詳細が開いてキャンバスが縮み 2 回目の位置にもう玉が無くても、その項目への 2 回押しとしてロックする
- 2 回目を押す位置に玉が無いことは、玉の選び方・押す位置の決め方で作る。前提の確認を外して、玉の有無に左右される確かめにしない
- 押下の規則（450ms 未満・24px 未満の 2 回目を前に押した項目への 2 回押しとする）と、それを実装した処理は変えない
- 原因の切り分けで、縮んだ後も押した位置に玉が残るのが実装の誤り（画面設計『ネットワーク』に反する）と分かった場合は、テストを変えずに差し戻す
