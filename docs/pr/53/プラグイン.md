## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ライセンスの本文 | リポジトリの直下に `LICENSE` を置き、MIT の本文と `Copyright (c) 2026 shuhei1101` を書く | 本文は SPDX の MIT のテキストのまま |
| プラグインのマニフェスト | `plugin.json` に `license`（`"MIT"`）・`homepage`・`repository`（どちらも `https://github.com/shuhei1101/mindstella`）を足し、`author` に `url`（`https://github.com/shuhei1101`）を足す | `name`・`description`・`author.name` は変えない。`version` は持たないまま |
| マーケットプレイスのマニフェスト | `plugins[]` の mindstella の項目に `license`・`homepage`・`repository` を `plugin.json` と同じ値で足す | マーケットプレイスの `name`・`owner`・`description` と、`plugins[]` の `name`・`source`・`description` は変えない |
| インターフェース定義 | 『マーケットプレイスの登録』の `request` に `plugins[].license`・`plugins[].homepage`・`plugins[].repository` を、『プラグインの読み込み』の `request` に `license`・`homepage`・`repository`・`author.url` を足し、両方の `request_example` を足した後の形にする | 期待値（`claude plugin validate` の警告は `version` の 1 件だけ）は変えない |
| 既存機能への影響 | `homepage`・`repository` の URL は、#41 の反映作業でリポジトリ名を `mindstella` に変えるまで開けない | 改名は #41 の `## 反映作業` で済ませる |
