# 要件

## 要望

- リポジトリの直下に MIT ライセンスの `LICENSE` を置く。著作権の表記は `Copyright (c) 2026 shuhei1101`
- プラグインのマニフェスト `plugins/mindstella/.claude-plugin/plugin.json` に `"license": "MIT"`・`"homepage"`・`"repository"` を足し、`author` に `"url": "https://github.com/shuhei1101"` を足す
- マーケットプレイスのマニフェスト `.claude-plugin/marketplace.json` の `plugins[]` の mindstella の項目に `"license": "MIT"`・`"homepage"`・`"repository"` を足す
- `homepage`・`repository` の値は `https://github.com/shuhei1101/mindstella`
- 足した後も、リポジトリの直下で `claude plugin validate` を流すと終了コード 0・誤り無し・警告は `plugin.json` の `version` の 1 件だけである
- ルートの `README.md` にライセンスの節を足し、MIT であることと `LICENSE` へのリンクを書く
