# リポジトリに MIT ライセンスを付け、プラグインの設定に作者とリポジトリの URL を載せる

## 概要

利用者が、mindstella のライセンス（MIT）と作者・リポジトリの URL を、リポジトリとプラグインの設定から読めるようにする。

## 背景

[Issue #15](https://github.com/shuhei1101/mindmap/issues/15) の要望。
今のリポジトリには `LICENSE` が無く、プラグインのマニフェストは `name`・`description`・`author.name` だけを持ち、ライセンス・リポジトリの URL・作者の URL を持たない。
`homepage`・`repository` は [Issue #17](https://github.com/shuhei1101/mindmap/issues/17)（[PR #41](https://github.com/shuhei1101/mindmap/pull/41)）の改名の後の URL `https://github.com/shuhei1101/mindstella` にする。
プラグインのマニフェストは PR #41 で `plugins/mindstella/.claude-plugin/plugin.json` へ移った。
