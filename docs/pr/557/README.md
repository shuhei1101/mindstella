# 入力欄にカーソルがある間と録音中は記録の更新を画面に反映せず、入力・変換・録音が途切れないようにする

## 概要

利用者が、AI が記録を書き換えている間もプレビューの入力欄で入力・変換・録音を途切れずに続けられるようになる。

## 背景

[Issue #514](https://github.com/shuhei1101/mindstella/issues/514) の要望（検討事項 D-448 で A を選択）。

- 常駐サーバーは記録の書き換えのたびに書き換えの知らせ（`changed`）を送り、画面は記録を読み直して描き直す。入力中の扱いは無い
- スマホでは変換中の文字が確定・取り消しされ、録音が途中で切れることがある
- 録音の状態は [#510](https://github.com/shuhei1101/mindstella/issues/510) で画面で 1 つ（`voice-store`）になった
