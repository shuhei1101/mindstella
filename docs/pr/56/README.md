# プラグインを配るフォルダ plugins/mindstella/ の中にも LICENSE を置く

## 概要

プラグイン mindstella をインストールした利用者の手元に、MIT のライセンスの本文と著作権の表記が届くようにする。

## 背景

[Issue #55](https://github.com/shuhei1101/mindmap/issues/55) の要望。
[Issue #15](https://github.com/shuhei1101/mindmap/issues/15)（[PR #53](https://github.com/shuhei1101/mindmap/pull/53)）でリポジトリの直下に `LICENSE` を置いた。
インストールで利用者の手元へ写るのは `.claude-plugin/marketplace.json` の `source` が指す `plugins/mindstella/` の中だけで（[PR #41](https://github.com/shuhei1101/mindmap/pull/41)）、直下の `LICENSE` は届かない。
MIT は写しにも著作権の表記と許諾の文を含めることを条件にしている。
