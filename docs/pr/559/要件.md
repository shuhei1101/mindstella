# 要件

## 要望

PreToolUse のフック `inject_session.py` が入力を書き換えたときの出力を `{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "allow", "permissionDecisionReason": …, "updatedInput": {…}}}` にする。

- `permissionDecision` は `allow` にする。フックの `matcher` は `mcp__plugin_mindstella_mindstella__.*` で、mindstella の MCP のツールだけに当たる。自分の MCP のツールの入力に値を追加するだけのフックを `allow` にするのは、knowledge の規約『フック作成ガイド』（`claude-hook` の `pretooluse-output-01`・`pretooluse-output-02`）の決まり
- 読めない入力で何も出さずに終える振る舞いは変えない
- 単体テストと結合テストで、出力に `permissionDecision` が `allow` で入ることを確かめる
- プラグインの PreToolUse のフックは `inject_session.py` の 1 つだけで、ほかに `permissionDecision` を付けるフックは無い（`hooks/hooks.json`）
