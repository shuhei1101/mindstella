## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| フックの出力 | `hookSpecificOutput` に `permissionDecision: "allow"` と `permissionDecisionReason` を `updatedInput` と並べて入れる | 読めない入力では従来どおり何も出さない |

| 既存機能への影響 | `updatedInput` の中身（`session` の値）は変えない | - |
