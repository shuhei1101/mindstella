## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 削除機能 | 項目を ID で指して消す・取り下げるツールを足し、`MCPサーバーの起動` のツールの一覧に載せる。消すときは種類の YAML から項目を、`docs/` から本文の Markdown を同じ書き込みで消す | 取り下げは `update` で、状態を持たない 5 種類は `withdrawn: true` と `reason` を書く |
| 参照切れ | ほかの項目・納品物・コメント・送信が指している項目は消さずにエラーにし、指している側の ID とキーを返す | - |
| 履歴・監査 | 消した項目を `changes.yaml` の `pending`・`sets` の `removed`（ID・種類・消したときのタイトル）に記録し、`changes_since_read`・`pending` が `removed` で返す。消すことも通し番号を 1 つ進める | - |
| ID の振り方 | 消した項目の ID を、後から足す項目に振らない | 連番の最大を、今ある項目と `changes.yaml` の `removed` の ID から取る |
| まとめての読み書き | `batch` には消す操作を足さない | 消す前に利用者に確かめるため、`remove` を単独で呼ぶ |
| 点検 | 過去のまとまりが消した項目の ID を持っていても参照切れにしない | - |
| エラー返却 | 無い ID・参照されている項目を指したときは、今のツールと同じ `エラー: {内容}` で返し、どのファイルも書き換えない | - |
| 既存機能への影響 | `changes.yaml` に足すキーは任意にし、今の版のワークスペースを移し替えなしで読む | - |
