# 要件

## 要望

話し合いの途中で、AI が検討事項・タスク・調査・資料・用語集・メモ・会話ログの項目を、MCP のツールで消す・取り下げられるようにする。
消した・取り下げた項目は、前回読んだ時点からの差分・まだまとめていない変更・書き換えのまとまりに出し、他の項目からの参照を切ったままにしない。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| 対象の種類 | 検討事項・タスク・調査・資料・用語集・メモ・会話ログの 7 種類すべての項目を、ID で指して消す・取り下げる |
| 消すか取り下げるか | やめた項目は取り下げで残す（検討事項は状態 `取り下げ`・`対象外`、タスクは状態 `中止`、状態を持たない調査・資料・用語集・メモ・会話ログは取り下げの印）。誤って足した・重複した項目だけを消すツールで消し、消す前に AI が消す項目を示して利用者に確かめる |
| 差分・まとめへの出し方 | 消した・取り下げた項目を、前回読んだ時点からの差分（`changes_since_read`）・まだまとめていない変更（`pending`）・書き換えのまとまり（`commit` の `sets`）で、足した・変えた項目と見分けて返す。`changes.yaml` の `pending` と `sets` に任意のキー `removed`（消した項目の ID・種類・消したときのタイトル）を足し、`changes_since_read`・`pending` も `removed` を返す |
| 参照切れ | 消した項目を、他の項目の `parent`・`depends_on`・`for`・`sources`・`related`、納品物の `doc`、コメント・送信の向け先が指したまま残さない。指されている項目は消さずにエラーにし、指している側の ID とキーを返す（付け替えるか外すかは内容で決まるため、AI が先に直す） |
| 消した項目の ID | 消した項目の ID を、後から足す項目に振り直さない |
| 点検 | 消した後のワークスペースで、点検（`check`）が消した項目について問題を返さない（過去のまとまりが消した項目の ID を持っていても参照切れにしない） |
| 話し合いの進行 | 話し合いの進行のスキルは、利用者がやめる・消すと言ったときにこのツールを使う。取り込みのステップの「項目は消さない」を、決めた扱いに合わせて書き直す |
| 既存のワークスペース | 今の版のワークスペースは、移し替えなしでそのまま読み書きできる |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 利用者が画面から項目を削除・取り下げる | 画面から書き込む口を作る Issue で扱う。この PR で決めた消し方・差分の出し方に乗せる | [#48](https://github.com/shuhei1101/mindstella/issues/48) |
| プレビューの変更履歴・前回からの差分の画面に消した項目を出し、取り下げた調査・資料・用語集・メモ・会話ログに取り下げの印を出す | 判断が分かれる。今の判断は含めない（要望は AI が MCP のツールで消す・取り下げることで、画面の見た目を変えない。消した項目の記録と取り下げの印はこの PR で入るため、画面に出すのはその後になる） | [#174](https://github.com/shuhei1101/mindstella/issues/174) |
| まとめての読み書き（`batch`）で項目を消す | 消す前に利用者に確かめるため、`remove` を単独で呼ぶ。今は要らない | 予定なし |
| 消した項目を戻すツール | 要望に含まれない。戻したい記録は消さずに取り下げる | 予定なし |
