## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 一括操作 | 状態の印の帯の一番右に文字の無いチェックの箱を 1 つ置き、空か横棒なら全ての状態を表示、チェックなら全て非表示にしてマップを描き直す | - |
| 状態表示 | 箱は全部表示でチェック、一部で横棒（`indeterminate`）、全部非表示で空。押した後、各状態のチェックボックスを表示 / 非表示の結果に揃える | - |
| 状態表示 | 全ての状態を隠したとき、マップの枠と字下げの一覧の両方に「表示する状態の検討事項はありません」を出す | - |
| 既存機能への影響 | 1 つずつのチェックボックスでの切り替えと、キーワードに当たった件数のバッジは今のまま残す | - |
| アクセシビリティ | 箱はネイティブの checkbox で、見える文字を持たないため、まとめて切り替える旨の名前を `aria-label` で持たせる | - |
| アクセシビリティ | 箱の横棒もチェックと同じく `border` で描き、ハイコントラスト（`forced-colors: active`）でも横棒と空を見分けられるようにする | - |
| 状態表示 | 箱は背景を透過にし、枠と記号（チェック・横棒）だけで描く | - |
| 一括操作 | つながりの項目の種類の並びの一番右にも同じ箱を置き、全ての種類の表示 / 非表示をまとめて切り替える | - |
| 状態表示 | つながりで全ての種類を隠したとき、枠の中央に「表示する種類の項目はありません」を出す | - |
| 状態表示 | 箱の枠と記号は状態の印と同じ細さにし、箱の枠の色はチップの枠と同じにする。チェックの記号を箱の中心に置く | ユーザーの判断で、箱の枠と背景のコントラストは 3:1 に届かない |
| 状態表示 | つながりの項目の種類のチップの枠と、表示中・非表示の見た目を、検討事項の状態の印と同じにする | - |
| 状態表示 | 両画面とも、非表示のチップの枠を点線にする（色の濃さは今のまま） | - |
| 単体テスト | `core/dom.ts` に `toggleAllState`（箱の状態）と `toggleAllBox`（箱を作る）を足し、`test_toggle_all_state`・`test_toggle_all_box` を `tests/unit/preview/test_dom.py` に足す。条件と期待値は設計書『基盤.ts』の各関数の補足にある | 書くツールがまだ無いテスト関数の名前を弾くため（[shuhei1101/ai-monitor#2169](https://github.com/shuhei1101/ai-monitor/issues/2169)）、単体テストの表への行はテスト照合で足す |
