# 要件

## 要望

検討事項のマップの状態の印の帯の一番右に、文字を添えないチェックの箱を 1 つ置く。
箱は、帯に並ぶ全ての状態を表示しているときはチェック、一部のときは横棒、全て隠しているときは空にする。
空か横棒のときに押すと全ての状態の項目をマップに出し、チェックのときに押すと全て隠す。
押した後の各状態のチェックボックスは、表示 / 非表示の結果と一致させる。
全ての状態を隠したときは、広い幅のマップの枠と狭い幅の字下げの一覧の両方に「表示する状態の検討事項はありません」を出す。
箱は背景を透過にし、枠と記号（チェック・横棒）だけで描く。
つながりの画面の項目の種類の並びにも、同じ箱を一番右に置き、全ての種類の表示 / 非表示をまとめて切り替える。
つながりで全ての種類を隠したときは、枠の中央に「表示する種類の項目はありません」を出す。
箱の枠と記号は、状態の印と同じ細さにそろえ、箱の枠の色はチップの枠と同じにする（ユーザーの判断。背景とのコントラストは 3:1 に届かない）。チェックの記号は箱の中心に置く。
つながりの項目の種類のチップは、枠と、表示中・非表示の見た目を検討事項の状態の印にそろえる。
両画面とも、非表示のチップの枠は点線にして、表示中と見分けやすくする（色の濃さは今のまま）。
