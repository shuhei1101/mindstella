# 検討事項のマップの状態の印に、状態をまとめて切り替えるチェックの箱を置く

## 概要

プレビューの検討事項のマップで、利用者が状態の印の表示 / 非表示をまとめて切り替えられるようになる。

## 背景

[Issue #34](https://github.com/shuhei1101/mindmap/issues/34) の要望。
[PR #21](https://github.com/shuhei1101/mindmap/pull/21) のモックを見てもらったときの[ご指摘](https://github.com/shuhei1101/mindmap/pull/21#discussion_r4163773519)で、#21 のスコープ外にしていた。
今の状態の印は状態ごとのチェックボックスだけで、全ての状態を出す・隠すには 1 つずつ押す必要がある。
