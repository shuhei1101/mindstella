## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 件数の数え方 | レビュー中のコメントを `target` ごとに数え、項目の ID → 件数の対応を作る。`target` が `null` のコメントは数えず、件数 0 の項目は対応に入れない | モジュール構成『入口』の `commentCounts`。単体テストは `tests/unit/preview/test_app.py` |
| 画面への渡し方 | 差分の印（`marks`）と同じく、件数の対応を検討事項・タスク・資料・記録の表・つながりの各画面へ渡す。サーバーにつながらないで開いたとき・配る書き出しでは渡さない | - |
| 描き替え | コメントを溜める・直す・消す・戻す・送ったあと、件数の対応が変わったときだけ印を描き替える。スクロールの位置・マップの拡大と位置・つながりの視点は保つ | `refreshCommentMarks`（印を置く場所 `data-comment-target` ごとに差し替える）・`setGraphComments` |
| 部品 | 吹き出しの印と件数を出す部品『コメントの印』を新しく置き、ボード・カード・マップ・字下げの一覧・表から使う。読み上げの名前は「コメント {件数} 件」 | 部品設計『コメントの印』を新規。単体テストは `tests/unit/preview/test_comment_mark.py` を新しく作る |
| 表 | 表の部品に、項目の ID → 件数の引数 `comments` を足し、タイトルの列の差分の印の隣に印を置く | 部品設計『表』の `comments` |
| つながり | 名前が読める大きさ（文字 8px 以上）で描いた玉のうちコメントのある玉に、名前の右へ印を出す。遠いときは何も出さず、名前と印が描く枠に収まらない玉には出さない | 画面設計『つながり』の要素『名前の横のコメントの印』 |
| 操作 | 印だけを押す操作は足さず、カード・行・節点・玉を押したときに詳細パネルを開く動きを変えない | - |
| レスポンシブ対応 | 幅 390px でも、印が差分の印と項目のタイトルを隠さない | 非機能要件『画面サイズ』 |
| 既存機能への影響 | トップバーのコメントのボタンの総数・詳細パネルのコメントは変えない | - |
