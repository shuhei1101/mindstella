## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 図の拡大（#152） | 「本文へ戻る」のボタンを削除し、図の拡大の外側（後ろのグレーアウト）を押すと閉じて開いた元へ戻す。Esc で閉じる操作は残す。枠を今より一回り大きくする | 大きさはモック作成で決める |
| 差分の表示中のリンク（#154） | 今の差分の表示（mdmark の「原文の差分」を含む）で再現を確認し、差分の表示中も用語のマーカー・項目の ID のリンクとツールチップを付ける | 原因は設計の工程で特定する |
| 案のカード（#161） | 記号を左上の丸いアイコン、推奨・採用・不採用をバッジにし、推奨の案の `reason` をそのカードの一番下の「推奨理由」の欄に出す。一覧の下には出さない | - |
| 変更履歴のボタン（#184） | 過去の差分を表示している間はボタンの右上にオレンジの点を付け、`DiffChip`（選んだ履歴のマーカー・タイトル）の代わりに差分の表示をやめる × だけを置く。日時も出さない | 読み上げの名前は「変更履歴（過去の差分を表示中）」 |
| ファビコン（#192） | brand-mark と同じ図柄の SVG を、配信の HTML と配る書き出しの HTML に `<link rel="icon">` で付ける。SVG の中で `prefers-color-scheme` を参照して色を切り替える | - |
| コピーのボタンの文言（#351） | `mount` と資料の 1 枚の HTML の起動のスクリプトに設定 `labels.paramCopy` を指定し、`relabelParamCopy` と同じ書き換えを削除する | - |
| スレッドの ID のリンク（#426） | 本文と書き込みの本文の `TH-{数字}` をスレッドを開くリンク、`TH-{数字}-{数字}` をその書き込みまでスクロールするリンクにする。記録に無い ID は文字のまま | - |
| 保留のバー（#635） | トップバーの下の「更新があります」のバーを削除し、入力中の反映の保留と入力欄から離れたときの反映は残す | - |
| 書体（#637） | 文字のトークンの書体を IBM Plex Sans JP にし、デザイン方針・Google Fonts の読み込みを合わせる | - |
| アクセシビリティ | 外側を押して閉じる図の拡大も Esc とフォーカスの戻りを保つ。バッジ・ボタンの色の変化は文字のコントラストを保ち、色だけで状態を伝えない（読み上げの名前に状態を入れる） | - |
