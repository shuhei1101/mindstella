| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ミニマップが出ないことの検証 | `test_normal_when_minimap_jump` の A-2 の検証を、詳細パネルの `.df-map` が見えないこと（要素が無いか、あっても見えない）に替える | 他の `.df-map` の `count() == 0` は差分の表示から抜けて要素が外れた後の検証で、変えない |
