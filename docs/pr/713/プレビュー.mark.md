### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 横スクロール | ページ・パネル・ペインの区画は `min-width: 0` で中身の幅に引っ張られないようにし、横スクロールは mdmark の表・コードブロックの部品の中だけで発生させる | どの画面も `document.documentElement.scrollWidth` が窓の幅を超えない |
| 文字 | 書き込み・タイトル・値の文字はペインの幅で折り返し（改行の無い長い URL も `overflow-wrap: anywhere` で折り返す） | 省略する箇所は全文を参照する手段を持たせる |
| マーカー | 「新規スレッド」「レビュー中」などのマーカー・札は `white-space: nowrap` と `flex: none` で折り返さない | - |
| 見直し | 横幅の共通の決まりをモジュール構成『React』の補足「横幅」に 1 か所だけ記載し、画面設計の 17 画面の全てに適用する。各画面設計・部品設計の補足には、その画面だけの例外と確認する場面だけを記載する | スレッド 1 件の見出しは #707 |
| 確認の場面 | 3000 文字を超える書き込み・改行の無い長い URL・スレッド 100 件・1 スレッドの書き込み 50 件・多いレビュー中の書き込み・列が多い表・幅 360px・最も狭めたパネルの場面を作り、実装の後のコードで撮影する | 場面の作り方は [shuhei1101/ai-monitor#3066](https://github.com/shuhei1101/ai-monitor/issues/3066) の手順 |
| 既存機能への影響 | 表の列の幅の変更・ピン止め・並べ替えなど mdmark の表の機能は変えない | - |
