### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 共通の部品 | 幅の区切りを `side`（`left` / `right`）を持つ共通の部品にし、`left` はポインターが左へ動くと広げ、`right` は右へ動くと広げる。矢印キーも向きに合わせる | ドラッグの間はルートの変数を書き換えず、離したときだけ端末に残す（#354 の作り） |
| コメントの一覧 | パネルの右端に `side: right` の区切りを配置し、スレッドの一覧・スレッド・レビュー中の書き込みで同じ幅を使用する | 幅 900px 以下は今のとおり全幅で区切りを出さない |
| 幅の決まり | 下限・既定・キーの 1 回の幅は部品設計で値を決める。上限は両方を開いたときも本文に残す幅を保つ | `未確定`（要件の 2 つの論点） |
| 保存 | 変えた幅を端末の保存領域に残し、開き直したときにその幅で出す | 詳細パネルの幅と同じ保存領域の決まりに合わせる |
| アクセシビリティ | `role="separator"`・`aria-orientation`・`aria-valuenow`・`aria-valuemin`・`aria-valuemax`・`aria-label` を向きごとに持ち、フォーカスで矢印キーを受ける | 指の端末は 44px のタップ領域 |
| 既存機能への影響 | 詳細パネルの区切りの振る舞い・値・保存は変えない | 単体テスト・結合テストで回帰を確認する |

### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 横スクロール | ページ・パネル・ペインの区画は `min-width: 0` で中身の幅に引っ張られないようにし、横スクロールは mdmark の表・コードブロックの部品の中だけで発生させる | どの画面も `document.documentElement.scrollWidth` が窓の幅を超えない |
| 文字 | 書き込み・タイトル・値の文字はペインの幅で折り返し（改行の無い長い URL も `overflow-wrap: anywhere` で折り返す） | 省略する箇所は全文を参照する手段を持たせる |
| マーカー | 「新規スレッド」「レビュー中」などのマーカー・札は `white-space: nowrap` と `flex: none` で折り返さない | - |
| 見直し | 画面設計の 17 画面の横幅の指定を見直し、画面ごとに横幅の決まりを画面設計へ記載する | スレッド 1 件の見出しは #707 |
| 確認の場面 | 3000 文字を超える書き込み・改行の無い長い URL・スレッド 100 件・1 スレッドの書き込み 50 件・多いレビュー中の書き込み・列が多い表・幅 360px・最も狭めたパネルの場面を作り、実装の後のコードで撮影する | 場面の作り方は [shuhei1101/ai-monitor#3066](https://github.com/shuhei1101/ai-monitor/issues/3066) の手順 |
| 既存機能への影響 | 表の列の幅の変更・ピン止め・並べ替えなど mdmark の表の機能は変えない | - |
