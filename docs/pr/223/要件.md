# 要件

## 要望

プレビューの表（検討事項・タスク・資料の表と、調査・用語集・メモ・会話ログの表）で、表に出す列を選ぶボタンの文言を UI として自然な言い方にし、表から離した位置に置く。

| 項目 | 要件 |
| --- | --- |
| ボタンの文言 | 「表示する列」をやめ、列のアイコンと「列の表示」にする。ボタンの読み上げ名とポップオーバーの題も「列の表示」にする |
| ボタンの置き場所 | 表の上の、条件のチップの行の右端に置き、行と表の間に 12px の余白を取る |
| 列の選びの動き | ポップオーバーで列を付け外しする・タイトルの列を外せない・「列・並べ替え・固定を初期設定に戻す」・端末に残す、の今の動きは変えない |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| ポップオーバーの「列・並べ替え・固定を初期設定に戻す」の文言 | 要望はボタンの文言と置き場所。ポップオーバーの中の操作は変えない | 予定なし |
| 表に作成日時・更新日時の列を足す | 同じ部品『表』を触る別の要望 | [#186](https://github.com/shuhei1101/mindstella/issues/186) |
| 図の拡大のテスト `test_raw_scroll_by_keyboard`（`tests/integration/preview/test_diagram_viewer_screen.py`）が同じコードで fail と pass に分かれる | テストが決定的でない不具合で、変更前から起きている。表のボタンの要望に含まれない | [#225](https://github.com/shuhei1101/mindstella/issues/225) |
