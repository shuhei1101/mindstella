# 要件

## 要望

origin/develop の `docs/pr/` の下にある作業 PR の撮影画像を、`git rm` の commit で削除する。

| パス | 件数 | 容量 |
| --- | --- | --- |
| `docs/pr/*/スクリーンショット/` | 3451 件 | 約 369MB |
| `docs/pr/*/ストーリー/` | 556 件 | 約 12MB |
| `docs/pr/*/画面/` | 161 件 | 約 11MB |

- 履歴は書き換えない
- 削除した後、作業ブランチの `git ls-tree -r HEAD docs/pr` に画像（`.png`・`.jpg`・`.jpeg`・`.gif`・`.webp`）が 0 件になる
- 削除する画像を指すリンクはリポジトリに無いため、他のファイルは変えない
