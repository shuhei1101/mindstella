# 無操作の上限を過ぎた MindStella のセッションを常駐サーバーが止めてアカウントを返却し、次のコメントで起動し直す

## 概要

利用者が数日返事をしない間も claude-balancer のアカウントを借り続けず、戻ってコメントを送信すれば同じ会話の続きから話し合いを再開できるようになる。

## 背景

[Issue #521](https://github.com/shuhei1101/mindstella/issues/521) の要望（[#481](https://github.com/shuhei1101/mindstella/issues/481) の子。資料 A-107 の「シナリオを作る順」の No 6）。

- MindStella のセッションは利用者の返事を数日待つことがあり、その間も claude-balancer のアカウントを借り続ける
- 資料 A-119 は「無操作の上限（設定値）を過ぎたら MindStella のセッションを止めてアカウントを返却する。クローズ待ちにはせず、コメントが届いたら前の会話を引き継いで起動し直す」と決めたが、未実装
- 落ちた・止まった後にコメントが届いたときの起動し直しは [#520](https://github.com/shuhei1101/mindstella/issues/520)（PR [#582](https://github.com/shuhei1101/mindstella/pull/582)）で入った。クローズ待ちでない停止済みの MindStella のセッションは、コメントの契機で起動し直す
- 単一ユースケース『MindStella のセッションを止めてワークスペースをクローズにする』は、無操作の上限での停止を #521 のスコープ外にしている
