## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ユースケース | 単一ユースケース『無操作の上限で MindStella のセッションを止める』を新規作成する（止めた後のコメントで起動し直すまで）。『MindStella のセッションを止めてワークスペースをクローズにする』のスコープ外の記載と、『止まったことを通知する』の止まった理由を合わせる | 停止までの流れは『MindStella のセッションを止めてワークスペースをクローズにする』と同じ |
| 最後の出来事の時刻 | 起動・応答の始まり・応答の終わり・コメントをペインへ貼ったときに、`session.json` の最後の出来事の時刻を進める | ER 図『常駐サーバーの状態』 |
| 見回り | 落ちたことの見回りと同じ間隔で、`running` で応答の途中でなく、最後の出来事から上限を過ぎた MindStella のセッションを止める | 起動し直しの途中・停止の途中は対象外 |
| 止め方 | 停止と同じく、まとめていない変更を commit させてから `/exit` を貼って止める。クローズ待ちにしない | 止めた後のコメントは、既存のコメントの契機の起動し直しで前の会話を引き継ぐ |
| 止まった理由 | 『停止の通知』に止まった理由 `idle_timeout`（無操作の上限）を追加し、『MindStella のセッションの一覧』で止まった理由を返却する | 一覧のキーはインターフェース定義設計で決める |
| 設定 | 無操作の上限の設定と既定値を追加する | `要件.md` の `未確定` |
| 公開ドキュメント | コマンドのリファレンス（環境変数）・話し合いを続きから再開する手順・Discord に通知する手順（止まった理由）を更新する | - |
