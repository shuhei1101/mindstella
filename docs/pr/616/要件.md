# 要件

## 要望

MindStella のセッションが使用中のアカウントの利用枠が、しきい値以上になったら、利用上限のエラーを待たずに、利用上限と同じ流れ（止める → 別のアカウントを借りる → Claude Code の `session_id` で会話を引き継ぐ）で起動し直す。

- しきい値は 5 時間枠 95 % 以上・週次枠 99 % 以上で、claude-balancer の貸与のしきい値（設定 `lease.five_hour_threshold`・`lease.seven_day_threshold`）を原本にする。MindStella に同じ値を持たない
- 常駐サーバーが、起動中の MindStella のセッションが使用中のアカウントの利用枠を、claude-balancer の `GET /accounts`（IF-275-12）で一定の間隔で確かめる。しきい値以上は、貸せない理由（`unavailableReason`）がしきい値以上を表す値かで見分ける
- 応答の途中なら、応答の終わり（Stop のフック）を待ってから止める
- 起動し直しでは、しきい値以上のアカウントを除いて借りる。空いたアカウントが無いときは、止めずに今のアカウントで続ける
- 止めたときは『停止の通知』を、利用上限と見分けられる止まった理由で呼ぶ
- 利用者がしきい値を超えた後も使い続けて Claude Code が利用上限のエラーを返したときは、今の利用上限の契機（PR [#582](https://github.com/shuhei1101/mindstella/pull/582)）のまま起動し直す
- アカウントを指定して起動した MindStella のセッションは、起動し直しても指定したアカウントを使い続ける。指定したアカウントが利用上限に達した・利用枠がしきい値以上になったときは、指定を解除して自動で選んだアカウントへ切り替え、以降はアカウントを指定しないセッションとして扱う
  - 解除するかは mindstella のホームの設定 `~/.config/mindstella/settings.yaml` でオンオフでき、既定はオン。オフのときはどの契機でも指定したアカウントのまま続け、しきい値では切り替えず、利用上限では止めたままにして利用上限で止まったことを通知する
- claude-balancer の待ち受け先は、同じホームの設定の `claude_balancer.url`（既定 `http://127.0.0.1:8770`）に置き、MindStella のセッションのペインにも `CLAUDE_BALANCER_URL` で指定する
- 使用中のアカウントは、claude-balancer の `exec` が子プロセスの `OTEL_RESOURCE_ATTRIBUTES` に入れる `claude_balancer.account` を SessionStart のフックが状態に記録し、`GET /accounts` の `account` と照らす（インターフェース定義設計で決定。claude-balancer の設定のファイルの書式に依存せず、claude-balancer の変更も要らない）
- 確かめる間隔は 60 秒（非機能要件『利用枠を見回る間隔』）
