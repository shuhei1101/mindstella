# 要件

## 要望

MindStella のセッションが使用中のアカウントの利用枠が、しきい値以上になったら、利用上限のエラーを待たずに、利用上限と同じ流れ（止める → 別のアカウントを借りる → Claude Code の `session_id` で会話を引き継ぐ）で起動し直す。

- しきい値は 5 時間枠 95 % 以上・週次枠 99 % 以上で、claude-balancer の貸与のしきい値（設定 `lease.five_hour_threshold`・`lease.seven_day_threshold`）を原本にする。MindStella に同じ値を持たない
- 常駐サーバーが、起動中の MindStella のセッションが使用中のアカウントの利用枠を、claude-balancer の `GET /accounts`（IF-275-12）で一定の間隔で確かめる。しきい値以上は、貸せない理由（`unavailableReason`）がしきい値以上を表す値かで見分ける
- 応答の途中なら、応答の終わり（Stop のフック）を待ってから止める
- 起動し直しでは、しきい値以上のアカウントを除いて借りる。空いたアカウントが無いときは、止めずに今のアカウントで続ける
- 止めたときは『停止の通知』を、利用上限と見分けられる止まった理由で呼ぶ
- 利用者がしきい値を超えた後も使い続けて Claude Code が利用上限のエラーを返したときは、今の利用上限の契機（PR [#582](https://github.com/shuhei1101/mindstella/pull/582)）のまま起動し直す

`未確定`: claude-balancer の待ち受けの読み方と、使用中のアカウントを `GET /accounts` の行に当てる方法（決める段: データ設計・インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | claude-balancer の設定のファイルの `port` と、アカウントの設定のフォルダを読み、`session.json` の `claude_config_dir` からアカウント名を引く | MindStella の設定を増やさない | claude-balancer の設定のファイルの書式に依存する |
| B | claude-balancer に、設定のフォルダか会話の ID で貸与中のアカウントの消費率を返す API を起票して待つ | 書式に依存しない | claude-balancer の対応を待つため、急ぎの着手が遅れる |

推奨: A

`GET /accounts` と設定のファイルで足りれば、claude-balancer の対応を待たずに入れられる。書式への依存は、インターフェース定義設計で claude-balancer の公開の設定の文書を参照して確かめる。

`未確定`: 確かめる間隔（決める段: インターフェース定義設計。非機能要件に決定値を置く）
