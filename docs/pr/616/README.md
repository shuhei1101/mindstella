# MindStella のセッションが使用中のアカウントの利用枠がしきい値以上になったら、利用上限のエラーを待たずに別のアカウントへ切り替えて会話を引き継ぐ

## 概要

利用者が、MindStella のセッションが使用中のアカウントの利用枠を使い切る前に別のアカウントへ切り替わり、利用上限で応答が途中で止まらずに話し合いを続けられるようになる。

## 背景

[Issue #588](https://github.com/shuhei1101/mindstella/issues/588) の要望（利用者の指定で急ぎ）。[#520](https://github.com/shuhei1101/mindstella/issues/520)（PR [#582](https://github.com/shuhei1101/mindstella/pull/582)）の続き。

- MindStella のセッションを起動する・起動し直すときは、claude-balancer が 5 時間枠 95 % 以上・週次枠 99 % 以上のアカウントを貸す候補から除く
- 動いている間に借りたアカウントがしきい値以上になっても、同じアカウントで続ける。Claude Code が利用上限のエラーを返してから止め、別のアカウントで会話を引き継ぐため、利用上限に当たった応答は途中で止まる
- 2026-11-18 に、話し合いのワークスペースで MindStella のセッションが利用上限で途中で止まった（話し合いのスレッド TH-1237）
