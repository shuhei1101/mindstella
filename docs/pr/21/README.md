# プレビューの画面（概要・検討事項・タスク・資料・つながり・詳細パネル）を見本に沿って作る

## 概要

利用者が、`build` の書き出した 1 枚の HTML を開くだけで、話し合いの記録を概要・マップ・ボード・表・つながり（3D）・詳細パネルで読み返せるようになる。
画面は、ユーザーと触りながら決めた見本に沿って作る。

## 背景

[Issue #5](https://github.com/shuhei1101/mindmap/issues/5) の要望。
[#11](https://github.com/shuhei1101/mindmap/pull/11) で `build` が記録の JSON を雛形 `skills/mindmap/preview/template.html` に埋め込んで `preview.html` を書き出すところまでを作り、雛形は種類ごとの件数を並べるだけにして、画面の中身をこの PR に渡した。
[#10](https://github.com/shuhei1101/mindmap/issues/10)・[#13](https://github.com/shuhei1101/mindmap/issues/13) で出た画面の要望のうち、Issue #5 へ移したものを含む。
見本はローカルの `tmp/preview-mock/`（git の外）にある。
