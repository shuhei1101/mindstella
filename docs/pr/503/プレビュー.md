## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 一覧へ戻った後のフォーカス | `backToList` で戻す先のスレッドの ID を ref の印として持ち、一覧を描き直した後の effect で印を 1 回だけ見る。開いていた行が描かれていればフォーカスを移し、描かれていなくても（絞り込みがオープンのままクローズにしたスレッドから戻った 等）印を消す。行が無いときはフォーカスを移さない | `requestAnimationFrame` は使わない。印を消す箇所を effect の 1 か所にし、後で行が描かれたときにフォーカスが移らないようにする |
| 単体テスト | `test_comments_panel_when_back_focus` を追加する。スレッドを開いた状態から一覧へ戻り、描き直しより先に次のコマが来る（`vi.stubGlobal` で `requestAnimationFrame` を差し替える）条件で、開いていた行にフォーカスがあることを確かめる。`test_comments_panel_when_back_without_row` を追加する。絞り込みがオープンのまま、クローズにしたスレッドから一覧へ戻り、その後「クローズ」へ切り替えても、フォーカスが絞り込みのボタンから動かないことを確かめる | モジュール構成 `MOD-489-5.tsx.yaml` にケースを追加する |
| 結合テスト | `test_back` を変えずに実行し、`requestAnimationFrame` をマイクロタスクで走らせる差し替えでも pass することを確かめる | - |
