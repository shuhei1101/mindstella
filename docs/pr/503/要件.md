# 要件

## 要望

スレッドから「一覧へ戻る」または入力欄の外の Esc で一覧へ戻ったとき、一覧の描き直しより先に次のコマが来ても、開いていた行（`[data-focus="thread:{id}"]`、溜めた新しいスレッドは `[data-focus="thread:new:{id}"]`）にフォーカスを戻す。

- 画面設計『スレッド.tsx』の「一覧へ戻る」の振る舞い（開いていた行へフォーカスを戻す）は変えない
- 直したことは、`requestAnimationFrame` をマイクロタスクで走らせる差し替えの下で、単体テストと結合テスト `test_spa_thread_screen.py::test_back` が pass することで確認する
- `frontend/src/` で `requestAnimationFrame` の中でフォーカスを移す箇所はこの 1 か所だけ（`thread-view.tsx` は PR #496 で修正済み）
