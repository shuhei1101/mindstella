## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| パネルの幅の上限（#725） | `detailPanelMax`・`leftPanelMax` を「表示の幅 × 2/3」（下限を下回るときは下限）の 1 つの式にし、`keepBody`・相手のパネルの幅を引かない | 幅 900px 以下の扱い（画面いっぱい）は変えない。幅を残すキーと値の形式は変えない |
| パネルの重なり順（#725） | 幅 1100px 以上で両方を開いて重なるとき、左のパネルを詳細パネルより上の重なり順にする。本文を詰める決まりは今のまま | 下になった部分は、利用者が左のパネルを閉じて参照する。左のパネルの部品と幅を共有する保存待ちのパネル・表示の設定も同じ上限と重なり順にする |
| 全画面のモーダル（#728） | モーダルを窓の幅と高さの 90%（上下左右 5%）にし、幅の上限を除外する | 画面設計『詳細の全画面』の 32px・1600px を書き換える。幅 720px 以下の扱いは画面設計で決める |
| コメントの件数のバッジ（#724） | 詳細パネル・詳細の全画面の「コメント」のタブのラベルの右と、ヘッダーのコメントのボタンのアイコンの右上に、その項目に向けたスレッドの数のバッジを出す。0 件のときは出さない | 読み上げの名前に件数を含める |
| ボタンの中の ID（#726） | スレッドの行で記録の文字のツールチップを出さない指定を部品『記録の文字』に追加し、行のボタンのフォーカスでも出さない | ほかの `marker` の呼び出し元は今のまま |
| 外部の URL（#708） | 描いた本文と記録の文字で、別のオリジンを指す `a` 要素に `target="_blank"`・`rel="noopener noreferrer"` を付ける | 埋め込んだ HTML（`html-frame.ts`）は今の `window.open` のまま |
| mdmark の機能（#710） | `MDMARK_FEATURES`・`MDMARK_EXPORT_FEATURES` を、MindStella の画面と重なる機能だけのオフにする（`syntax`・コードブロックのバーと行の部品はオン） | オフに残す機能ごとの理由を外部ライブラリ『mdmark』に記載する |
| 本文の区切りの間（#729） | `div.md-section-body` の直下のブロック同士に `--mdmark-space` の上の間を付ける規則を本文のスタイルに追加する | mdmark の `.mdmark-section-body > * + *` と同じ値 |
| 表示の設定のパネル（#715） | 幅 900px 以下の本文の領域の左右の余白を広げる | 値は `detect_screen_issues` で検出が消える幅を確認して決める |
| 列の幅のつまみ（#714） | ストーリー `MdmarkTable` で再現と原因の切り分けをし、mdmark の側なら shuhei1101/mdmark へ起票して依存に加える | mindstella の側なら mindstella で修正する |
| 結合テスト（#716・#717） | `test_diff_source` を欄が描かれない期待値にする。`test_normal_when_records_changed_while_typing` は結合テストで pass を確認する | - |
| アクセシビリティ | バッジの件数を読み上げの名前に含め、重なったときもフォーカスの順を変えない | - |
| レスポンシブ対応 | 幅 390px・768px・1280px で、バッジ・全画面のモーダル・表示の設定のパネルがはみ出さない | - |
