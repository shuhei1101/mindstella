# 幅 480px 以下でも、トップバーの全てのボタンの押せる的を 24px 以上に保つ

## 概要

プレビューの利用者が、幅 320〜480px の端末でも、トップバーの表示の設定・絞り込み・コメントのボタンを押し損ねずに押せるようにする。

## 背景

[Issue #291](https://github.com/shuhei1101/mindstella/issues/291) の報告。
幅 389px 以下で、件数の札を持たない表示の設定・絞り込みのボタンが幅 22px・間隔 1px まで縮み、押せる的が 24px 未満になる（axe の `target-size`、WCAG 2.2 の 2.5.8）。
この規則は [PR #263](https://github.com/shuhei1101/mindstella/pull/263)（起点 [#239](https://github.com/shuhei1101/mindstella/issues/239)）が幅 320px でトップバーを収めるために入れたもので、印だけのボタンは幅 28px に揃えたが、件数つきのボタンには幅の下限を置かなかった。
[PR #289](https://github.com/shuhei1101/mindstella/pull/289)（起点 [#269](https://github.com/shuhei1101/mindstella/issues/269)）のモック作成で、designer が 320 x 568 の崩れの検出で見つけた。
その後 develop に入った [PR #290](https://github.com/shuhei1101/mindstella/pull/290)（起点 [#270](https://github.com/shuhei1101/mindstella/issues/270)）が、幅 390〜480px に幅の下限の無い同じ詰め方を足したため、範囲を 480px まで広げた（[確認ログ](./確認ログ.md)）。
