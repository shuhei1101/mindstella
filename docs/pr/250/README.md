# 本文の印のツールチップの結合テスト test_body_alias_tooltip_scroll を毎回同じ結果にする

## 概要

本文の印のツールチップの結合テスト `test_body_alias_tooltip_scroll` が、同じコードなら毎回同じ結果になる。

## 背景

[#233](https://github.com/shuhei1101/mindstella/issues/233) の不具合。
[PR #214](https://github.com/shuhei1101/mindstella/pull/214) の E2E テスト作成で、implementer が結合テストの全実行で見つけた（[完了報告](https://github.com/shuhei1101/mindstella/pull/214#discussion_r4242165723)）。
develop（b7b24d13）単独で 8 回中 4 回 fail し、fail した回はツールチップが印の下（`gap` 6）でなく上（`gap` -382）に出ている。
本文を `scrollTop = 300` に送った直後に本文の上の要素の高さが変わって `scrollTop` が 297〜298 にずれると、印が本文の領域の上端に隠れ、`page.hover` が印を見える位置まで送り直して本文が先頭へ戻る。
