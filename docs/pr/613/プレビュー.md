## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 単一 UC | 『音声でコメントする』に、修正の入力欄で録音し、文字起こしの結果をカーソルの位置へ挿入して「修正」で確定する流れを記載する。『コメントを選んで送る』の修正の操作から参照する | 画面に無い間の結果とキャンセルの扱いは[要件](./要件.md)のとおり |
| インターフェース定義 | 『SPAを開く』『プレビューを開く』の制約「音声の入力」に、修正の入力欄を向けた先に加え、文字起こし後の挙動を挿入だけにする。『音声の文字起こし』『文字起こしの可否』の呼ぶ入力欄に修正の入力欄を加える | サーバーの API は変えない |
| 画面設計 | 『レビュー中の書き込み』『詳細パネル』（今の画面・React）の修正の入力欄に、マイクのボタン・録音中の波形と経過の時間・× と ✓ を追加する | 見た目はコメント・返信の入力欄と同じ部品を使用する |
| 部品設計 | 『スレッドの書き込み』（今の画面・React）のレビュー中の返信の修正に、同じ要素を追加する。『トップバー』の音声入力中の表示から修正の入力欄を開く | - |
| モジュール構成 | 今の画面の `reviewEditForm` と React の `ReviewEditForm` に音声の引数（`VoiceProps`）を追加し、呼び出し元から指定する。React の `VoiceDestination` と今の画面の音声入力の状態に、修正するレビュー中の書き込みを向けた先として追加する | - |
| 公開ドキュメント | 『プレビューを見る』の `### 音声でコメントする` に、修正の入力欄でも使えることと、結果を挿入だけにすることを記載する | - |
| 単体テスト | 修正の入力欄の音声の props、挿入だけにする扱い、同時に 1 つの判定を確認する | 今の画面と React の両方 |
| 結合テスト | レビュー中の書き込みの画面・詳細パネル・スレッドの修正の入力欄で、マイクのボタンから録音し、文字起こしの結果がカーソルの位置へ挿入されることを確認する | 今の画面と React の両方。実行範囲は実行の前に表にして確認を受ける |
