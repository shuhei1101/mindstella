# 書き込みを修正する入力欄でも、音声で入力できるようにする

## 概要

利用者が、レビュー中の書き込みを修正する入力欄でも、コメント・返信の入力欄と同じマイクのボタンで、音声を入力できるようになる。

## 背景

[Issue #533](https://github.com/shuhei1101/mindstella/issues/533) の要望。
コメント・返信の入力欄には、マイクのボタンがあり、音声を文字起こしして入力できる（[#476](https://github.com/shuhei1101/mindstella/pull/476)・[#500](https://github.com/shuhei1101/mindstella/pull/500)）。
レビュー中の書き込みを修正する入力欄（今の画面の `reviewEditForm`、React の `ReviewEditForm`）には、マイクのボタンが無い。
利用者は、キーボードではなく音声入力で操作しているため、修正のときだけ音声で入力できない。
