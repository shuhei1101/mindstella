## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ユースケース | 単一ユースケース『常駐サーバーの起動』を資料 A-107 の No 10・A-119・D-323 の流れで新規作成し、『常駐サーバーの起動と停止』から関連を張る | - |
| 状態の照合 | 待ち受けを始める前に、見回りの 1 回分（watch_crashes_once）を呼ぶ | 落ちたかの判定・鍵・通知は見回りと同じ |
| ID の一覧の作り直し | workspaces.yaml が無いときだけ、GET /settings/sources の行のうち config の末尾が /.mindstella/dev-docs.yaml の行の ID で作る | クローズした行も含める（IF-605-1） |
| エージェントフローの配信元 | 待ち受けを始めた後に別のスレッドで、mindstella-agent-flows の行の config が今のプラグインのパスと違えば、PATCH /settings/sources/{id} で書き換える | 行が無いときは足さない。待ち受けの前の project-index の呼び出しを ID の一覧が無いときの GET 1 回（上限 5 秒）に限る（IF-605-1） |
| エラー処理 | 3 つのどれが失敗しても起動を止めず、ログに 1 行記録して次へ進む | - |
