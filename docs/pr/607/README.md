# 録音中の波形の棒の幅を固定し、枠を埋めた後に棒が細くならないようにする

## 概要

利用者が、録音を始めてから終えるまで、同じ幅と間隔の棒で並ぶ波形を見られるようになる。

## 背景

[Issue #535](https://github.com/shuhei1101/mindstella/issues/535) の報告。
[PR #500](https://github.com/shuhei1101/mindstella/pull/500) で入れた録音中の波形は、右端から棒が増え、棒が枠の幅を埋める頃に全ての棒が細くなり、波形が圧縮されて見える。
棒のスタイルが今の画面の `.send-wave i`・React の `@utility wave-bar` とも `flex: 0 1 3px; min-inline-size: 2px;` で、棒の合計の幅が枠を超えると、はみ出す前に 3px から 2px へ縮むため。
