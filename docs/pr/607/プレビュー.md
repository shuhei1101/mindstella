## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 部品設計 | コメントの入力・返信の入力（今の画面・React）の録音中の波形に、録音を始めてから終えるまで棒の幅と間隔が変わらず、枠からはみ出した古い棒を左で切ることを書く。`RecordingNarrow` の `levels` を、波形の枠を超える 80 本にする | - |
| ストーリー | 録音中のストーリーのコメントを部品設計の状態の説明に合わせ、`RecordingNarrow` の `levels` を部品設計の 80 本にする | 今の画面と React の両方 |
| 棒のスタイル | 今の画面の `.send-wave i` と React の `@utility wave-bar` の棒を縮めず、幅 3px に固定する | 間隔（`gap: 2px`）と、古い棒を左で切る枠の `overflow: hidden`・`justify-content: flex-end` は変えない |
| 結合テスト | `RecordingNarrow` のストーリーで、棒の合計の幅が波形の枠を超え、表示されている全ての棒の描画の幅が `Recording` の棒と同じ 3px のままであることを確かめる | 今の画面と React の両方 |
