# 要件

## 要望

コメントの入力・返信の入力の録音中の波形で、録音を始めてから終えるまで、棒の幅（3px）と間隔（2px）を変えない。今の画面と React の画面の両方が対象。

- 棒の合計の幅が枠の幅を超えた後も、全ての棒の描画の幅が 3px のまま
- 枠からはみ出した古い棒は、今の設計のとおり左で切る（新しい棒は右端に足す）
