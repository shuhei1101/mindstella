# 要件

## 要望

プレビューの項目の ID のボタン（`.idlink`）から、押せる的の大きさの検出（`target-size`）をなくす。
見た目の方向（[デザイン方針](https://github.com/shuhei1101/mindmap/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%83%87%E3%82%B6%E3%82%A4%E3%83%B3%E6%96%B9%E9%87%9D.md)）は変えない。

| 検出 | 今の箇所 | 直した後の状態 |
| --- | --- | --- |
| `target-size` | [style.css](https://github.com/shuhei1101/mindmap/blob/develop/plugins/mindstella/skills/mindmap/preview/style.css) の `.idlink`（`padding: 0 4px; margin: 0 4px 2px 0; font-size: 11.5px;`）。検討事項の表の前提・タスクの表の進める検討事項・記録の表の関連の列と、詳細パネル・詳細の全画面の参照の一覧に並ぶ | ID のボタンの押せる的が縦横 24px 以上あるか、隣のボタンと 24px の円が重ならない間隔を持つ |

確かめ方: プレビューの ID のボタンを持つ画面（検討事項・タスク・記録の表の表、詳細パネル・詳細の全画面）を `detect_screen_issues` に 1280x800 と 390x844 でかけ、`target-size` の検出が 0 件。

押せる的の広げ方: `.idlink` の見えている枠そのものの高さと幅の下限を 24px（`--target-min`）にし、ID の文字を中央に置く（[確認ログ](./確認ログ.md)）。
