## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ID のボタンの押せる的 | `.idlink` の見えている枠そのものに `display: inline-flex`・中央揃え・`min-inline-size` / `min-block-size` を `--target-min`（24px）で付け、縦横 24px 以上にする。文字の大きさ（11.5px の等幅）・枠の線と色・ホバーの色は変えない | `--target-min` は `tokens.css` に置く |
| 画面設計 | 記録の表・詳細の全画面の `mock` をこの PR のモックへ付け替える | 検討事項は 38 の `b-check`、タスク・詳細パネルは PR #60 のモックをそのまま残す |
| デザイン方針 | `## 形と奥行き` に ID のボタンの行を足し、見えている枠を縦横 `--target-min` 以上にするきまりを 1 か所で持つ | - |
| 結合テスト | 5 画面の結合テストに、ID のボタンの外形が縦横 24px 以上の確かめを足す | - |
| 既存機能への影響 | ID のボタンを押して詳細を開く動き、表の行の選択・ピン留め・並べ替えは変えない | 回帰の確認でプレビューの結合テストを全て流す |
| アクセシビリティ | キーボードのフォーカスの輪（印の色の 2px）は今のまま見える | - |
