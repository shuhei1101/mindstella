# プレビューの ID のボタン（.idlink）の押せる的の大きさの検出（target-size）を解消する

## 概要

プレビューの画面を開いた利用者が、表と詳細パネルに並ぶ項目の ID のボタンを、押し外さずに押せるようにする。

## 背景

[Issue #61](https://github.com/shuhei1101/mindmap/issues/61) の要望。
[PR #60](https://github.com/shuhei1101/mindmap/pull/60)（[Issue #58](https://github.com/shuhei1101/mindmap/issues/58)）のモックを `detect_screen_issues` にかけたところ、資料の表の ID のリンク（`.idlink`）が 1280x800 で `target-size` に当たり、reviewer が [PR #21](https://github.com/shuhei1101/mindmap/pull/21) から引き継いだ検出として報告した（[報告](https://github.com/shuhei1101/mindmap/pull/60#discussion_r4174048392)）。
PR #60 は `undersized-ui-text`・`edge-flush-cards`・`layout-transition` だけを扱う。
