# 要件

## 要望

まだまとめていない変更（MCP のツール `pending`）の返り値を辞書ごと比べる E2E の 3 箇所の期待値を、インターフェース定義『まだまとめていない変更』の返り値（`added`・`changed`・`removed`）に合わせて `{"added": [], "changed": [], "removed": []}` にする。

| テスト | 行 | 今の期待値 |
| --- | --- | --- |
| [tests/e2e/単一ユースケース/test_record_add_update.py](https://github.com/shuhei1101/mindstella/blob/release/v0.7.0/tests/e2e/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/test_record_add_update.py) の `test_normal_when_changes_committed` | 224 | `assert second.data == {"added": [], "changed": []}` |
| [tests/e2e/単一ユースケース/test_utterance_intake.py](https://github.com/shuhei1101/mindstella/blob/release/v0.7.0/tests/e2e/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/test_utterance_intake.py) の `test_normal` | 169 | `assert pending == {"added": [], "changed": []}` |
| [tests/e2e/単一ユースケース/test_settings_update.py](https://github.com/shuhei1101/mindstella/blob/release/v0.7.0/tests/e2e/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/test_settings_update.py) | 289 | `assert pending == {"added": [], "changed": []}` |

直した 3 つのテストファイルが pass する。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 単体・結合テストの `{"added": [], "changed": []}` | `changes.yaml` の入力の値か、`changes.yaml` を直接読んだ値で、ツール `pending` の返り値ではない | 予定なし |
