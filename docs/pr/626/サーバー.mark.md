## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文のフォルダ | ワークスペースの直下の `docs/` を本文のフォルダにし、作成・点検・変更の検知・記録の取得・本文の読み書きが直下の `docs/` を扱う | `body` の値は `../docs/{ID}.mark.md`（要件） |
| 埋め込むファイルのフォルダ | 直下の `files/` にする | 要件の決定 |
| 配信の設定 | project-index の配信の設定（`.mindstella/dev-docs.yaml`）に `paths_base: ..` を加えて配信元の基準をワークスペースの直下にし、`body_file` が `../docs/{ID}.mark.md` を指せるようにする | project-index の `body_file` は YAML のファイルからの相対で、配信元の基準のフォルダの外部を返却しない。`body` の値は要件の決定（B）のとおり |
| 移し替え | v0.14.0 の既存の手順（`remove_discussion_keys`・`markdown_bodies_to_mark_md`）の後ろに追加する手順 `move_bodies_to_root` で、`.mindstella/docs/` と `.mindstella/files/` を直下へ移し、`.mindstella/release/` を削除する | 直下に `docs/`・`files/` が既にあれば止めてバックアップから戻す（要件）。移し替えの後は、変更の検知の前回の中身を作り直す（『変更の検知』の `rebase_snapshot`） |
| 既存のバージョンの手順 | v0.6.0 の手順と、v0.14.0 の既存の手順の期待値は変えない。v0.14.0 の移し替え全体の期待値（『記録の形式の移行』）は、追加した手順の後の構造に修正する | v0.14.0 は未リリースで、#565・#618 と同じスプリントに載る |
