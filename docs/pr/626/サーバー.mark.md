## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文のフォルダ | ワークスペースの直下の `docs/` を本文のフォルダにし、作成・点検・変更の検知・記録の取得・本文の読み書きが直下の `docs/` を扱う | `body` の値の基点は `未確定`（要件） |
| 埋め込むファイルのフォルダ | 要件の推奨のとおり、直下の `files/` にする | `未確定`（要件） |
| 配信の設定 | project-index の配信の設定（`.mindstella/dev-docs.yaml`）に `paths_base: ..` を加えて配信元の基準をワークスペースの直下にし、`body_file` が `../docs/{ID}.mark.md` を指せるようにする | project-index の `body_file` は YAML のファイルからの相対で、配信元の基準のフォルダの外部を返却しない。`body` の値の基点は `未確定`（要件の推奨は B） |
| 移し替え | 次のバージョンの手順で `.mindstella/docs/`（と `.mindstella/files/`）を直下へ移し、`.mindstella/release/` を削除する | 既存のフォルダとの衝突と `release/` の扱いは `未確定`（要件）。移し替えの後は、変更の検知の前回の中身を作り直す（『変更の検知』の `rebase_snapshot`） |
| 既存のバージョンの手順 | v0.6.0・v0.14.0 の手順と期待値は変えない | 過去のバージョンの構造への変換のため |
