## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| お気に入りの残り先 | ワークスペースの記録にお気に入りを持たせ、JSON Schema と ER 図に追加する | 残り先は `未確定`（[要件](./要件.mark.md)） |
| AI からの登録・解除 | MCP のツールを 1 つ足し、登録・解除を引数で分ける。登録済みの登録・未登録の解除はエラーにせず、登録・解除した後のお気に入りを返却する | 記録に無い ID はエラーにする。推奨の案 C の場合（[要件](./要件.mark.md)） |
| 画面からの登録・解除 | 押した時点で確定させ、保存待ちに溜めない | 経路はインターフェース定義設計で決める |
| 記録の取得 | プレビューへ渡す記録にお気に入りを含める | 配る書き出しは書き出した時点のお気に入りを塗った星で出し、星は押せない |
| 移し替え | スキーマに合わない今のワークスペースが無いよう、既定は「お気に入り無し」にする | 移し替えの手順が要るかは `migrations/no-steps.yaml` の判定で決める |
