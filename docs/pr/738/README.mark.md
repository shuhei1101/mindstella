# 詳細パネルのヘッダーからお気に入りに登録・解除でき、AI も利用者の指示で項目をお気に入りに登録・解除できるようにする

## 概要

利用者が、詳細パネルの固定のヘッダーから、開いている項目をお気に入りに登録・解除できるようになる。
利用者が指示すれば、MindStella のセッションの AI も項目をお気に入りに登録・解除できるようになる。

## 背景

[Issue #727](https://github.com/shuhei1101/mindstella/issues/727) の要望。
項目のお気に入りは [PR #721](https://github.com/shuhei1101/mindstella/pull/721)（#353）で入ったが、星はカード・ボードのカード・表の行にしか無く、詳細パネルのヘッダーからは登録・解除できない。
お気に入りはブラウザーの端末の保存領域（`localStorage` の `mindmap-preview` の `favorites`）にだけ残り、AI からは書き込めない。
aituber の台本作成で、毎回参照する資料（台本の資料など）を AI が作成したときにお気に入りに登録しておく使い方を想定している。
