## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 詳細のヘッダーの星 | 詳細パネル・詳細の全画面の固定のヘッダーに部品『お気に入りの星』を置き、開いている項目の登録・解除をする | 並びの位置は画面設計で決める |
| お気に入りの読み書き | `useFavorites` の `ids`・`toggle` の読み書きの先を、端末の保存領域からワークスペース（サーバー）へ移す。`first`・`only` は端末の上書きのまま | 残り先は `未確定`（[要件](./要件.mark.md)） |
| 今のお気に入りの引き継ぎ | 端末の保存領域に残っている `favorites` を、初回にワークスペースへ登録してから端末の保存領域から外す | 登録に失敗したら端末の値を残す |
| AI が変えたお気に入りの反映 | 書き換えの通知で記録を再読み込みしたときに星を描き直す | - |
| アクセシビリティ | ヘッダーの星も `aria-pressed`・読み上げの名前は一覧の星と同じ | - |
| 既存機能への影響 | 一覧の星・表の星の列・表示の設定のお気に入りの区画が同じお気に入りを読む | 単一ユースケース『表示の設定を変える』を回帰確認 |
