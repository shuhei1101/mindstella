# 記録が数百件のワークスペースでも、項目の更新とスレッドの操作を 1 秒程度で終える

## 概要

利用者が、記録が数百件あるワークスペースでも、項目 1 件の更新とスレッドの操作を 1 秒程度で終えられるようになる。

## 背景

[Issue #485](https://github.com/shuhei1101/mindstella/issues/485) の要望。資料 136 件・検討事項 392 件・用語 162 件・スレッド 787 件のワークスペースで、資料 15 件の本文の更新と、スレッド 18 件の既読・取り込み済み・クローズに、それぞれ 120 秒を超える時間がかかった。
[#481](https://github.com/shuhei1101/mindstella/issues/481) の作り直しで記録の書き込みは project-index へ移るが、スレッドの操作は MindStella に残る。
