| 操作 | MCP のツール |
| --- | --- |
| 項目 1 件の更新 | `update`（`run_update`） |
| スレッド 1 件の読み取りと既読 | `thread`（`run_thread`） |
| スレッド 1 件のクローズ・オープン | `set_thread_status`（`run_set_thread_status`） |

- 記録の形式と、MCP のツールの入力・出力・エラーの種類とエラーの行の形は変えない。YAML として読めないファイルの理由の文言は、YAML のライブラリの C 実装の文言に変わる（位置の `line`・`column` は残る）
- 計測の対象は Issue の実例（`/mnt/c/Users/shuhe/repo/tmp/何でも会話`）のコピーとし、記録のフォルダが Linux の領域にある場合と Windows のドライブ（`/mnt/c`）にある場合の両方で測る
- 1 回の操作で、どの種類の YAML を読み込み・検査・書き込みしているかを計測して設計に記載し、変更の無い種類の読み込み・検査・書き込みを省けるかを判断する
- #481 で書き換わる `run_update` 固有の部分より、読み込みと検査の共通の経路とスレッドの操作を優先する
