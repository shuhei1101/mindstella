## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 表 | 部品『表』を `<mdmark-table>` を包む部品にし、列の定義・行のデータ・`features` を props から指定し、行の押下を `mdmark-row-click` で受ける。お気に入りの星・状態の札などの独自の列は `columns[].render` で描く | 行の選択・キーボード操作・狭い幅での出し分けが残せるかは PoC 検証で確認する |
| 表の上のボタン | 「項目の追加」「列の表示」をツールチップ付きのアイコンだけのボタン（knowledge の部品『ボタン』のアイコンだけの形状）にして横に並べる。列の表示は `<mdmark-table>` のテーブル設定へ移せるなら移す | ピン止めのアイコンは `<mdmark-table>` のピン止めの機能のアイコンを使用する |
| ボード | 一覧の共通の画面・検討事項の画面のボード表示を `<mdmark-view>` にし、項目の押下を `mdmark-item-click` で受けて詳細パネルを開く | カードのマーカー・タグの押下での絞り込みが残せるかは PoC 検証で確認する |
| 図の拡大 | mermaid で描く図の拡大を `<mdmark-map>` にし、`source` に図の Mermaid を指定する | map で描けない種類の図は今の描き方を残す |
| 選んだ箇所へのコメント | 詳細パネル・詳細の全画面の本文と項目の値を `<mdmark-comments>` で包み、`mdmark-comment-save` の `quote`・`prefix`・`suffix` を箇所にしてレビュー中のコメントへ溜める。マーカーと吹き出しは `comments` に指定したコメントから描く | 選んだ範囲から元の Markdown の行を求める処理は削除する |
| コメントの一覧・スレッド・レビュー中の書き込み | スレッドの一覧・レビュー中の書き込み・まとめて送信は mindstella の画面に残し、向けた箇所の表示と開いた項目の中で箇所を示す処理を新規の箇所の形式に合わせる | `未確定`（決める工程: PoC 検証。[要件](./要件.mark.md) の `### 未確定`） |
| 箇所の型 | `openapi.yaml` の `loc` のスキーマを新規の形式にし、orval の生成物を再生成する | - |
| 機能の欠け | PoC 検証・設計で、今の画面の機能が 1 つでも失われると分かった箇所は置き換えを進めず、`議論中` を付けて利用者に通知する | [要件](./要件.mark.md) の `### 置き換えの条件` |
| 外部ライブラリ | 置き換えで使用しなくなったライブラリ（`@tanstack/react-table` など）を依存と外部ライブラリの設計書から削除する | 使用が残るかは実装で確定する |
| 配信のビルド | `frontend/` を変えたら、ビルドした `plugins/mindstella/skills/mindmap/preview/spa/` も再作成して commit する | - |
