## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文の箇所の形式 | コメント・下書き・スレッドの本文の箇所を、mdmark の `{quote, prefix, suffix}`（選んだ文字・その前後の文字）にし、本文の行の範囲を持たない | - |
| 値の箇所の形式 | 項目の値へのコメントの箇所の形式を決める | `未確定`（決める工程: データ設計。[要件](./要件.mark.md) の `### 未確定`） |
| 箇所の照合 | 今の項目の本文・値に、箇所の `quote` が `prefix`・`suffix` と並んで出るかで合うかを確認する。合わない箇所は今のとおり除外できるようにする | - |
| スキーマ | `comments.schema.json`・`drafts.schema.json`・`threads.schema.json` の `loc` を新規の形式にする | スキーマのバージョンを上げる |
| 移し替え | 次のバージョンの `migrations/{バージョン}/` に、既存の `loc`（本文の行の範囲と選んだ文）を新規の形式へ移す手順とスクリプトを追加する。前後の文字は、記録にある今の本文から算出する | 本文が変わって求められない箇所の扱いはデータ設計で決める |
| 既存の機能への影響 | コメントの追加・書き換え・下書き・まとめて送信・記録の取得の入出力の `loc` を新規の形式にし、他のキーは変えない | `破壊的変更`（既存のワークスペースは移し替えで読める） |
