# ワークスペースに版を記録し、プラグインを上げたときに版に沿って移し替えられるようにする

## 概要

利用者が、プラグイン mindstella の版を上げても、作ったワークスペースを壊さずに今の版の形へ移し替えられるようになる。
ワークスペースに最後に整えたときのプラグインの版を記録し、版ごとの移し替えの手順を版の順に当てる。

## 背景

[Issue #43](https://github.com/shuhei1101/mindstella/issues/43) の要望。
今の `migrate`（[#21](https://github.com/shuhei1101/mindstella/pull/21) で入った）は版を持たず、資料の `done`・設定の `summary` の有無というデータの形から前の形式を推し量って一度だけ書き換える。
形式の変更が増えると、どの手順を当てるかを形から決められなくなる。
[#24](https://github.com/shuhei1101/mindstella/issues/24)・[#46](https://github.com/shuhei1101/mindstella/issues/46)・[#44](https://github.com/shuhei1101/mindstella/issues/44) がワークスペースの YAML の形を変える予定で、その前に入れる（[#1 のコメント](https://github.com/shuhei1101/mindstella/issues/1#issuecomment-5972720298)）。
`migrate` の MCP への移行は [#13](https://github.com/shuhei1101/mindstella/issues/13) が同じ入出力で行う。
