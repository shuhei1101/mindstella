## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| SessionStart の注入 | MindStella のセッションでだけ、起動の契機（`source`）と再開の状況（未読のコメント・前回参照した後に変わった項目の ID と要約・要見直しの検討事項・進行中の作業）を注入し、起動と再開のエージェントフロー（`mindstella/startup`）を先に進めるよう案内する。進め方の文書の場所の注入は今のまま | `source` ごとの注入は A-119 のフックの表 |
| 注入文 | `references/起動時の指示.md` をプロンプトファイルへ移す | A-107 の `## 削除の候補` の「移行」の行 |
| エージェントフローの配信 | プラグインのエージェントフローのフォルダを project-index の配信元として配信し、どのセッションも ID で参照できるようにする。配信元の `scope.read` に許可するフォルダを含める | 常駐サーバーの起動のときにプラグインの配信元のパスを確認して登録し直す処理は [#525](https://github.com/shuhei1101/mindstella/issues/525)（スコープ外） |
| 通常のセッションへの案内 | MindStella の MCP の instructions で、使い方（エージェントフロー）があることを案内する | A-119 |
