## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| エージェントフロー | A-111・A-112・A-113 の YAML（`id`・`title`・`summary`・`condition`・`steps[].name`・`body`・`when`・`calls`・`refs`）を、プラグインの配下に 1 エージェントフロー 1 ファイルで新規作成する。`calls` の `server` は MindStella の MCP と project-index の MCP を指し、ツールの名前は今の MCP のツールにそろえる | 配置場所とファイルの形式は、モジュール構成設計で判定フローチャート『ドキュメント配置判定』『データ化判定』で決める |

| 文章と HTML の書き方 | knowledge の規約に任せ、プラグインに持たない | A-107 |
| 作業の完了の通知（#569）の追従 | IF-489-12・IF-489-13・IF-489-43 と MOD-489-177・MOD-531-4 を書き換えるときに、#569 が追加した制約「作業の完了の通知」と IF-568-1 への参照を残す。`setup` のスキルの `steps/起動スクリプトの登録.md` にある `MINDSTELLA_DISCORD_WEBHOOK_FILE` の説明は、`register.py` と一緒に起動のコマンドのサブコマンドの説明へ移す | [取り込みの合格](https://github.com/shuhei1101/mindstella/pull/565#discussion_r4608736206) |
