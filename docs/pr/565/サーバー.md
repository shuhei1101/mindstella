## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 削除するツール | `next`・`goal`・`write_release`・`clear_release`・`status`・`migrate` を MindStella の MCP から削除し、呼ぶ処理とモジュールを削除する | A-107 の行き先が「削除」「フック」「常駐サーバー」の行 |
| 要見直しの判定 | `status` の要見直しの判定は残し、SessionStart の注入から呼ぶ | - |
| 前回参照した時点 | 前回参照した時点を常駐サーバーの状態のフォルダに持ち、SessionStart の注入と `changes_since_read` が同じ時点を使用する | D-326・D-342 |
| 削除するキー | スキーマから削除し、書き込みで受け付けない。次のバージョンの移し替えの手順で既存のワークスペースから除く | 参照のキーの `related` への移し替えは [PR #540](https://github.com/shuhei1101/mindstella/pull/540) で済み |
| 読み込みのときの移し替え | 常駐サーバーがワークスペースを読み込むときにバージョンを比べ、古ければ移し替えの手順を適用してから配信する。移し替えに失敗したワークスペースは書き換えず、理由を返却する | D-288。失敗の扱いは単一ユースケース設計で決める |
| 設定の更新 | `update_settings` から削除するキーと `phase_map`・`target_map`・`category_map` を除く | - |
| 点検 | 設定に無いフェーズの検査など、削除するキーに依存する検査を除く | - |
| README と instructions | ワークスペースの `README.md` からスキルの呼び方を除く。MCP の instructions は、記録の検索と書き込みを project-index で行うことに加え、エージェントフローを案内する | - |
| 配る書き出し | ゴール・納品物・フェーズを描く部分を除く | - |
