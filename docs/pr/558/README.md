# 今ある E2E のテストと、E2E だけが使う部品を develop から削除する

## 概要

develop から、今ある E2E のテスト（`tests/e2e/`）と、E2E だけが使う部品・実行方法の記述を削除する。設計書のシナリオは残す。

## 背景

[Issue #477](https://github.com/shuhei1101/mindstella/issues/477) の要望。0.x の間は E2E を回さず修正もしない（決定 D-307 A）ため、今ある E2E は仕様の変更で古くなり、エージェントが参照して誤解するノイズになる。決定 D-311 A で、全てのリポジトリの develop から E2E のテストと E2E だけが使う部品を削除すると決めた。
