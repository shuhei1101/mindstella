E2E のテストは常駐サーバーを子プロセスで立てて MCP のツールと配信を通しで確かめるため、テストの削除はこの計画書に載せる。

## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| E2E のテスト | `tests/e2e/` を丸ごと削除し、`tests/files.yml` の `e2e/` の行を削除する | - |
| 共有の部品 | ファイルと fixture は残し、docstring・`tests/files.yml` の概要文から E2E を外す。E2E だけが使っていた `launch_fixtures.read_tool_names` と `external_access_helpers.ForwardProxy` は削除する | - |
| テスト実行方法 | TL-5 の `run_all` を `未確定`（TL-6 と同じ形）にし、E2E の `prerequisites`・`run_one` を外す | 種別の enum に `E2E テスト` があるため層は残す |
