# 幅 320px でもプレビューのトップバー以外の画面を横にスクロールさせず、見切れなく操作できるようにする

## 概要

プレビューの利用者が、幅 320px の端末でも、トップバー以外の全ての画面を横にスクロールせず、見切れなく最後まで操作できるようにする。

## 背景

[Issue #269](https://github.com/shuhei1101/mindstella/issues/269) の要望。
[PR #263](https://github.com/shuhei1101/mindstella/pull/263)（起点 [#239](https://github.com/shuhei1101/mindstella/issues/239)）で非機能要件『画面サイズ』の決定値を「幅 390px 以上」から「幅 320px 以上」へ下げ、測り方も「表示幅を 320px…にして全ての画面を開き、操作が最後まで済むことを見る」になった。
PR #263 が 320px に収めたのはトップバーだけで、他の画面と部品の狭い幅の作りと確かめは 390px までしか見ていない。
