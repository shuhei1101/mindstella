# 要件

## 要望

プレビューの変更履歴で選んだ時点（まとまりの ID・`pending`・`since`）を URL のハッシュの引数に持たせ、その URL を開くと同じ時点の差分の表示で開く。
今の URL の状態（画面・表示形式・項目・全画面・見出し）はハッシュに `URLSearchParams` の形で持っているため、選んだ時点も同じハッシュの引数として持つ。
選んだ時点を変える・差分の表示をやめると、履歴に積まずにハッシュを置き換える。
記録に無いまとまりの ID と、まだまとめていない変更が空の `pending` を指すハッシュでは、差分を出さずに開き、ハッシュからその引数を外す。
引数を持たない今のハッシュは、今と同じように開ける。

AI（`session`）が、別の Issue のスレッドや会話ログに「ここで直しました」と書くときに、そのまとまりの差分を開くリンクを貼れるようにする。
リンクが指すのは `commit` が返したまとまりの ID（`V-{番号}`）で、開く端末や時刻で中身が変わる `since`・`pending` は使わない。

ハッシュに時点が無いときは、端末の保存領域に残した時点で開き、その時点をハッシュにも書く。
AI が貼るリンクは、`preview_url` に `diff` でまとまりの ID を渡して返った絶対の URL にする。

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| インターフェース定義『プレビューを開く』の `変更履歴で選んだ時点` の「端末の保存領域に持ち、URL のハッシュには書かない」 | [743c3f2b](https://github.com/shuhei1101/mindstella/commit/743c3f2b)（`項目に変更履歴を持たせ、画面で前回からの差分を表示する (#79)`） | [#79](https://github.com/shuhei1101/mindstella/pull/79) で差分の表示を入れたときに、選んだ時点を全ての画面で使い回し、開き直しても保つために端末の保存領域に置いた。ハッシュに書かない理由は PR ドキュメントにも残っていない | 1 回 | 端末の保存領域に残す振る舞いは保ったまま、ハッシュにも持たせる直し方なので、全ての画面で使い回す・開き直しても保つ目的を壊さない |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 変更履歴に「この時点のリンクをコピー」のボタンを足す | 要望に含まれない。時点を選べばアドレス欄の URL をそのまま貼れる | 予定なし |
| 変更履歴の画面を時系列の一覧にし、未読の印を出す | 版を選ぶ一覧の作り替えで、選んだ時点を URL に書くこととは別の要望 | [#156](https://github.com/shuhei1101/mindstella/issues/156) |
| コメントのスレッドで AI が返信する | AI がリンクを貼る先の 1 つだが、会話ログにも貼れるため前提にしない | [#208](https://github.com/shuhei1101/mindstella/issues/208) |
| 本文の中でまとまりを指す、ポートによらない相対のリンク | 本文の中の `#` のリンクは見出しを指すため、別の書き方が要る。ポートを固定していないワークスペースでは、配信を立て直すと今回の絶対の URL が開けなくなる | [#242](https://github.com/shuhei1101/mindstella/issues/242) |
