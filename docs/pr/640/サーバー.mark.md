## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 返却するメッセージ | 対応表の NG の単語を置き換え、エラーには原因と対処を入れる | インターフェース定義を先に修正し、実装をそれに合わせる |
| 記録の形式・MCP の引数・Enum の値・キー | 変えない | 既存のワークスペースと呼び出しをそのまま使用できるようにする（破壊的変更なし） |
| 設計書の文章 | 冗長表現と話し言葉を修正する。振る舞いの記述は変えない | - |
| テストの期待値 | 修正したメッセージに合わせる | - |

### 通知・エラーの文面の置き換え先

画面の文言の一覧に無い、通知・エラーの文面のうち、変えるものの一覧。種類が「通知」の行は、MindStella のセッションのペインに入力され利用者の目に触れるため、ユーザーの承認を得る。

| 今の文面 | 置き換え先 | 種類 |
| --- | --- | --- |
| [mindstella] ユーザーからのコメントが {件数} 件届きました。読み直してください。 | [mindstella] ユーザーからのコメントが {件数} 件届きました。再読み込みしてください。 | 通知 |
| [mindstella] 同じ ID の項目が 2 件あります: {ID}（{ファイル名}）。片方の ID を next_id で振り直してください | [mindstella] 同じ ID の項目が 2 件あります: {ID}（{ファイル名}）。片方の ID を next_id で再採番してください | 通知 |
| {ID} の案 {記号}: 採用している案は消せません。先に adopt で採用をほかの案へ移してください | {ID} の案 {記号}: 採用している案は削除できません。先に adopt で採用をほかの案へ移してください | MCP のエラー |
| {ID} の案 {記号}: 状態 {状態} の検討事項は案を 1 つ以上持ちます。先に add で別の案を足してください | {ID} の案 {記号}: 状態 {状態} の検討事項は案を 1 つ以上持ちます。先に add で別の案を追加してください | MCP のエラー |
| {ID} はほかの記録が指しているため消せません | {ID} はほかの記録が指しているため削除できません | MCP のエラー |
| クローズにできませんでした。サーバーが止まっています。立ち上げ直してから押してください。 | クローズにできませんでした。サーバーが止まっています。再起動してから押してください。 | 画面のメッセージ |
| スレッドを読めませんでした。サーバーが止まっています。立ち上げ直してから開いてください。 | スレッドを読めませんでした。サーバーが止まっています。再起動してから開いてください。 | 画面のメッセージ |
| 送れませんでした。{理由} | 送信できませんでした。{理由} | 画面のメッセージ |
| {版} の手順 {番号}（{操作}）: {理由} | {バージョン} の手順 {番号}（{操作}）: {理由} | エラー |
| 直しを送る | 修正 | 画面のボタン |
