## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 返却するメッセージ | 対応表の NG の単語を置き換え、エラーには原因と対処を入れる | インターフェース定義を先に修正し、実装をそれに合わせる |
| 記録の形式・MCP の引数・Enum の値・キー | 変えない | 既存のワークスペースと呼び出しをそのまま使用できるようにする（破壊的変更なし） |
| 設計書の文章 | 冗長表現と話し言葉を修正する。振る舞いの記述は変えない | - |
| テストの期待値 | 修正したメッセージに合わせる | - |
