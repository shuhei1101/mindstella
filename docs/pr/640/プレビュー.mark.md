## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 置き換え先の一覧 | 画面に出る文言（ボタン・ラベル・見出し・表の列名・状態名・メッセージ）のうち対応表の NG の単語を含むものを洗い出し、置き換え先の一覧を画面設計・部品設計に反映する | ユーザーが承認済み（確認ログ） |
| ボタン | 漢語の「する」を省く（追加・削除・送信） | 規約『入力と文言』 |

| 今の画面と React の画面 | 同じものは両方の画面で同じ単語にする | 今の画面は #371 で廃止するまで配布する |

| テストの期待値 | 修正した文言に合わせる。文言を照合しないテストは変えない | - |

### 画面の文言の置き換え先

部品設計・画面設計の文言（「」で括った表示・メッセージと、読み上げの名前 `label`）のうち、変えるものの一覧。
ユーザーが承認済み（確認ログ）。公開ドキュメント・ほかの設計書の同じ文言・モック・実装・テストの期待値を、この置き換え先に合わせる。
置き換え先と同じものを指す要素名・説明文の呼び名も、同じ単語にしている（承認で置き換え先が変われば一緒に戻す）。

当てた規則:

| 対象 | 規則 | 例 |
| --- | --- | --- |
| 対応表の単語 | 対応表の置き換え先にする | 送る→送信、消した→削除した、足した→追加した、立ち上げ直す→再起動、書きかけ→下書き、印→アイコン・記号 |
| 見えるボタンの文言 | 規約『入力と文言』のとおり、漢語の「する」と目的語の後ろの「を」を省く | 項目を追加→項目追加、送信する→送信、まとめて送る→まとめて送信 |
| 読み上げの名前・`title`（文として読まれるもの） | 「を」を残す（「を」を省くと聞き取りにくくなるため、このリポジトリで決める区別） | 箇所を解除、{値} を解除、主題を解除、{スレッドの ID} への返信を送信する |
| 「続きを表示」のボタン | 「を」を残す例外にする。「続き表示」は辞書に無い造語になる（規約『文章の書き方』の原則「造語を作らない」） | 続きを読む→続きを表示 |
| メッセージ | 文のまま、対応表の単語だけを置き換える。文の中の自然な動詞は残す | 送れませんでした→送信できませんでした、見られます（そのまま） |
