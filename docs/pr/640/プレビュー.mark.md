## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 置き換え先の一覧 | 画面に出る文言（ボタン・ラベル・見出し・表の列名・状態名・メッセージ）のうち対応表の NG の単語を含むものを洗い出し、置き換え先の一覧を画面設計・部品設計に反映する | `未確定`（決める工程: 画面設計・部品設計の承認確認）。ユーザーの承認を得る |
| ボタン | 漢語の「する」を省く（追加・削除・送信） | 規約『入力と文言』 |
| メッセージ | 「〜できませんでした」「〜しますか?」にし、エラーには原因と対処を入れる | 規約『入力と文言』 |
| 今の画面と React の画面 | 同じものは両方の画面で同じ単語にする | 今の画面は #371 で廃止するまで配布する |
| 生成した `.js` | `.ts` を修正した後に tsc で生成し直して commit する | 手で修正しない |
| コードの識別子・CSS のクラス・`data-*` の値 | 変えない | Issue の対象外 |
| テストの期待値 | 修正した文言に合わせる。文言を照合しないテストは変えない | - |
