# 要件

## 要望

このリポジトリの文書と UI 文言の単語を、knowledge の対応表 [AI slop の単語の対応表](https://github.com/shuhei1101/knowledge/blob/6d9ad3e/docs/word-list/word-list-ai-slop.yaml) と規約『文章の書き方』に合わせて修正する。
対応表に無い単語は、規約『文章の書き方』の原則と判定フローチャート『用語の選び方』で判断する。
画面の UI の操作の単語は、規約『入力と文言』の対応表に従う。

| 対象 | 修正すること |
| --- | --- |
| 文章でない所（UI のラベル・ボタン・見出し・表の列名・項目名・分類の値） | IT の分野に定着した単語（漢語・カタカナ語）にする。対応表の NG の単語を使用しない |
| 文章 | 冗長表現（することができる・を行う）と話し言葉を修正する。自然な文の中の動詞は残してよい |
| ボタン・画面タイトル・メッセージ | ボタンは漢語の「する」を省く。画面タイトルは名詞。メッセージは「〜できませんでした」「〜しますか?」にし、エラーには原因と対処を入れる |
| 呼び名 | 同じものは同じ単語で呼ぶ。長音は語末の -er/-or/-ar/-y に付ける |
| ファイル名・見出し | 変えたときは、そのファイル・見出しへのリンクと参照も修正する |

対象の範囲:

| 範囲 | 場所 |
| --- | --- |
| 公開ドキュメント | `docs/guide/`・ルートの `README.md`・`CLAUDE.md` |
| 設計書 | `docs/` の種類のフォルダ（`scenario`・`interface`・`module`・`screen`・`component`・`er`・`config`・`library`・`external-api`・`nonfunctional`・`architecture`・`test-procedure`）と `docs/design-policy.mark.md`・`files.yml` の `description` |
| エージェントが参照する文書 | `plugins/mindstella/agent-flows/`・`plugins/mindstella/content/prompts/`・`plugins/mindstella/skills/mindmap/README.md`・`schemas/` の説明文 |
| UI 文言 | React の画面 `frontend/src/`、今の画面 `plugins/mindstella/skills/mindmap/preview/`（tsc で生成した `.js` を含む）、Storybook のストーリー |
| サーバーのメッセージ | `plugins/mindstella/skills/mindmap/scripts/` が画面・MCP の呼び出し元へ返却するメッセージと、起動スクリプト `plugins/mindstella/bin/mindstella` のメッセージ |
| モック | `docs/mock/components/`・`docs/mock/pages/` |
| テストの期待値 | 修正した UI 文言・メッセージを照合する単体・結合テスト |
