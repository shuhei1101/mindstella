# 要件

## 要望

起動スクリプトの登録を、次のとおりにする。

| 対象 | 要件 |
| --- | --- |
| 登録できる環境変数 | `set` の `--env`・`--unset-env` で `MINDSTELLA_TRANSCRIBER`・`MINDSTELLA_TRANSCRIBER_URL` を受け、`registration.json` と `shell.sh` に記載・解除する。`shell.sh` には `ENV_KEYS` の順（`MINDSTELLA_PREVIEW_STOP_HOOK` の後に `MINDSTELLA_TRANSCRIBER`・`MINDSTELLA_TRANSCRIBER_URL`）で記載する |
| 値の検証 | ほかのキーと同じく、改行を含まないことだけを確認する（サービスの名前と URL の形式は常駐サーバーの起動が確認する） |
| 既定の URL | `http://127.0.0.1:47823`（voice-paste の既定のポート）のまま変えない |
| 手順・リファレンス | 登録できる環境変数を挙げる手順・リファレンス・スキルの手順に、文字起こしの 2 つを追加する |
