# 要件

## 要望

MindStella のセッションは、1 件の検討事項で 1 つの質問だけを聞く。
決める内容が複数あるときは、内容ごとに検討事項を分ける。
決まりは記録のエージェントフロー `mindstella/record`（`plugins/mindstella/agent-flows/record.yaml`）の工程「検討事項に案を記載する」に入れ、単一ユースケース『記録の使い分け』とガイド『エージェントフロー』を合わせる。

マージの前に、ワークスペースの記録（Issue の必読の会話ログ L-1・検討事項 D-1・D-3）と実装を突き合わせ、落とした機能が無いことを確認する。
完了したら [shuhei1101/aituber#254](https://github.com/shuhei1101/aituber/issues/254) に着手できる旨をコメントし、`確認:task-planner` を付ける。
