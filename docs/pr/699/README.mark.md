# 1 件の検討事項で 1 つの質問だけを聞く決まりを記録のエージェントフローに追加する

## 概要

MindStella のセッションが、1 件の検討事項で 1 つの質問だけを聞き、決める内容が複数あるときは内容ごとに検討事項を分けるようになる。

## 背景

[Issue #686](https://github.com/shuhei1101/mindstella/issues/686) の要望。aituber の台本作成で、台本作成ノードが 1 件の検討事項に尺・題材の切り口・話す範囲など 6 項目をまとめ、案「OK」「修正する」で確認した。
記録のエージェントフロー `mindstella/record` の「利用者に聞くことを方針と細部に分ける」「検討事項に案を記載する」は、1 件の検討事項に入れる質問の数を定めていない。

aituber の受付のエージェントフローへの追加は [shuhei1101/aituber#254](https://github.com/shuhei1101/aituber/issues/254) が受け持つ。
