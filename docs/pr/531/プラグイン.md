## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| MindStella のセッションの見分け | セッションの管理が起動のときに渡す環境変数があるセッションでだけ、下のフックの処理をする。通常のセッションでは何もしない | 環境変数の名前は設定の設計書で決める |
| SessionStart | Claude Code の `session_id` と tmux のペインを常駐サーバーの状態に登録する。`clear`・`compact` の後は新しい `session_id` で登録し直す。進め方の文書の場所（環境変数）を注入する | 起動と再開のエージェントフローの注入は #518 |
| SessionEnd | `reason` が `clear`・`resume` のほかのとき、状態の MindStella のセッションを停止済みにする | - |
| UserPromptSubmit・Stop・StopFailure | 応答の始まりと終わりを状態に記録する（停止のときに最後の書き込みを待つため） | StopFailure（`rate_limit`）の起動し直しの依頼は #520 |
| フックから常駐サーバーへの受け口 | フックが状態を登録・記録する受け口を常駐サーバーに持たせる | API の表に無い受け口（#481 の資料に未反映の点）。インターフェース定義設計で決める |
