# 要件

## 要望

`dev/` を廃止し、文書を [shuhei1101/ai-monitor#3307](https://github.com/shuhei1101/ai-monitor/pull/3307) と同じ構成（[docs/pr/3307/モニター.md](https://github.com/shuhei1101/ai-monitor/blob/af7258c2d/docs/pr/3307/%E3%83%A2%E3%83%8B%E3%82%BF%E3%83%BC.md) の `### 種類のフォルダ`・`### 置き場所の規則`）で `docs/` 1 つへ 1 回の PR で移す。
公開ドキュメントは、`visibility: public` の文書だけを mdmark で描いて GitHub Actions で Pages へ配信する。

### 進め方

1. AI Monitor の develop の [f135cff63](https://github.com/shuhei1101/ai-monitor/commit/f135cff63c1f6b4089f3db4bfdc1b2cb5bcdcb71)（ai-monitor#3307 のマージの直前の commit）の `dev/テンプレート/変換/v0.4.0.py` で、`dev/` の置き場所のまま設計書へ v0.4.0 の変換（ID の付与と、パスの参照の ID への書き換え）を掛ける
2. 変換した設計書と他の文書を、下の表のとおり `docs/` の種類のフォルダへ移す
3. 移した後の置き場所を指す設定と参照を修正し、AI Monitor の develop の設計書の検証（`ai_monitor.design_docs validate`）に合格させる
4. Pages を配信する `.github/workflows/` のワークフローを作る
