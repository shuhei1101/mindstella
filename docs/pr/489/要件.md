# 要件

## 要望

`dev/` を廃止し、文書を [shuhei1101/ai-monitor#3307](https://github.com/shuhei1101/ai-monitor/pull/3307) と同じ構成（[docs/pr/3307/モニター.md](https://github.com/shuhei1101/ai-monitor/blob/af7258c2d/docs/pr/3307/%E3%83%A2%E3%83%8B%E3%82%BF%E3%83%BC.md) の `### 種類のフォルダ`・`### 置き場所の規則`）で `docs/` 1 つへ 1 回の PR で移す。
公開ドキュメントは従来の配信（Jekyll）のまま `docs/guide/` へ移し、mdmark と GitHub Actions での配信への切り替えは [#490](https://github.com/shuhei1101/mindstella/issues/490) に分ける。

### 進め方

1. AI Monitor の develop の [f135cff63](https://github.com/shuhei1101/ai-monitor/commit/f135cff63c1f6b4089f3db4bfdc1b2cb5bcdcb71)（ai-monitor#3307 のマージの直前の commit）の `dev/テンプレート/変換/v0.4.0.py` で、`dev/` の置き場所のまま設計書へ v0.4.0 の変換（ID の付与と、パスの参照の ID への書き換え）を掛ける
2. 変換した設計書と他の文書を、下の表のとおり `docs/` の種類のフォルダへ移す
3. 移した後の置き場所を指す設定と参照を修正し、AI Monitor の develop の設計書の検証（`ai_monitor.design_docs validate`）に合格させる
4. 公開ドキュメントのページを指すリンク（プラグインが書き出すワークスペースの README・スキルの README）を、移した後の URL（`/guide/{ページ}.html`）に合わせる

### 移す先

<!-- table: data -->

| 今（origin/develop） | 移した後 | 終わりの条件 |
| --- | --- | --- |
| `dev/設計書/{種別}/`（YAML の設計書。サブフォルダを含む） | `docs/{kind}/`（`scenario`・`interface`・`module`・`component`・`screen`・`config`・`er`・`architecture`・`nonfunctional`・`external-api`・`library`・`test-procedure`） | 種類のフォルダの中がフラットで、ファイル名が `{ID}.yaml`（モジュール構成など言語の規約を注入する種別は `{ID}.{lang}.yaml`） |
| `dev/設計書/デザイン方針.md` | `docs/design-policy.md` | - |
| `dev/テンプレート/*.schema.yaml` | `schemas/{kind}.schema.yaml`（`common`・`index` を含む） | 既存の `schemas/files.schema.yaml` と並び、内容が AI Monitor の develop の `schemas/` の同じ種類の Schema と一致する |
| `dev/pr/`・`dev/mock/`・`dev/generated/` | `docs/pr/`・`docs/mock/`・`docs/generated/` | `docs/pr/` は既にある #476・#486・#487 と並ぶ |
| `docs/はじめに/`・`docs/使い方/`・`docs/リファレンス/` | `docs/guide/` | 分類（はじめに・使い方・リファレンス）は `files.yml` の行の `category` が持ち、サブフォルダにあったファイルは `{サブフォルダ}-{ファイル名}` |
| `dev/index.yaml`・`dev/README.md`・各フォルダの `index.yaml`・`README.md` | `docs/index.yaml` と種類のフォルダの `index.yaml`・`README.md` | `docs/index.yaml` の行が種類のフォルダを指す |
| `dev/エージェント運用/`・`dev/コーディング規約/`（目次だけで文書を持たない） | 削除する | - |
