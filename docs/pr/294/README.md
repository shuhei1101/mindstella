# 詳細パネルの本文の差分の足した印を、設計と実装で揃える

## 概要

詳細パネルの本文の差分で、足した部分に付く印の見た目が、画面設計・使い方・画面の 3 か所で同じになる。

## 背景

[#283](https://github.com/shuhei1101/mindstella/issues/283) の不具合。
画面設計『詳細パネル』の要素「本文の差分」と使い方『プレビューを見る』は、足した段落・見出し・箇条書き・表の行に「足した色の面と +・下線」を付けると書くが、`style.css` は面と + の記号だけで下線を付けない。
[PR #261](https://github.com/shuhei1101/mindstella/pull/261) の結合テスト作成中に見つかり、インラインの本文の差分の食い違いとして対象外に切り出された。
