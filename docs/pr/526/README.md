# React の検討事項のマップの節のロックを、タブを行き来しても残す

## 概要

React のプレビューの検討事項のマップで、利用者が節をロックしてからほかのタブへ移って戻っても、ロックが残るようにする。

## 背景

[#508](https://github.com/shuhei1101/mindstella/issues/508) の不具合。
画面設計『検討事項.tsx』の「節の鍵」「節のロックの操作」はロックをページを開いている間だけ保ち、タブを行き来しても残すと定めているが、`decision-map.tsx` はロックを `useState` で持つため、タブを移ってマップが外れるとロックが消える（[#444](https://github.com/shuhei1101/mindstella/pull/444) で入った）。
[#507](https://github.com/shuhei1101/mindstella/pull/507) でネットワークのロックだけを画面の外の store（`features/graph/graph/store.ts`）に持たせた際に、検討事項のマップは対象外として切り出した。
