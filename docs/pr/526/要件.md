# 要件

## 要望

React のプレビューの検討事項のマップで、ロックした節を、タブの帯でほかの画面へ移ってから検討事項のタブへ戻ったときも同じ節のロックのまま示す（画面設計『検討事項.tsx』の「節の鍵」「節のロックの操作」）。

<!-- table: data -->

| 対象 | 要件 |
| --- | --- |
| ロックの持ち方 | ページを開いている間だけ保ち、URL にも端末の保存領域にも書かない。ページを読み込み直したらロックは無い |
| ネットワークとの関係 | ネットワークのロックとは別々に持つ（どちらかをロックしても、もう一方のロックは変わらない） |
| ロックの操作 | 押したときの規則・素早い 2 回押しの扱い・鍵の震えは今のまま変えない |

<!-- /table -->
