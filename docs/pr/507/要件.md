## 要望

親 [#365](https://github.com/shuhei1101/mindstella/issues/365) の決定（D-8・D-13・D-14・D-16・D-20〜D-23）と、[#429](https://github.com/shuhei1101/mindstella/pull/429)・[#444](https://github.com/shuhei1101/mindstella/pull/444)・[#469](https://github.com/shuhei1101/mindstella/pull/469) で配置した React の土台と画面の決まり（モジュール構成『プレビュー / React』）に従い、親の分割の子 5 の画面を React へ移行する。
子 6（[#371](https://github.com/shuhei1101/mindstella/issues/371)）で切り替えるまで、今の画面（`/mindstella.html`）とその部品・ストーリー・テストはそのまま配信し、動かし続ける。

| Issue | 終わりの条件 |
| --- | --- |
| [#370](https://github.com/shuhei1101/mindstella/issues/370) | ネットワークの画面（3D の描画・見た目の選択・起点のロック）と全体の検索の画面が React へ移り、既存の機能が失われずに再現されている（D-23） |
