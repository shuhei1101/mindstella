## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 画面の状態 | ネットワークの画面を `tab` の `graph` で、全体の検索を開いているかを search の値で持ち、`validateSearch` + Zod で検証する | インターフェース定義『SPAを開く』 |
| フォルダ構成 | ネットワークを `features/graph/graph/`、全体の検索を `features/search/search/` に配置する。玉と線の計算・見た目の描き方・検索の求め方は React に依存しない `.ts` に分け、画面の部品から呼ぶ | モジュール構成『プレビュー / React』と knowledge の規約『フォルダ構成』 |
| 3D の描画 | 今の `graph.ts`・`looks.ts` の計算と描き方を移し、キャンバスへの毎コマの描画は React の外で回す。React の部品はキャンバスと重ねる層（名前・印・鍵・見た目のドロップダウン・条件のチップ）を描く | knowledge の規約『useEffect』 |
| ロック | `shared/core/lock.ts` の判定を使用し、ロックした項目は画面の中の状態に持つ（URL にも端末の保存領域にも書かない） | - |
| 見た目の選択 | 個人の上書きを `prefs-store` の今のキーで読み書きし、無ければ `settings.display.network_look`、それも無ければ `deep` を適用する | - |
| 絞り込み | 絞り込みのドロワー・条件のチップは、一覧の画面と同じ部品と `use-screen-filters` を使用する | - |
| 全体の検索 | 今の検索の求め方（空白で区切った語を全て含む・3 つの段・種類の順と連番の順）を移し、shadcn/ui のダイアログで描く | - |
| トップバー | ネットワークの入口と検索の入口で、今の画面を開かずに search を書き換える。ネットワークの画面では絞り込みのボタンを出す | - |
| Storybook | 移す画面の状態ごとのストーリーを追加し、データは MSW の handler と props で差し込む | knowledge の規約『Storybook』 |
| アクセシビリティ | Storybook の addon-a11y と、結合テストの Playwright の axe で WCAG の違反を検査する | - |
| 既存機能への影響 | 今の画面・部品・ストーリー・テストは触らない | 子 6 で削除する |
