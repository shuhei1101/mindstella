# リリースのときに、プラグインの版をタグと揃える

## 概要

リリースのとき、プラグインの版 `plugins/mindstella/version.ini` の 1 行目も、リリースのタグ・リポジトリ直下の `version.ini` と同じ版に揃える。

## 背景

[Issue #70](https://github.com/shuhei1101/mindstella/issues/70) の要望で、[PR #66](https://github.com/shuhei1101/mindstella/pull/66) の `## スコープ外` から切り出した。

- 今のリリースでは、tester がリポジトリ直下の `version.ini` だけを上げている（[fb68442](https://github.com/shuhei1101/mindstella/commit/fb68442)）
- PR #66 で、`plugins/mindstella/version.ini` を、ワークスペースの版と比べるプラグイン側の版と、`init` がワークスペースに書く版の正本にした
- 同じ PR で、ワークスペースの形を変える作業 PR がプラグインの版を次の版へ上げると決めた。
  形を変えなかったスプリントでは、プラグインの版がタグから遅れたままになりうる
