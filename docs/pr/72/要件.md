# 要件

## 要望

release を master へ入れてタグ `v{バージョン}` を打った時点で、[plugins/mindstella/version.ini](https://github.com/shuhei1101/mindstella/blob/develop/plugins/mindstella/version.ini) の 1 行目が、そのタグ・リポジトリ直下の [version.ini](https://github.com/shuhei1101/mindstella/blob/develop/version.ini) の 1 行目と同じ版になっている。

- ワークスペースの形を変える作業 PR が、`migrations/{次の版}/` を足すのと同じ PR でプラグインの版を上げる決め事（PR #66）は保つ
- 2 つの `version.ini` は 1 つにまとめない。
  プラグインの版はインストールしたプラグインのフォルダの中で読む必要があり、リポジトリ直下の `version.ini` は AI Monitor の規約『バージョニング』が置き場所を決めているため
- 形を変えなかったスプリントでも、リリースで tester がリポジトリ直下の `version.ini` を上げるときに、プラグインの版も同じ値へ上げる。
  AI Monitor へ、リリースマージで揃える版のファイルをプロジェクトから引けるようにするルール改修の Issue を起票する
- hotfix のタグでは、リポジトリ直下の `version.ini` と同じく、プラグインの版を動かさない
- 既にある単体テスト `test_plugin_version_not_behind_latest_tag` の比べる先を、最新のタグからリポジトリ直下の `version.ini` に変える。
  AI Monitor 側の手順が変わる前に揃え漏れても、次の作業 PR のテストで落ちる
