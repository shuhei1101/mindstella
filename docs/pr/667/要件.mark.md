#347 の差分は、mdmark が持つ見せ方だけを mdmark へ置き換え、持たない見せ方は mindstella 側に残す（単一 UC 設計で確定。下の表）。

| mindstella 側の見せ方 | mdmark の機能 | 扱い |
| --- | --- | --- |
| Markdown の本文のインライン（描いた本文の段落にマーカー） | 比較元の Markdown（`baseMarkdown`）でのブロックの色分け | mdmark に置き換える。書き換えた段落は追加の色だけになり、前の段落と変わった単語の濃い面は出さない |
| 変わった単語の濃い面 | 取り出し元（`diffSource`）と `diffMode: "open"` の行の差分 | Markdown の本文に「原文の差分」を追加し、mdmark の行の差分で出す（ミニマップ・埋め込んだ HTML のソースとプレビューの切り替えも mdmark のもの） |
| 左右に並べる | 無い | mindstella 側に残す |
| 描いた本文の上のミニマップ | 行の差分の間だけある | 描いた本文の上は mindstella 側に残し、mdmark の色分けのブロックを参照する |
| HTML の本文（本文の形式が HTML の資料）の差分 | 無い（埋め込んだ HTML の範囲だけ） | mindstella 側に残す |
| 図のノードの色付け | 無い | mindstella 側に残す |
| 印刷 | `features.print` | Markdown の本文の部品でオンにする（詳細パネル・詳細の全画面とも） |
