### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文の差分（インライン） | 変更履歴で選んだ時点の本文を比較元の Markdown（`baseMarkdown`）にして mdmark の色分けで描き、mindstella 側のインラインの差分の描画を削除する | 描いた本文の上では変わった単語を出さない（確認ログで決定） |
| 本文の差分（原文の差分） | Markdown の本文にも「原文の差分」を追加し、選んだ時点と今の本文を返す取り出し元と `diffMode: "open"` で mdmark の行の差分を出す。mdmark が出す「変更表示」のボタンとリビジョンの欄は出したままにし、取り出し元が返すリビジョンは選んだ時点と今の 2 つに絞る | 確認ログで決定。ボタンと欄を出さない指定は shuhei1101/mdmark#784 で依頼。「変更表示」で閉じた後の状態の扱いは部品設計で決める |
| 切り替えの文言 | 「描いた結果」「原文の差分」（HTML の本文の差分と同じ） | モックで決定（確認ログ） |
| 左右に並べる表示 | 使用しないため、左右に並べた本文の差分・本文の差分の並べ方の切り替え・表示の設定の端末の上書き（並べ方）を削除する | 確認ログで決定。mdmark へは shuhei1101/mdmark#783 で依頼 |
| mdmark が持たないほかの見せ方 | 描いた本文の上のミニマップ・HTML の本文の差分・図のノードの色付けは mindstella 側に残す | `要件.mark.md` の表 |
| 印刷 | `MDMARK_FEATURES` の `print` をオンにし、Markdown の本文の部品（詳細パネル・詳細の全画面）で mdmark の印刷を使用する | - |
| 変更履歴の記録 | 形式を変えない | - |
| 設計書 | 単一 UC『前回からの差分を見る』・インターフェース定義『プレビューを開く』（IF-489-70 の制約『本文の差分の並べ方』を削除し、『端末の保存領域』から本文の差分の並べ方を外す）・部品設計・画面設計・モジュール構成を mdmark の機能に合わせ、削除する部品の設計書を削除する | - |
| テスト | 削除する部品のストーリーと結合テストを削除し、mdmark の差分と印刷を確認する結合テストへ置き換える | - |
