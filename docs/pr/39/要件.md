# 要件

## 要望

ゴールで渡すものの呼び名・書き出しの呼び名・書き出すフォルダを、次のとおり改める。

| 対象 | 今 | 改めた後 |
| --- | --- | --- |
| 資料のうち、渡すと決めたもの（`deliverable: true`） | 成果物 | 納品物 |
| ゴール判定で確定して書き出すこと | 引き渡し | リリース |
| 書き出すフォルダ | `handoff/` | `release/` |
| ゴール判定で書き出した資料を受け取る人（関係者） | 引き渡し先 | 受け取り手 |

- `release/` はゴール判定のたびに上書きし、最新の確定版の一式だけを置く（版はフォルダで切らない）。書き出す前にスクリプトの新しいコマンド `clear-release` で `release/` の中身を消す（`session` は Bash を `mindmap.py` だけに絞り、Write はファイルを消せないため）
- キー `deliverable`・`goal.deliverables` は変えない
- `init` が作るワークスペースは `docs/` と `release/` を持ち、`handoff/` を作らない
- 改めた後、`skills/`・`docs/`・`dev/設計書/`・`tests/` に「成果物」「引き渡し」「`handoff`」が 0 件になる（`dev/pr/`・`dev/mock/` と、前の版の `handoff/` に触れない旨の記述を除く）
- プレビューの画面の文言（成果物の印・資料の絞り込みの値・概要のチェックリストの見出し）も「納品物」にする
