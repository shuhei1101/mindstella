# 成果物を「納品物」に、引き渡しを「リリース」に改め、書き出すフォルダを release/ にする

## 概要

ゴールで渡すものの呼び名を「成果物」から「納品物」に、書き出しを「引き渡し」から「リリース」に改め、書き出すフォルダを `handoff/` から `release/` にする。

## 背景

[Issue #35](https://github.com/shuhei1101/mindmap/issues/35) の要望。
[#11](https://github.com/shuhei1101/mindmap/pull/11) でワークスペースに書き出す資料を置く `handoff/` を作り、[#20](https://github.com/shuhei1101/mindmap/pull/20) でゴール判定がそこへ「引き渡しの資料」を書き出すようにした。
[#21](https://github.com/shuhei1101/mindmap/pull/21) で作ったプレビューの画面も「成果物」の印と絞り込みを持つ。
「成果物」を「納品物」へ改めることは [#10](https://github.com/shuhei1101/mindmap/issues/10) でユーザーが提案し、[#6](https://github.com/shuhei1101/mindmap/issues/6) の点検の観点からこの Issue へ移した。
