## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| フォルダ名の定数 | `kinds.py` の `HANDOFF_DIR = "handoff"` を `RELEASE_DIR = "release"` に改め、論理名を「リリースのフォルダ名」にする | `store.py` の import と使う所も揃える |
| ワークスペースの作成 | `init` は `docs/` と `release/` を作り、出力の `files` に `release/` を載せる。`handoff/` は作らない | |
| スキーマの説明 | `docs.schema.json`・`settings.schema.json` の `description` の「成果物」を「納品物」、「引き渡す」を「リリースする」にする | キー `deliverable`・`goal.deliverables` と検証の規則は変えない |
| コメント・docstring | `checker.py`・`graph.py` の「成果物」を「納品物」にする | 処理は変えない |
| テストの fixture | `tests/workspace_fixtures.py` が `release/` を作る | |
| リリースの片付け | コマンド `clear-release` を足す。`release/` の中のファイルとフォルダを消し、`release/` が無ければ作る。`release/` の外は触らない | 処理は `store.py` の `clear_release`、出力の形は `commands.py` の `run_clear_release`、振り分けは `mindmap.py` |
| 既存のワークスペース | `handoff/` があっても読み書きせず、`check` の点検の対象にもしない | `migrate` は変えない（[要件](./要件.md) の `## スコープ外`） |
