## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文のパス | Markdown の本文を記載するパスを、要件で決めた拡張子にする | `未確定`（決める工程: データ設計。要件の『ワークスペースの記録の本文』） |
| スキーマ | 種類ごとのスキーマの `body` の `pattern` と説明を、決めた拡張子に修正する | スキーマの変更のため、移し替えの手順を加える |
| 本文の形式の判定 | `.mark.md` を Markdown の本文として判定する | `.html` の判定は変えない |
| 点検・変更の検知・配信 | 本文のファイルのパターンを、決めた拡張子のファイルに修正する | - |
| 移し替え | 次のバージョンの `migrations/{バージョン}/` に、`docs/` の Markdown の本文を改名し、`body` の値を書き換える手順を加える | 改名先が既にあるときの扱いはインターフェース定義設計で決める |
| release の書き出し | release に書き出す本文の拡張子を、決めた拡張子に合わせる | `未確定`（決める工程: インターフェース定義設計） |
