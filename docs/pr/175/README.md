# E2E『前回からの差分を見る』の本文を読むセレクタを、案の値の描画を拾わない形にする

## 概要

E2E テスト『前回からの差分を見る』で、詳細パネルの本文を読む検証が本文だけを読むようにする。

## 背景

[Issue #168](https://github.com/shuhei1101/mindstella/issues/168) のテスト不備。
release/v0.7.0（`798c84b`）の E2E（[#164 の実行の結果](https://github.com/shuhei1101/mindstella/pull/164#discussion_r4225621041)）で、`tests/e2e/単一ユースケース/test_diff_view.py` の 10 件中 5 件が fail した（本文を読む `page.inner_text("aside.panel .md")` が `'案 A'` を返す）。
[#127](https://github.com/shuhei1101/mindstella/pull/127) で詳細に出す文字列の値を `.md.md-value` で描くようになり、本文より前に並ぶ案の値の要素をセレクタが拾っている。
直さないと v0.7.0 を master へ入れられないため、release/v0.7.0 を base にする。
