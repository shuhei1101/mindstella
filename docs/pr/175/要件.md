# 要件

## 要望

`tests/e2e/単一ユースケース/test_diff_view.py` で詳細パネルの本文を読む検証を、文字列の値の要素（`.md-value`）を除いた本文の要素だけを読む形にする。

- 対象は `page.inner_text("aside.panel .md")` で本文を読む 6 箇所（`test_normal` の 2 箇所・`test_normal_when_history_limit_zero`・`test_normal_when_change_set_history_trimmed`・`test_error_when_previous_version_unavailable`・`test_normal_when_since_history_dropped`）
- 満たす基準は、release/v0.7.0 の E2E で fail した 5 件を含む `test_diff_view.py` の 10 件の pass
- 検証する期待値・準備の記録と、プレビューの描画は変えない
