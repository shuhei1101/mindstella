## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文言の点検 | 画面設計・部品設計の表示文言と、実装の文字列（表示・`aria-label`・`title`・プレースホルダ・空の表示・エラーの文）を、要件の 6 つの観点で 1 語ずつ点検し、「今の語 → 直した語・当てた観点」の表をこの節に置く | 表は単一ユースケース設計の段で作る |
| 設計書への反映 | 点検の表の語を、シナリオの期待値・画面設計・部品設計・インターフェース定義・モジュール構成の文言へ当てる | 直した語は設計書を正本にし、実装とテストはそれに揃える |
| 表示 / 非表示の切り替え | 検討事項のマップの状態と、つながりの種類の切り替え（チェックボックス）は、ラベルを変えない形のまま、ラベルの語だけを点検する | - |
| テスト | 文言を確かめる単体・結合・E2E のテストの期待値を、直した語に揃える | 振る舞いは変えない |
