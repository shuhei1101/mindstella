# プレビューの画面とスキルの文言を 1 語ずつ点検して直す

## 概要

プレビューの画面とスキルの文章に出る日本語を 1 語ずつ点検し、辞書の語・既存の製品の呼び名・決まった型に沿った文言に直す。

## 背景

[Issue #6](https://github.com/shuhei1101/mindmap/issues/6) の要望。
画面の文言に「最近日本に来た外国人のよう」「かわいらしい」と指摘があり、見本では直したが、本実装（[#5](https://github.com/shuhei1101/mindmap/issues/5) の画面と [#4](https://github.com/shuhei1101/mindmap/issues/4) のスキルの文章）にも同じ点検を通す。
決まりの元は [shuhei1101/ai-monitor#2363](https://github.com/shuhei1101/ai-monitor/issues/2363)。
