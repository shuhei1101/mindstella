# 要件

## 要望

プレビューの画面と、スキル（`setup`・`session`・`mindmap`）の文章に出る日本語を 1 語ずつ点検し、次の観点に外れる語を直す。

| 観点 | 基準 |
| --- | --- |
| 語の出所 | 辞書の語か、既存の製品（Jira・Backlog・Notion・Redmine）での呼び名を使う。和語を名詞にした造語（〜事・〜もの・〜さ）を作らない |
| 品詞 | タブ・列名・見出し・状態は漢語の名詞。ボタンは定番の操作語（表示 / 非表示・解除・削除・並べ替え・絞り込み） |
| 状態名 | 未〇〇 / 〇〇中 / 〇〇待ち / 〇〇済み / 完了 / 要〇〇 の型に当てはめる |
| 空の表示 | 一覧は「〇〇はありません。」、検索の 0 件は「該当する〇〇はありません。別の条件を試してください。」、値の欄は「なし」 |
| 1 文字の値 | 値を 1 文字だけで、何の値かを添えずに出さない |
| トグル | ラベルを変えないチェックボックスかスイッチにする |

点検の対象は、画面に出る文字列（表示の文言・`aria-label`・`title`・プレースホルダ・空の表示・エラーの文）と、スキルの文章のうち利用者へ見せる文言（質問・知らせ・提案の文と、その書式の例）。
決まった呼び名（検討事項・未整理・フェーズ・カテゴリー・進め方ガイド・影響度・後続の件数・調査・資料・納品物・タイトル、状態の名前）は変えずに使う。

点検の結果は、画面とスキルごとに「今の語 → 直した語・当てた観点」の表にして [プレビュー](./プレビュー.md)・[スキル](./スキル.md) の `## 変更方針` に置き、reviewer の合格を経て設計書と実装へ反映する。
