# MindStella のセッションの進め方の決まり 9 件を共通のエージェントフローに入れる

## 概要

どのワークスペースの MindStella のセッションも、報告のスレッド・検討事項の挙げ方・資料とタスクの状態などの進め方の決まり 9 件に、共通のエージェントフローで従うようになる。

## 背景

[Issue #689](https://github.com/shuhei1101/mindstella/issues/689) の要望。9 件の決まりは 1 つのワークスペースのローカルルール（ワークスペースの直下の `CLAUDE.md`）にだけ記載されていて、ほかのワークスペースでは適用されない。
共通の決まりは `plugins/mindstella/agent-flows/` の `startup.yaml`・`on-comment.yaml`・`record.yaml` にあり、`record.yaml` の「利用者に聞くことを方針と細部に分ける」は方針の質問を先にスレッドで聞くとしていて、No 2・No 3 と食い違う。

[#686](https://github.com/shuhei1101/mindstella/issues/686)（1 件の検討事項で 1 つの質問だけを聞く）は、この作業 PR の後に入れる（#686 の依存に #689 がある）。
