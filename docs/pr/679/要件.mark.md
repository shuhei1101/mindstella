| 案 | 内容 |
| --- | --- |
| A | 要求の応答と、応答の後の読み直し（query の invalidate）が終わるまで押せなくする |
| B | A に加えて、書き込んだ内容が記録の読み直しの結果に現れるまで押せなくする |

推奨: B

origin/develop の送信のボタンは既に A の間押せない（`review-view.tsx` の `send.isPending`）のに、利用者は押した回数だけ反映されると報告している。A の後にも押せる間があるため、反映を読み直しの結果で確かめる。
