# 変更履歴を時系列の一覧と未読のマーカーにし、検討事項の案を画面で選べるようにして、差分の表示・スレッド・音声の表示の不具合を修正する

## 概要

利用者が、変更履歴を「最新」から始まる時系列の一覧で参照し、まだ見ていない変更を未読のマーカーとトップバーの件数で気づけるようになる。
利用者が、検討事項の詳細で案のカードを押して案を選び、AI がその選択を取得して採用まで済ませられるようになる。
差分の表示のタブのマーカー・資料を開いたときの画面のスクロール・スレッドの書き込みのカードの重なり・音声の再生バーの見切れを修正する。

## 背景

束の親 [Issue #722](https://github.com/shuhei1101/mindstella/issues/722) の子 5 件をまとめて対応する。

- [#705](https://github.com/shuhei1101/mindstella/issues/705): スレッドの画面を `detect_screen_issues` にかけると、Impeccable の `nested-cards` が検出される。書き込みと削除した後の行が `rounded-card` のカードの見た目のまま並ぶ（[#703](https://github.com/shuhei1101/mindstella/pull/703) のレビューで報告）
- [#720](https://github.com/shuhei1101/mindstella/issues/720): 資料に埋め込んだ音声の再生バーの下が見切れる。mdmark だけで描いた音声は全体を表示するため（shuhei1101/mdmark#814）、原因は資料の画面の側にある
- [#692](https://github.com/shuhei1101/mindstella/issues/692): 差分の表示の間にタブの変更のマーカーが付かない（画面の組み立てが `marked` を指定していない）。資料を開くと画面の全体が縦にスクロールする。[#674](https://github.com/shuhei1101/mindstella/pull/674) で追加した「差分の表示をやめる」のボタンを利用者は使用しない
- [#156](https://github.com/shuhei1101/mindstella/issues/156): 変更履歴の「差分を出さない（今の内容）」「前回開いてから」が分かりにくく、AI が記録を書き換えても画面を見ている利用者は気づけない
- [#363](https://github.com/shuhei1101/mindstella/issues/363): 利用者は検討事項の案を選ぶとき、スレッドに「a」「b」と記載して回答しており、1 回に 30 件を超えることがある。AI もスレッドを 1 件ずつ参照して `adopt` している
