## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 詳細パネルの幅の区切り（#676） | 見た目の線の幅は変えず、指の操作で 44px 以上のタップ領域を持たせ、ポインターのイベント（タッチを含む）でドラッグさせる | knowledge の規約『レイアウト』のタップ領域。タップ領域の配置はモック作成で決める |
| 確認済みのボタン（#675） | 詳細パネルの見出しから確認済みのボタンを削除する | 削除する範囲は要件の `未確定`（データ設計で決める） |
| ボードの横のスクロール（#669） | カードと操作できる要素の無い所をポインターで押して動かすと、ボードを横にスクロールする。カードの上から始めたドラッグとテキストの選択は今のまま | React に置き換える前の動作に合わせる |
| 選択中・ホバー・未読の見分け（#671） | 表示形式の切り替え・コメントの一覧の状態のタブなど、選んだ状態を保つ部品の選択中とホバーを、ほかの状態とコントラストで見分けられる色にし、未読のマーカーを未読と分かる色にする | 色はデザイン方針 `docs/design-policy.mark.md` のトークンから選び、モック作成のスクリーンショットで確認する |
| コメントのマーカーの位置（#671） | 資料の番号の横から、カードの見やすい位置へ移す | 位置はモック作成で決める |
| ドロワーの絞り込みと並べ替えの履歴（#650） | ドロワーでの絞り込みの変更（値の選択・解除・すべて解除・タグの組み合わせ方）と並べ替えの変更を、URL の置き換えではなく履歴の追加にする。文字の入力は打ち終えた単位（入力の確定か一定時間の入力の停止）で 1 つにする | 打ち終えた単位の決め方はインターフェース定義設計で決める |
| 表の既定のピン止め（#639） | 要件の `未確定` で決めた扱いを `mount` の `config` に反映し、結合テスト 4 件の期待値と docstring を合わせる | - |
| 結合テストの待ち（#680） | ID のボタンの数を `expect(...).to_have_count(1)` で待つ | - |
