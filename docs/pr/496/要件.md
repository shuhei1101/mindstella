# 要件

## 要望

次の 4 件を、単独の実行と `tests/integration/preview` の全件実行のどちらでも毎回 pass させる。

| テスト | develop での事象 |
| --- | --- |
| `test_detail_panel_screen.py::test_body_scroll_restored` | `Page.wait_for_function` が 30 秒でタイムアウトし、毎回 fail する |
| `test_detail_panel_screen.py::test_body_scroll_when_heading` | `Page.wait_for_function` が 30 秒でタイムアウトし、実行のたびに結果が変わる |
| `test_detail_panel_screen.py::test_voice_input_when_service_stopped` | 「音声で入力」ボタンのクリックが `Element is outside of the viewport` で fail し、実行のたびに結果が変わる |
| `test_spa_thread_screen.py::test_reason_input` | 「オープンに戻す」ボタンが `to_be_focused` にならず、実行のたびに結果が変わる |

- 原因がテストの待ち方にあればテストを修正し、画面の側にあれば画面のコード（`screens/detail.ts`・`thread-view.tsx`）を修正する。テストが確認する画面の振る舞い（画面設計のとおりの期待値）は変えない
- 毎回 pass することは、4 件をそれぞれ 10 回続けて実行して全て pass することと、全件実行で pass することで確認する
