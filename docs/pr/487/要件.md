# 要件

## 要望

AI Monitor の配布物を [v0.2.0..v0.3.0](https://github.com/shuhei1101/ai-monitor/compare/v0.2.0...v0.3.0) の差分に追従させ、`ai-monitor-version.ini` を `v0.3.0` にする。
分類ごとの行動は、v0.3.0 の配布物リスト `distribution.yaml` の `action` に従う。

<!-- table: data -->

| 分類 | 配布元の変更 | このリポジトリの今の状態（origin/develop） | 終わりの条件 |
| --- | --- | --- | --- |
| サイトのレイアウト | `docs/_theme/`（`_layouts/default.html`・`_includes/`・`_data/nav.yml`・`assets/`・`search.json`・`llms.txt`）を新設 | `docs/_theme/` が無く、`docs/_layouts/`・`docs/_includes/`・`docs/_data/`・`docs/assets/` に旧来の共通部品を配置している | `python -m ai_monitor.distribution import-site --version v0.3.0` で `docs/_theme/` を取り込み、`ai-monitor-theme.yaml` が `v0.3.0` を指す。旧来の共通部品は `docs/_theme/` へ置き換わり、プロジェクト固有の `nav.project.yml` は残る |
| 配信設定 | `docs/_config.yml` に `layouts_dir`・`includes_dir`・`data_dir`・`collections.theme` を追加 | 4 つのキーが無い | 4 つのキーを追加し、Jekyll のビルドで既存のページが今までと同じ URL で出力される |
| テンプレート | `dev/テンプレート/` の Schema の改訂（`共通`・`シナリオ`・`テスト実行方法`・`画面設計`・`非機能要件`・`index`）と `開発コマンド.schema.yaml`・`変換/` の新設 | Schema は v0.3.0 より前の内容で、`開発コマンド.schema.yaml`・`変換/` が無い | `dev/テンプレート/` の配布物の Schema が v0.3.0 と一致し、設計書の検証（`ai_monitor.design_docs validate`）に既存の設計書が合格する。v0.3.0 の `変換/versions.yaml` は v0.4.0 の変換だけを持つため、`convert --from v0.2.0 --to v0.3.0` で変わる設計書は無い |
| 規約・外部規約・判定・観点 | 規約 35 件・外部規約 100 件余り・判定フローチャート / チェックシート / 観点の改訂と新設（新設は『反映作業の実行』『対象外の逸脱の報告』『資源の値の決め方』『開発時の従量課金APIの実行』『複数リポジトリのAPI契約』『コンテンツの置き場所』『ドキュメントの部品』『並列不可の判定』『画面設計要否』『設定値の置き場所』『コマンドの書き先』など） | 規約の本文は配布元から rule-inject で参照し、このリポジトリは複製を持たない | 変わった規約・判定・観点のうち、このリポジトリの成果物に該当するものを洗い出し、従っていない箇所を修正するか、スコープ外へ Issue で切り出す |
| フェーズ手順 | エージェントのフェーズ手順の改訂 | 手順は配布元から参照する | エージェントの動きが変わる箇所を確認し、このリポジトリの成果物に影響する箇所が無いことを確認する |
| ルール索引 | `rules.global.yaml` の行が Markdown のテンプレートから Schema へ移り、`content/`・`static/`・`assets/` の行などが増えた | `rules.yaml` は `rules.global.yaml` に掲載する規約を掲載しない方針で、このリポジトリだけのテンプレートの行を持つ | 増えた行のうち、このリポジトリの `rules.yaml` に追加が要る行（このリポジトリだけのパスに適用する行）を追加する |
| プラグイン・設定スキーマ・MCP ツール | `plugins/ai-monitor/`・`settings.yaml.example`・MCP のツールの改訂 | リポジトリの外（モニターの端末の設定）で持つ | 反映作業で取り直しと設定の見直しを済ませる |
