# 結合テストの不安定さを解消する（保存待ちの編集を待つ判定・コメントの一覧のスクロールの位置）

## 概要

プレビューの結合テストのうち、保存待ちの編集を待つ判定と、コメントの一覧を開き直したときのスクロールの位置を確認するテストが、毎回同じ結果になるようにする。

## 背景

[Issue #432](https://github.com/shuhei1101/mindstella/issues/432)（束の親）の要望。子 Issue は次の 2 件。

- [#383](https://github.com/shuhei1101/mindstella/issues/383): `preview_edit_helpers.py` の `SAVED_EDIT_JS`・`NO_SAVED_EDITS_JS` と、`test_workspace_settings_screen.py` のゴールの中身を待つ判定が async 関数で、`page.wait_for_function` が返った Promise を真として扱うため待たずに通る。[#427](https://github.com/shuhei1101/mindstella/pull/427) の結合テストの実行では `test_edit_tags_main_toggle` が `FileNotFoundError: .../.mindstella/edits.yaml` で fail した
- [#428](https://github.com/shuhei1101/mindstella/issues/428): `test_comments_screen.py::test_reopen_restores_scroll` が develop でも不安定に fail し、開き直した後の `.comments-body` の `scrollTop` が 0 になる。テストと開き直したときの位置の戻し方は [#422](https://github.com/shuhei1101/mindstella/pull/422) で変わった

どちらも負荷で再現の頻度が変わり、Sprint v0.12.0 の他の作業 PR の結合テストの実行にも当たっている。
