## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ユースケース | 単一ユースケース『ワークスペースと MindStella のセッションの状態を取得する』を資料 A-126 のシナリオで新規作成し、『MindStella のセッションを止めてワークスペースをクローズにする』から関連を張る | E2E は `tests/e2e/単一ユースケース/test_session_status.py`。MindStella のセッションのエージェントは Mock にする |
| 状態の取得 | `GET /workspaces/{id}` と MCP のツール `workspace` を追加する。ワークスペースの管理が状態（`active` / `stopped` / `closed`）・画面の URL・未読の 2 つの数・最後の更新の日時・クローズ済みかを、セッションの管理が一覧と同じ項目・クローズ待ちか・追加の MCP とプラグインの記録があるかを返却する | 返却のキーの名前は `要件.md` の `未確定` |
| ワークスペースの一覧 | `GET /workspaces` と MCP のツール `workspaces` を追加する。状態のフォルダの ID の一覧にあるワークスペースのうち、クローズしていないものを返却し、指定したときだけクローズしたものを含める | - |
| 書き換えない | 状態の取得・ワークスペースの一覧・『MindStella のセッションの一覧』は、記録・配信元の行・状態のフォルダを書き換えない。『MindStella のセッションの一覧』から、`crashed` を状態に記録して『停止の通知』を呼ぶ副作用を取り除く | 破壊的変更（一覧を呼んでも落ちたことが状態に残らない）。落ちたことの記録と通知は『落ちたことの見回り』と作成・クローズ・起動し直しが行う |
| クローズ済みの判定 | 配信元の行を、project-index の API でなくグローバルの設定のファイルから直接参照し、`outside_read: false` でクローズ済みとする | 資料 A-126 の `notes.クローズの判定` |
| 未読の数 | 利用者が読んでいない AI の書き込みの数と、MindStella のセッションが取り込んでいない利用者のコメントの数を、スレッドの記録から数える | 画面・`threads` の未読・取り込み待ちと同じ判定を使用する |
| 追加の MCP・プラグイン | 状態のフォルダの記録（`launch.json`）の有無だけを返却し、中身は返却しない。指定が空の記録は「ある」とする | - |
| エラー返却 | ID の一覧に無い ID は 404。記録のフォルダが無いときと、グローバルの設定のファイルを参照できないときは 200 で、分かる項目と警告を返却する | 本文は他の API と同じ `application/problem+json`（エラー）と警告の並び |
| 公開ドキュメント | コマンドのリファレンスに、2 つの API と MCP のツールを追加し、MindStella のセッションの一覧が状態を書き換えないことを記載する | - |
