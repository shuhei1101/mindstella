# コメントのペインに項目での絞り込みを追加し、詳細ペインのボタンからその項目のコメントを一覧できるようにする

## 概要

利用者が、詳細パネルの上の方のボタンから、開いている項目に関係するコメントだけに絞ったコメントの一覧を開けるようになる。

## 背景

[Issue #536](https://github.com/shuhei1101/mindstella/issues/536) の要望。
詳細パネルでコメントを追加した後に、その項目のコメントを確認するには、詳細パネルを一番下までスクロールする必要がある。
コメントの一覧（左のパネル）の絞り込みは、今の画面（`plugins/mindstella/skills/mindmap/preview/screens/comments.ts`）・React の画面（`frontend/src/features/comments/comments-panel/comments-panel.tsx`、search params の `tstatus`・`ttag`）とも、状態とタグだけで、項目では絞れない。
話し合いの検討事項 D-520（TH-1055 の利用者の回答）で、詳細パネルの下の一覧と入力欄は残し、コメントの一覧に項目での絞り込みを追加して詳細パネルのボタンから開く構成に決定した。
