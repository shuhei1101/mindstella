# 要件

## 要望

コメントの一覧に項目での絞り込みを追加し、詳細パネルのボタンから、開いている項目で絞ったコメントの一覧を開けるようにする。今の画面と React の画面の両方が対象。

| 対象 | 要件 |
| --- | --- |
| コメントの一覧の項目の絞り込み | 1 つの項目でスレッドを絞れる。絞っている間は、絞っている項目（ID とタイトル）と、絞り込みを解除するボタンを絞り込みの帯に出す |
| 状態・タグの絞り込みとの組み合わせ | 項目で絞っている間も、状態の絞り込み（オープン・クローズ・すべて）とタグの絞り込みを使用できる。状態の絞り込みの件数は、項目で絞った後の件数にする |
| 詳細パネルのボタン | 詳細パネルの見出しに、コメントのアイコンのボタン（コメントの一覧）を配置する。押すと、コメントの一覧が、開いている項目で絞ったスレッドの一覧で開く |
| 項目に関係するコメントの範囲 | スレッドの向けた項目がその項目のスレッドと、その項目へのまだ送っていない新しいスレッド。書き込みの本文でその項目の ID を挙げただけのスレッドは含めない |
| 別の項目へ移ったときの絞り込み | 項目の絞り込みは、解除するか別の項目の詳細パネルのボタンを押すまで、押したときの項目のまま保つ |
| 詳細パネルの今の構成 | 詳細パネルの下のレビュー中のコメントの一覧と、コメントの入力欄は変えない |
| React の URL | 項目の絞り込みを、状態・タグの絞り込みと同じく URL の search params に持ち、開き直しても同じ絞り込みで開く |
