# 要件

## 要望

- 今の画面（`plugins/mindstella/skills/mindmap/preview/`）のトップバーで、どの状態の表示とボタンの組み合わせでも、幅 320px 以上のどの幅でも、トップバーとページが横にはみ出さない（`scrollWidth <= clientWidth`）
- トップバーの状態の表示（サーバーにつながらない表示・音声入力中の表示）とボタン（検索の入口・変更履歴・表示の設定・絞り込み・保存待ち・コメント）は、幅に関わらず文字を出さず、アイコンと件数だけにする。名前と状態（読んだ日時・経過時間・キーの案内）はツールチップと読み上げに持つ（PR の確認事項へのユーザーの回答）
- 報告のあった幅 901px・1441px と、作りの区切り（480 / 481・900 / 901・1100 / 1101・1440 / 1441px）の前後で、つながらない表示の有無・録音中・文字起こし中のそれぞれを確認する
