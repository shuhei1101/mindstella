## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| レスポンシブ対応 | トップバーの状態の表示とボタンは、幅に関わらず文字を出さずアイコン（と件数）だけにする。文字は見た目から外して読み上げに残し、名前と状態をツールチップに持たせる。ツールチップは `title` を使わず、選んだ箇所のコメントの起点（`.sc-tip`）と同じ見た目の CSS のツールチップをボタンの下に置き、ホバーとキーボードのフォーカス（`:focus-visible`）で出す（読み上げはボタンの名前に任せて `aria-hidden`）。右寄りのボタンは右端を揃え、長い文は幅 240px で折り返す。フォーカスを残したまま別の要素にホバーしている間は、フォーカスの側を出さない | つながらない表示は読んだ日時をツールチップに入れる。音声入力中の表示の経過時間と、幅 901px 以上の検索の入口のキーの案内（`Ctrl+K`）は、見た目に残す（ユーザーの回答） |
| レスポンシブ対応 | 幅 901px 以上は、検索の入口を虫眼鏡とキーの案内だけの幅にし、変更履歴・つながらない表示を 32px の四角にし、件数を持つボタンは文字の分の余白を詰める。幅 900px 以下は今の狭い幅の作りのまま | 幅 1100px 以下・`:has(.conn)` の幅 1440px 以下でボタンの文字を隠す規則は、文字を出さなくなるため消す。ボタンを追加するたびに規則へ名前を並べ直す作りも無くなる（[要件](./要件.md) の変更箇所の由来） |
| レスポンシブ対応 | 幅 481〜600px で音声入力中の表示を出している間は、幅 480px 以下と同じくツール名の文字を隠し、要素の間隔と左右の余白を詰める | 今の作りでは幅 481px で 90px はみ出す。幅 360px 以下でつながらない表示と音声入力中の表示が並ぶ間は、ツール名の印も隠し、間隔を 1px、左右の余白を 8px に詰める |
| 状態の見本 | 部品設計『トップバー』の `states` と Storybook のストーリーの見せ方を、アイコンだけの見た目に合わせて直し、録音中・文字起こし中とつながらない表示が並ぶ状態と、ツールチップを出した状態を追加する | - |
| 既存機能への影響 | 差分の札・題名・タブの帯・「更新があります」と音声入力の知らせの帯は変えない | 既存のストーリーの結合テストのうち、ボタンの文字を前提にした期待値は直す |
