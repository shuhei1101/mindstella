# 要件

## 要望

- `lefthook.yml` の pre-commit から `lint`・`typecheck` のジョブを削除し、`spa-build` のジョブだけを残す
- lefthook を前提にした設計書の記述を、`spa-build` だけを実行する状態に合わせる（対象は `要件.yaml` の `docs`）
