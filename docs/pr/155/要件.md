# 要件

## 要望

サーバーのプレビューの配信に、次の 3 つを任意の設定として足す。
どれも未設定なら今と同じ動き（`127.0.0.1` の空きポートで待ち受け、`Host` と `Origin` は `127.0.0.1` / `localhost` だけを受ける）にする。
待ち受けるアドレスは設定に関わらず `127.0.0.1` のままにする。
コード・設計書に特定のサービス（Cloudflare など）の名前を出さない。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| 待ち受けポートの固定 | ポートの指定があれば、そのポートで待ち受ける。そのポートで待ち受けられなければ、今の待ち受けを立てられないときと同じく配信を立てずにエラーを返す |
| 外から来るホスト名の許可 | 許可するホスト名を指定すると、`Host` がそのホスト名の要求も受ける。`Origin` は、指定したホスト名の `https://` と `http://` も受ける。どちらもポートを外したホスト名の部分で比べ、入口のポートを問わない。指定の無いホスト名は今と同じく `Host` を 403、`Origin` を断る |
| 起動・終了時のフック | 起動時のコマンドを指定すると配信を立てた直後に、終了時のコマンドを指定すると配信を止めるときに、ポートとワークスペースの名前を渡して呼ぶ |
| 使い方 | ローカルだけは何も設定しない。ワークスペースが少なく固定の URL で見るときはポートの固定と許可するホスト名を設定し、外の入口にポートを 1 回登録する。複数のワークスペースで立てては消すときは許可するホスト名とフックを設定し、フックで手元のゲートウェイへ登録・削除する |
| 公開ドキュメント | 使い方に「外から見る」の手順を足し、Cloudflare Tunnel は例の 1 つとして書く |

<!-- /table -->

設定の置き場所は、待ち受けのポートをワークスペースの `config.yaml` の `preview.port` に置く。
許可するホスト名とフックは MCP サーバーの環境変数（`MINDSTELLA_ALLOWED_HOSTS`・`MINDSTELLA_PREVIEW_START_HOOK`・`MINDSTELLA_PREVIEW_STOP_HOOK`）に置く。
ポートはワークスペースごとに決まる値で、許可するホスト名とフックは端末ごとに決まる値のため。
フックはコマンドを動かすので、ワークスペースと一緒に他の端末へ渡る `config.yaml` には置かない。

フックは、起動時と終了時で別のコマンドを指定し、どちらもコマンドの末尾にポートとワークスペースの名前（フォルダの名前）を引数で足して呼ぶ（例 `pub add 47800 家計簿`）。
登録と削除のコマンドを、振り分けのスクリプト無しで書けるため。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `127.0.0.1` 以外のアドレスでの待ち受け（ほかのマシンへの公開） | 要望は外の入口（トンネル・リバースプロキシ）の内側で使うもので、待ち受けは `127.0.0.1` のまま、認証は外の入口に任せる。公開範囲は #25 が扱う | [#25](https://github.com/shuhei1101/mindstella/issues/25) |
| 共有サーバーを複数の人で使う | 1 人が自分の端末のサーバーを外から見る今回の要望とは別のもの | [#14](https://github.com/shuhei1101/mindstella/issues/14) |
| 特定のサービス（Cloudflare など）向けの設定・連携 | 要望でコードに特定のサービスの名前を出さないと決めている。公開ドキュメントでは例の 1 つとして書くだけにする | 予定なし |
