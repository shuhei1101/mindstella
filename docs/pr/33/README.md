# GitHub Pages を AI Monitor の共通のレイアウト・スタイルで配信する

## 概要

利用者が、mindmap の GitHub Pages を AI Monitor のドキュメントサイトと同じ共通のレイアウト・スタイルで読めるようにする。

## 背景

[Issue #29](https://github.com/shuhei1101/mindmap/issues/29) の要望。
今の `docs/` には `_config.yml`・`_layouts/`・`_includes/`・`assets/` が無く、GitHub Pages の既定のテーマで描かれている。
AI Monitor には共通の部品を初期構築で写す仕組みがまだ無く（[shuhei1101/ai-monitor#60](https://github.com/shuhei1101/ai-monitor/issues/60)）、この PR で準拠バージョン `v0.2.0` のものを手で写す。
