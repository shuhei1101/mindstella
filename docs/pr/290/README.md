# 幅 390px 以上でも、絞り込み 2 桁・コメント 99+ のトップバーを画面幅に収める

## 概要

プレビューの利用者が、絞り込みのバッジが 2 桁・コメントの件数が `99+` のときも、幅 390px 以上で横にスクロールせずにトップバーの全てのボタンを使えるようにする。

## 背景

[Issue #270](https://github.com/shuhei1101/mindstella/issues/270) の報告。
[PR #263](https://github.com/shuhei1101/mindstella/pull/263)（起点 [#239](https://github.com/shuhei1101/mindstella/issues/239)）のレビューと実装の実測で、絞り込みのバッジ 2 桁・コメントの件数 `99+` のとき、つながる・差分ありと、つながらない・差分なしで幅 390〜400px（390px で 11px）、つながらない・差分ありで幅 390〜394px（390px で 5px）トップバーが横にはみ出すと分かった（[範囲の追記](https://github.com/shuhei1101/mindstella/issues/270#issuecomment-6195510269)）。
PR #263 は幅 389px 以下だけをこの中身で収め、390px 以上の規則は変えていない。
非機能要件『画面サイズ』の決定値は「幅 320px 以上」。
