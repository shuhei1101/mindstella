# 音声入力の文字起こしを入力欄へ挿入するだけにし、録音中は波形を表示する

## 概要

利用者が、音声入力で文字起こしした結果を入力欄で確認・修正してから、送信のボタンでレビュー中へ入れられるようになる。

## 背景

[Issue #499](https://github.com/shuhei1101/mindstella/issues/499) の報告。
[PR #476](https://github.com/shuhei1101/mindstella/pull/476) で入れた音声入力は、`config.yaml` に `transcription.action` が無いときの既定が `send` で、文字起こしの直後に入力欄の全文がレビュー中を経ずにスレッドへ送信される。
利用者は誤認識を修正できず、テストの発話もスレッドになった（2026-11-11）。
録音中に入力している音声の波形の表示が無く、録音中もキーボードで入力できる。
