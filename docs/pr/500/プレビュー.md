## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文字起こしの結果 | 今の画面・React とも、返った文字を入力欄のカーソルの位置へ挿入して終える。すぐ送信を呼ばない | `send` は `config.yaml` に記載したときだけ今の振る舞いを残す |
| 送信 | 挿入した後は、キーボードで入力したときと同じく「レビューに追加」でレビュー中に溜める | 既存の操作を変えない |
| 録音中の入力欄 | 入力欄を読み取り専用にし、入力欄の場所に録音している音声の波形を表示する。録音を終えたら入力欄に戻し、録音前の文字とカーソルの位置を残す | 波形の見た目はモック作成で決める |
| 波形 | マイクの音声を Web Audio API の `AnalyserNode` で取得し、描画のたびに音量を描く。録音を終えたら止める | - |
| 設定の画面 | 文字起こし後の挙動の選択を、`send` の扱いの決定に合わせる | - |
| アクセシビリティ | 波形は装飾として読み上げの対象から除外し、録音中であることは今の結果の行の読み上げで伝える | - |
