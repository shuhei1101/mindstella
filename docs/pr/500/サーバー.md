| 対象 | 方針 | 補足 |

| 既定の挙動 | `config.yaml` に `transcription.action` が無いとき、文字起こしの可否は `insert` を返却する | - |
| すぐ送る | `send` を廃止するなら `POST /api/comments/send-now` と、コメント・スレッドのすぐ送るの処理を削除する。残すなら変えない | `未確定`（`要件.md`。決める段: 単一ユースケース設計） |
| 設定のスキーマ・設定の更新 | `transcription.action` の値の候補と説明を、`send` の扱いの決定に合わせる | 廃止する場合、`action` を記載した既存のワークスペースの読み込みもあわせて決める |
