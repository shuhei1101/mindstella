## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| プリセットの保存（#362） | ドロワーに今の絞り込みを名前付きで保存する入力を置き、サーバーのプリセットを書き込むエンドポイントへ送信する。保存した後は書き換えの通知で記録を読み直し、ドロワーの一覧に並べる | タグの条件以外の絞り込み（状態・列の文字など）をプリセットの式にどう写すかは単一ユースケース設計で決める |
| 検索からの絞り込み（#143） | 検索の文字を、その画面の絞り込みの値（タグ・状態など）の名前と突き合わせ、一致した値を結果の先頭に「絞り込みをオンにする」候補として並べる。押すと検索を閉じ、その画面の絞り込みの条件に値を加える | 一致の判定（前方一致・部分一致・大文字小文字）は単一ユースケース設計で決める |
| 本文と補足の見分け（#159） | 詳細の上の切り替えボタンで「本文」「関連」「コメント」を切り替える | 要件の本文と補足の欄の見分け方 |
| 本文の目次（#160） | 本文の Markdown の見出しから目次を作り、詳細のヘッダーのボタンで開いて、項目を押すとその見出しへスクロールする | 目次はポップオーバーで開く。HTML の本文は対象外かを単一ユースケース設計で決める |
| 原文の差分（#668） | `body-links.ts` の原文の差分の `mount` の `opts` に mdmark#784 の指定を加え、ボタンと欄を出さない | mindstella は既定で mdmark の develop の先頭を読む |
| アクセシビリティ | 保存の入力・候補・目次のボタンと項目を、キーボードで選べて名前を持つ要素にする | - |
