## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配信の経路 | React の画面だけを配り、今の画面を返却する応答（雛形の組み立て）を削除する | 配る URL のパスは `要件.mark.md` の `未確定`（決める工程: インターフェース定義設計） |
| 画面の URL を返すツール | `preview_url`・ワークスペースの作成・README が返却する URL を、切り替えた URL にそろえる | - |
| 配る書き出し | `export_preview` を React のビルドから作り、記録の埋め込み（`mindmap-data`）・mdmark の配布ファイルの差し込み・ライセンスの表示（`mindmap-licenses`）・`integrity` の照合・失敗の扱いは今の制約のまま残す | 組み立て方は `要件.mark.md` の `未確定`（決める工程: PoC 検証） |
| 雛形の組み立ての削除 | `assemble_template`・`SCRIPT_FILES`・`TEMPLATE_FILE` など今の雛形だけが使用する定数と関数を削除する | 書き出しが使用し続けるものは残す |
