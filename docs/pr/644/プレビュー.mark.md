- 所感: React の画面は、記録の読み込み（`apiClient`）・ルーター・書き換えの通知・描画のライブラリの読み込みの 4 か所を、埋め込みの要素の有無で切り替えるだけで `file://` で動いた。書き出しの画面には編集・コメント・保存の操作が出たままになるため、インターフェース定義設計で書き出しの画面で出さない操作を決める
- 所感: ビルドの JavaScript の中に文字列の `</body>` があるため、差し込みは最後の `</body>` の前に入れる。雛形の差し込み口の数を数える今の作りは使用できない
- 所感: `index.html` の Google Fonts の `<link>` は書き出しでは外部への要求になるため、差し込みのときに除外した（文字はシステムのフォントになる）
