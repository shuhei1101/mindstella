# 要件

## 要望

- `dev-docs.yaml` の `files_guide`・`files_root` の行の `exclude` から `"*.yml"` を削除する（`"*.yaml"` と他の要素は残す）
- 修正の後、project-index の `search_docs` で種類 `files_guide`・`files_root` の文書が返り、AI Monitor の `update_dev_docs_section` で `docs/guide/` の Markdown が `served: true` になることを確認する

`docs/guide/`・`docs/_root/` にある `.yml` は `files.yml` だけで、`"*.yml"` を削除しても他のファイルは配信の範囲に入らない。
