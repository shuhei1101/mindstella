# 要件

## 要望

このリポジトリを Claude Code のマーケットプレイスにし、プラグイン `mindmap` を配る枠を作る。

- `.claude-plugin/marketplace.json` がプラグイン `mindmap` を 1 件載せ、`/plugin marketplace add` でこのリポジトリを登録できる
- 登録したマーケットプレイスから `/plugin install mindmap@mindmap` でインストールでき、インストール後のプラグインの一覧に `mindmap` が出る
- プラグインはスキル `skills/mindmap/` を持ち、その配下に `schemas/`・`scripts/` を置くフォルダ構成にする。hooks は持たない
- 要件・構成の設計書（アーキテクチャ図・非機能要件）と、`dev/`・`docs/` のドキュメントの土台を作る
