# プロジェクトの土台と、プラグイン mindmap を配るマーケットプレイスの枠を作る

## 概要

利用者が、このリポジトリをマーケットプレイスとして登録し、プラグイン `mindmap` をインストールできるようにする。
あわせて、要件・構成の設計書とドキュメントの土台を作る。

## 背景

[Issue #2](https://github.com/shuhei1101/mindmap/issues/2) の要望。
リポジトリには README だけがあり、設計書も実装も無い。
スキル `mindmap` の中身は [#4](https://github.com/shuhei1101/mindmap/issues/4)、スキーマとスクリプトは [#3](https://github.com/shuhei1101/mindmap/issues/3)、プレビューの画面は [#5](https://github.com/shuhei1101/mindmap/issues/5) が持ち、どれもこの PR が作る枠の上に載る。
