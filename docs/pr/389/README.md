# E2E とシナリオの期待値を、v0.11.0 の本文の描画（mdmark）・セクションの折りたたみ・詳細パネルの既定の幅に合わせる

## 概要

v0.11.0 の画面の変更に追従していない E2E 5 件と、その元のシナリオ 2 件の期待値・セレクタを今の画面に合わせ、release/v0.11.0 の E2E が通るようにする。

## 背景

[#387](https://github.com/shuhei1101/mindstella/issues/387) の E2E の fail。
release/v0.11.0 の E2E（[実行の結果](https://github.com/shuhei1101/mindstella/pull/384#discussion_r4433842741)）で 5 件が 2 回とも fail した。
同じ Sprint で入った [#342](https://github.com/shuhei1101/mindstella/pull/342)（本文の描画を mdmark へ置き換え）・[#327](https://github.com/shuhei1101/mindstella/pull/327)（セクションの折りたたみ）・[#340](https://github.com/shuhei1101/mindstella/pull/340)（詳細パネルを同じ既定の幅で開く）が画面の構造・挙動を変え、テストとシナリオが前の構造のまま期待している。
画面は各 PR の設計どおりに動いており、製品のコードは変えない。
