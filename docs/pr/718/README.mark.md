# コメントのパネルのスレッドの見出し・一覧・タブのハイライト・パネルから開いた資料の操作・スマホのリンクを修正する

## 概要

利用者が、長い書き込みから作ったスレッドでも見出しに画面を埋められずに書き込みを参照し、区切りの線で分けた一覧でスレッドを探し、ロックしていないコメントのパネルから開いた資料を操作し、スマホでは資料のリンクを 1 回押して開けるようになる。

## 背景

[Issue #707](https://github.com/shuhei1101/mindstella/issues/707) の要望（話し合いのワークスペースの TH-64・D-42）。
利用者は音声入力で長い書き込みを送信するため、スレッドを開くと見出しが書き込みの全文で埋まる。スクロールで高さを制限した後も、見出しが折り返さずにパネルの右端を突き抜ける（[#706](https://github.com/shuhei1101/mindstella/issues/706) から移した）。
[#372](https://github.com/shuhei1101/mindstella/issues/372) は送信の後に見出しを 1 行に省略したが、開いた直後は全文を出す作りのまま。
ロックしていないコメントのパネルでは、パネルの外を押すとパネルを閉じる判定になり、スレッドのリンクから開いた資料も押せない。
コメントの一覧のパネルの幅の区切り（[#357](https://github.com/shuhei1101/mindstella/issues/357)）は、利用者の指示どおり先に [#713](https://github.com/shuhei1101/mindstella/pull/713) でマージした。
