## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スレッドの見出し | 開いた直後から、見出しのタイトルを 2 行で省略し、収まらないときだけ「続きを表示」「折りたたむ」のボタンで全文を開く。省略の間もパネルの幅で折り返す | 全文は見出しの中で 288px までにしてスクロールさせる |
| スレッドの一覧 | 行を角丸のカードにせず、背景を付けずに行の間を区切りの線で分ける | 押す範囲とフォーカスの枠線は行の全体 |
| タブのハイライト | 選んだボタンの影をやめ、選択の色の線をボタンの内側に収め、隣のボタンにかからないようにする。3 か所の切り替え（スレッドの状態・詳細の本文・表示形式）が共有するクラスを修正する | ライトモードとダークモードで同じクラスを使用する。表示形式の切り替えは部品設計『表示形式の切り替え』の状態、ほかの 2 か所は結合テストと撮影で、ライトモードとダークモードを確認する |
| ロックしていないパネルから開いた資料 | コメントの一覧から開いた詳細パネルはグレーアウトの上に重ね、`inert` にしない。詳細パネルの中の押下ではコメントの一覧を閉じない | 詳細パネルの外のグレーアウトを押したときは今のとおり閉じる |
| スマホのリンク | 指で押したとき（ポインターの `pointerType` が `touch`）は、項目の ID のリンクとボタンを 1 回押すと開き、ツールチップを出さない | マウスの端末は今のとおり乗せるとツールチップを出す。用語のマーカーは指の端末でも 1 回目のタップでツールチップを出し、出ている間の 2 回目のタップで用語の詳細を開く |
| アクセシビリティ | 全文を開くボタンは `aria-expanded` を持ち、キーボードで開閉できる | 指の端末は 44px のタップ領域 |
| 既存機能への影響 | スクロールした後の 1 行の省略・ピン止めの間の `inert`・絞り込みのドロワーとの排他は変えない | 結合テストで回帰を確認する |
