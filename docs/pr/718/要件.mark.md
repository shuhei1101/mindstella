## 要望

React のプレビューで、次の箇所を修正する。

| 場所 | 要件 |
| --- | --- |
| スレッドの見出し | 3000 文字を超える 1 件の書き込みから作ったスレッドでも、開いた直後から見出しを決めた行数に収め、全文を開く操作を持つ。スクロールで高さを制限した後も、パネルの幅で折り返してパネルの右端を超えない |
| スレッドの一覧 | 角丸のカードを詰めて並べず、区切りの線で分けた一覧にする。カードはグリッドに並べるときだけ使用する |
| 切り替えのタブ（オープン・クローズ・全て、本文・関連・コメント、表示形式） | ライトモードで選んだタブのハイライトが、隣のボタンと選択の色の線にかからない |
| ロックしていないコメントのパネル | スレッドのリンクから開いた資料（詳細パネル）をグレーアウトせず、押してもパネルを閉じずに操作できる |
| スマホの資料・項目の ID のリンク | 1 回押すと資料を開き、ツールチップを出さない |

確認する場面は、3000 文字を超える 1 件の書き込みから作ったスレッド・スレッド 100 件・ライトモードとダークモード・スマホ幅（360px）と最も狭めたパネル。
修正した画面は実装の後のコードで上の場面を撮影し、崩れていないことを確認する。
