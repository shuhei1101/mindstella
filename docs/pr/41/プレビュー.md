## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 置き場所 | `skills/mindmap/preview/` を `plugins/mindstella/skills/mindmap/preview/` へ移す（`skills/` ごとの `git mv`） | `builder.py` は自分のファイルからの相対で雛形を引くため変えない |
| ツール名の表示 | トップバーの名前を `mindstella` にする | 見本（Issue の資料）に揃える |
| ページの題 | 雛形の `<title>` を `プレビュー \| mindstella` にする | - |
| ビルドの設定 | `tsconfig.json` の `rootDir`・`include`・`exclude`、`.storybook/main.js` の `PREVIEW_DIR`・`stories`、`.storybook/tsconfig.json` の `include` を移した先にする | `npm run build`・`npm run typecheck`・`npm run build-storybook` が通る |
| 名前 | 名前空間 `MindmapPreview`・要素の ID `mindmap-data`・`mindmap-style`・`mindmap-app`・`mindmap-licenses` は変えない | `要件.md` の `## スコープ外` |
