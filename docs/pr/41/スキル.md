## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 置き場所 | `skills/` を `plugins/mindstella/skills/` へ `git mv` で移す | 本文の `${CLAUDE_PLUGIN_ROOT}/skills/...` はプラグインの直下からのパスのため書き換えない。`allowed-tools` の起動の形も変えない |
| スキルの呼び名 | SKILL.md と `steps/` の案内の `/mindmap:setup`・`/mindmap:session` を `/mindstella:setup`・`/mindstella:session` にする | スキル名 `setup`・`session` は変えない（#16） |
| プラグインの README | 見出し・インストールのコマンド（`shuhei1101/mindstella`・`mindstella@mindstella`）・スキルの呼び名・公開ドキュメントの URL（`https://shuhei1101.github.io/mindstella/`）を変える | - |
| 結合テスト | `skill_files.py` のスキルのフォルダを `plugins/mindstella/skills`、プラグインの中のパスの実在を確かめる起点を `plugins/mindstella/` にする | - |
