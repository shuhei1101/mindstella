# ツールの名前を mindmap から mindstella に変え、プラグインを plugins/mindstella/ に分けて配る

## 概要

利用者が、ツールを新しい名前 mindstella のマーケットプレイスとプラグインとして入れ、プラグインのフォルダの中だけを手元へ受け取れるようにする。

## 背景

[Issue #17](https://github.com/shuhei1101/mindmap/issues/17) の要望。
ツールの名前を mindmap から mindstella（マインドステラ）に変える。
今はマーケットプレイスがプラグインの置き場所をリポジトリの直下（`./`）で指しており、インストールすると `dev/`・`docs/`・`tests/`・`.storybook/`・`package.json` までリポジトリ全体が利用者の手元へ写される。
この置き方は [PR #9](https://github.com/shuhei1101/mindmap/pull/9) でマーケットプレイスの枠を作ったときから変わっていない。
[Issue #15](https://github.com/shuhei1101/mindmap/issues/15) のプラグインの設定の `homepage`・`repository` は、この改名の後の URL（`https://github.com/shuhei1101/mindstella`）を前提にしている。
