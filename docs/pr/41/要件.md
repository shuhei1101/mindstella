# 要件

## 要望

ツールの名前を mindstella（表記は小文字、カタカナは「マインドステラ」）に変える。

- マーケットプレイス名とプラグイン名を `mindstella` にする。
  利用者は `claude plugin marketplace add shuhei1101/mindstella` で登録し、`claude plugin install mindstella@mindstella` で入れ、スキルを `/mindstella:setup`・`/mindstella:session` で呼ぶ
- プラグインを `plugins/mindstella/` に分ける。
  `plugin.json` を `plugins/mindstella/.claude-plugin/plugin.json` に、`skills/` を `plugins/mindstella/skills/` に移す。
  `marketplace.json` はリポジトリの直下の `.claude-plugin/` に残し、プラグインの `source` を `./plugins/mindstella` にする
- インストールしたプラグインのフォルダに `.claude-plugin/plugin.json` と `skills/` があり、`dev/`・`docs/`・`tests/`・`.storybook/`・`package.json` が無い
- 結合テスト・E2E テストのプラグインの場所と名前を新しいものにする。
  スクリプト・プレビュー・スキルを指すテストとビルドの設定（`tsconfig.json`・`.storybook/`）の場所を移した先にする
- README・docs のツール名・インストールのコマンド・スキルの呼び名と、リポジトリの中のファイルへのリンクを新しい名前と場所にする。
  `docs/_config.yml` の `baseurl` を `/mindstella` にし、改名した後の GitHub Pages（`https://shuhei1101.github.io/mindstella/`）でトップ・パンくずのリンクが切れないようにする
- プレビューのトップバーの名前を `mindstella`、ページの題を `プレビュー | mindstella` にする
- GitHub のリポジトリ名を `shuhei1101/mindmap` から `shuhei1101/mindstella` に変える（`## 反映作業`）
