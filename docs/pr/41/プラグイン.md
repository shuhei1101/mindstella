## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| マーケットプレイス | `.claude-plugin/marketplace.json` の `name` と `plugins[].name` を `mindstella`、`plugins[].source` を `./plugins/mindstella` にする | ファイルはリポジトリの直下の `.claude-plugin/` に残す。`owner`・`description` は変えない |
| プラグインのマニフェスト | `plugin.json` を `plugins/mindstella/.claude-plugin/plugin.json` へ `git mv` で移し、`name` を `mindstella` にする | `description`・`author` は変えない |
| スキルのフォルダ | `skills/` を `plugins/mindstella/skills/` へ `git mv` で移す | 中身はスキル・スクリプト・プレビューの計画書 |
| 配る中身 | インストールしたフォルダに `.claude-plugin/plugin.json` と `skills/` があり、`dev/`・`docs/`・`tests/`・`.storybook/`・`package.json` が無い | 結合テストと E2E で確かめる |
| マニフェストの検証 | リポジトリの直下で `claude plugin validate` を流すと、終了コード 0・誤り無し・警告は `plugin.json` の `version` の 1 件だけ | 警告の `path` の値は実装で流して確かめ、結合テストの期待値を合わせる |
| 既存機能への影響 | 旧名 `mindmap@mindmap` で入れた利用者は、マーケットプレイスとプラグインを登録し直す | `破壊的変更`。入れ直しは `要件.md` の `## 反映作業` |
