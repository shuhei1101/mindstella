# モックの tokens.css の参照先を plugins/mindstella/ の下へ直す

## 概要

`dev/mock/` のモックが tokens.css を読めるようにし、決めた時点の見本として開けるようにする。

## 背景

[Issue #57](https://github.com/shuhei1101/mindmap/issues/57) の要望。
[PR #41](https://github.com/shuhei1101/mindmap/pull/41)（[Issue #17](https://github.com/shuhei1101/mindmap/issues/17)）でプラグインを `plugins/mindstella/` へ移した後も、モックはリポジトリの直下の `skills/mindmap/preview/tokens.css` を参照しており、CSS を読めずに素の HTML で出る。
[PR #52](https://github.com/shuhei1101/mindmap/pull/52)（[Issue #6](https://github.com/shuhei1101/mindmap/issues/6)）のモックのレビューで、reviewer が対象外の逸脱として報告した。
