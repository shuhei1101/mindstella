# コメントのパネルをトップバーの下だけに出し、詳細パネルのコメントの入力欄をパネルの下端に固定する

## 概要

利用者が、コメントのパネルを開いたままトップバーを操作でき、資料の詳細パネルでスマホと PC のどちらの幅でもコメントの入力欄をパネルの 1 番下で使用できるようになる。

## 背景

[Issue #660](https://github.com/shuhei1101/mindstella/issues/660) の束。ユーザーが最優先で対応し、まとめて対応してよいと指示した 2 件（[指示](https://github.com/shuhei1101/mindstella/issues/654#issuecomment-7061198639)）を 1 つの作業 PR で対応する。

| Issue | 背景 |
| --- | --- |
| [#653](https://github.com/shuhei1101/mindstella/issues/653) | React の画面への移行（[#469](https://github.com/shuhei1101/mindstella/pull/469)）で、コメントの一覧のパネルが `fixed inset-y-0`、グレーアウトが `fixed inset-0` になり、画面の上端からトップバーまで覆う。画面設計『コメントの一覧』はグレーアウトを「トップバーとタブの帯の下から」と記載している |
| [#654](https://github.com/shuhei1101/mindstella/issues/654) | 詳細パネルのコメントの入力欄が、レビュー中のコメントの一覧とまとめて本文のスクロール領域の中で `sticky bottom-0` になっている。本文が短いと本文の直後に浮き、長いとレビュー中のコメントまで下に留まる。画面設計『詳細パネル』は入力欄を「パネルの下端に留め」、レビュー中のコメントを「関係する項目の後」と記載している |
