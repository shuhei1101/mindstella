## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ラベルとボタンの折り返し（#690） | 固定の文言のラベルとアイコンのボタンを縮めず折り返さない指定にし、長い値はタイトルの側で 1 行に省略する。レビュー中の書き込み・スレッドの一覧・スレッド・詳細パネルのヘッダーの各行を、長いタイトル・長い ID・幅 390px で確認する | 長い値の場面のストーリーを追加し、React のストーリーの結合テストでスクリーンショットを撮る |
| lint の除外（#691） | `eslint.config.js` で、git の管理外の `.venv`・`storybook-static` を検査しないようにする | `package.json` の `lint` を `eslint frontend/src` にして検査の対象を絞る |
| 戻る・進む（#148） | 一覧・ボード・表・検索から別の項目を開いたときも、詳細の履歴の末尾に追加して進むの側を切り捨てる。タブの切り替えは履歴に追加せず、URL のハッシュを置き換える（戻っても後ろのタブは今のまま）。詳細パネルの「前の項目へ戻る」「次の項目へ進む」は詳細の履歴の 1 つ前・後の項目を開き、間にある絞り込み・並べ替えの履歴は飛ばす。ブラウザの戻る・進むは今までどおり履歴を 1 つずつたどる | インターフェース定義『プレビューを開く』の制約「履歴」を書き換える。スクロールの位置の復元は #452 |
| 前後の項目（#364） | 一覧・表・ボードの画面が、絞り込み・並べ替え・ボードの列を適用して描いた項目の ID の並びを画面の状態として持ち、詳細パネル・詳細の全画面は並びの中の今の位置から前後を決める。並びの元の画面が無いときはボタンを出さない。押して開いた項目は #148 の履歴に追加する | 戻る・進む（← →）の左に並べ、名前は「一覧の前の項目」「一覧の次の項目」。キーは `k`（前）・`j`（次）で、表示の設定でまとめてオフにできる |
| 値の欄の ID のリンク（#688） | `ValueText` が描いた後に、本文と同じ `linkBody` を適用して、項目の ID・スレッドの ID をリンク・ツールチップ・用語のマーカーにする | 範囲は値の欄だけにする（[要件](./要件.mark.md)） |
| 作成日時・更新日時（#186） | 共通の表に作成日時・更新日時の列を追加して並べ替えられるようにし、カードに日時を出して、カードの画面に作成日時・更新日時の並べ替えの選択を追加する | 記録の `created`・`updated` をそのまま使用し、記録のスキーマは変えない。画面を開いた直後の並べ替えは、資料は更新日時の新しい順、ほかの種類は連番。日時は今年なら `MM/DD HH:mm`、今年でなければ `YYYY/MM/DD HH:mm` で出す |
| スレッドの見出し（#372） | 書き込みの並びが一番上のときはタイトルを全文出し、スクロールしたら 1 行にして末尾を「…」にする（Issue の案 A）。戻る・状態の切り替えの行は留め、高さの変化で書き込みの位置がずれないようにする | タイトルの行数を増やしたストーリーとスクリーンショットで高さを確認する |
| スレッドを開いたとき（#374） | 開いたら書き込みの並びを最新の書き込みまでスクロールしてフォーカスし、最新以外の送信済みの長い書き込みを部品『本文の折りたたみ』で折りたたむ | 部品『本文の折りたたみ』の使用先にスレッドの送信済みの書き込みを加える |
| アクセシビリティ | 前後の項目のボタンに名前と押せない状態を持たせ、キーで操作できるようにする。キーは入力欄の中と IME の入力中は無効にする | 規約『キーボード操作』の共通のキーの割り当てに合わせる |
| 既存機能への影響 | 戻る・進むの履歴の追加の仕方が変わるため、詳細の中のリンク・関係する項目から開く既存の動きを結合テストで確認する | - |
