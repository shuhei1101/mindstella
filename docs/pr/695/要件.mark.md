推奨: B

テスト実行方法の lint の層は `frontend/src/` を検査すると定めており、対象を絞れば worktree に配置されるフォルダの種類によらず同じ結果になる。

項目の ID をリンクにする範囲（#688）: 詳細パネル・詳細の全画面の値の欄（`ValueText` で描く欄）だけにする。押すと詳細を開く一覧の行・カードの中にリンクを入れると操作が重なるため、タイトル・一覧の行・ツールチップの中の ID はスコープ外にする（単一ユースケース『項目の詳細を読む』の『正常シナリオ（値の欄の項目の ID で移る）』）。

前後の項目へ移るキー（#364）: 規約『キーボード操作』（`ui-keyboard`）の共通の割り当ての `k`（前）・`j`（次）にする。同じ規約のとおり、表示の設定に「1 文字のショートカットを使用する」を追加してまとめてオフにできるようにする（部品設計『表示の設定』）。
