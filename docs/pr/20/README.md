# 話し合いを記録しながら形にするスキルを、プラグイン mindmap の中に作る

## 概要

利用者が、Claude Code で抽象と具体を行き来する話し合いをしながら、決め事・派生する問い・調べものをワークスペースに記録し、ゴールまで進められるようにする。
プラグイン mindmap に、セットアップのスキルと話し合いを進めるスキルを同梱する。

## 背景

[Issue #4](https://github.com/shuhei1101/mindmap/issues/4) の要望。
[#9](https://github.com/shuhei1101/mindmap/pull/9) でマーケットプレイスとプラグインの枠を、[#11](https://github.com/shuhei1101/mindmap/pull/11) でワークスペースの YAML のスキーマとスクリプトのコマンドを作った。
この PR は、そのコマンドを呼んで会話を記録するスキルの手順を作る。
[#10](https://github.com/shuhei1101/mindmap/issues/10)・[#16](https://github.com/shuhei1101/mindmap/issues/16) の扱いの判断で、成果物の格下げ・起動の振り分け・スキルの分割・外部ライブラリの設計書がこの Issue へ移った。
