# 「レビューに追加」の後に入力欄へフォーカスを戻すかを設定で選べるようにし、スマホでは戻さないことを既定にする

## 概要

利用者が、「レビューに追加」の後に入力欄へフォーカスを戻すかを設定で選べ、スマホではソフトウェアキーボードに隠されずに、追加した後の資料を参照できるようになる。

## 背景

[Issue #534](https://github.com/shuhei1101/mindstella/issues/534) の要望。
詳細パネルのコメントの入力欄で「レビューに追加」を押すと、追加の後もフォーカスが入力欄にある。
スマホでは入力欄にフォーカスがあるとソフトウェアキーボードが開いたままになり、追加した後に参照したい資料が隠れる。
今の画面は追加の後に入力欄へフォーカスを戻し、React の画面は入力欄にフォーカスが残る。音声入力の確定の後は、どちらの画面も入力欄へフォーカスを戻す。
