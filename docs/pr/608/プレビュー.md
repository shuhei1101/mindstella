## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 溜めた後のフォーカス | コメントの入力・返信の入力で溜めた後（「レビューに追加」・Ctrl+Enter・音声入力の確定）に、設定が戻すなら入力欄へ、戻さないなら入力欄以外の要素へフォーカスを移す | 戻さないときの移動先は、押した「レビューに追加」のボタン（[確認ログ](./確認ログ.yaml)） |
| 設定の値 | 表示の設定に 1 項目を加え、個人の上書きとして端末の保存領域に持つ。サーバーへは送信しない | 値は「自動・入力欄へ戻す・戻さない」の 3 つ。項目名と置き場所は [要件](./要件.md) |
| 既定 | 上書きが無いときは、`pointer: coarse` に該当する端末では戻さない、それ以外は戻す | - |
| 既定に戻す | 表示の設定の「既定に戻す」の対象に含め、「ワークスペースの既定にする」の対象には含めない | 要件.yaml のスコープ外 |
| 失敗したとき | 溜められなかったとき・空白だけのときは、今と同じく入力欄へフォーカスを戻す | 修正する内容が入力欄にあるため |
| アクセシビリティ | 戻さないときもフォーカスを `body` に落とさず、溜めた結果は今と同じく読み上げる | - |
| 画面の対象 | 今の画面と React の画面を同じ振る舞いにする | - |
| 利用者向けの使い方 | 公開ドキュメント『プレビューを見る』の表示の設定とコメントのセクションを合わせる | 要件.yaml の更新ドキュメント |
