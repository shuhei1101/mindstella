# 要件

## 要望

幅 720px 以下でも、詳細パネルと詳細の全画面のレビュー中のコメントの「修正」「削除」を、その行の右上（行の右上の隅から 24px 以内）に出す。
詳細パネルの見出しの右の「次の項目」「全画面」などのボタンに重ねない。

コメントの一覧（レビュー中の書き込み・スレッドの画面）の行の「修正」「削除」の置き方は、幅 720px 以下でも今のまま変えない。

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `style.css` の `@media (max-width: 720px)` の `.row-actions { position: absolute; top: 10px; right: 10px; }` | [1f7e8d61](https://github.com/shuhei1101/mindstella/commit/1f7e8d61)（`プレビューのコメントをレビュー中に溜めて選んで送り、選んだ箇所へコメントできるようにする (#78)`） | 狭い幅のコメントの一覧で、行の余白を詰めて「修正」「削除」を行の右上に重ねる。当時 `.row-actions` はコメントの一覧の行だけにあった | 1 回 | 当たる範囲をコメントの一覧の行に絞る直し方は、この目的を壊さない |
| `style.css` の `.review-list .row-actions` | [2596b6f7](https://github.com/shuhei1101/mindstella/commit/2596b6f7)（`詳細パネルのレビュー中のコメントから、コメントを直す・消すことができるようにする (#190)`） | 詳細パネルの行に同じ `reviewRowActions` を置き、行の 2 列目に並べた。狭い幅の規則が当たることは扱っていない | 1 回 | 詳細パネルの行の 2 列目の置き方は変えない |
| `style.css` の `.post.pending .row-actions { position: static; }` | [6bf9d54a](https://github.com/shuhei1101/mindstella/commit/6bf9d54a)（`コメントをスレッドにし、AI が返信・質問でき、オープン・クローズと要約を持てるようにする (#235)`） | スレッドの中のレビュー中の書き込みで、狭い幅の規則を打ち消して書き込みの頭の中に置く | 1 回 | 同じ規則の当たりすぎを、置き場所ごとに打ち消している。規則の当たる範囲を絞れば、この打ち消しは要らなくなる |
