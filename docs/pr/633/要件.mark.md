### #188 の要件

- 全ての種類の項目（資料・検討事項など）が確認済みかどうかを持ち、既定は未確認にする。確認済みを持たない既存のワークスペースは、全ての項目を未確認として扱う
- 利用者が画面の操作で、項目を確認済みにし、確認済みを解除できる。項目を開いただけでは確認済みにしない
- 利用者が画面で編集して保存した変更以外（MindStella のセッション・通常の Claude Code のセッション・エディタでの直接の編集）で項目が変わったら、その項目を未確認に戻す。エディタでの直接の編集を含む点は要望の「AI が書き換えたら」より広く、ユーザーの確認で決定した（確認ログ）
- 項目へコメントを送信したら、その項目を確認済みにする。設定でオン・オフでき、既定はオン
- 確認済みは変更履歴の 1 件ごとではなく項目に対して持つ

確認済みは `history.yaml` の項目の行に `items.{ID}.confirmed` として持ち、コメントの送信で確認済みにするかの設定はワークスペースの設定 `config.yaml` に `confirm_on_comment`（既定 `true`）として持つ（確認ログで決定）

確認済みのマーカーは、詳細パネルの見出しの種類と ID の後・「編集する」の前に「確認済み」のボタンとして配置し、チェックと色で状態を示す（幅 480px 以下はアイコンだけ。確認ログで決定）
