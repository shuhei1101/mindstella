## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 確認済みのマーカー（#188） | React の詳細パネルの見出しの、種類と ID の後・「編集する」の前に、共通コンポーネント `ConfirmedToggle`（文言は「確認済み」、チェックと色で状態を示す）を配置する。書き込みの間は押せず、失敗したら元に戻して見出しの下に `role="alert"` で通知する（React の画面にトーストの仕組みが無いため） | モックはストーリー `Shared/ConfirmedToggle`。記録の表の列は #158 で扱う（確認ログで決定） |
| 設定の切り替え（#188） | React の設定の画面に、コメントの送信で確認済みにするかの切り替えを追加する（既定はオン） | 配置先はサーバーのデータ設計に合わせる |
| 書き込みの本文の折り返し（#619） | 再現の条件を特定し、送信済みの書き込みと並べるリストの幅をパネルの幅に収める。表・コードブロックは要素の中だけ横にスクロールする | 画面設計『スレッド』に記載し、結合テストを追加する。再現の条件はパネルの幅より広い表かコードブロックを含む書き込みで、幅によらない。書き込みの本文は `table: false` で描くため表がスクロールの入れ物を持たず、並び（`ol`）と書き込み（`article`）がグリッドで `min-w-0` を持たないため、表の幅まで書き込み全体が広がる |
| 詳細パネルの最も狭い幅（#625） | 幅 320px で見出しのボタンが表示幅に収まるように、今の画面の詳細パネルの見出しを修正する | テストの期待が誤っていた場合はテストを修正する。幅 320px で見出しの要素（戻る・種類と ID 77px・編集する・コメントの一覧・戻る・進む・全画面表示と 8px の間隔 9 つ・左右の余白 30px）が約 370px になり、全画面表示がはみ出す。幅 480px 以下は種類の名前を常に隠し、間隔と左の余白を詰める |
