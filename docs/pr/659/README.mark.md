# 検討事項にまとめて回答でき AI が決めた検討事項を区別でき、絞り込みのプリセットを一覧の上に並べて押すだけで開けるようにする

## 概要

利用者が、推奨どおりでよい複数の検討事項を 1 回の操作で決め、AI が決めた検討事項を一覧で確認して変えたいものだけ変えられ、AI が作った絞り込みのプリセットを一覧の上から押すだけで開けるようになる。

## 背景

[Issue #658](https://github.com/shuhei1101/mindstella/issues/658) の束。現在の Sprint の未着手の 2 件を 1 つの作業 PR で対応する。

| Issue | 背景 |
| --- | --- |
| [#484](https://github.com/shuhei1101/mindstella/issues/484) | 検討事項への回答は検討事項ごとにスレッドを作って書き込むため、34 件の検討事項に回答するのに 36 件のスレッドを作った。推奨の案のある決定済みの検討事項の 86% は推奨どおりに決定している。AI が決めた検討事項と利用者が決めた検討事項を記録の上で区別できない。AI の側も検討事項ごとにスレッドを作成していた（TH-834。1 件の通知のスレッドにまとめる部分は単一ユースケース『AIがスレッドの作成』で入っている） |
| [#361](https://github.com/shuhei1101/mindstella/issues/361) | [#360](https://github.com/shuhei1101/mindstella/issues/360) で AI が絞り込みのプリセットを作り、記録の取得に該当する件数つきで載るようになったが、画面にはまだ並ばず、毎回タグで絞り込む手間が残っている |
