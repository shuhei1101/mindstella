### 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閲覧機能 | 項目を並べる画面（タスク・検討事項・記録の表・資料）の絞り込みのドロワーの先頭に、記録の取得のプリセットを並び順で並べる。プリセットが 0 件のときは並びを出さない | - |
| 閲覧機能 | プリセットを押すと、そのプリセットのタグの式でタグの条件を置き換える。状態・種類・文字など今のほかの条件は残す。プリセットのチップ・解除の操作は持たず、タグの条件を外して解除する | 今のタグの条件がプリセットと同じ式のとき、そのプリセットを選んだ表示にする |
| 閲覧機能 | タグの条件を、簡易（選択したタグのすべて・いずれか）か、詳細（プリセットと同じ式。条件の含む・含まない、束のすべて一致・いずれか一致・一致しない、3 レイヤーまでの入れ子）で指定する。簡易で表せない式は詳細の表示にする | 式の上限はプリセットのタグの式と同じ |
| 閲覧機能 | 該当する件数が 0 のプリセットに、ドロワーでマーカーを出す。押せるまま残す | 件数は、その画面の項目のうちプリセットの式に合う件数 |
| 状態表示 | 式で絞っている間は、絞り込みの条件のチップに式を文で出し、× で式ごと解除できる | - |
| 既存機能への影響 | タグの式を今の絞り込みの条件と同じく URL の search params とタブの保存領域に持ち、画面の切り替え・戻る・進むで戻る。簡易で表せる式は今の `f.tags`・`tagmatch` のまま持つ | 保持先は knowledge の判定フローチャート『画面の状態の保持先』で確認する |
