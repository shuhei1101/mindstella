### 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 一括操作 | 検討事項のボード・表で未決定の検討事項を複数選び、「推奨の案で決定」を 1 回押すと、選んだ検討事項をそれぞれ推奨の案に決める。推奨の案を持たない検討事項は選べない | 選ぶ操作の置き場所と文言はモック作成で決める |
| 一括操作 | 通知のスレッドの検討事項の表から、並んだ未決定の検討事項を選んで「推奨の案で決定」を押せる | 一覧と同じ書き込みの経路を使用する |
| 閲覧機能 | 検討事項に誰が決めたか（利用者・AI）を表示し、絞り込みのドロワーと表の列に「誰が決めたか」の条件を追加する。値「AI」で絞ると AI が決めた検討事項だけが並ぶ | 列の名前・値の文言はモック作成で決める |
| 状態表示 | まとめて決めている間は操作を受け付けず、決めた後は選択を解除して一覧を再描画する。書き込めなかった検討事項があれば、理由とともに残す | - |
| 既存機能への影響 | 詳細パネルで AI が決めた検討事項の案を変えられることは今の編集（保存待ち）のまま。変えた後は誰が決めたかが利用者になる | 個別に案を選ぶ操作は #363 |

### 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閲覧機能 | 項目を並べる画面（タスク・検討事項・記録の表・資料）の一覧の上に、記録の取得のプリセットを並び順で並べる。プリセットが 0 件のときは並びを出さない | 置き場所・形状はモック作成で決める |
| 閲覧機能 | プリセットを押すと、その画面の一覧をプリセットのタグの式で絞る。状態・種類・タグ・文字など今の絞り込みの条件は残し、プリセットの式と AND で組み合わせる。もう一度押すとプリセットを解除する | 選べるプリセットは同時に 1 つ |
| 閲覧機能 | 該当する件数が 0 のプリセットに、一覧でマーカーを出す。押せるまま残す | 件数は記録の取得の値を使用する |
| 状態表示 | 選んだプリセットを絞り込みの条件のチップに並べ、× で解除できる。絞り込みのボタンの件数に含める | - |
| 既存機能への影響 | 選んだプリセットを今の絞り込みの条件と同じく URL の search params とタブの保存領域に持ち、画面の切り替え・戻る・進むで戻る。記録の取得に無いプリセットの名前は除外する | 保持先は knowledge の判定フローチャート『画面の状態の保持先』で確認する |
