# React の設定の画面で、文字起こし後の挙動と用語集のプリセットを続けて選んでも、もう一方の値は最後に選んだものを保つ

## 概要

利用者が、React の設定の画面で文字起こし後の挙動と用語集のプリセットを続けて選んでも、先に選んだ値を失わずに保存待ちへ溜められるようになる。

## 背景

[Issue #502](https://github.com/shuhei1101/mindstella/issues/502) の報告。
React の設定の画面は、挙動とプリセットのもう一方の値を、保存された記録の `settings.transcription` から取っている。
挙動を選んだ直後（保存待ちの編集を読み直す前）にプリセットを選ぶと、記録の挙動の値で `transcription` が溜まり、選んだ挙動が上書きされる。
今の画面は、最後に選んだ値をローカルの変数に持って保っている。
[PR #500](https://github.com/shuhei1101/mindstella/pull/500) の結合テスト `test_transcription` が、負荷のある端末でまれに時間切れになって見つかった。
