# 要件

## 要望

React の設定の画面（`workspace-settings-screen.tsx` の「音声入力」のまとまり）で、文字起こし後の挙動と用語集のプリセットを次のとおりにする。

| 対象 | 要件 |
| --- | --- |
| 挙動を選んだとき | 溜める `transcription` の `preset` は、この画面で最後に選んだプリセット（まだ選んでいなければ記録の値）にする |
| プリセットを選んだとき | 溜める `transcription` の `action` は、この画面で最後に選んだ挙動（まだ選んでいなければ記録の値）にする |
| 確認 | 挙動を選んだ直後、保存待ちの編集を読み直す前にプリセットを選んでも、溜まる値が両方の最後の選択になる（今の画面の `transcriptionFields` と同じ振る舞い） |
