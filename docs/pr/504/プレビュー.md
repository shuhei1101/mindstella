## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 最後に選んだ値 | 挙動とプリセットの最後に選んだ値を画面の状態（`useRef` 等、描き直しで作り直さないもの）に持ち、選んだときに溜める `transcription` のもう一方の値をそこから取る。まだ選んでいなければ記録の `settings.transcription` の値を使う | 今の画面の `transcriptionFields` と同じ振る舞い |
| 画面設計 | 挙動・プリセットの説明の「今の `preset` / `action` を保ったオブジェクト」を、最後に選んだ値を保つ旨に改める | 今の画面の画面設計『設定の画面』（SCR-489-27）は実装が既に同じ振る舞いのため、同じ文言に揃える |
| 単体テスト | 「送信する」を選んだ直後にプリセットを選び、2 回目の `POST /api/edits` が `{action: send, preset: 一般}` になるケースを足す | - |
| バンドル | `frontend/` をビルドし、`preview/spa/` を作り直す | - |
