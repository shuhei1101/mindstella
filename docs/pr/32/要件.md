# 要件

## 要望

進め方ガイドの置き場所 `skills/mindmap/playbooks/` に、資料作りと壁打ちの 2 つの進め方ガイドを足す。

- `資料作り.md`: 最上位の軸の呼び名は `資料`
- `壁打ち.md`: 最上位の軸の呼び名は `テーマ`
- どちらも、既存のガイド（`システム開発.md`・`調査.md`）と同じ節（最上位の軸の呼び名・カテゴリーの分け方・フェーズと観点・必ず調べるもの・ゴールの候補・引き渡しの形）を同じ並びで持つ
- ゴールの候補は既定を 1 つ持ち、セットアップがたたき台に使えるようにする
- 進め方ガイドの一覧を載せているページ（スキルの README・セットアップの手順・公開ドキュメント・インターフェース定義）を 4 分野に揃える
