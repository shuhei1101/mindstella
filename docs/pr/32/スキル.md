## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 資料作りの進め方ガイド | `資料作り.md` を、最上位の軸の呼び名 `資料` で、既存のガイドと同じ 6 つの節を同じ並びで書く | フェーズの並びとゴールの候補はインターフェース定義設計で決める。観点・必ず調べるもの・成果物・引き渡しの形は実装で書き、ユーザーにはガイドの本文で確かめる |
| 壁打ちの進め方ガイド | `壁打ち.md` を、最上位の軸の呼び名 `テーマ` で、既存のガイドと同じ 6 つの節を同じ並びで書く | 同上 |
| ゴールの候補 | 各ガイドの `## ゴールの候補` に、既定（`（既定）` を付けた行）を 1 つ置く | セットアップがたたき台の推奨に使う |
| スキルの README | `## ユースケース（分野）` の表に、2 つのガイドへのリンクとゴールの例の行を足す | |
| セットアップの手順 | `### 分野を決める` の置き場所の分野の列挙を 4 分野にする | 当てはまらないときの扱いは変えない |
| インターフェース定義 | 話し合いの進行の共通の置き場所の制約を 4 分野にし、各ガイドが 6 つの節を持つことを制約に足す | |
| 結合テスト | `test_session.py` で、`playbooks/` に 4 分野のガイドがあり、各ガイドが 6 つの節の見出しを持つことを確かめる | |
| 既存機能への影響 | スクリプト・スキーマは変えない。`field` は自由な文字列で、分野の名前を列挙していない | |
