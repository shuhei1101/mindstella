# 進め方ガイドに、資料作りと壁打ちの 2 つの分野を足す

## 概要

利用者が、新しい話し合いを資料作りか壁打ちの分野で始め、その分野の進め方ガイドに沿ってゴールまで進められるようにする。

## 背景

[Issue #31](https://github.com/shuhei1101/mindmap/issues/31) の要望。
[#4](https://github.com/shuhei1101/mindmap/issues/4) は最上位の軸の呼び名を進め方ガイドが決めるとし、資料作り（資料）と壁打ち（テーマ）の呼び名も挙げていた。
[#20](https://github.com/shuhei1101/mindmap/pull/20) はシステム開発と調査の 2 つの進め方ガイドだけを作り、資料作り・壁打ちはスコープ外に切り出した。
