# 要件

## 要望

結合テスト `test_body_alias_tooltip_pinned`（`tests/integration/preview/test_detail_panel_screen.py`）で、押して残したツールチップを出したままの間の操作を、ツールチップに覆われない位置で行う。
あわせて、決まった時間の待ち（`wait_for_timeout`）を条件での待ちに置き換える。

<!-- table: data -->

| 操作 | 今 | 修正 |
| --- | --- | --- |
| ほかの印に乗せても替わらないことの確認 | `page.hover(f"{PANEL_MARKS} >> nth=1")` で 2 つ目の印へ乗せる。ツールチップが印を覆うと、待ちの上限まで再試行して fail する | ツールチップの矩形と重ならない印を選び、その位置へポインターを動かす |
| 外を押して閉じることの確認 | `page.click("aside.panel .panel-kind")` で押す。ツールチップが押す先を覆うと（`subtree intercepts pointer events`）、待ちの上限まで再試行して fail する | ツールチップの矩形の外で、詳細パネルの中の座標を押す |
| 印から外しても閉じないことの確認の待ち | `page.wait_for_timeout(400)` | 印から外した時刻から、隠す待ち（`TIP_HIDE_DELAY_MS`）を過ぎたことを条件に待つ |
| ほかの印に乗せた後の待ち | `page.wait_for_timeout(300)` | ポインターが乗せた印の上にあることを条件に待つ |

<!-- /table -->

テストが確認する内容（押すと残る・印から外しても閉じない・ほかの印に乗せても替えない・Esc と外を押すと閉じる）は変えない。
製品コードは変えない。
完了の基準は、このテストを単独で 10 回続けて実行して全 pass し、負荷を掛けた状態（CPU を使い切る busy loop を並べる）で `test_detail_panel_screen.py` を実行して全 pass すること。
